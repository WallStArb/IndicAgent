# Archived superpowers plans

Implementation plans from July and September 2026 for the v2.x and v3.0-era `ic_engine`, ensemble and
counterfactual tracker. Each plan's todo is completed, and the code it targeted was shipped or has since been
deleted (`services/ic_engine.py` and `services/counterfactual_tracker.py` in phase 186, `scripts/analysis/`
in 186-16). Kept for history only. The matching design specs stay in `docs/superpowers/specs/`, because
source files and migration 271 cite them by path.
