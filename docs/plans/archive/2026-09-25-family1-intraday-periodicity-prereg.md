# Pre-registration: family 1, cross-sectional intraday periodicity

Original: 2026-09-25 (registered after AGY review; evidence run 2026-09-25).
Archived 2026-10-31: voided-era prereg, results voided by the owner's 2026-10-30 data reset.

Hypothesis (Heston, Korajczyk and Sadka 2010): a stock's residual return in a given half-hour
slot predicts its same-slot residual return on following days (lags 1 to about 40), relative
to other names; mechanism is recurring institutional order splitting. Direction: continuation
in every same-slot member. 15m bars, 26 slots, S1 residual returns, market-on-open entry.

Verdict: EVIDENCE RECORDED, BOOK V1 REFUSED. Member detection stands (the E16 statistic is
biased toward zero for own-history members), book v1 was underpowered at IC 0.002. Later
exploration (iterations 1-4) located the effect at the two auction prints but no standalone
version cleared measured cost. Ledger row: docs/research/construction-verdict-ledger.md section 1.
