## Key Design Decisions (reference these when executing)

1. **`src/intelligence/llm_providers.py` is NOT rebuilt** — it's MOVED to `src/core/llm/providers.py`. Leave a re-export stub at the original path.

2. **`counter()` helper in `src/observability/metrics.py` does NOT support labels** — swarm metrics use `Counter`, `Gauge`, `Histogram` from `prometheus_client` directly (see 56-04 metrics.py).

3. **Narrative agent subscribes to `topic_intelligence_journal`** (not `topic_intelligence_record` — that function doesn't exist). The journal topic carries `BarIntelligenceRecord`.

4. **All stub agents return `AgentResult`** — the `SwarmAggregator` assembles `AlphaMultiplier`. Agents never build `AlphaMultiplier` themselves.

5. **`shadow_only=True` is the default** — no agent affects production until `alpha_promotion.py` segment analysis passes ρ ≥ 0.4, n ≥ 100, p < 0.05 per (symbol, tf, hmm_regime).

6. **`SwarmContextCache` TTL = 5 minutes** — returns None for stale entries. Caller sends to DLQ.

7. **Phase 57 = SkepticAgent** (first real swarm agent, built on this foundation).
