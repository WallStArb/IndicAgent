# Nightly process contract: judge only completed work, and one pull digest of last night

## What

Design today (verified in the unit files): the IBKR fetcher timer is clock-free (OnBootSec 15 min, OnUnitInactiveSec 15 min; the queue decides what runs, RuntimeMaxSec 18000); D7 fires at 06:00 UTC, the dividend writer at 06:30 UTC; D7 reads logs/ibkr_history_fetcher_status.json written at the end of each fetcher run. The fetcher timer is disabled until 189-10 Task 3; the Tradier timer is disabled until 185-48 deletes it.

Gaps a Renaissance review would close:

1. Judgment ordering is by clock, completion only through a status file. A D7 run while the update lane is mid-run, or after a partial run, must report the freshness and coverage checks as unjudged with the reason (run incomplete, run age), never as failures of the data. Verify that D7 does this and add a test; today it is unverified.
2. The nightly sequence is implicit across five units (fetcher, run-end derive, scrub, D7, dividend). Write it once as a documented contract with each stage's input marker and output marker (fetch run complete, daily stage complete, scrub fact, D7 verdict rows), so a missing stage is visible as a missing marker.
3. Alerts are deliberately off during UAT (owner), so nothing pushes. Add a pull surface instead: one digest file (logs/data_layer_daily.md or a Grafana panel) generated by D7 listing last night's fetch outcome, names stale, verdict failures by check, queue depth and the 5m drain position. One command answers "did last night work".
4. Lane budgets: the daily update lane keeps its pre-registered 120 minute bound (todo 505); the 5m drain gets its own lane and bound pre-registered from the 189-10 Task 2 pilot before the numbers are read. The gap-fill lane has its own per-run budget row.
5. Single-vendor risk (IBKR only for prices, D-01): the mitigation is detection, not a second vendor. freshness_1d plus the pull digest is the detection; confirm the weekly gateway auth gap (todo 395) shows up there.

## Done when

D7 reports unjudged, not failed, for an incomplete run (tested); the nightly contract is a section in docs/foundation; the digest exists and is generated by D7.
