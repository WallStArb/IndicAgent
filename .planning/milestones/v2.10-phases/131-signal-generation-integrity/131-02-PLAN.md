<objective>
Two targeted one-liner fixes that are fully independent of A4/A7 and can run in parallel with plan 131-01.

A6: Eliminate look-ahead bias in BOCPD changepoint volume check. The current `np.mean(vol[-20:])` includes the current bar's volume in the average used to evaluate whether the current bar is a spike — the bar evaluates itself against an average that includes itself. Fix: `np.mean(vol[-21:-1])` (prior 20 bars only, matching the SMA-20 pattern already used in the same function at line 285).

B7: _verify_replay in lifecycle_replay.py reports a total that is inflated by the LEFT JOIN to trade_frames + trade_executions. When one signal_event has multiple trade_frame rows (dual-track framing), each frame row multiplies the COUNT(*). Add COUNT(DISTINCT se.signal_id) as a separate output line so the absolute count is unambiguous.

Purpose: These are correctness fixes with zero risk of regressions. A6 is a 1-character change. B7 is additive (no existing query changed — new output line only). Neither fix requires A4/A7 confirmation.
