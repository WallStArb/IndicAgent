**Goal:** Add 6 columns to `production/migrations/137_3table_schema.sql` and apply them to the live DB before Phase 129 fills the tables with data.

## Columns Being Added

### signal_events (3 new columns)

| Column | Type | Purpose |
|--------|------|---------|
| `feature_ts` | `timestamptz` | Anchor to `intelligence_features` row that generated this signal. JOIN key: `intelligence_features WHERE ts = signal_events.feature_ts AND tf = signal_events.tf AND symbol = signal_events.symbol`. No FK (TimescaleDB hypertable constraint). Nullable — backfill signals may predate feature rows. |
| `concurrent_signal_count` | `int2` | Number of other signals in `active` status at fire time. Captures crowding — many concurrent signals indicates noisy regime. |
| `concurrent_plugins` | `text[]` | Array of `setup_plugin` values for all concurrent active signals at fire time. Structured for ML — queryable with `&& ARRAY['plugin_name']` operator. |

### trade_frames (1 new column)

| Column | Type | Purpose |
|--------|------|---------|
| `regime_at_activation` | `int2` | HMM regime code at the moment the entry condition triggered (e.g. pullback hit, reclaim confirmed). NULL for `at_close` entry type (fires immediately at bar close — regime_at_activation = hmm_regime_at_fire). Phase 130 TradeFrameWriter populates this. |

### trade_executions (1 new column)

| Column | Type | Purpose |
|--------|------|---------|
| `regime_at_exit` | `int2` | HMM regime code at the bar when the position was exited. Enables regime-transition analysis: "did regime flip before exit?" is a strong exit predictor. |

### signal_ledger_full view (add new columns to SELECT)

The view must expose all new columns so downstream consumers don't need to query base tables.

### New Column Obligations (Phase 130)

**SignalWriter / SignalAggregatorWriter** (populates `signal_events`):
- `feature_ts`: set to the `ts` of the `intelligence_features` bar that produced the signal's flat_features. Available from the bar's `IntelligenceEvent.ts` field.

**TradeExecutionWriter** (populates `trade_executions`):
- `regime_at_exit`: record `hmm_regime` from the bar when the exit event occurred (stop hit, target hit, TTL expired, manual close).
