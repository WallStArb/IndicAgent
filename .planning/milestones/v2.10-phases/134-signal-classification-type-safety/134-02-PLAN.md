<objective>
Create `EntryType(str, Enum)` and replace ALL string literals for entry type across `src/`.
Today `entry_type` is typed as `str` with a comment listing valid values — no enum, no DB
constraint, no enforcement. A typo writes silently and is undetectable until a query returns
0 rows. This plan follows the same pattern as `SignalOutcome(str, Enum)`: define once in
`signal_outcome.py`, use everywhere, enforce at the DB level with a CHECK constraint.

**Literal sweep completeness (resolves review finding #3, HIGH):** A repo-wide grep confirms
the literals are NOT confined to trade_framer.py + gap_analysis_setup.py + signal_schema.py.
There is also a bare fallback default in `src/intelligence/ai/narrative/narrative_prompts.py:75`
(`entry_type = (i7.entry_type if i7 else None) or "at_close"`). If that file is not edited, the
Plan 02 acceptance grep returns a non-empty result and the plan fails its own gate. The narrative
file is now in scope.
</objective>
