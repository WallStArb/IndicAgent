<objective>
W3: Make intelligence_pipeline shut down gracefully on SIGTERM. The `async for ... in self._kafka_consumer.messages()` loop blocks indefinitely inside poll() when Kafka is idle; setting `self.running = False` from the signal handler has no effect because the loop body never executes. The fix is to stop the consumer in the shutdown path so the async generator terminates, plus a belt-and-suspenders inner stop-check, plus an explicit systemd backstop.

Purpose: Eliminate SIGKILL on every restart (which risks Kafka offset skew and lost in-flight computations).
Output: 3a inner stop-check, 3b consumer-stop in shutdown hook, 3c TimeoutStopSec=90 in the unit file.
</objective>
