## Task 5: Recreate signal_ledger_full view to expose new columns

<read_first>
- production/migrations/137_3table_schema.sql (lines 197 onward — CREATE VIEW signal_ledger_full)
</read_first>

<action>
The signal_ledger_full view was created during Phase 128 UAT. It does not yet include the 5 new columns. DROP and recreate:

```bash
PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent -c "DROP VIEW IF EXISTS signal_ledger_shadow; DROP VIEW IF EXISTS signal_ledger_full;"

# Pipe only the view portion from migration 137 (from CREATE VIEW line onward)
PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent -c "
CREATE OR REPLACE VIEW signal_ledger_full AS
SELECT
    se.signal_id,
    se.ts,
    se.ts AS timestamp,
    se.symbol,
    se.tf,
    se.tf AS timeframe,
    se.setup_plugin,
    se.direction,
    se.raw_confidence,
    se.calibrated_confidence,
    se.cis_score,
    se.factor_scores,
    se.context_features,
    se.ctf_score,
    se.ctf_confirmed,
    se.zone_friction_score,
    se.hmm_regime_at_fire,
    se.plugin_regime_type,
    se.is_shadow,
    se.is_backfill,
    se.status,
    se.signal_schema_version,
    se.ttl_bars,
    se.expires_at,
    COALESCE(se.signal_computed_at, se.ts) AS signal_computed_at,
    se.signal_computed_at AS signal_computed_at_raw,
    se.feature_ts,
    se.concurrent_signal_count,
    se.concurrent_plugins,
    tf.frame_id,
    tf.entry_type,
    tf.entry_price,
    tf.stop_price,
    tf.target_price,
    tf.r_multiple,
    tf.counterfactual_pnl_r,
    tf.counterfactual_mfe,
    tf.counterfactual_mae,
    tf.counterfactual_exit_reason,
    tf.was_selected,
    tf.regime_at_activation,
    te.execution_id,
    te.actual_pnl_r,
    te.actual_fill_price,
    te.actual_exit_price,
    te.exit_reason,
    te.executed_at,
    te.exited_at,
    te.regime_at_exit
FROM signal_events se
LEFT JOIN trade_frames tf ON tf.signal_id = se.signal_id AND tf.signal_ts = se.ts
LEFT JOIN trade_executions te ON te.frame_id = tf.frame_id;"
```

Expected: `DROP VIEW`, `DROP VIEW`, `CREATE VIEW`
</action>

<acceptance_criteria>

- `SELECT COUNT(*) FROM signal_ledger_full;` returns 0 (empty — data migration not yet run)
</acceptance_criteria>
