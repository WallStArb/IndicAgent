**ASVS Level 1 Threat Model for AnchoredVWAPReversion Rewrite**

High severity threats:
1. **Look-ahead bias (CRITICAL):** If sigma buffer uses future values, signals contaminated. MITIGATION: sigma_buffer uses deque with maxlen=50, real-time appends only; departure_sigma captured at time of departure, not retroactively.
2. **State corruption (MEDIUM):** If _state not isolated per (symbol, tf), cross-symbol contamination. MITIGATION: _get_state() uses f"{symbol}_{tf}" key; factory lazy init.
3. **Wick-only leak (MEDIUM):** If reclaim check uses high/low instead of close, wick-only reclaims leak through. MITIGATION: Explicit close > session_vwap check; unit test verifies wick-only rejection.
4. **False departure (LOW):** If departure detection uses sigma_min threshold alone, noise triggers. MITIGATION: sigma_min from config (default 1.5); combined with return velocity requirement reduces false fires.
