<threat_model>
**ASVS Level 1 Threat Model for TrendFollowing Rewrite**

High severity threats:
1. **Look-ahead bias (CRITICAL):** If pullback detection uses future SMA values not available at bar time, signals are contaminated with look-ahead. MITIGATION: MA history buffer uses deque(maxlen=50) with real-time appends; pullback checks only current and historical values, never future.
2. **State corruption (MEDIUM):** If _state dict is not properly isolated per (symbol, tf), cross-symbol contamination causes false signals. MITIGATION: _get_state() uses f"{symbol}_{tf}" key, factory lazy init, PatternPlugin base class maintains state isolation.
3. **Infinite consolidation tracking (MEDIUM):** If consolidation bounds never reset, stale bounds cause false breakouts. MITIGATION: Reset on breakout detection or range expansion; consolidation_bars counter limits window.

Opt-out: None - structural rewrite is mandatory for QUALITY-01.
</threat_model>
