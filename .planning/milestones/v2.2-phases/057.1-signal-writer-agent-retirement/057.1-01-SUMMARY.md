# Phase 57.1 Plan 01: SignalWriterAgent Retirement Summary

**One-liner:** Retire `signal_generator_agent` and establish `SignalWriterAgent` as dedicated I7 signal persistence layer, fixing winner routing bug (`topic_intelligence` → `topic_signals_aggregated`) and adding `intelligence.i7.signals` Kafka topic for all-signals fan-out.

## What Was Built

1. **`topic_intelligence_i7_signals`** added to `src/core/stream_keys.py` — returns `<env>.intelligence.i7.signals`

2. **`_run_i7` pipeline modified** in `services/intelligence_pipeline_agent.py`:
   - Annotates every ranked signal with `composite_rank`, `num_signals_bar`, `was_selected`, `status`, `regime_type`, `hmm_regime_at_fire`, `is_shadow`
   - Publishes ALL ranked signals (including regime_suppressed) to `intelligence.i7.signals`
   - Fixes winner routing: `topic_intelligence` → `topic_signals_aggregated` (so signal_tracker_agent receives it)

3. **`SignalWriterAgent`** created at `services/signal_writer_agent.py`:
   - WriterAgent role: zero compute, DB-only
   - Consumes `intelligence.i7.signals` via `KafkaConsumerClient`, group `signal_writer_group`
   - `_payload_to_ledger_entries()` converts signal dicts to `LedgerEntry` with all Phase 57 attribution fields
   - `_flush()` batch-inserts via `SignalLedgerRepository.insert_signals()`
   - Metrics port 9119, Golden Signals instrumented
   - `BATCH_SIZE=100`, `FLUSH_INTERVAL_SECS=5.0`

4. **TDD**: 21 tests written (RED before implementation, all GREEN after)

5. **Systemd unit** installed: `indicagent-signal-writer` — `Active: active (running)`

6. **`signal_generator_agent` retired**: stopped, disabled, archived to `_archived_signal_generator_agent.py`

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] agent.run() → agent.start()**
- **Found during:** Task 5 (systemd service start)
- **Issue:** Design doc and plan used `asyncio.run(agent.run())` but `BaseAgent` only exposes `start()`, not `run()`
- **Fix:** Changed entry point to `asyncio.run(agent.start())`
- **Files modified:** `services/signal_writer_agent.py`
- **Commit:** fbaf2fa

**2. [Rule 1 - Bug] setup_service_logging path must include directory**
- **Found during:** Task 5 (log file at wrong path)
- **Issue:** `setup_service_logging("signal_writer_agent")` created log at project root as bare filename; should be `logs/signal_writer_agent.log`
- **Fix:** `setup_service_logging("logs/signal_writer_agent.log")`
- **Files modified:** `services/signal_writer_agent.py`
- **Commit:** 2829908

**3. [Rule 1 - Bug] PERSISTENCE_BATCH_LATENCY label name is `agent_id` not `agent`**
- **Found during:** Task 4 (implementation)
- **Issue:** Design doc used `.labels(agent="signal_writer_agent")` but `src/observability/metrics.py` defines `["agent_id"]` label
- **Fix:** Changed to `.labels(agent_id="signal_writer_agent")`
- **Files modified:** `services/signal_writer_agent.py`
- **Commit:** c8aab4e

**4. [Rule 1 - Bug] `agent.running = True` removed from test `__new__` pattern**
- **Found during:** Task 4 (TDD green phase)
- **Issue:** `BaseAgent.running` is a read-only `@property` — setting it raises `AttributeError`
- **Fix:** Removed `agent.running = True` from `_make_agent()` in test file
- **Files modified:** `tests/unit/service_tests/test_signal_writer_agent.py`
- **Commit:** c8aab4e
