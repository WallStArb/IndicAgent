  **Tests to add to tests/unit/test_plugin_validator.py:**

  Test setup pattern — use monkeypatch to inject a broken registry state rather than modifying real registry:

  ```python
  def test_fails_when_i7_plugin_missing_regime_type(monkeypatch):
      """validate_all() hard-crashes when I7 plugin lacks regime_type."""
      register_all_plugins()
      validator = PluginValidator()
      # Remove regime_type from one I7 plugin in the validator's registry view
      from src.intelligence.register_plugins import TIER_I7
      first_i7 = TIER_I7[0]
      plugin = validator.registry.patterns[first_i7]
      original = plugin.__class__.regime_type
      del plugin.__class__.regime_type
      try:
          with pytest.raises(RuntimeError, match="regime_type"):
              validator.validate_all()
      finally:
          plugin.__class__.regime_type = original
  ```

  Similarly for: invalid regime_type value, missing tier registration, TREND_SETUPS drift.

  **Constructor fixes in src/core/plugin_validator.py:**

  1. Fix logging call: change `setup_service_logging("plugin_validator")` to `setup_service_logging("logs/plugin_validator.log")` — per CLAUDE.md "setup_service_logging requires full log path".

  2. Fix Prometheus metrics: replace all direct `prometheus_client.Gauge(...)` / `prometheus_client.Counter(...)` instantiation with the `src/observability/metrics.py` `gauge()` / `counter()` factories.

     The labeled metrics (`plugin_validator_registered_plugins_total` with `["tier"]`, `plugin_validator_validation_status` with `["validation", "status"]`, `plugin_validator_validation_errors_total` with `["validation"]`) cannot use the bare `gauge()`/`counter()` helpers (which don't accept labelnames). Instead, define them as module-level constants at the top of `plugin_validator.py`, guarded by `try/except ValueError` — exactly like `metrics.py` does for `PLUGIN_EXECUTION_TOTAL` etc.:

     ```python
     # Module-level to prevent duplicate registration across test runs
     try:
         _REGISTERED_PLUGINS_GAUGE = PrometheusGauge(
             "plugin_validator_registered_plugins_total",
             "Total registered plugins per tier",
             ["tier"],
         )
     except ValueError:
         from prometheus_client import REGISTRY as _PR
         _REGISTERED_PLUGINS_GAUGE = next(  # type: ignore[assignment]
             c for c in _PR._collector_to_names
             if "plugin_validator_registered_plugins_total" in _PR._collector_to_names[c]
         )
     ```

     Then in `__init__`, just assign `self._registered_plugins_gauge = _REGISTERED_PLUGINS_GAUGE` (etc.) — no try/except in `__init__`.

  3. Remove `from src.core.service_utils import setup_service_logging` from the constructor — it should be a top-level import.
