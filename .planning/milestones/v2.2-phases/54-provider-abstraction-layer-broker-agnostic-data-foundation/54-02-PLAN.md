# Plan 54-02: IBKRAdapter + provider_meta Migration

## Objective

Create `IBKRAdapter` that wraps `IBKRProvider` and produces `BarMessage` directly. Migrate `provider_meta` from flat format to nested-by-broker format. The adapter encapsulates all IBKR-specific logic (5s RTB aggregation state machine) so `BaseProviderAgent` never sees IBKR details.

Purpose: The adapter is commodity wire-protocol translation. Swapping IBKR for another broker = one new adapter file. Everything downstream is untouched.

Output: IBKRAdapter implementing DataProviderAdapter, nested provider_meta in settings.

**1. `src/providers/ibkr_adapter.py`** — NEW file. Class `IBKRAdapter`:

- `provider_name: str = "ibkr"` — matches key in `provider_meta` lookups
- Constructor takes `host: str`, `port: int`, `client_id: int` (passed through to IBKRProvider)
- `connect()` — calls `self._provider.connect()`, returns bool
- `disconnect()` — calls `self._provider.disconnect()`
- `is_connected()` — delegates to `self._provider.is_connected()`
- `stream_bars(instruments)` — **MOVE the RTB aggregation state machine from `DataProviderAgent._rtb_loop()`**. This is ~200 lines of IBKR-specific 5s bar aggregation. Internally calls `self._provider.stream_real_time_bars()`. Yields completed 1m `BarMessage` with:
  - `source=SOURCE_IBKR_GENERIC`
  - UTC-aware `ts` (use `replace(tzinfo=UTC)` if IBKR returns naive, per CLAUDE.md rules)
  - `session_type` via `normalize_session_type()`
  - Also subscribes to `self._provider.stream_official_bars()` in background task for `is_reconciled`/`drift_detected` enrichment (same pattern as current DataProviderAgent)
- `fetch_historical(symbol, tf, start, end)` — calls `self._provider.fetch_historical_bars()`, converts each `OHLCVBar` to `BarMessage` with `source=SOURCE_IBKR_NAMED`
- `qualify_instrument(instrument)` — reads `instrument.provider_meta.get(self.provider_name, {})` (uses `self.provider_name` not hardcoded `"ibkr"`). Extracts `trading_class` and passes to provider qualification.

Import `SOURCE_IBKR_GENERIC`, `SOURCE_IBKR_NAMED` from `src.core.bar_normalizer`. Import `normalize_session_type` from `src.core.service_utils`.
