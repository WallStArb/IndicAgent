# Phase 053.1 Plan 02: BarAuditorAgent + DataProviderAgent Gap Loop Summary

**One-liner:** Self-healing gap detection loop wired end-to-end: BarAuditorAgent detects missing market_data_ohlcv bars using TradingSession expected counts, publishes BarGapRequest via Kafka, DataProviderAgent consumes and re-fetches from IBKR.

## What Was Built

### Task 1: BarAuditorAgent (`services/bar_auditor_agent.py`)

AuditorAgent that reads `market_data_ohlcv` and detects < 95% bar completeness per instrument/day:

- `_expected_bars_for_date(session, date)`: static method computing expected 1m bar count from TradingSession — handles crypto_24_7 (1440/day), fx_24_5 (1440 on trading days), futures_24_5 (1380 = 23h), nyse (390)
- `_detect_gaps(lookback_days=3)`: queries DB per (symbol, calendar_date), skips non-trading days, publishes BarGapRequest when completeness < 0.95
- `_run_audit()`: orchestrates detect + publish; catches all exceptions so loop continues on transient DB failures
- `_run()`: startup audit + `asyncio.wait_for(_stop_event.wait, timeout=300)` interruptible loop — only audits during market hours after startup
- Golden Signals via direct `prometheus_client`: `audits_run_total`, `gap_requests_published_total`, `audit_duration_seconds`, `audit_errors_total`, `canonical_completeness_pct{agent,symbol,tf}`
- `topics_consumed = []` (audit-loop-driven, no Kafka consumption — per D-10)
- `topics_produced = [topic_gap_requests(env)]`

### Schema finalization (`src/core/schemas/market_events.py`)

`BarGapRequest` upgraded from stub to full implementation:
- Added `request_id: str = Field(default_factory=lambda: str(uuid.uuid4()))` for DLQ traceability
- Added `source: str = "bar_auditor"` to identify producer

### Stream key (`src/core/stream_keys.py`)

Added `topic_gap_requests(env_name)` returning `{env}.market.events.gap_requests` — follows `topic_roll_events()` pattern.

### Task 2: DataProviderAgent._gap_requests_loop (`services/data_provider_agent.py`)

Added `_gap_requests_loop()` coroutine to DataProviderAgent:

- Creates `KafkaConsumerClient` for `topic_gap_requests`, group_id `"data_provider_consumer"`
- Parses `BarGapRequest.model_validate(payload)` — malformed payloads log error and continue
- Calls `self.provider.fetch_historical_bars(symbol, timeframe, start, end)` for each request
- Re-publishes each fetched bar to `topic_market_bars` with `source="ibkr_gap_fill"`
- Submitted ONCE before reconnect while-loop; NOT cancelled on IBKR disconnect; IS cancelled in `cleanup()`

## End-to-End Flow

```
BarAuditorAgent → topic_gap_requests → DataProviderAgent._gap_requests_loop
  → IBKR.fetch_historical_bars → topic_market_bars → BarWriterAgent → market_data_ohlcv
```
