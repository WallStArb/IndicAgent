**Create `services/bar_auditor_agent.py`:**

```python
#!/usr/bin/env python3
"""BarAuditorAgent — self-healing gap detection for market_data_ohlcv.

Reads market_data_ohlcv on startup + every 5 minutes during market hours.
Compares actual row counts vs expected counts derived from TradingSession.
Publishes BarGapRequest events to topic_gap_requests for DataProviderAgent
to consume and fetch from IBKR.

DB-aware (reads market_data_ohlcv). Not a ComputeAgent — an AuditorAgent.
Metrics port: :9123

Golden Signals (D-14):
- Traffic: audits_run_total, gap_requests_published_total
- Latency: audit_duration_seconds
- Errors: audit_errors_total
- Saturation: canonical_completeness_pct{symbol,tf} (gauge)
"""
```

- `self._db_pool: asyncpg.Pool | None = None`

**`_setup()`**: create asyncpg pool, create KafkaProducerClient, start both. Load instruments via `get_active_contracts()`.

**`_teardown()`**: stop producer, close pool.

**`_expected_bars_for_date(session: TradingSession, target_date: date) -> int`**:
- Compute expected 1m bar count for a specific date.
- For crypto_24_7 (`open_time == close_time` and 7-day trading_days): return 1440 if `target_date.weekday() in session.trading_days` else 0.
- For fx_24_5 (`open_time == close_time` and 6-day trading_days): return 1440 if `target_date.weekday() in session.trading_days` else 0.
- For futures_24_5 (overnight wrap, `open_time > close_time`): count total minutes from open_time to close_time spanning midnight, subtract trading_breaks. Return count if trading day, else 0. CME futures: 18:00 CST open to 17:00 CST close = 23 hours = 1380 minutes.
- For exchange sessions like nyse (same-day, `open_time < close_time`): minutes = (close_time - open_time).total_seconds() / 60, minus break minutes. Return count if `target_date.weekday() in session.trading_days` else 0. NYSE: 09:30–16:00 = 390 minutes.

**`_detect_gaps(lookback_days: int = 3) -> list[BarGapRequest]`**:
- For each instrument from `get_active_contracts()`:
  - Get `trading_session` from `instrument.trading_session`
  - For each of the last `lookback_days` dates:
    - Compute expected = `_expected_bars_for_date(session, date)`
    - If expected == 0, skip (non-trading day)
    - Query: `SELECT COUNT(*) FROM market_data_ohlcv WHERE symbol = $1 AND timeframe = '1m' AND timestamp >= $2 AND timestamp < $3` (date boundaries in UTC)
    - Compute completeness = actual / expected
    - Update `canonical_completeness_pct` gauge with completeness value
    - If completeness < `_COMPLETENESS_THRESHOLD`:
      - Create `BarGapRequest(symbol=instrument.symbol, tf="1m", start_ts=date_start_utc, end_ts=date_end_utc)`
      - Add to results

**`_run_audit() -> None`**:
- Record start time for `audit_duration_seconds` histogram.
- Call `_detect_gaps()`.
- For each `BarGapRequest`, publish to `topic_gap_requests(self._env_name)` via `self._kafka_producer.publish(topic, gap_req.model_dump(mode="json"), key=gap_req.symbol)`.
- Increment `gap_requests_published_total` per request. Increment `audits_run_total`.
- On exception: increment `audit_errors_total`, log error, do not re-raise (audit loop continues).

**`_any_session_open() -> bool`**:
- Check if any active instrument's trading session is currently open using `instrument.trading_session.is_open(datetime.now(UTC))`.

**`_run()`**: main loop — run audit on startup, then loop:
  1. `await self._run_audit()` (startup audit per D-12)
  2. `while self.running:` — sleep `_AUDIT_INTERVAL` seconds, check `_any_session_open()`, if open: `await self._run_audit()`.
  3. Use `asyncio.wait_for(self._stop_event.wait(), timeout=_AUDIT_INTERVAL)` pattern for interruptible sleep (don't use `asyncio.sleep` which ignores shutdown signal).

**`__main__` block**: `init_tracing("bar_auditor_agent")`, `asyncio.run(BarAuditorAgent().start())`

2. **Add `_gap_requests_loop()` coroutine** (after `_heartbeat_loop`, before `run()`):

```python
async def _gap_requests_loop(self) -> None:
    """Consume BarGapRequest events and re-fetch bars from IBKR.

    Per D-01a/D-01b: runs in self.loop alongside _rtb_loop, _official_bars_loop.
    Consumer group: data_provider_consumer.
    On receipt: parse BarGapRequest, call self.provider.fetch_historical_bars(),
    re-publish each bar to topic_market_bars with source="ibkr_gap_fill".

    IMPORTANT: This is a pure Kafka consumer loop — it has NO dependency on
    IBKR connection state. It is submitted ONCE in run() before the reconnect
    while-loop and is NOT cancelled/restarted on IBKR disconnect. The IBKR
    fetch inside the loop will naturally fail if IBKR is disconnected, and
    the per-message try/except handles that gracefully.
    """
    gap_consumer = KafkaConsumerClient(
        topic_gap_requests(self.env_name),
        bootstrap_servers=self.settings.kafka_bootstrap_servers,
        group_id="data_provider_consumer",
        auto_offset_reset="earliest",
    )
    await gap_consumer.start()
    self.logger.info("gap_requests_loop.started", topic=topic_gap_requests(self.env_name))

    try:
        async for _topic, _key, payload in gap_consumer.messages():
            if not self.running:
                break
            try:
                req = BarGapRequest.model_validate(payload)
                self.logger.info(
                    "gap_requests_loop.received",
                    request_id=req.request_id,
                    symbol=req.symbol,
                    tf=req.tf,
                    start_ts=req.start_ts.isoformat(),
                    end_ts=req.end_ts.isoformat(),
                )

                bars = await self.provider.fetch_historical_bars(
                    symbol=req.symbol,
                    timeframe=req.tf,
                    start=req.start_ts,
                    end=req.end_ts,
                )

                for bar in bars:
                    bar_data = {
                        "symbol": req.symbol,
                        "tf": req.tf,
                        "ts": bar.timestamp.isoformat(),
                        "open": bar.open,
                        "high": bar.high,
                        "low": bar.low,
                        "close": bar.close,
                        "volume": bar.volume,
                        "source": "ibkr_gap_fill",
                        "is_reconciled": True,
                        "drift_detected": False,
                        "is_flat_bar": False,
                    }
                    await self._kafka_producer.publish(
                        topic_market_bars(self.env_name),
                        bar_data,
                        key=message_key(req.symbol, req.tf),
                    )

                self.logger.info(
                    "gap_requests_loop.fulfilled",
                    request_id=req.request_id,
                    symbol=req.symbol,
                    bars_fetched=len(bars),
                )

            except Exception as exc:
                self.logger.error(
                    "gap_requests_loop.error",
                    error=str(exc),
                    payload_preview=str(payload)[:200],
                )
                # Continue consuming — don't crash the loop on a single failure

    finally:
        await gap_consumer.stop()
```
