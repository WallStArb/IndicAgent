  <action>
    Create `src/intelligence/trading/gap_analysis_setup.py` following the exact pattern of `mean_reversion.py`.

    Plugin name: `"trad_GapAnalysisSetup"`
    capability_tags: `frozenset({"trading", "gap"})`
    outputs: `frozenset({"signal_type", "direction", "bias", "gap_size_atr", "confidence", "entry_type", "entry_price", "stop_loss", "targets", "regime_context", "supporting_factors"})`
    min_lookback: 50
    supports_incremental: False
    inputs: `(InputSpec(symbol=".*", timeframe="1m", lookback=100),)`

    Parameters (class-level defaults):
    - `gap_min_atr: float = 0.3` — minimum gap size as ATR multiple to fire
    - `gap_continuation_atr: float = 1.0` — gap size threshold for continuation bias
    - `volume_confirm_ratio: float = 1.2` — last bar volume / mean(prior 20 bars volume) threshold for continuation
    - `stop_atr_fade: float = 1.0` — ATR multiplier for fade stop
    - `stop_atr_cont: float = 1.5` — ATR multiplier for continuation stop
    - `target_atr_cont: float = 2.0` — ATR multiplier for continuation target

    compute_full() logic:
    1. Guard: len(df) < min_lookback → return {}
    2. Extract: close = df["close"].to_numpy(), open_ = df["open"].to_numpy()
    3. Gap: gap_size = open_[-1] - close[-2]  (prior close vs current open — GAP-01)
    4. Direction: gap_size > 0 → direction=1 (bullish), gap_size < 0 → direction=-1 (bearish), ==0 → _no_signal()
    5. ATR: atr = features.get("atr_14", 0.0); if <= 0: fallback np.mean(high[-14:] - low[-14:]); if still <= 0: _no_signal()
    6. Gate: abs(gap_size) < gap_min_atr * atr → _no_signal()
    7. gap_size_atr = abs(gap_size) / atr
    8. Volume check: vol = df["volume"].to_numpy(); vol_ratio = vol[-1] / np.mean(vol[-21:-1]) if len enough; high_volume = vol_ratio >= volume_confirm_ratio (default True if not enough history)
    9. Bias (GAP-02): if gap_size_atr >= gap_continuation_atr AND high_volume → bias="continuation"; else → bias="fade"
    10. Entry (GAP-03):
        - fade: entry_type="at_limit", entry = close[-2] (gap fill level)
        - continuation: entry_type="at_pullback", entry = open_[-1] + (-direction * 0.25 * atr)  # pullback entry
    11. Stop (GAP-03):
        - fade long (direction=1): stop = open_[-1] - stop_atr_fade * atr
        - fade short (direction=-1): stop = open_[-1] + stop_atr_fade * atr
        - cont long: stop = open_[-1] - stop_atr_cont * atr
        - cont short: stop = open_[-1] + stop_atr_cont * atr
    12. Target (GAP-03):
        - fade: target = close[-2]  (gap fill)
        - cont long: target = open_[-1] + target_atr_cont * atr
        - cont short: target = open_[-1] - target_atr_cont * atr
    13. Confidence:
        - base = min(1.0, gap_size_atr / 2.0)  (larger gap = higher base confidence)
        - if high_volume: base += 0.15
        - confidence = round(min(0.95, max(0.05, base)), 4)
    14. signal_type: "gap_fade_long" | "gap_fade_short" | "gap_cont_long" | "gap_cont_short"
    15. supporting_factors: list of strings — e.g. ["large_gap", "volume_confirm", "fade_bias"]
    16. Return dict with all output fields.

    No tail-calling signal_schema.make_signal() — return raw dict like other I7 plugins (aggregator handles framing).

    Module-level: `plugin = GapAnalysisSetupPlugin()`
