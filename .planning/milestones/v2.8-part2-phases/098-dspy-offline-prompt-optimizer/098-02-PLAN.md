<objective>
Build the `DSPyOptimizer` core class — the compile-and-store path. This is the heart of OPT-01 (read labeled tuples, compile offline) and the write half of OPT-02 (store the compiled DSPy program state in prompt_versions). The class mirrors the `MLTrainer` batch-class pattern exactly: a `BaseDaemon` subclass with `_setup`/`_run`/`_teardown`, a per-agent data gate, and direct asyncpg DB access (MLTrainer is the established precedent for timer-triggered batch optimizers performing DB I/O).

CRITICAL FRAMING (REVIEWS Finding 6): `dspy.BootstrapFewShot` compiles few-shot DEMONSTRATIONS, not instruction text. It does not rewrite the prompt. The output of compilation is a DSPy compiled program state — a list of selected/synthesized few-shot demos plus program/signature metadata. All language in this plan, the code comments, and structlog events MUST say "compiled few-shot program state" (or "compiled program"), never "optimized prompt". The JSONB written to `prompt_versions.compiled_prompt` is the `program.save()` JSON: a dict whose `predict.demos` key holds the demos list.

CRITICAL agent_id KEY (REVIEWS Finding 1): `llm_calls.agent_id` stores each agent's class-level `agent_id` attribute, which for most agents equals the version string but for skeptic does NOT. Verified from source on 2026-06-03:
- correlation_agent.py: agent_id = "correlation_v1", ACTIVE_VERSION = "correlation_v1"
- skeptic_agent.py: agent_id = "skeptic", ACTIVE_VERSION = "skeptic_v2"   <-- MISMATCH
- counterfactual_agent.py: agent_id = "counterfactual_v1", ACTIVE_VERSION = "counterfactual_v1"
- regime_coherence_agent.py: agent_id = "regime_coherence_v1", ACTIVE_VERSION = "regime_coherence_v1"
- narrative_agent.py: agent_id = "narrative_v1", ACTIVE_VERSION = "narrative_v1"
AGENT_SIGNATURES MUST be keyed by the class-level agent_id (the string that appears in llm_calls). A separate `version_tag` field per entry holds the ACTIVE_VERSION for registry lookup. Querying llm_calls with `agent_id = 'skeptic_v2'` returns zero rows and silently passes the gate — this is the exact bug being fixed.

Purpose: Produce compiled few-shot program states per agent and persist them as `candidate` rows, with strict separation of concerns — this class never touches the live inference path (DAG Invariant 3).
Output: `src/intelligence/optimization/dspy_optimizer.py` (DSPyOptimizer class), `agent_signatures.py` (per-agent registry), `__init__.py`.
</objective>
