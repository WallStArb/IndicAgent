    **Task 1: CIS rel_volume + killzone wire-ins (cis_scorer.py)**

    In `_momentum(self, f, po)`, add rel_volume sub-term within the existing score expression.
    Use a 0.10 weight sourced from the other sub-terms (reduce existing weights proportionally
    to preserve total = 1.0, or add as supplemental — see CONTEXT.md: "additive sub-terms
    within existing bucket methods"). Recommended: make it supplemental (small weight, e.g. 0.05)
    so it doesn't dominate but still affects scoring:
    ```python
    rel_vol = self._fval(f, "rel_volume", default=1.0)
    vol_boost = 0.05 * clamp((rel_vol - 1.0) / 1.0)  # maps [0,2] → [-0.05, +0.05]
    ```

    In `_regime(self, f, po)`, add killzone sub-term:
    ```python
    in_kz = max(self._fval(f, "in_london_killzone"), self._fval(f, "in_ny_killzone"))
    kz_boost = 0.05 * (1.0 if in_kz > 0.5 else -0.2)  # active kz = slight boost, dead = slight suppress
    ```
    Both sub-terms are additive. Pass result through `clamp()` as before.

    Note: if plan 29-01 has already refactored bucket methods to return (float, dict), ensure
    these new sub-terms are also included in the contributions dict. If 29-01 is not complete,
    these methods still return float — this plan does not change the return type.

    **Task 2: Per-setup cooldown gate (signal_generator_service.py)**

    Add constant near `MIN_BARS_BETWEEN_SIGNALS` (line 68):
    ```python
    _SIGNAL_COOLDOWN_BARS: dict[str, int] = {"1m": 3, "5m": 2, "15m": 2, "1h": 2}
    ```

    Add to `__init__` near `_signal_gate`:
    ```python
    self._setup_cooldown: dict[tuple[str, str, str, int], int] = {}
    # keyed by (symbol, tf, setup_plugin, direction) — value is bars_until_eligible
    ```

    In the per-bar signal evaluation loop, before inserting a signal into `fired`:
    1. Decrement all cooldown counters for the current (symbol, tf) — iterate dict, decrement, remove when reaches 0
    2. Check: if cooldown[(symbol, tf, plugin, direction)] > 0 → skip this signal entirely (hard gate, QUAL-04 is dedup not soft decay)
    3. After a signal is accepted: set cooldown[(symbol, tf, plugin, direction)] = _SIGNAL_COOLDOWN_BARS[tf]

    CRITICAL per RESEARCH.md: QUAL-04 runs before QUAL-02 (alpha decay) — skip cooldown-blocked signals before they enter the alpha decay path.
