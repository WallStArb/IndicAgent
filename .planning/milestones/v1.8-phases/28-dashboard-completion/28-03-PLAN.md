  <action>
    Create `dashboard/src/components/signal-scorecard.tsx` as a client component.

    Suppression label mapping constant:
    ```typescript
    const SUPPRESSION_LABELS: Record<string, string> = {
      regime_prob: "< 60% conf",
      regime_duration: "< 5 bars",
      regime_type: "wrong regime",
    };
    function suppressionLabel(reason: string | null): string {
      if (!reason) return "";
      return SUPPRESSION_LABELS[reason] ?? reason;
    }
    ```

    Component signature:
    ```typescript
    export function SignalScorecard({ data }: { data: SignalScorecardData | undefined }) {}
    ```

    Render logic:
    - If `data` is undefined or `data.ranked.length === 0`: render empty state div with text
      "No signals this bar" in `var(--text-muted)` style, small text.
    - Otherwise:
      - Compute `firedCount = data.ranked.length`
      - Compute `suppressedCount = data.ranked.filter(r => !r.regime_eligible).length`
      - Compute `winner = data.ranked.find(r => r.is_winner)`
      - Render summary header: `{firedCount} fired · {suppressedCount} regime-gated · winner: {winner?.setup_type ?? "none"}`
        in small muted text below the section heading
      - For each signal in `data.ranked` (sorted by composite_rank ascending):
        - Rank badge: rank 1 (is_winner) = filled circle `●`, others = open circle `○`
          Color: winner = `var(--accent-cyan)` or green; others = muted
        - Plugin name: `signal.setup_type` — strip "trad_" / "ind_" / "smc_" prefix for display
        - Direction arrow: `direction > 0 ? "▲" : direction < 0 ? "▼" : "–"`
          color: long = `var(--green)`, short = `var(--red)`, neutral = muted
        - Confidence: `(signal.confidence * 100).toFixed(0)}%`
        - Eligibility: `signal.regime_eligible`
          - true: `✓` in green
          - false: `✗ {suppressionLabel(signal.suppression_reason)}` in #f59e0b (amber)
      - Layout: each row is a flex row with gap, text-xs or text-[0.7rem]
      - No cross-bar carry — this is the current bar's scorecard only

    Keep styling consistent with other drill panel sections (compact, dense, monospace numbers).
    Do NOT add animations or transitions.
