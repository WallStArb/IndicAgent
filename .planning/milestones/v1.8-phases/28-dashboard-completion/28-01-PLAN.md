IMPORTANT: "intelligence_i7" starts with "intelligence" — the existing check
`candidate.startswith("intelligence:")` will NOT match "intelligence_i7:" because
"intelligence_i7:" != "intelligence:..." but "intelligence_i7:".startswith("intelligence:")
is FALSE (colon mismatch). HOWEVER: the `known_domains` set does NOT include "intelligence_i7"
so it will be treated as an env-prefixed stream and `candidate` will be set to the
rest after the first colon split. Need to add "intelligence_i7" to known_domains
AND add the startswith check BEFORE the existing intelligence: check.

Payload format for intelligence_i7 stream:
  {"ts": "...", "symbol": "ES", "tf": "1m", "data": "[{...}, {...}]"}
  where data is a JSON-encoded string array of RankedSignal objects.
