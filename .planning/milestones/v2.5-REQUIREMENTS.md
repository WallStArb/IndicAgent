## v2.5 Requirements (Phases 69–82)

### Writer Agent Reliability (Phase 69)

- [x] Single consumer creation pattern across all 6 writers
- [x] 5/6 writers use base class `_run()` loop (feature_writer keeps custom loop)
- [x] Buffer overflow triggers critical alert + 0.5s backpressure at 80% threshold
- [x] 5 new Prometheus metrics per writer: flush_latency, commit_latency, parse_failures, flush_errors, commit_errors

### BaseAgent Infrastructure (Phase 71)

- [x] Settings singleton in BaseAgent — zero tribal knowledge for new agents
- [x] Auto `init_tracing()` in BaseAgent — no manual `__main__` calls
- [x] Default `_report_consumer_lag()` — 15 manual overrides removed

### Signal Transform Log (Phase 72)

- [x] `signal_transform_log` hypertable + `transform_graduation` table
- [x] TransformRecorder wired into all 9 transforms (6 math + 3 swarm)
- [x] GraduationComputeAgent + GraduationWriterAgent in shadow mode
- [x] Graduation gate: n>=50 samples, p<0.05, Pearson r>0

### AI/LLM Architecture (Phase 73)

- [x] `src/core/ai/`: BaseAIAgent, BaseGroupService, AIContext, AgentOutput, LLMProviderChain
- [x] Mandate-based agent groups in `src/intelligence/ai/`
- [x] 6 LLM chain fixes: rate limiter, guardrails, auto-audit, real token counts, cache key, budget observability
- [x] `signal_lineage` hypertable + LineageRecorder + LineageWriterAgent
- [x] `prompt_version` auto-injected into `llm_calls`

### Shadow Governance (Phase 75, delivered via 77)

### OTel Unification (Phase 77)
