## Executive Summary

The v1.0 milestone successfully delivered its core value proposition: a canonical typed intelligence bus (IntelligenceEvent), durable feature store (intelligence_features hypertable), historical data population, REST+SSE query API, live pipeline with all 8 services running under systemd, dashboard connected to all intelligence tiers (I1–I8), and a Composite Intelligence Score with 14 I7 plugins and adaptive weight learning framework.

**Gaps are of two types:**

1. **Planned gap-closure work (Phases 8–9):** Integration fixes (weight_updater trigger, backfill SQL, legacy table removal) and formal verification artifacts (VERIFICATION.md for Phases 03/05/06, DASH-07 sign-off). These are explicitly tracked in ROADMAP.md Phases 8–9 and assigned there by the previous v1.0 audit.

2. **Minor defects:** MACD field name mismatch silently degrades CIS momentum bucket; stochastic field names cause display miss in indicator panel. Neither is a blocker.

There are no missing core implementations that block production use.

### Critical Integration Issues

#### 1 — HIGH: CIS Learning Loop Has No Automated Trigger

`weight_updater.py::run_weight_update(db_manager)` is fully implemented (22 unit tests pass). Zero services or systemd timers call it. CIS score will use bootstrap weights indefinitely until manually invoked.

**Targeted by:** Phase 8 plan 08-01 (systemd timer)

#### 2 — MEDIUM: Backfill SQL Does Not Write CIS Columns

`_INSERT_SYNC_SQL` has 24 columns; migration 011 added 4 CIS columns. All backfill signal rows have permanent NULLs for `cis_score`, `bucket_scores`, `weights_version`, `signal_quality`. Weight_updater training query excludes all historical signals.

**Targeted by:** Phase 8 plan 08-02

#### 3 — MEDIUM: Legacy `intelligence` Table Write Active

`market_analysis_service.py` line 351 calls `_persist_intelligence()` on every processed bar. Writes to legacy `intelligence` table (superseded by `intelligence_features`). Error-swallowed; no crash but dead DB write.

**Targeted by:** Phase 8 plan 08-03

#### 4 — MEDIUM: Backfill Plugin Lists Stale

Historical `intelligence_features` rows lack: `kalman_*` fields (I4), DoubleTB/HeadShoulders/TriangleWedge (I5), `hmm_*`/`bsl_*`/`ssl_*` (SMC), and 7 I7 plugins. Historical training data is sparse vs live pipeline.

#### 5 — LOW: MACD Field Name Mismatch

`I1Indicators` declares `macd_hist_12_26_9`; MACD plugin outputs `macd_histogram_12_26_9`. CIS Scorer reads `None` for MACD momentum bucket input. HMM and dashboard unaffected.

#### 6 — LOW: Stochastic Dashboard Display Bug

Dashboard maps `stoch_k_14_3`/`stoch_d_14_3` (lines 407–408 of `use-market-stream.ts`) but indicator_service outputs `stoch_k`/`stoch_d`. Stochastics show as zero in indicator panel.
