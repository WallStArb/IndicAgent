    **OFI Plugin (`src/intelligence/indicators/ofi.py`):**

    Create `OFIPlugin` dataclass following OBVPlugin pattern:
    - `name = "ind_OFI"`
    - `outputs = frozenset({"ofi_ewma_5", "ofi_ewma_20", "ofi_divergence", "ofi_spike_z", "ofi_variant"})`
    - `min_lookback = 5`
    - `supports_incremental = True`
    - `capability_tags = frozenset({"volume", "microstructure"})`
    - `inputs = (InputSpec(symbol=".*", timeframe="1m", lookback=120),)`
    - `_state: dict = field(default_factory=dict)`
    - `_PROXY_EPSILON: float = 1e-9` (class-level constant)

    `compute_full(self, frames)`:
    1. Extract `df = frames.get("main")` and `tick_buf = frames.get("tick_buffer") or []`
    2. Guard: if df is None or len(df) < self.min_lookback, return {}
    3. If tick_buf is non-empty, compute raw_ofi via `_compute_tick_ofi(tick_buf)`, set variant="tick"
    4. If tick_buf is empty, compute raw_ofi via `_compute_proxy_ofi(df)`, set variant="proxy"
    5. Update `_state["ofi_history"]` (deque maxlen=100) with raw_ofi
    6. EWMA update: alpha5 = 2.0/(5+1), alpha20 = 2.0/(20+1)
       - `_state["ewma5"] = prev_ewma5 * (1-alpha5) + raw_ofi * alpha5` (init to raw_ofi if first call)
       - `_state["ewma20"] = prev_ewma20 * (1-alpha20) + raw_ofi * alpha20`
    7. Z-score: numpy array from ofi_history, if len >= 5: mean of all-but-last, std of all-but-last + 1e-9, spike_z = (raw_ofi - mean) / std; else spike_z = 0.0
    8. Divergence: compare sign of raw_ofi vs sign of (close[-1] - close[-2]). ofi_divergence = float(ofi_dir - price_dir) where each is +1/0/-1
    9. Store `_state["prev_close"] = float(df["close"].iloc[-1])`
    10. Return dict with all 5 output fields, rounded to 6 decimal places (4 for divergence/spike_z)

    `_compute_tick_ofi(self, tick_buf: list[dict]) -> float`:
    - Tick rule: iterate ticks, `price = float(tick.get("price", 0))`, `size = float(tick.get("size") or 0)`
    - If price > prev_price: buy_vol += size; if price < prev_price: sell_vol += size; equal: neutral
    - Return buy_vol - sell_vol

    `_compute_proxy_ofi(self, df: pd.DataFrame) -> float`:
    - Last row: `(close - low) / (high - low + PROXY_EPSILON) * volume`

    `compute_next` delegates to `compute_full` (same as OBV pattern).

    Create `CVDPlugin` dataclass following OBVPlugin pattern:
    - `name = "ind_CVD"`
    - `outputs = frozenset({"cvd", "cvd_slope_5bar", "cvd_divergence", "cvd_spike_z"})`
    - `min_lookback = 2`
    - `supports_incremental = True`

    `compute_full(self, frames)`:
    1. Extract df and tick_buf from frames
    2. Guard: if df is None or len(df) < self.min_lookback, return {}
    3. Session reset check: extract timestamp from df, convert to ET using `zoneinfo.ZoneInfo("America/New_York")`. If et_hour == 9 and et_minute >= 30 and et_date != _state.get("last_session_date"), reset `_state["cum_cvd"] = 0.0` and set `_state["last_session_date"] = et_date`
    4. Compute single-bar delta:
       - If tick_buf non-empty: use tick rule (same as OFI) to get buy_vol - sell_vol
       - If tick_buf empty: proxy = `(2*close - high - low) / (high - low + 1e-9) * volume` (bar proxy for buy/sell split)
    5. Accumulate: `_state["cum_cvd"] = _state.get("cum_cvd", 0.0) + bar_delta`
    6. Update `_state["cvd_history"]` (deque maxlen=100) with cum_cvd value
    7. cvd_slope_5bar: if len(cvd_history) >= 5, use `np.polyfit(np.arange(5), last_5, 1)[0]`; else 0.0
    8. cvd_divergence: compare sign of cvd_slope_5bar vs sign of price change over 5 bars. float, signed.
    9. cvd_spike_z: single-bar delta vs 100-bar rolling mean/std of single-bar deltas (separate deque: `_state["delta_history"]`). z-score formula same as OFI.
    10. Return dict with all 4 output fields

    `compute_next` delegates to `compute_full`.
