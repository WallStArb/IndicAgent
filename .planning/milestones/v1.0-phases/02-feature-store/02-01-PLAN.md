Create `production/migrations/010_signal_ledger_feature_cols.sql`:

```sql
-- Add feature linkage columns to signal_ledger
-- These are nullable — historical signals (before Phase 2) will have NULL feature_ts/feature_tf.
-- A signal with feature_ts IS NOT NULL can be JOINed to intelligence_features on (symbol, feature_ts, feature_tf).
ALTER TABLE signal_ledger
    ADD COLUMN IF NOT EXISTS feature_ts  TIMESTAMPTZ,
    ADD COLUMN IF NOT EXISTS feature_tf  TEXT;

-- Partial index — only covers rows that have feature linkage (post-Phase 2 signals)
CREATE INDEX IF NOT EXISTS idx_ledger_feature_ts
    ON signal_ledger (feature_ts)
    WHERE feature_ts IS NOT NULL;
```

CRITICAL: Both columns MUST be nullable (no NOT NULL constraint). signal_ledger already has rows from any prior backfill runs. Adding NOT NULL without a default would fail with "column contains null values".
