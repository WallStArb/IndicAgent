  <behavior>
Given: A Redis stream intelligence:ESH6:5m contains a message {"event": "<IntelligenceEvent JSON>"}
When: feature_writer_service processes it
Then: a row is inserted into intelligence_features with ts=event.ts, symbol=event.symbol, tf=event.tf, and all 7 JSONB columns populated from the event sub-models

Testable cases:
- _parse_intelligence_event(valid_fields) → IntelligenceEvent (not None)
- _parse_intelligence_event(empty_fields) → None
- _parse_intelligence_event(malformed_json_fields) → None (ack-and-skip, no crash)
- _event_to_insert_params(event) → 13-element tuple; element[0] is a datetime; elements[6:] are JSON strings (not dicts)
- _maybe_flush(force=True) with 3 buffered events calls execute_batch with 3 params
- _maybe_flush(force=False) with events older than FLUSH_INTERVAL_SECS calls execute_batch
- _maybe_flush(force=False) with events younger than FLUSH_INTERVAL_SECS does NOT call execute_batch
- graceful_shutdown sets shutdown_requested=True and flushes buffer
  </behavior>
  <implementation>
Clone the consumer group loop skeleton from signal_generator_service.py. Replace the I7 plugin pipeline body with buffer management + batch write. Key implementation rules:

**Consumer group name:** Fixed string `"feature_writer:persist"` — NOT `f"feature_writer_{int(time.time())}"`. This is intentional: the fixed name lets the service resume from the last acknowledged position on restart.

**_parse_intelligence_event:** Module-level pure function, identical pattern to signal_generator_service.py lines 73-85. Reads b"event" key, calls IntelligenceEvent.model_validate_json(), returns None on any failure.

**_event_to_insert_params:** Module-level pure function. Returns 13-element tuple matching _INSERT_FEATURE_SQL positional params ($1..$13). JSONB columns MUST be json.dumps(model.model_dump(exclude_none=True)) strings, NOT dicts — asyncpg does not auto-serialize. Use model.model_dump() for bar (no exclude_none — bar always has data). i1 also uses model.model_dump() (not exclude_none — I1 has many dynamic fields from extra="allow").

**_INSERT_FEATURE_SQL:**
```python
_INSERT_FEATURE_SQL = """
INSERT INTO intelligence_features (
    ts, symbol, tf, platform, source, schema_version,
    bar, i1, i3, i4, i5, smc, i6
) VALUES (
    $1, $2, $3, $4, $5, $6,
    $7::jsonb, $8::jsonb, $9::jsonb, $10::jsonb, $11::jsonb, $12::jsonb, $13::jsonb
)
ON CONFLICT (ts, symbol, tf) DO NOTHING
"""
```

**Buffer:** `self._buffer: list[tuple] = []` (flat list of param tuples, not keyed by symbol/tf). Flush when `len(self._buffer) >= BATCH_SIZE` OR `time.monotonic() - self._last_flush >= FLUSH_INTERVAL_SECS`. Constants: `BATCH_SIZE = 50`, `FLUSH_INTERVAL_SECS = 5.0`.

**Metrics port:** 9116 (signal_tracker_service already occupies 9115 — confirmed in config/signal_tracker_service.json and services/signal_tracker_service.py. feature_writer_service uses the next available port, 9116).

**Graceful shutdown:** Register SIGTERM and SIGINT handlers that set `self.shutdown_requested = True`. In the process loop, after the loop exits, call `await self._maybe_flush(force=True)` before closing connections.

**Config:** Load from config/feature_writer_service.json (create this file with symbols, timeframes, processing_interval matching market_analysis_service.json pattern). The service must run with `python services/feature_writer_service.py --config config/feature_writer_service.json`.

**Do NOT remove or modify `_persist_intelligence()` in market_analysis_service.py** — it writes to the legacy `intelligence` table. Leave it in place (additive design).
