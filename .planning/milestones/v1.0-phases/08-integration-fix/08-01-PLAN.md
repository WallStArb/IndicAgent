<objective>
Create systemd timer + service pair to automate the CIS adaptive weight learning loop. The weight_updater.py already has a __main__ entrypoint that runs run_weight_update() against the live DB. This plan wires it to run daily via systemd timer so the CIS learning loop activates automatically after 50+ resolved signals accumulate.

Purpose: Close the integration gap identified in v1.0 audit — run_weight_update() has no automated trigger; CIS adaptive learning is currently manual-only.
Output: indicagent-weight-updater.service + .timer installed in systemd, verified running.
</objective>

<tasks>

<task type="ops">
  <name>Task 1: Create service and timer unit files in production/systemd/</name>
  <files>
    production/systemd/indicagent-weight-updater.service
    production/systemd/indicagent-weight-updater.timer
  </files>
  <action>
    Create `production/systemd/` directory if it doesn't exist (ls production/ to verify).

    Create `production/systemd/indicagent-weight-updater.service`:

    ```ini
    [Unit]
    Description=IndicAgent CIS Weight Updater
    After=network-online.target
    Documentation=https://github.com/bg/indicagent

    [Service]
    Type=oneshot
    User=bg
    WorkingDirectory=/home/bg/dev/indicagent
    Environment=PYTHONPATH=/home/bg/dev/indicagent
    ExecStart=/home/bg/dev/indicagent/.venv/bin/python -m src.intelligence.weight_updater
    StandardOutput=journal
    StandardError=journal
    SyslogIdentifier=indicagent-weight-updater
    ```

    Create `production/systemd/indicagent-weight-updater.timer`:

    ```ini
    [Unit]
    Description=IndicAgent CIS Weight Updater — daily at 02:00
    Requires=indicagent-weight-updater.service

    [Timer]
    OnCalendar=*-*-* 02:00:00
    Persistent=true
    Unit=indicagent-weight-updater.service

    [Install]
    WantedBy=timers.target
    ```

    Note: `Persistent=true` means if the system was off at 02:00, the timer fires on next boot (catches up missed runs).
  </action>
  <verify>
    ls production/systemd/indicagent-weight-updater.service production/systemd/indicagent-weight-updater.timer
  </verify>
  <done>
    Both unit files exist in production/systemd/.
  </done>
</task>
