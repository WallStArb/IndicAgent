    New functions to add to production/scripts/historical_backfill.py:

    1. _INSERT_FEATURE_SYNC_SQL (module-level constant):
       - psycopg2 %s placeholder SQL (NOT asyncpg $N)
       - Columns: ts, symbol, tf, platform, source, schema_version, bar, i1, i3, i4, i5, smc, i6
       - 13 VALUES placeholders: %s, %s, %s, %s, %s, %s, %s::jsonb, %s::jsonb, %s::jsonb, %s::jsonb, %s::jsonb, %s::jsonb, %s::jsonb
       - ON CONFLICT (ts, symbol, tf) DO NOTHING

    2. _build_intelligence_event(bar, i1_features, intelligence, symbol, tf, ts) -> IntelligenceEvent | None:
       - Imports: from src.intelligence.schemas import IntelligenceEvent, OHLCVBar, I1Indicators, I3Structure, I4Context, I5Patterns, SMCContext, I6Confluence
       - Define inner helper: _pick(model_cls, src) = {k: v for k, v in src.items() if k in model_cls.model_fields}
       - Use _pick for I3–I6 (extra='forbid') but pass i1_features directly to I1Indicators (extra='allow')
       - bar keys are "open", "high", "low", "close", "volume"
       - source="backfill" always
       - Wrap entire function body in try/except Exception: return None — never crash the replay loop

    3. _event_to_sync_params(event: IntelligenceEvent) -> tuple:
       - Returns 13-element tuple in same column order as _INSERT_FEATURE_SYNC_SQL
       - JSONB columns serialized with json.dumps(model.model_dump()) for bar and i1
       - JSONB columns serialized with json.dumps(model.model_dump(exclude_none=True)) for i3, i4, i5, smc, i6
       - First element: event.ts (datetime object — psycopg2 handles natively)

    4. _insert_features_sync(conn, rows: list[tuple]) -> None:
       - Guard: if not rows: return
       - with conn.cursor() as cur: psycopg2.extras.execute_batch(cur, _INSERT_FEATURE_SYNC_SQL, rows)
       - conn.commit()

    5. Update _build_ledger_entries signature:
       - Add parameter: feature_ts: datetime | None = None, feature_tf: str | None = None
       - Pass these to LedgerEntry constructor (replacing the hardcoded None/None that was set in Phase 2)
       - Existing callers that don't pass feature_ts continue to get None (backward compatible)

    6. Update replay_symbol() inner loop (after running run_analysis_pipeline, before run_i7_and_persist):
       - Call: event = _build_intelligence_event(bar, i1_features, intelligence, symbol, tf, ts)
       - If event is not None: call _insert_features_sync(db_conn, [_event_to_sync_params(event)])
         - Set written_feature_ts = ts (will pass to ledger builder)
       - If event is None: written_feature_ts = None
       - Pass written_feature_ts to run_i7_and_persist (or pass directly to _build_ledger_entries within)
       - Adjust run_i7_and_persist to accept feature_ts parameter and pass it through to _build_ledger_entries

    NOTE on _insert_features_sync call site: For efficiency, batching per-bar is acceptable for the backfill (no latency requirement). Each bar writes one features row — single-element list is fine. For a clean interface, the function accepts list[tuple] to match _insert_signals_sync pattern.

    CRITICAL pitfalls to avoid (from 03-RESEARCH.md):
    - DO NOT use $N placeholders — use %s only (psycopg2, not asyncpg)
    - DO NOT pass unfiltered intelligence dict to I3-I6 models (extra='forbid' will raise)
    - DO NOT import from services/feature_writer_service.py — duplicate logic inline
    - DO NOT call run_analysis_pipeline twice — only call at existing call site in replay_symbol
