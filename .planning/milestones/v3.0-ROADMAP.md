## Overview

Replaced the binary hand-crafted I7 signal pipeline with an empirical IC-weighted alpha engine. Feature Factory computes 54 orthogonal OHLCV primitives into a typed `feature_vectors` hypertable. IC Engine measures Spearman predictive power per feature × symbol × TF × regime × lookahead with bootstrap CI and BH-FDR correction. Ensemble Builder derives Ledoit-Wolf covariance-optimized weights. Alpha Emitter publishes `alpha_events` in shadow mode via Kafka.

Jim Simons' core insight applied: discard everything that doesn't have demonstrated IC. Hand-crafted logic deciding when a feature combination constitutes an edge is replaced by empirical measurement, walk-forward validation, and ensemble weighting by IC Sharpe × orthogonality.

## Milestone Summary

### Key Accomplishments

1. **Feature Factory** — 54-feature typed `feature_vectors` hypertable (36 float columns, no JSONB) replaces `intelligence_features` as v3.0 training corpus. `FeatureFactory.compute()` and `compute_batch()` cover the live and backfill paths. I5/I6/I7 archived intact.
2. **IC Engine** — Vectorized Spearman IC per (feature, symbol, tf, regime, lookahead) with circular-block-bootstrap 95% CI, BH-FDR multiple-testing correction, 20K independent observation gate, and 3-fold walk-forward validation.
3. **Causal Pipeline** — Forward returns via LEAD() with no lookahead; HMM regime labeling via forward-filter alpha-pass (not Viterbi smoother); cross-asset series with date-indexed causal alignment.
4. **Ensemble Layer** — Ledoit-Wolf covariance shrinkage with LW cluster deflation, per-feature 20% weight cap, `effective_N = 1/sum(w²)` diversification metric, vectorized `X @ signed_weights` alpha matmul.
5. **Alpha Emission** — Direction-aware CI gate (`long: ci_lower > 0`, `short: ci_upper < 0`). Shadow Kafka emission to `alpha.events`. `alpha_events` TimescaleDB hypertable with composite PK `(event_id, bar_ts)`.
6. **Batch Path Correctness** — Causal cross-asset series (incremental O(D) replacing O(D×N)), unified Wilder RSI (`_wilder_rsi_series`), `compute_batch` owns external state injection (no post-injection patch), `MIN_WINDOW` derived from APR config.

### Key Decisions (load-bearing — do not re-derive)

- **HMM_RANDOM_STATE = 42** — module-level constant in `regime_writer.py`; changing it invalidates all `feature_ic_scores` and requires full re-run
- **Pooled IC (is_pooled=true)** — diagnostic artifacts only; Phase 139 and all downstream reads exclusively use `WHERE is_pooled = false`
- **IC Sharpe gate** — `sharpe_window_size = 2000` raw bars; gate is `n_raw_bars >= 20,000` (not n_independent); stride divides inside `_compute_ic_rolling_metrics`
- **regime_label_source DEFAULT** — `'forward_filter'` (not `'filtered'`) in both `forward_returns` and `feature_ic_scores`
- **Gradient column naming** — `return_fast/mid/slow/extended`; `momentum_z_fast/mid/slow`; `volatility_rank_z` (tunable via APR, not hardcoded)
- **alpha_events table** — created in Phase 139 P1 migration 168 (not Phase 138)
- **1d non-pooled rows** — expected empty below 20K IC Sharpe gate per symbol at 4-symbol scale; 58-symbol full corpus fills these
- **BaseBatch pattern** — all AlphaEngine batch nodes extend `src/core/agent/base_batch.py` (D-06, OTel, pool lifecycle)
