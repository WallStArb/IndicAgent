# Current implementation (score method, lines 100-159)

The score() method computes bucket scores individually:
```python
bucket_scores: dict[str, float] = {
    "trend": self._trend(features),
    "momentum": self._momentum(features, plugin_outputs),
    "structure": self._structure(features, plugin_outputs),
    "pattern": self._pattern(features, plugin_outputs),
    "institutional": self._institutional(features, plugin_outputs),
    "regime": self._regime(features, plugin_outputs),
}

cis_raw = sum(self._weights[b] * bucket_scores[b] for b in BUCKET_NAMES)
cis_score = clamp(cis_raw)
```

# Vectorization opportunity

1. Bucket score computation can use numpy arrays for weighted sums
2. Agreement counting (lines 141-146) can be vectorized:
   ```python
   cis_sign = 1.0 if cis_score >= 0 else -1.0
   agreeing = sum(
       1 for b in BUCKET_NAMES
       if bucket_scores[b] * cis_sign > BUCKET_NOISE_FLOOR
   )
   ```
   Becomes:
   ```python
   import numpy as np
   bucket_array = np.array([bucket_scores[b] for b in BUCKET_NAMES])
   agreeing = int(np.sum(bucket_array * cis_sign > BUCKET_NOISE_FLOOR))
   ```

3. CIS aggregation can be vectorized:
   ```python
   weights_array = np.array([self._weights[b] for b in BUCKET_NAMES])
   scores_array = np.array([bucket_scores[b] for b in BUCKET_NAMES])
   cis_raw = float(np.dot(weights_array, scores_array))
   ```

# Constraints

1. Maintain exact numerical equivalence — no precision drift from vectorization
2. Keep bucket methods (_trend, _momentum, etc.) as-is for readability
3. Only vectorize the aggregation layer (score method)
4. Add import numpy as np at module level
