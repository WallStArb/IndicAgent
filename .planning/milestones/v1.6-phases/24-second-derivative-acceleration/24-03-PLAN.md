ExhaustionScore logic:
```
Bull conditions: rsi_14 > 70 AND rsi_curvature < 0 AND macd_hist_slope < 0
Bear conditions: rsi_14 < 30 AND rsi_curvature > 0 AND macd_hist_slope > 0
Score tiers: 3/3 → 1.0, 2/3 → 0.6, 1/3 → 0.2, 0/3 → 0.0
exhaustion_side: "bull" if bull_count > 0, "bear" if bear_count > 0, "none" otherwise
exhaustion_bars: _state counter — increment when any exhaustion holds, reset to 0 when score == 0.0
NOTE: exhaustion_bars stored in _state, NOT read from features accumulator
NOTE: return defaults even when no exhaustion (score=0.0, side="none", bars=0.0)
```

AccelerationRegime logic:
```
Sign-vote each input (+1 if positive, -1 if negative, 0 if zero/unavailable):
  vote_rsi = +1 if rsi_curvature > 0 else (-1 if rsi_curvature < 0 else 0)
  vote_macd = +1 if macd_hist_slope > 0 else (-1 if macd_hist_slope < 0 else 0)
  vote_price = +1 if price_accel > 0 else (-1 if price_accel < 0 else 0)
accel_score = (vote_rsi + vote_macd + vote_price) / 3.0  # range: -1.0 to +1.0
accel_agreement = abs(vote_rsi + vote_macd + vote_price) / 3.0  # range: 0.0 to 1.0

Regime (evaluated in ORDER):
  "building" if accel_score > 0.5
  "peak" if prev_accel_score > 0.3 AND accel_score <= 0.3   (inflection, single-bar)
  "trough" if prev_accel_score < -0.3 AND accel_score >= -0.3  (inflection, single-bar)
  "waning" if accel_score < -0.3
  "neutral" otherwise

_state key: "prev_accel_score" — written each bar AFTER regime determination
```
