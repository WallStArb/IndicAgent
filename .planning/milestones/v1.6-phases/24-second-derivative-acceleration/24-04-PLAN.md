SwingMomentum algorithm:
```
# Peak/valley detection (self-contained, ±N=3 window):
Confirm swing high at bar i: df["high"][i] == max(df["high"][i-N:i+N+1])
Confirm swing low at bar i: df["low"][i] == min(df["low"][i-N:i+N+1])

_state["extremes"]: list of (price, bar_index, type) tuples — last 5 confirmed extremes
_state["bar_count"]: total bars processed (for bar_index tracking)
_state["last_extreme_bar"]: bar_index of most recent confirmed extreme

Warmup gate: len(extremes) < 6 → return {}

Amplitude computation (last 3 complete swings from 6 extremes):
  Each swing amplitude = abs(extreme[i].price - extreme[i+1].price) / (atr_14 if atr > 0 else 1.0)
  Get amplitudes for last 3 swing pairs from extremes[-6:]
  amplitude_ratio = amplitudes[-1] / (mean(amplitudes) + 1e-9)
  swing_amplitude_expanding = 1 if amplitudes[0] < amplitudes[1] < amplitudes[2] else 0

Velocity (bars per swing):
  swing_velocities = [bar_index diff between consecutive extremes] for last 3
  swing_velocity_bars = float(swing_velocities[-1])
  velocity_trend: if velocities[-1] < velocities[-2] → "accelerating"
                  elif velocities[-1] > velocities[-2] → "decelerating"
                  else → "stable"

struct_energy formula:
  reference_bars = 20  (typical bars per swing for 1m TF — tunable)
  speed_factor = clamp(reference_bars / max(swing_velocity_bars, 1), 0.1, 3.0)
  struct_energy = clamp(amplitude_ratio * speed_factor / 3.0, 0.0, 1.0)

struct_accel_bias:
  Look at last 2 swing highs and lows in extremes
  If highs making higher highs AND lows making higher lows → +1
  If highs making lower highs AND lows making lower lows → -1
  Else → 0
```
