Per Council review: enforce I6 presence, NOT a minimum factor count (cargo-cult, easily gamed). Output: base.py changes, validate_tier enforcement, TIER_I7 sweep test, pre-commit check 9, and requires_i6_confluence declarations on all existing I7 plugins.
</objective>
