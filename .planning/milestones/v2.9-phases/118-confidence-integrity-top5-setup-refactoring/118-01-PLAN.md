<objective>
Refactor trad_OFIContinuation to use a multi-factor intrinsic confidence formula and tighten its entry gates.

Purpose: The current confidence is `0.50 + abs(ofi_ewma_20) * 0.001` — a single-factor formula that fires on trivially small OFI values (abs(ofi_ewma_20) = 1.0 produces confidence 0.501). The plugin has 1.59M historical firings. Adding a magnitude floor gate (500) and raising the consecutive-bar minimum (10) eliminates noise signals. The 4-factor composite rewards magnitude, EWMA alignment, persistence, and volume conviction — all measured from the OFI pattern itself.

Note: Wave 0 already stripped ctf_score, hmm_regime_weight, and apply_exhaustion_guard from this file. This plan adds the intrinsic upgrade on the clean base.

Review-driven changes (REVIEWS.md): the `ofi_ewma_5` dependency must be verified against actual I1 output keys before writing the formula (Codex + Ollama MEDIUM), every factor must be clamped to [0,1] before the weighted sum (Codex LOW), and missing I1 inputs must use explicit is-None safe fallbacks (Gemini suggestion).

Output: ofi_continuation.py with magnitude gate, raised bar minimum, 4-factor clamped confidence with safe fallbacks; unit test covering all new logic including the missing-feature path.
</objective>

**Primary formula (use ONLY if `ofi_ewma_5` is confirmed emitted by I1):**
- `upper_ref = _OFI_MAG_UPPER_REF.get(symbol, _OFI_MAG_UPPER_REF_DEFAULT)`
- `magnitude_score = min(1.0, max(0.0, (abs(ofi_ewma_20) - mag_threshold) / max(1e-9, upper_ref - mag_threshold)))`
- EWMA alignment with safe fallback:
  - `ofi_ewma5 = features.get("ofi_ewma_5")`
  - `if ofi_ewma5 is not None: alignment_score = 1.0 if (float(ofi_ewma5) * ofi_ewma_20 > 0) else 0.3`
  - `else: alignment_score = 0.65`  (neutral fallback)
- `persistence_score = min(1.0, max(0.0, (count - _MIN_CONSECUTIVE_BARS) / 10.0))`
- Volume conviction with safe fallback:
  - `rel_vol = features.get("rel_volume")`
  - `rel_vol = float(rel_vol) if rel_vol is not None else 1.0`
  - `volume_score = min(1.0, max(0.0, (rel_vol - 1.0) / 1.5))`
- Weighted sum (all factors already clamped to [0,1]):
  - `raw_conf = 0.40 * magnitude_score + 0.25 * alignment_score + 0.20 * persistence_score + 0.15 * volume_score`

**Fallback formula (use if `ofi_ewma_5` is NOT emitted by I1):** drop alignment_score and redistribute its weight:
  - `raw_conf = 0.55 * magnitude_score + 0.20 * persistence_score + 0.25 * volume_score` (weights sum to 1.0)

In either branch, every factor must be wrapped in `min(1.0, max(0.0, ...))` BEFORE entering the weighted sum.

Pass raw_conf through `compose_confidence(raw_conf)` (already used in the file for final clamping to [0.0, 0.95]).
