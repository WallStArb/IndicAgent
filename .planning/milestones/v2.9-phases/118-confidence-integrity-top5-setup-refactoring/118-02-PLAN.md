<objective>
Refactor trad_PatternCompletion to fix the data flow bug, raise quality gates, restrict to trending regime, and replace the exhaustion-boosted single-factor confidence with a 4-factor intrinsic composite.

Purpose: PatternCompletion has 897K historical firings, most on marginal I5 confidence (above the low 0.50 threshold). The current formula multiplies I5 confidence by 0.9 then applies apply_exhaustion_boost — meaning exhaustion state (an extrinsic regime state) inflates confidence above the I5 detector's own score. The data flow bug means pattern fields (pattern_name, pattern_raw_confidence, pattern_count) are not persisted as structured numeric fields — they exist only in string supporting_factors, making them unavailable as ML features. Fixing the threshold (0.70), restricting to trending regime, and adding structured field persistence corrects all three problems.

Architectural clarification (Codex MEDIUM): `regime_type = "trend"` is an EXTRINSIC GATE consumed by the aggregator regime filter — it decides WHETHER the signal is eligible in the current regime. It is NOT a confidence modifier. Confidence remains purely intrinsic (pattern geometry only). This distinction matters: the phase invariant forbids extrinsic factors in CONFIDENCE, not extrinsic factors in ELIGIBILITY GATING. Document this explicitly in a code comment next to `regime_type = "trend"` so a future reader does not mistake the gate for confidence contamination.

Downstream note (Codex LOW): the three new structured fields (pattern_name, pattern_raw_confidence, pattern_count) land in the i7 JSONB bucket of `intelligence_features`. JSONB is schemaless — no migration is required to add keys. Verify (grep) that no downstream consumer asserts a fixed i7 key set that would reject extra keys; if such an assertion exists, note it in the SUMMARY for Phase 119/120 follow-up. Do not block this plan on it.

Note: PatternCompletion is NOT in Wave 0 scope (Wave 0 did not modify this file). The exhaustion_boost removal happens here. Also set requires_i6_confluence = True (removes the TODO).

Output: pattern_completion.py with threshold 0.70, regime_type "trend" (gate, commented), structured field persistence, 4-factor clamped intrinsic confidence, requires_i6_confluence=True, shadow_only=True; unit tests.
</objective>

- `raw_conf = 0.45 * pattern_score + 0.25 * strength_score + 0.20 * convergence_score + 0.10 * direction_purity`
