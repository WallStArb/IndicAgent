<objective>
Refactor trad_CVDDivergence to validate and raise the divergence threshold, increase the confirmation bar requirement, and replace the step-function confidence with a 4-factor intrinsic gradient formula.

Purpose: _CVD_DIV_THRESHOLD = 0.002 was set in Phase 117.5 to eliminate float noise (improved from 0.0). The target of 0.5 in the phase description requires a data distribution check first — a 250x jump without validation could filter all signals if the live distribution is below 0.1. The task runs a bounded DB query, sets the threshold to an empirically grounded value AND captures the p90 as an upper reference for magnitude normalization. _CONFIRMATION_BARS = 3 is low for a divergence signal. The current confidence is a step function (0.55 base + flat increments) — it does not reward larger divergences with proportionally higher confidence.

CRITICAL review fix (HIGH — all 3 reviewers, consensus item #1): the original plan's magnitude divisor `threshold * 125.0 + 2.5` is mathematically broken. At threshold=0.5 it produces ~65.0, compressing virtually all divergence values to near-zero confidence — a silent-failure defect. This plan REPLACES it with an empirical range: `div_mag_score = clamp01((abs(cvd_div) - threshold) / (upper_ref - threshold))` where `upper_ref` is the p90 value from the bounded distribution query. This guarantees 0.0 at threshold, 1.0 at p90, monotonically increasing in between — verified by a dedicated continuous-gradient test.

Additional review fixes: bound the DB query by date range and instrument set to avoid an expensive full scan (Codex LOW); guard `cvd_slope_5bar` with is-None fallback (Ollama MEDIUM); clamp every factor before weighting (Codex LOW).

Note: Wave 0 already stripped hmm_regime_weight and ctf_score from this file. This plan adds the intrinsic upgrade on the clean base.

Output: cvd_divergence.py with empirical threshold + _CVD_DIV_UPPER_REF, _CONFIRMATION_BARS=5, correct 4-factor gradient confidence, shadow_only=True; new unit tests including a continuous-gradient assertion.
</objective>

Replace with the 4-factor intrinsic gradient formula. The magnitude factor MUST use the empirical upper_ref divisor (this is the consensus HIGH fix — do NOT use `threshold * 125.0 + 2.5`):

- Factor 1 — divergence magnitude (CORRECTED):
  - `span = max(1e-9, _CVD_DIV_UPPER_REF - _CVD_DIV_THRESHOLD)`  (guard against zero division)
  - `div_mag_score = min(1.0, max(0.0, (abs(cvd_div) - _CVD_DIV_THRESHOLD) / span))`
  - This yields 0.0 at the threshold and 1.0 at upper_ref (p90), increasing continuously in between.
- Factor 2 — dual divergence: `dual_score = 1.0 if dual_divergence else 0.3`
- Factor 3 — persistence beyond minimum:
  - `extra_bars = max(0, count - _CONFIRMATION_BARS)`
  - `persistence_score = min(1.0, max(0.0, extra_bars / 5.0))`  (0.0 at bar 5, 1.0 at bar 10)
- Factor 4 — CVD slope alignment with is-None guard:
  - `cvd_slope_raw = features.get("cvd_slope_5bar")`
  - `if cvd_slope_raw is not None: slope_score = 1.0 if (float(cvd_slope_raw) * cvd_div > 0) else 0.2`
  - `else: slope_score = 0.5`  (neutral fallback when I1 omits the key)
- Weighted sum (all factors clamped to [0,1]):
  - `raw_conf = 0.40 * div_mag_score + 0.25 * dual_score + 0.20 * persistence_score + 0.15 * slope_score`

Pass raw_conf through `compose_confidence(raw_conf)`.
