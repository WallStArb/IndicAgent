<objective>
Refactor trad_GapAnalysisSetup to raise the minimum gap magnitude filter and replace the 2-factor confidence formula with a 4-factor intrinsic composite.

Purpose: The current min_gap_atr_mult = 0.3 fires on 0.3x ATR gaps — sub-threshold noise. With 331K historical firings, most are marginal. The current confidence is base (gap size / 2.0) plus a flat +0.15 if high volume — just 2 factors with no session timing or gap type weighting. The 4-factor intrinsic formula adds session timing (early-session gaps are more meaningful) and gap type quality (continuation vs fade), both measured from the gap pattern itself.

Review-driven changes (REVIEWS.md):
- The `vol_ratio` vs `volume_ratio` nomenclature mismatch (Gemini LOW, Ollama LOW) must be resolved by reading the actual variable name from the file before writing formula code. Same for `bias`.
- timing_score is intrinsic ONLY if gap timing is part of setup geometry; Codex MEDIUM warns it can penalize valid later-session gaps. Mitigation: timing_score floors at 0.2 (down-weight, never zero), so a late-session gap with strong geometry/volume still fires. Document this in a code comment.
- Every factor clamped to [0,1] before weighting (Codex LOW).

Note: Wave 0 already stripped apply_exhaustion_boost and hmm_regime_weight from this file. This plan adds the intrinsic upgrade on the clean base.

Output: gap_analysis_setup.py with min_gap_atr_mult=0.8, 4-factor clamped confidence, verified variable names, shadow_only=True; existing tests extended.
</objective>
