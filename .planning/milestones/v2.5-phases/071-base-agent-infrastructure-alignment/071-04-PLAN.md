<objective>
Default _report_consumer_lag() in BaseAgent — Eliminate Boilerplate

Implement Change 3 from design doc: BaseAgent provides a working default `_report_consumer_lag()` that emits `PERSISTENCE_CONSUMER_LAG` with the agent name. BaseWriterAgent overrides it to report buffer depth instead. Remove all 15 manual overrides.

Purpose: 15 agents override `_report_consumer_lag()` with near-identical code: import PERSISTENCE_CONSUMER_LAG, label with agent_id, set to 0, sleep 15. This is pure boilerplate. Worse, several agents create their own `lag_task = asyncio.create_task(self._report_consumer_lag())` inside `_run()` even though BaseAgent.start() already creates one — resulting in duplicate lag tasks (already fixed in Plan 03).

Output: BaseAgent provides default implementation. BaseWriterAgent overrides for buffer depth. All agents inherit working lag reporting.
</objective>

    ```python
    async def _report_consumer_lag(self) -> None:
        """Report consumer lag as buffer depth (override of BaseAgent default).

        Writer agents accumulate unflushed records in self._buffer.
        Lag = buffer size (records waiting to be flushed to DB).
        """
        # Use cached gauge from BaseAgent if available, else create
        if not hasattr(self, "_consumer_lag_gauge"):
            self._consumer_lag_gauge = PERSISTENCE_CONSUMER_LAG.labels(agent_id=self.name)

        while not self._stop_event.is_set():
            self._consumer_lag_gauge.set(len(self._buffer))
            await asyncio.sleep(15)
    ```

    This override reports actual buffer depth for writer agents instead of the default 0.
