    ### Fix 3: Rate limiter wiring (D-04, D-11)

    After the cache miss check (existing code returns cached result), BEFORE the budget check, insert:
    ```python
    # D-04: Rate limiter — covers OpenRouter + OllamaCloud + OllamaLocal
    limiter = self._rate_limiters.get(self._inner.last_provider_id) or next(
    ```

    The limiter lookup uses `self._inner.last_provider_id` for per-provider rate limiting, falling back to the first configured limiter if no provider ID is available yet (first call).
