Brier score formula (binary outcome):
  brier = mean((confidence - outcome)^2)
  outcome ∈ {0, 1}; confidence ∈ [0, 1]

Calibration slope:
  Linear regression: outcome = a + b * confidence + ε; calibration_slope = b
  Perfect calibration → b = 1.0

Expected Calibration Error (ECE), 10 equal-width bins on confidence:
  bin_i: confidence ∈ [i/10, (i+1)/10)
  ece = sum_i (|bin_i| / N) * |mean(confidence in bin_i) - mean(outcome in bin_i)|

       ```python
       def _brier(conf: np.ndarray, outcome: np.ndarray) -> float:
           return float(np.mean((conf - outcome) ** 2))

       def _calibration_slope(conf: np.ndarray, outcome: np.ndarray) -> float | None:
           if conf.size < 10 or np.std(conf) < 1e-9 or np.std(outcome) < 1e-9:
               return None
           # polyfit returns [slope, intercept] for deg=1
           slope, _ = np.polyfit(conf, outcome.astype(float), 1)
           return float(slope)

       def _ece(conf: np.ndarray, outcome: np.ndarray, n_bins: int = 10) -> float:
           if conf.size == 0:
               return 0.0
           edges = np.linspace(0.0, 1.0, n_bins + 1)
           total = 0.0
           n = float(conf.size)
           for i in range(n_bins):
               lo, hi = edges[i], edges[i + 1]
               mask = (conf >= lo) & (conf < hi) if i < n_bins - 1 else (conf >= lo) & (conf <= hi)
               if not mask.any():
                   continue
               total += (mask.sum() / n) * abs(conf[mask].mean() - outcome[mask].mean())
           return float(total)
       ```
