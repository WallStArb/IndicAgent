## Notable Finding: evaluate_market_entry bars >= ttl

`lifecycle_tracker.py` line 591 contains `if bars >= ttl:` — this is inside `evaluate_market_entry()`, a separate function for the parallel market-entry tracking path. This function uses `bars_elapsed` from accumulated state, not a wall-clock comparison, because the market-entry track has no `expires_at` equivalent. This is intentional and not a residual bug from the fix. The zone-entry TTL in `evaluate_signal()` (the target of LIFECYCLE-FIX-03) was correctly replaced at line 347.
