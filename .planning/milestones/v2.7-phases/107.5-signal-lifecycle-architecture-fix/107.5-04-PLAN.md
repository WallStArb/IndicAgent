  <action>
    Create `production/scripts/backfill_expires_at.py` as a standalone async script.

    The backfill is entirely self-contained within signal_ledger — no JOIN to other tables:

      UPDATE signal_ledger
      SET expires_at = timestamp + (ttl_bars * CASE feature_tf
          WHEN '1m'  THEN  60
          WHEN '5m'  THEN  300
          WHEN '15m' THEN  900
          WHEN '1h'  THEN  3600
          WHEN '4h'  THEN  14400
          WHEN '1d'  THEN  86400
          END) * INTERVAL '1 second'
      WHERE expires_at IS NULL
        AND ttl_bars IS NOT NULL
        AND feature_tf IN ('1m','5m','15m','1h','4h','1d')
        AND signal_id IN (
            SELECT signal_id FROM signal_ledger
            WHERE expires_at IS NULL
              AND ttl_bars IS NOT NULL
              AND feature_tf IN ('1m','5m','15m','1h','4h','1d')
            LIMIT 10000
        )

    NOTE (REVIEW FIX): the CASE has NO `ELSE 60` default — unknown timeframes must NOT be silently
    coerced to 60s (that corrupts expires_at, D-03 fail-loud). Instead the WHERE clause restricts to
    the six known timeframes, and the reconciliation step (below) fails the run if any candidate row
    has an unknown timeframe.

    Loop in 10k batches until rows_affected == 0. Throttle: `await asyncio.sleep(0.1)` (100ms) between
    batches to match the zone backfill and prevent lock contention on the hypertable.

    After the loop, run a RECONCILIATION query that classifies still-NULL rows into:
      a. data-quality nulls (acceptable): ttl_bars IS NULL OR feature_tf IS NULL
      b. unknown-timeframe nulls (MUST be 0, REVIEW FIX):
           COUNT(*) WHERE expires_at IS NULL AND ttl_bars IS NOT NULL
                      AND feature_tf IS NOT NULL
                      AND feature_tf NOT IN ('1m','5m','15m','1h','4h','1d')
      c. unexpected nulls (MUST be 0): ttl_bars IS NOT NULL AND feature_tf IN (the six)
         AND expires_at IS NULL (backfill should have covered these)

    Print reconciliation report:
      === EXPIRES_AT BACKFILL COMPLETE ===
      Before: {before_null_count} NULL expires_at rows (of {total} total)
      Updated: {total_updated} rows in {batch_count} batches
      Data-quality NULL (missing ttl_bars or feature_tf): {dq_null} rows
      Unknown-timeframe NULL (MUST be 0): {unknown_tf_null} rows
      Unexpected NULL (MUST be 0): {unexpected_null} rows
      After: {after_null_count} NULL expires_at rows remaining

    If unknown_tf_null > 0 OR unexpected_null > 0, print the offending feature_tf values and
    sys.exit(1) — do not allow Fix 3 to proceed on corrupt or incomplete expires_at data.

    DATABASE_URL from environment, asyncpg.connect for simplicity.

    Run the script after the migration is applied (expires_at column must exist).
  </action>
