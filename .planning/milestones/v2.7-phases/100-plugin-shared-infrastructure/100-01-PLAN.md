Create shared utility functions for common plugin patterns: Wilder's smoothing, EMA updates, and OHLCV DataFrame extraction. These functions eliminate code duplication across 28+ I1 plugins and provide a single source of truth for bug fixes.

Output: New src/intelligence/plugins/mixins.py module with wilders_update(), update_ema(), and get_main_df() functions, plus comprehensive unit tests.

  <action>
    Create src/intelligence/plugins/mixins.py with three pure functions.

    1. wilders_update(prev: float, new_val: float, period: int) -> float
       Formula: (prev * (period - 1) + new_val) / period
       NaN propagation: if math.isnan(prev) or math.isnan(new_val), return float("nan"). This matches existing inline behavior in ATR (line 47 checks pd.notna before using), RSI (lines 58-59 never receive NaN because _seed_state always computes from valid data), and MFI (line 41 checks pd.isna before using).
       Raises ValueError if period < 1.
       Docstring: must include formula, NaN rule ("NaN in -> NaN out"), and usage example referencing ATR's Wilder's smoothing.

    2. update_ema(current: float, prev_ema: float, span: int) -> float
       Formula: alpha * current + (1-alpha) * prev_ema where alpha = 2/(span+1)
       NaN propagation: if math.isnan(current), return float("nan"). If math.isnan(prev_ema), also return float("nan"). This matches existing behavior where EMA bootstrap always uses valid seed values, so NaN prev_ema indicates a real error. Both NaN cases produce NaN output -- no silent fallback.
       Raises ValueError if span < 1.
       Docstring: must include alpha formula, NaN rule ("NaN in either arg -> NaN out"), and usage example referencing MACD EMA chains.

    3. get_main_df(frames: dict[str, Any], min_bars: int) -> pd.DataFrame | None
       Contract: returns None when data is insufficient. Callers MUST check for None and handle appropriately (typically return {} for plugins).
       Returns frames.get("main") if it is a DataFrame with len >= min_bars, else None.
       Also returns None if frames itself is None or not a dict.
       Docstring: must explain the None-return contract and the min_bars guard pattern.

    All functions: module-level (not class methods), pure (no side effects), type-annotated. Add __all__ = ["wilders_update", "update_ema", "get_main_df"]. Import math for isnan checks.
  </action>
