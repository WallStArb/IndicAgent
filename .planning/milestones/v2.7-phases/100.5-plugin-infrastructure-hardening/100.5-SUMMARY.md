## Decisions Made

- IncrementalMixin state contract: `_compute_next_core` mutates state dict in-place; mixin manages `_state` key attachment/detachment. This prevents callers from needing to handle state plumbing.
- BOCPD `_seed_state` uses `copy.deepcopy()` for numpy arrays -- aliasing would corrupt run-length posteriors across calls.
- BOCPD O(R) algorithmic bound documented in source file header: reducing below O(R) requires approximation (particle filter/pruning); do not attempt forced O(1).
- Legacy fixture source copies deleted after Task 16; golden JSON snapshots retained permanently for BOCPD/HMM/GARCH/Kalman regression baselines.
- CI gate simplified from xfail shrinking allowlist to hard assertion once UNMIGRATED_PLUGINS became empty.
