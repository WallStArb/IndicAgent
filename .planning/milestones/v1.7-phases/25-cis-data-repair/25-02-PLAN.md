<objective>
Create `production/scripts/repair_cis_nulls.py` — a standalone audit + repair script that:
1. Counts NULL cis_score rows in signal_ledger, classifies them as recoverable vs orphaned
2. Re-runs CISScorer on the feature vector from intelligence_features for every recoverable row
3. Batch-UPDATEs signal_ledger with computed CIS values
4. Logs orphaned signal_ids at WARNING level
5. Prints before/after NULL counts for operator verification

Purpose: Fixes the historical debt — all existing backfill rows that are NULL due to the bug fixed in plan 25-01.

Output: `production/scripts/repair_cis_nulls.py` + unit tests for the audit and orphan-classification logic.

Schema — JOIN key between signal_ledger and intelligence_features:
```sql
-- Recoverable: has matching intelligence_features row
SELECT sl.signal_id, sl.symbol, sl.feature_ts, sl.feature_tf,
       f.i1, f.i3, f.i4, f.i5, f.smc, f.i6
FROM signal_ledger sl
JOIN intelligence_features f
    ON f.ts = sl.feature_ts
    AND f.symbol = sl.symbol
    AND f.tf = sl.feature_tf
WHERE sl.cis_score IS NULL
  AND sl.feature_ts IS NOT NULL

-- Orphaned: NULL cis_score but no matching intelligence_features row
SELECT sl.signal_id
FROM signal_ledger sl
LEFT JOIN intelligence_features f
    ON f.ts = sl.feature_ts
    AND f.symbol = sl.symbol
    AND f.tf = sl.feature_tf
WHERE sl.cis_score IS NULL
  AND f.ts IS NULL
```

intelligence_features JSONB columns for feature extraction:
- i1 JSONB: flat indicator values (rsi_14, macd_line, etc.)
- i3, i4, i5, smc, i6 JSONB: merged into flat feature dict for CISScorer

CIS UPDATE SQL:
```sql
UPDATE signal_ledger
SET cis_score = %s,
    bucket_scores = %s::jsonb,
    weights_version = %s
WHERE signal_id = %s::uuid
  AND cis_score IS NULL  -- idempotency guard
```

    ```
    repair_cis_nulls.py
    ├── sys.path setup (same as historical_backfill.py)
    ├── imports: argparse, json, logging, sys, pathlib, psycopg2, psycopg2.extras
    ├── from src.config.settings import Settings

    ├── merge_feature_jsonb(i1, i3, i4, i5, smc, i6) -> dict

    │     Skips None/empty tier dicts gracefully.
    ├── audit_null_cis(conn) -> (total, recoverable_rows, orphaned_ids)
    │     Returns total NULL count, list of recoverable rows (with feature data), list of orphaned signal_ids.
    │     Uses the LEFT JOIN + JOIN queries from the interfaces block above.
    ├── repair_recoverable(conn, rows) -> int
    │     For each recoverable row:
    │       1. Call merge_feature_jsonb() on the row's JSONB tier columns
    │       2. scorer = CISScorer(); result = scorer.score(features, plugin_outputs={})
    │          (plugin_outputs={} — we don't have per-plugin outputs for historical rows;
    │          CISScorer falls back gracefully on empty plugin_outputs)
    │       3. Collect (cis_score, json.dumps(bucket_scores), weights_version, signal_id)
    │     Batch UPDATE via psycopg2.extras.execute_batch with the idempotency guard.
    │     Commits in batches of 500 rows (avoid holding large transactions).
    │     Returns count of rows updated.
    ├── log_orphans(orphaned_ids)
    │     Log each signal_id at WARNING level.
    │     Also print summary count.
    ├── main()
    │     1. Print "=== CIS Null Audit ==="
    │     2. audit_null_cis() → print total/recoverable/orphaned counts
    │     3. If --dry-run: print plan and exit
    │     4. If recoverable > 0: repair_recoverable() → print updated count
    │     5. If orphaned > 0: log_orphans()
    │     6. Re-run audit_null_cis() → print post-repair NULL count (verification)
    │     7. Print "=== Repair Complete ==="
    └── if __name__ == "__main__": main()
    ```
