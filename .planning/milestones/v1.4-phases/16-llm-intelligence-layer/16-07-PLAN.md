<objective>
Upgrade _apply_score_routing in ai_narrative_service.py to select the best model per (call_type, regime) pair rather than globally across all regimes.

Purpose: LLM-05 specifies that adaptive routing promotes the is_significant winner "for that call_type + regime combination." The current implementation picks the single globally-best model by max avg_pnl_r across all regimes and promotes it for all calls of that call_type. This is coarser than the requirement — when models perform differently across regimes (trending vs ranging vs volatile), the routing will always promote the trending winner even for ranging calls. As the llm_model_scores table accumulates data beyond the significance threshold (n>=30, p<0.05), per-regime routing will produce meaningfully better model selection.

Output: _apply_score_routing builds a per-regime preferred model dict; call sites inject the regime-specific winner when promoting the provider chain.
</objective>

```python
    async def _apply_score_routing(self) -> None:
        """Read Redis score cache and promote significant winner per call_type+regime."""
        if not self.redis_client:
            return
        new_preferred: dict[str, dict[str, str]] = {}
        for call_type, chain in [
            ("per_signal", self.per_signal_chain),
            ("group_synthesis", self.group_chain),
        ]:
            regime_winners: dict[str, str] = {}
            for regime in ("trending", "ranging", "volatile", "__all__"):
                cache_key = llm_scores_cache(self.env_prefix, call_type, regime)
                try:
                    raw = await self.redis_client.hgetall(cache_key)
                except Exception:
                    continue
                best_model: str | None = None
                best_avg_pnl_r: float = float("-inf")
                for model_bytes, blob_bytes in (raw or {}).items():
                    try:
                        blob = json.loads(
                            blob_bytes.decode() if isinstance(blob_bytes, bytes) else blob_bytes
                        )
                        if blob.get("is_significant") and float(blob.get("avg_pnl_r", 0)) > best_avg_pnl_r:
                            best_avg_pnl_r = float(blob.get("avg_pnl_r", 0))
                            best_model = (
                                model_bytes.decode()
                                if isinstance(model_bytes, bytes)
                                else model_bytes
                            )
                    except Exception:
                        continue
                if best_model:
                    regime_winners[regime] = best_model
                    self.logger.info(
                        "Per-regime provider preferred",
                        call_type=call_type,
                        regime=regime,
                        model=best_model,
                        avg_pnl_r=best_avg_pnl_r,
                    )
            new_preferred[call_type] = regime_winners
        self._preferred_models = new_preferred
```
