## v1.6 Requirements

Requirements for signal quality improvements — gate-based firing control and second-derivative acceleration. Each maps to roadmap phases.

### Signal Generator Gate (SG)

**P0 — Signal generator emits onset events, not persistent condition fires.**

- [x] **SG-01**: Signal generator publishes onset events (not persistent condition fires)
- [x] **SG-02**: Cross-bar signal memory prevents duplicate fires
- [x] **SG-03**: Direction flip suppression while prior signal active
- [x] **SG-04**: Gate reset when prior signal resolves (direction=0 event)
- [x] **SG-05**: Min bars between signals (cooldown) configurable per TF
- [x] **SG-06**: InputSpec cleanup — remove dead timeframe="1m" declarations
- [x] **SG-07**: 4h/1d processing documented as intentional exclusion

### Second-Derivative Acceleration (2D)

**P1-P2 — Second-derivative intelligence for early inflection detection and exhaustion guards.**

- [x] **2D-01**: HMA I1 plugin added (hull moving average)
- [x] **2D-02**: MomentumAcceleration extended (+5 outputs: rsi_curvature, macd_hist_slope, price_accel, hma_slope, hma_accel)
- [x] **2D-03**: ExhaustionScore I2 plugin created
- [x] **2D-04**: AccelerationRegime I2 plugin created
- [x] **2D-05**: SwingMomentum I3 plugin created
- [x] **2D-06**: I7 exhaustion wiring — LiquiditySweepReclaim + LiquidityHunt boost, MomentumBreakout + TrendFollowing guard
- [x] **2D-07**: All plugins registered in register_plugins.py
