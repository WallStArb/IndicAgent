## Phase Boundary

Move VIX regime and EQ cross-asset context from I6 (pass-through layer) to two new I4 plugins,
fix the per-TF VIX z-score data quality defect, consolidate `CROSS_ASSET_VALID_TFS` constant,
and rename `capture_confluence_features` → `capture_signal_features` across 36 I7 plugins.

</domain>

<decisions>
## Implementation Decisions

### Architecture: Two New I4 Plugins (Locked)
- `VIXRegimePlugin` (`ctx_VIXRegime`) in `src/intelligence/context/vix_regime.py`
  - Reads `frames["vix"]` injected by `feature_pipeline_service` using **fixed `VIX_REGIME_TF="1h"`** bars
  - Outputs: `vix_level`, `vix_z`
  - Symbol scope: ALL symbols (VIX is a global fear gauge)
  - Returns `{}` when VIX bars unavailable — silent degradation, not an error
- `CrossAssetContextPlugin` (`ctx_CrossAssetContext`) in `src/intelligence/context/cross_asset_context.py`
  - Reads `frames["cross_asset"]` — already injected for EQ_INDEX symbols
  - Outputs: `eq_spread_z`, `eq_pairs_confirming`
  - Symbol scope: EQ_INDEX symbols only → returns `{}` for all others

### Schema Changes (Locked)
- `I4Context` gets 4 new fields: `vix_level: float | None`, `vix_z: float | None`, `eq_spread_z: float | None`, `eq_pairs_confirming: float | None`
- `I6Confluence` loses 4 fields: `ctf_vix_level`, `ctf_vix_z`, `ctf_eq_spread_z`, `ctf_eq_pairs_confirming`

### VIX Frame Injection Fix (Locked)
- Module-level constant: `VIX_REGIME_TF: str = "1h"` in `feature_pipeline_service.py`
- Replace `self._bar_history.get(self._vix_symbol, tf)` with `self._bar_history.get(self._vix_symbol, VIX_REGIME_TF)`
- All TF bars for all symbols now see identical VIX regime reading for the same market moment

### I6 Cleanup (Locked)
- Remove ~20-line VIX/cross-asset pass-through block from `CrossTimeframeConfluencePlugin.compute_full()`
- Remove 4 field names from `outputs` frozenset
- I6 returns to pure cross-TF alignment computation

### Constants Consolidation (Locked)
- `CROSS_ASSET_VALID_TFS` moves from both service files to `src/core/service_utils.py`
- Both services import from there — no local redefinition

### Function Rename (Locked)
- `capture_confluence_features()` → `capture_signal_features()` in `confidence_utils.py`
- Shadow dict keys renamed: `ctf_vix_level` → `vix_level`, `ctf_vix_z` → `vix_z`, `ctf_eq_spread_z` → `eq_spread_z`, `ctf_eq_pairs_confirming` → `eq_pairs_confirming`
- All 36 I7 plugin callers updated (mechanical rename via sed)

### What Does NOT Change (Locked)
- `vix_context.py` — pure function module correct as-is, reused
- `CrossAssetDivergencePlugin` (I7) — continues reading full `frames["cross_asset"]` directly
- `signal_generator_service` cross-asset subscription — retained for `CrossAssetDivergencePlugin`
- `ctf_score` formula — untouched
- `ConfluenceWeightProfile` / `FAMILY_PROFILES` — unchanged

### Testing (Locked — TDD)
- Write failing tests BEFORE implementation for each plugin and schema change
- New test files: `test_vix_regime.py`, `test_cross_asset_context.py`, `test_macro_context_schema.py`
- Update: `test_cross_timeframe_confluence.py`, `test_capture_confluence_features.py` (rename to `test_capture_signal_features.py`)
- Regression baseline: ≥2716 existing tests pass

### Claude's Discretion
- Wave grouping of tasks (Tasks 1-2 can be wave 1; plugins 3-4 can be wave 1; remainder wave 2)
- Whether to split into 1 or 2 PLAN.md files
