    Create `src/intelligence/context/vix_context.py` with this exact public interface (per D-09):

    ```python
    def compute_vix_context(vix_bars: deque[BarMessage], z_window: int = 20) -> dict[str, Any]:
    ```

    Implementation details:
    - Extract close prices from the last `z_window` bars in `vix_bars`
    - If `len(vix_bars) < z_window`, return `{"ready": False}`
    - Compute: `level = closes[-1]` (most recent VIX close)
    - Compute: `mean = sum(closes[-z_window:]) / z_window`
    - Compute: `std = statistics.stdev(closes[-z_window:])` or equivalent manual calc
    - If `std < 1e-8` (near-zero threshold, same as `_LOW_VOL_THRESHOLD` in cross_asset_features.py), set `z_score = 0.0`
    - Otherwise: `z_score = (level - mean) / std`
    - Return `{"level": round(level, 4), "z_score": round(z_score, 4), "ready": True}`

    Module-level docstring following cross_asset_features.py pattern:
    ```python
    """VIX context computation -- pure-function module.

    No Kafka, no DB, no side effects. All I/O lives in the service layer.
    Computes VIX level and z-score from bar history for I6 confluence expansion.
    """
    ```

    Imports allowed: `collections.deque`, `math`, `typing.Any`, `src.core.schemas.bar_message.BarMessage`.
    Do NOT import anything from `services/`, `src/core/kafka_utils`, `src/config/settings`.
