# Phase 44.2 Plan 01: Pipeline Pure Function Modules Summary

**One-liner:** Extracted 6 Kafka-service stage `process()` bodies into pure sync functions at `src/intelligence/pipeline/`, enabling in-process pipeline execution in SignalGeneratorService.

## What Was Built

### 6 Pure Function Pipeline Stages (`src/intelligence/pipeline/`)

| Module | Function | Description |
|--------|----------|-------------|
| `quality_gate.py` | `apply_quality_gate(signals, thresholds)` | `min(hurst_q, entropy_q) * drift_penalty` applied to confidence |
| `regime_gate.py` | `apply_regime_gate(signals, regime_data)` | HMM three-tier gate: prob, duration, regime_type compatibility |
| `tod_adjuster.py` | `apply_tod_adjustment(signals, tod_table, tf, hour_et)` | Bayesian TOD multiplier, clamped [0.7, 1.3] |
| `calibrator.py` | `apply_calibration(signals, cal_curves, tf)` | `np.interp` isotonic calibration per (plugin, tf) |
| `ranker.py` | `rank_signals(signals, perf_weights, tf)` | `SETUP_PRIORITY * perf_multiplier` adjusted rank |
| `winner_selector.py` | `select_winner(signals, cis_scorer, features)` | CIS override + majority/priority fallback |

All functions:
- Accept and return `list[dict]` (copy-on-write, never mutate input)
- Have zero imports from `kafka_utils`, `database_manager`, or service modules
- Are synchronous (no async/await)
- Inject external state as arguments (not loaded internally)

### New Pydantic Models in `schemas.py`

- `RankedSignal`: single I7 signal after all pipeline stages, with `is_winner` flag
- `BarIntelligenceRecord`: full bar record — intelligence event + all ranked signals + funnel counts + latency

### New Stream Key

- `topic_intelligence_record(env_name)` → `"{env}.intelligence.record"` — atomic persistence source for PIPE-06

### 34 Unit Tests (6 test files)

All tests synchronous, no Kafka/DB mocking needed. Coverage: happy path + edge cases + mutation guards.
