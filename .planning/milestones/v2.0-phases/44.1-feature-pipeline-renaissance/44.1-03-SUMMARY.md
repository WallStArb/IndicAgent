## What Was Built

### FeaturePipelineService (`services/feature_pipeline_service.py` — 1078 lines)

Unified I1-I6 in-process pipeline service:

**Architecture:**
- Replaces `indicator_service` + `market_analysis_service` + `timeframes_builder_service`
- Eliminates 3 Kafka hops (indicator→market_analysis, market_analysis→signal_generator, timeframes→indicator)
- Runs I1→I2→I3→I4→I5→SMC→I6 per-bar in a single asyncio context

**Critical correctness patterns (verified by tests):**
- `threading.Lock` per `(plugin_name, symbol, tf)` for `asyncio.to_thread` CPU-bound plugins
- `self._plugin_states[_key] = _p._state` write-back — GARCH/HMM state persists across bars
- `_prev_i1_features` injection before I1, stored after I1 — I2 crossover detection works from bar 2+
- `smc_trend_direction` rename: `smc_results.pop("trend_direction")` before `features.update(smc_results)`
- `asyncio.Semaphore(min(32, (os.cpu_count() or 4) * 2))` concurrency bound (D-34)

**BarHistory + BarAccumulator integration:**
- `_bar_history = BarHistory(maxlen=200)` — typed deque store for all (symbol, tf) pairs
- `_bar_accumulator = BarAccumulator(timeframes=["5m", "15m", "1h"])` — session-aware HTF aggregation
- HTF bars published to `development.market.bars.htf` via `_publish_htf_bar()` (D-06/D-16)
- Completed HTF bars appended to BarHistory and processed through I1-I6 pipeline

**Gap detection (D-20):**
- `_last_bar_ts: dict[str, float]` per `"{symbol}:{tf}"`
- `gap_preceding=True` when `(current_ts - prev_ts) > tf_seconds * 1.5`

**Roll event handling (D-40 through D-42):**
- `BarHistory.migrate_symbol(old_symbol, new_symbol)` — atomic transfer of bar deques
- `PRICE_SENSITIVE_PLUGINS = {"bollinger_bands", "keltner_channel", "donchian_channel"}` — adjusted by `roll_gap` via `_adjust_price_state()`
- Volume-neutral plugin states copied verbatim
- `_prev_i1_features` and `_last_bar_ts` caches also migrated

**DB seed (D-27/D-28/D-31):**
- Single `ROW_NUMBER() OVER (PARTITION BY symbol, tf ORDER BY ts DESC)` window query — no N×M queries
- Fallback to `market_data_ohlcv` for (symbol, tf) pairs below `min_bars_for_tf(tf)`
- Re-publishes last known `IntelligenceEvent` per (symbol, tf) for dashboard warmup

**Tick buffer:**
- Preserved from indicator_service pattern — OFI/CVD I1 plugins require `frames["tick_buffer"]`
- Per-symbol buffer capped at 10k ticks; drains on overflow

**Metrics at `:9119`:**
- `feature_pipeline_latency_ms` gauge
- `feature_pipeline_bars_processed_total` counter
- `feature_pipeline_errors_total` counter
- `feature_pipeline_service_uptime_seconds` gauge
