<objective>
Apply gradient transforms to the highest-impact plugins: I4 SessionContext + AnchoredVWAP + TrendRegime + VolatilityRegime, and I2 composites (ma_composites, volume_events, rsi_events).

Renaissance design principles:
- **Replace in-place where safe.** I7 plugins use `> 0.5` threshold checks on session flags (verified in research), not `== 1.0`. Replacing 0.0/1.0 with continuous 0.0-1.0 range is safe and avoids field proliferation.
- **Highest DAG cascade first.** SessionContext feeds 6+ I7 plugins directly. I2 composites feed I6 CTF which feeds all 37 I7 plugins. Fixing these two layers propagates gradient through the entire downstream.
- **No field proliferation.** Don't add `_progress` companion fields when replacing the binary flag itself is safe. Exception: trend_regime_continuous is additive because the bucketed regime value IS used for gating.

Output: ~25 binary fields converted to continuous gradients across 7 plugins, with updated schemas and tests.
</objective>
