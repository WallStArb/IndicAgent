    GREEN: Create src/intelligence/utils/gradient_utils.py with these functions:

    **4 Mathematical Primitives:**

    1. `linear_ramp(x, lo, hi, out_lo=0.0, out_hi=1.0) -> float` -- Piecewise-linear map from [lo, hi] to [out_lo, out_hi], clamped at boundaries. The workhorse function. Every other gradient is either this or a composition involving this. Use `max(out_lo, min(out_hi, out_lo + (out_hi - out_lo) * (x - lo) / (hi - lo)))`. Guard hi==lo to avoid division by zero (return midpoint of output range).

    2. `threshold_decay(x, center, width, peak=1.0, floor=0.0) -> float` -- Triangular proximity score. Peaks at center, linearly decays to floor over +/-width. `peak * max(0, 1 - abs(x - center) / width)` clamped to floor. For proximity-to-level scoring (POC, VWAP, S/R, killzone center). Guard width==0 (return peak if x==center, else floor).

    3. `sigmoid_score(x, center, steepness=1.0) -> float` -- Standard sigmoid: `1.0 / (1.0 + math.exp(-steepness * (x - center)))`. For RSI extremes, z-score saturation. Import `math`, nothing else. Clamp steepness * delta to [-500, 500] to prevent math.exp overflow.

    4. `freshness_decay(touch_count: int, k: float = 0.5) -> float` -- `math.exp(-k * max(0, touch_count))`. Exponential decay from 1.0 (fresh) toward 0.0 (stale). For order block freshness, supply/demand zone freshness.

    **2 Domain Conveniences:**

    5. `session_progress(elapsed_frac, start_frac, end_frac) -> float` -- Tent-shaped score: 1.0 at midpoint of [start, end], decays to 0 at edges. `position = (elapsed_frac - start_frac) / (end_frac - start_frac)`, then `max(0.0, 1.0 - abs(2 * position - 1))`. Returns 0 outside window. Guard end==start. For session/killzone time-based scoring.

    6. `hmm_regime_weight(features: dict, regime_direction: str) -> float` -- Extract continuous HMM probability. Map "up" -> "hmm_prob_trending_up", "down" -> "hmm_prob_trending_down", "ranging" -> "hmm_prob_ranging". Fallback to 0.5 if key missing or value is None. Clamp to [0, 1]. This enforces consistent field names across all I7 plugins.

    **2 Thin Wrappers (delegate to linear_ramp):**

    7. `z_score_to_score(z, sigma_scale=2.0) -> float` -- `linear_ramp(abs(z), 0.0, sigma_scale)`. Maps z-score magnitude to [0, 1].

    8. `streak_score(streak_count: int, saturation: int = 5) -> float` -- `linear_ramp(float(streak_count), 0.0, float(saturation))`. Maps streak length to [0, 1].

    Module design rules:
    - `import math` ONLY. No numpy, no intelligence-layer imports.
    - Every function: scalar float in, scalar float out.
    - Every function: one-line docstring with mapping description, what binary pattern it replaces.
    - Module-level `__all__` listing all 8 names.
    - Functions are stateless, no side effects, no class required.

    REFACTOR: Verify z_score_to_score and streak_score produce identical results to calling linear_ramp directly (assert in tests).

    Module API:
    ```python
    def scan_all_plugins(root_dir: str = "src/intelligence") -> list[dict]:
        """Scan all plugin files for binary scoring violations.
        Returns list of {file, line, pattern, context, is_exempt} dicts.
        """

        """Format violations for human-readable output."""
        ```

    Scanner logic (inside `scan_all_plugins`):
    1. Walk all `.py` files under `root_dir` (features/, composites/, context/, trading/, confluence/)
    2. Use regex patterns to find:
       - `= 1 if .* else 0` and `= 1.0 if .* else 0.0` (binary assignment)
       - `= 0 if .* else 1` and `= 0.0 if .* else 1.0` (inverted binary)
       - `np.where(.*, 1, 0)` and `np.where(.*, 1.0, 0.0)` (numpy binary)
       - `== 1.0` or `== 0.0` equality on `hmm_regime` specifically (not all floats)
    3. Apply an allowlist to exclude legitimate patterns (mark `is_exempt=True`):
       - Direction encoders: lines containing `direction`, `_dir`, `_sign`, `signal_type`
       - Crossover/detection events: lines containing `cross`, `crossed`, `detected`, `fired`
       - Day-of-week flags: `is_monday`, `is_friday`
       - Type/category fields: `fvg_type`, `sweep_type`, `swing_high_type`, `swing_low_type`
       - Existing utility functions in `utils/common.py`, `utils/core.py`
       - Lines with `# gradient-exempt` comment (escape hatch)
       - Eligibility gates: `hmm_regime not in` or `hmm_regime !=` in return/guard contexts
    4. Return non-exempt violations only by default. Include exempt ones in verbose mode.

    CLI (argparse):
    - `--verbose`: full context output including exempt patterns
    - `--json`: machine-readable output
    - `--baseline`: save current count to `tools/.binary_baseline.json`
    - Exit code: 0 if zero non-exempt violations, 1 if any found
