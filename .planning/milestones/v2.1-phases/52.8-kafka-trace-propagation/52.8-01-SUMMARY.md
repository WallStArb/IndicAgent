# Phase 52.8 Plan 01: Kafka Trace Propagation Summary

**One-liner:** W3C traceparent inject/extract wired into KafkaProducerClient.publish() and KafkaConsumerClient.messages() via _KafkaHeadersCarrier AIOKafka adapter, with 15 comprehensive unit tests.

## What Was Built

Added W3C traceparent header propagation to `src/core/kafka_utils.py` so OTel spans link across service boundaries in the DAG. A trace ID originating in one agent (e.g. IndicatorComputeAgent) now flows through the Kafka message headers and is restored as the active context when SignalGeneratorAgent or FeatureWriterAgent consumes the message — visible as a single waterfall trace in Grafana Tempo.

### Key Changes

**`src/core/kafka_utils.py`**

1. Added `_KafkaHeadersCarrier` — private adapter class bridging OTel carrier protocol (`get/set/keys`) to AIOKafka's `list[tuple[str, bytes]]` header format. The `get()` method accepts an optional `default` argument to satisfy the OTel `DefaultGetter` which calls `carrier.get(key, None)`.

2. `KafkaProducerClient.publish()` — injects current trace context into headers before `send_and_wait()`. When no `TracerProvider` is configured, `inject(carrier)` is a no-op and `headers=[]` is passed — zero overhead, zero behavior change.

3. `KafkaConsumerClient.messages()` — extracts `traceparent` from `msg.headers`, calls `otel_context.attach(ctx)` before yielding, and `otel_context.detach(token)` in a `finally` block after yield resumes. Handles `None` and empty headers without error.

**`tests/unit/test_kafka_utils.py`** (new, 332 lines, 15 tests)

- 5 synchronous tests for `_KafkaHeadersCarrier` round-trip, encoding, missing keys
- 4 async tests for `publish()` — headers injected, empty headers on no-span, signature unchanged with/without key
- 6 async tests for `messages()` — extract/attach/detach called correctly, None/empty headers no-crash, yield tuple contract unchanged, detach count per message

## Decisions Made

1. **`_KafkaHeadersCarrier.get()` default parameter** — OTel's `DefaultGetter.get()` calls `carrier.get(key, None)` with a second positional argument. The CONTEXT.md spec only showed `get(self, key)`. Extended to `get(self, key, default=None)` to satisfy the real SDK call signature without breaking the carrier contract. Auto-fixed per Rule 1.

2. **No conditional tracing guards** — OTel SDK's no-op behavior handles disabled tracing automatically. `propagate.inject({})` with no TracerProvider costs ~microseconds and avoids scattered `if tracing_enabled:` guards across the codebase.

3. **`_MockConsumer` with class-level `__aiter__`** — AsyncMock with instance-level `__aiter__` silently yields 0 iterations (dunder lookup on type, not instance). Implemented proper async iterable class per plan guidance.
