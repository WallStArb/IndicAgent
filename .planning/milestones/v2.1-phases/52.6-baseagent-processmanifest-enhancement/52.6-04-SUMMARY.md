# Phase 52.6 Plan 04: SignalGeneratorAgent BaseAgent Migration + Lifecycle Tests Summary

SignalGeneratorAgent migrated to BaseAgent inheritance eliminating sync signal.signal() invariant violation and manual metrics server startup. Lifecycle-contract tests added for both IndicatorComputeAgent and SignalGeneratorAgent per D-17.

## What Was Built

### Task 2: SignalGeneratorAgent BaseAgent Migration

`services/signal_generator_agent.py` now inherits `BaseAgent` with the full lifecycle contract:

- `class SignalGeneratorAgent(BaseAgent)` — inheritance added
- `super().__init__(name="signal_generator_agent", metrics_port=9112)` — called at top of `__init__`
- `signal.signal()` calls removed — `BaseAgent._register_signal_handlers()` handles SIGTERM/SIGINT via `loop.add_signal_handler()`
- `start_metrics_server(port=9112)` removed from `__init__` — `BaseAgent.start()` auto-starts it
- `self.running = False`, `self.shutdown_event`, `self.shutdown_requested` removed
- `_setup()` — connects DB, seeds bar history, starts Kafka clients, loads all weight caches
- `_run()` — `asyncio.gather()` over all processing tasks (previously in `start()`)
- `_teardown()` — closes Kafka consumer/producer and DB connection
- Old `start()` override eliminated
- `topics_consumed`, `topics_produced`, `lag_threshold_messages` properties added
- `shutdown_requested` checks replaced with `not self.running` throughout all loops
- `shutdown_event.wait()` in `_run_refresh_loop` replaced with `self._stop_event.wait()`

## Deviations from Plan

### Pre-existing Test Failures (Out of Scope)

48 tests in `test_signal_generator_service.py` fail because they import `services.signal_generator_service.SignalGeneratorService` — a module/class name that no longer exists (file renamed to `signal_generator_agent.py`, class renamed to `SignalGeneratorAgent`). This pre-dates Plan 04 and was already failing before any changes in this plan. Count confirmed: 48 failures before and after our changes.

These failures are tracked in `deferred-items.md`.

## Decisions Made

1. `super().__init__()` called before `_load_config()` — logger must be initialized first since `_setup_logging()` reassigns `self.logger`, but the BaseAgent logger assignment is needed before any logging calls in the chain.

2. `self.shutdown_requested` fully replaced by `not self.running` — the `running` property (`not self._stop_event.is_set()`) is semantically identical. All 4 occurrences in process loops and resolution listener updated.

3. Old `stop()` removed entirely — `_teardown()` handles all Kafka/DB cleanup; `BaseAgent.stop()` handles the `agent.stopped` log message.
