<objective>
Fix the accidental data loss caused by coupling signal_ledger writes to winner selection.
Move the entries-building loop and DB INSERT to run unconditionally whenever `all_ranked`
is non-empty. Populate `regime_type_at_fire` and `hmm_regime_at_fire` on every LedgerEntry.

Purpose: Renaissance principle — never drop data that could contain signal. Regime-suppressed
signals are labeled training data for ML scoring (Phase 53+). Per-regime segmented performance
(DATA-11) requires non-NULL `regime_type_at_fire`.

Output: Modified `signal_generator_service.py` with decoupled persist/winner stages, 6 new
passing tests confirming the fix.
