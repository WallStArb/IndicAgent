<objective>
Make the signal lifecycle forensically correct. Move mutable lifecycle state (status, market_entry_price) off the canonical dicts and into SignalState so canonical dicts in _active_index are read-only after ingestion. Route backfill signals to the replay auditor instead of falsely publishing EXIT. Bootstrap and persist running MAE/MFE so a restart does not zero them. Seed the regime cache from fire-time regime so the first live bars after restart are not regime-blind. Switch the signal consumer to earliest offset so no in-flight signal is silently skipped.

Purpose: These five lifecycle fixes are the consumer-side complement to the clean signal schema (v2) established in Wave 2. Without them, restart loses running MAE/MFE, backfill signals contaminate the ledger with bogus exits, and canonical-dict mutation makes signal provenance unauditable.
Output: Immutable canonical dicts, backfill routing with a dedicated counter, MAE/MFE bootstrap + persistence trigger, regime-cache bootstrap, earliest offset.
</objective>
