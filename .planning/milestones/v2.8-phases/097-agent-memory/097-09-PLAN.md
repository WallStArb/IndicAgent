<objective>
Close Gap 3 (LiteLLM consistency). `src/core/memory/embedding.py` calls Ollama directly via raw `httpx` instead of routing through `litellm.embedding()`. Every other LLM call in the system goes through LiteLLM; the direct httpx path means the embedding model cannot be swapped via env/Settings and is inconsistent with the provider-chain architecture. This plan replaces the raw httpx Ollama call with `litellm.embedding()` and makes the model configurable via Settings.

Purpose: Architectural consistency — embeddings route through LiteLLM like all other model calls, and the embedding model is swappable without code changes.
Output: LiteLLM-routed EmbeddingService + `embedding_model` setting + updated tests.
</objective>
