    Implement in src/core/memory/client.py recall():
    1. Wrap the `await self._embedding.embed_context(context)` call in `asyncio.wait_for(..., timeout=embed_timeout_ms/1000)` where embed_timeout_ms is a MemoryClient constructor arg (default from config/memory.yaml; add an `embed_timeout_ms` key, default 30). On TimeoutError: record MEMORY_RECALL_RESULTS_TOTAL result="timeout", record MEMORY_RECALL_LATENCY_MS, return []. This caps the embed contribution so total recall (embed_timeout + 40ms HNSW) stays inside a documented envelope.
    2. Add the `embed_timeout_ms: int = 30` parameter to MemoryClient.__init__ and thread it into the wait_for. Do NOT change recall's return contract.

    This is the minimal, correct fix: it bounds the synchronous embed instead of pre-caching (precomputed embeddings are not available at agent recall time — the query context is new each bar). Document in the docstring that the 50ms gate is the embed_timeout (30ms) + backend timeout (40ms) envelope, and that the p95 is measured empirically in Task 2.

    Keep import-light: import asyncio at module top (Ring 0 safe).
