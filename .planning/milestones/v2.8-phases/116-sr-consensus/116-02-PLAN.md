<objective>
Extend `zone_engine` so its candidate synthesis covers the missing structural sources (fib, session H/L, VP HVN, AVWAP bands, Keltner midline) and expose a proximity-gated `collect_sr_candidates()` for the Step 3 consensus plugin.

Purpose: The existing zone synthesis engine is sound but its input set is incomplete. Adding 6 missing sources per direction plus an HVN-distance strength handler gives the consensus plugin (Step 3) a complete candidate set. The critical fix in this plan is `_SR_VP_DIRECTION`: existing `_VP_DIRECTION` is keyed by TRADE direction (1=long -> support-side VP fields val/nearest_hvn_below). `collect_sr_candidates(direction=1)` means RESISTANCE. Reusing `_VP_DIRECTION[1]` would pick support-side fields (val/nearest_hvn_below) for resistance candidates — silently wrong. This plan adds a separate `_SR_VP_DIRECTION` dict keyed by SR direction (1=resistance -> vah/vah_rolling/nearest_hvn_above) and uses it exclusively inside `collect_sr_candidates`.

Output: Extended `_SUPPORT_SPECS`/`_RESISTANCE_SPECS`/`_STRENGTH_FIELD`, a new `_SR_VP_DIRECTION` dict alongside (not replacing) `_VP_DIRECTION`, a `dist_atr` branch in `_resolve_strength`, and the new public `collect_sr_candidates()` and `find_best_level()` functions. Updated/extended zone_engine unit tests including VP direction correctness tests.

    Body:
    ```python
    tf = features.get("timeframe", "")
    raw: list[ZoneCandidate] = []
    for feat_key, name, default_str, tier, family in specs:
        p = _fval(features, feat_key)
        if p <= EPSILON or not (lo < p < hi):
            continue
        strength = _resolve_strength(features, name, default_str)
        raw.append(ZoneCandidate(price=p, name=name, strength=strength,
                                 source_tier=tier, source_family=family))

    # VP block: use _SR_VP_DIRECTION (SR-semantic: 1=resistance->vah, -1=support->val)
    # NOT _VP_DIRECTION (trade-semantic: 1=long->val)
    poc = _select_vp(features, tf, "poc_price", "poc_price_rolling")
    if direction not in _SR_VP_DIRECTION:

    c_sess, c_roll, c_name, hvn_key, hvn_name = _SR_VP_DIRECTION[direction]
    companion = _select_vp(features, tf, c_sess, c_roll)
    hvn = _fval(features, hvn_key)
    for p, name in [(poc, "poc"), (companion, c_name), (hvn, hvn_name)]:
        if p > EPSILON and lo < p < hi:

                                     strength=0.8 if name == "poc" else 0.7,
    ```
