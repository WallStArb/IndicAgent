  <action>
Create `src/intelligence/ai/evaluators/occam_razor_evaluator.py` with the following components:

1. **EVAL_STATE enum** (str, Enum):
   - `PENDING = "pending"` — not yet evaluated
   - `EVALUATED = "evaluated"` — evaluated, complex model wins
   - `REJECTED = "rejected"` — evaluated, baseline wins or tie
   - `INSUFFICIENT_DATA = "insufficient_data"` — n < 30 or data quality issues

2. **ModelScore dataclass** (frozen=True):
   - `agent_id: str`, `sharpe: float`, `win_rate: float`, `mean_pnl_r: float`, `complexity_score: float`, `n: int`, `returns: tuple[float, ...]`

3. **OccamResult dataclass** (frozen=True):
   - `complex_model: ModelScore`, `baseline: ModelScore`, `winner: str` (literal "complex"/"baseline"/"tie"), `ci_lower: float`, `ci_upper: float`, `sharpe_delta: float`, `penalized_delta: float`, `recommendation: str` (literal "retain_shadow"/"reject_complex"), `state: EVAL_STATE`

4. **_bootstrap_paired_delta()** method:
   - Signature: `(self, complex_returns: list[float], baseline_returns: list[float], n_boot: int = 1000) -> tuple[float, float, float]` — returns (mean_delta, ci_lower, ci_upper)
   - PAIRED BOOTSTRAP: `delta_t = complex_return_t - baseline_return_t` for each timestamp-aligned pair. The two lists MUST have equal length. Raise `ValueError("length mismatch")` if not.
   - Bootstrap resamples the paired deltas (NOT the two return series independently). This is the critical fix from review feedback.
   - For each of n_boot iterations: `rng.choice(delta_arr, size=n, replace=True)` → compute mean of resample → collect boot_means
   - ci_lower = percentile(boot_means, 2.5), ci_upper = percentile(boot_means, 97.5)
   - Guard: if `len(complex_returns) < 30` → return `(0.0, float('-inf'), float('inf'))` with state INSUFFICIENT_DATA
   - Guard: if `np.std(delta_arr) < 1e-9` → zero volatility, return `(0.0, 0.0, 0.0)`
   - Guard: if any NaN in inputs → raise `ValueError("NaN in returns")`
   - Fixed seed `np.random.default_rng(42)` for reproducibility

5. **_compute_complexity_score()** method (per D-02):
   - Signature: `(self, n_params: int, latency_ms: float, train_time_ms: float) -> float`
   - Formula: `log(n_params + 1) * (1 + latency_ms / 1000) * (1 + train_time_ms / 60000)`
   - Raise `ValueError` if `n_params < 0`
   - Return `0.0` for `n_params=0, latency=0, train_time=0` (log(1) * 1 * 1 = 0)

6. **_compare_models()** method — the EXPLICIT penalized decision rule:
   - Signature: `(self, complex_score: ModelScore, baseline_score: ModelScore, complex_returns: list[float], baseline_returns: list[float]) -> OccamResult`
   - Step 1: Compute raw sharpe_delta = complex_score.sharpe - baseline_score.sharpe
   - Step 2: Compute complexity_ratio = complex_score.complexity_score / max(baseline_score.complexity_score, 0.001)
   - Step 3: Compute penalty = self._penalty_weight * np.log1p(complexity_ratio)
   - Step 4: Run paired bootstrap: `mean_delta, ci_lower, ci_upper = self._bootstrap_paired_delta(complex_returns, baseline_returns)`
   - Step 5: Compute penalized_delta = mean_delta - penalty
   - Step 6: Adjust CI bounds by penalty: `penalized_ci_lower = ci_lower - penalty`, `penalized_ci_upper = ci_upper - penalty`
   - Step 7: Decision:
     - If `penalized_ci_lower > 0` → winner="complex", recommendation="retain_shadow", state=EVALUATED
     - If `penalized_ci_upper < 0` → winner="baseline", recommendation="reject_complex", state=REJECTED
     - Else (CI spans 0) → winner="tie", recommendation="reject_complex", state=REJECTED
   - NO simplified CI path. NO fallback t-test. Always use full paired bootstrap.

7. **OccamRazorEvaluator class** (inherits from Evaluator):
   - Class attrs: `agent_id = "occam_razor"`, `group = "alpha"`, `tiers_needed = frozenset()`, `latency_budget_ms = 1000.0`, `shadow_only = True`
   - `__init__(self, *, dependencies, **kwargs)`: store `self._pool = dependencies.pool` (raise ValueError if None), `self._penalty_weight = float(os.environ.get("OCCAM_PENALTY_WEIGHT", "0.5"))`
   - `_compute()` returns `self._neutral(error="occam_razor_runs_in_graduation_cycle_only")` — ORE runs in background cycle, not per-signal
