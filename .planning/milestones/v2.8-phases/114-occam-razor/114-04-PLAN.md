Create `tests/unit/intelligence/ai/evaluators/test_occam_e2e.py`:

**GOLDEN DATASET E2E TEST** — tests the full pipeline from raw returns through baseline construction, paired bootstrap, penalized decision, to OccamResult, without DB:

1. **test_e2e_complex_outperforms**:
   - Generate 100 deterministic paired returns: complex = baseline + 0.03 + noise(seed=42)
   - Build features from complex returns (reshape to 2D), targets = (pnl_r > 0).astype(int)
   - Use LinearBaseline: fit(features, targets), predict(features) → baseline_returns
   - Compute Sharpe for both, build ModelScores
   - Call OccamRazorEvaluator._compare_models(complex_score, baseline_score, complex_returns, baseline_returns_list)
   - Assert: winner=="complex", state==EVALUATED, sharpe_delta > 0
   - Record exact values: `assert result.ci_lower > 0` (complex wins even with penalty)
   - Record: `assert result.penalized_delta > 0`

2. **test_e2e_baseline_outperforms**:
   - Generate 100 returns where baseline consistently beats complex
   - Same pipeline as above
   - Assert: winner=="baseline", state==REJECTED

3. **test_e2e_complexity_penalty_applied**:
   - Set complexity_ratio high (complex_score=10.0, baseline_score=1.0)
   - With penalty_weight=0.5, penalty = 0.5 * log1p(10) ≈ 1.20
   - Complex Sharpe must exceed baseline by > 1.20 to win
   - Create returns where raw sharpe_delta is positive but < 1.20
   - Assert: recommendation=="reject_complex" despite positive raw delta

4. **test_e2e_insufficient_data_skips**:
   - 15 returns → _bootstrap_paired_delta returns (0.0, -inf, inf)
   - OccamResult.state == INSUFFICIENT_DATA

5. **test_e2e_deterministic_reproducibility**:
   - Run test_e2e_complex_outperforms twice with same seeds
   - Assert identical ci_lower, ci_upper, penalized_delta values
   - Proves fixed-seed reproducibility

All tests use mock AgentDependencies (no DB pool, no Kafka). Tests verify the STATISTICAL pipeline end-to-end, not the DB writes (those are integration tests outside scope).
