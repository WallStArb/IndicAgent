<objective>
Component F (todo 097, P1). Add a vol-normalized return target - `return_x / trailing_sigma(symbol)` using `true_range_pct` as the sigma proxy - for POOLED-strata IC, and compare it against the raw-return baseline as an EXPLICIT A/B. The ensemble trains exclusively on POOLED strata, where raw-return ranks are dominated by whichever symbols are running hot on a given bar - a real bias against the ensemble's training population.

Purpose/locked contract: this is a measured A/B, NOT a silent swap. Because Components A, E, and F all touch the same `ic_ci_lower`/`ic_ci_upper` numbers in the same corpus re-run, landing F as a silent replacement would confound attribution. If vol-normalized rankings are materially identical to the raw baseline, retire the transform rather than keep it on theory alone.

Sequenced after A (rides the same corpus load, uses the corrected CI), before E. Uses `true_range_pct` (already loaded in `_compute_cross_sectional_tf`'s query, raw non-z-scored, zero marginal cost) - NOT `atr_z` (already z-scored, unusable as a sigma denominator) and NOT a new rolling-window vol computation (RESEARCH resolved item 8, Assumption A1).

Output: an epsilon-guarded vol-normalization helper reachable by the cross-sectional path, a read-only A/B diagnostic script, unit coverage. This plan does not change the production return target.
</objective>
