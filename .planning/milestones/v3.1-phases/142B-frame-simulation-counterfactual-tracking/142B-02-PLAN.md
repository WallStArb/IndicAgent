<objective>
Build `CounterfactualTracker` — the `BaseBatch` oneshot that, in one streaming sweep per (symbol, tf)
cell, computes each open frame's price-unit ATR and T+1 entry from `market_data_ohlcv`, fills the
frame geometry, scans the subsequent price path to close it via the four-trigger DIRECTION-AWARE state
machine (FRAME-02/03), scores counterfactual P&L, and evaluates the FRAME-04 exit gate (day-clustered
block bootstrap per (tf, regime)). Depends on Plan 01's migration and AlphaFrameWriter output.

Purpose: this is where hypothetical positions become measured counterfactual outcomes — the number
that answers Phase 142B's binary question (can a sensible frame capture the IC as positive P&L). This
plan was revised from a cross-AI review (142B-REVIEWS.md). The single most important fix is H3: the
prior `determine_exit` was long-only and would have closed every `direction='short'` frame as an
instant false stop-out, silently corrupting ~half the corpus while passing every test. It is now
direction-aware with mandatory short-frame test cases. Other fixes: H4 (BCa infeasible + overlap-blind
→ day-clustered block bootstrap), H2/M2/M4 (ATR source + single-sweep geometry fill), M3 (UPDATE key),
L2 (executable gap-through fills), L3 (edge cases). The correctness-critical infrastructure requirement
remains fidelity to the proven anti-OOM patterns on BOTH sides: a named psycopg2 cursor on the read
side and per-symbol incremental flush on the write side.

Output: `services/counterfactual_tracker.py` (pure-fn exit/pnl/gate cores + service + gate mode), an
IC-staleness gauge, service registration, RED→GREEN tests (including explicit short-frame cases), and
the D-10 follow-on todo.
</objective>

    - Bar carries open/high/low/close (open is required for gap-through fills, review L2).
    - determine_exit(direction, bars_since_entry, stop_price, target_price, hold_max_bars, ic_ci_lower):
      empty bars_since_entry → return None (frame stays open; never fabricate a close, review L3b).
      Per-bar, in priority order (stop checked before target — conservative on a same-bar both-hit):
        direction='long':
          (1) bar.low <= stop_price → closed_stop, exit_price = min(bar.open, stop_price)  [gap-through worse fill, L2]
          (2) bar.high >= target_price → closed_target, exit_price = target_price           [conservative limit fill]
        direction='short':
          (1) bar.high >= stop_price → closed_stop, exit_price = max(bar.open, stop_price)   [gap-through worse fill, L2]
          (2) bar.low <= target_price → closed_target, exit_price = target_price             [conservative limit fill]
        both directions:
          (3) i >= hold_max_bars → closed_max_hold, exit_price = bar.close
      After the bar loop with no per-bar exit: (4) ic_ci_lower is not None and < 0 → closed_ic_decay,
      exit_price = last bar.close; else None (still open). bars = i (1-indexed from entry).
    - compute_frame_pnl_r(direction, entry_price, stop_price, exit_price) -> float:
      risk = abs(entry_price - stop_price) (the stop distance, always positive).
      long → (exit_price - entry_price) / risk ; short → (entry_price - exit_price) / risk.
      A stop-out is ~ -1.0 R; a target hit is ~ +target_r_multiple R (both directions).
    - frame_gate_passes(pnl_r_values, cluster_ids, min_n, bootstrap_max_n, bootstrap_batch) -> (passes, ci_lower, ci_upper):
      if len(pnl_r_values) < min_n → (False, nan, nan) [frame-count sufficiency floor, alpha.scoring.min_strategy_n].
      Aggregate pnl to per-cluster means (group by cluster_id = calendar date) → cluster_means (review H4).
      if len(cluster_means) < 2 → (False, nan, nan) [cannot form a CI from <2 blocks].
      if len(cluster_means) <= bootstrap_max_n: scipy.stats.bootstrap(cluster_means, np.mean,
        confidence_level=0.95, alternative='greater', method='BCa', batch=bootstrap_batch) → ci_lower.
      else: analytic one-sided 95% CLT lower bound ci_lower = mean - 1.645 * std(ddof=1)/sqrt(n_clusters)
        (BCa's jackknife is infeasible and its bias-correction negligible at this cluster count, review H4).
      passes iff ci_lower > 0; returns (passes, ci_lower, ci_upper).
