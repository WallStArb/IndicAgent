## Decisions Made

- Combined Tasks 1-3's helper implementations into a single Edit/commit (`55294c0a`) since all
  three groups are small, independent, pure-function additions in the same file region with no
  cross-task dependency risk; documented here rather than 3 near-identical micro-commits.
- Combined Task 5 (wiring) and Task 7 (domain/cold-start/registry) into one commit (`dcf2aad7`):
  splitting them would leave an intermediate commit where `compute()` is wired but
  `_cold_start_vector()` still raises `TypeError` on any bar history shorter than 2 -- not a
  meaningfully-separable unit of work.
- `ret_lag_*` in `compute_batch()` reads `closes[:i+1]` (a numpy view, O(1) to construct) rather
  than the pre-existing bounded `w_closes` window array, because `ret_lag_slow`'s APR window
  (test default 60) can exceed `MIN_WINDOW` (test default 40, driven by CCI/Aroon/vol_ratio/CMF
  periods) -- using the bounded window would silently read the wrong bar or raise IndexError at
  scale. `overnight_gap_z` instead gets a dedicated O(n) `_series_full` precompute (matching the
  existing pattern for every other z-scored primitive in the file) since its streaming
  implementation rebuilds a full array per call, making a naive per-bar loop O(n^2).
