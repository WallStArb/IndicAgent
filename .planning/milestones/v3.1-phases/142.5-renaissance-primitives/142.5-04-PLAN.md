## Alternative Volatility Estimators (3)

| Feature | Estimator | APR Key |
|---|---|---|
| `parkinson_vol_z` | z-score of `ln(H/L)^2 / (4*ln(2))` | `feature.parkinson_vol.window` |
| `garman_klass_vol_z` | z-score of GK estimator | `feature.garman_klass_vol.window` |
| `yang_zhang_vol_z` | z-score of YZ estimator | `feature.yang_zhang_vol.window` |

GK: `0.5*ln(H/L)^2 - (2*ln(2)-1)*ln(C/O)^2`. YZ: `var(overnight) + k*var(open-to-close)`, k ≈ 0.34.

## Volatility Dynamics Primitives (5)

| Feature | Formula | APR Key |
|---|---|---|
| `parkinson_vol_velocity` | `parkinson_vol_z_t - parkinson_vol_z_{t-1}` | None |
| `garman_klass_vol_velocity` | `garman_klass_vol_z_t - garman_klass_vol_z_{t-1}` | None |
| `yang_zhang_vol_velocity` | `yang_zhang_vol_z_t - yang_zhang_vol_z_{t-1}` | None |
| `vol_velocity_z` | z-score of rolling `atr_z` velocity | `feature.vol_velocity.window` |
| `intraday_noise_ratio` | `sum(\|ret\|) / \|net_ret\|` over session | `feature.intraday_noise.window` |

## Cold-start contract (antigravity H1)

`_cold_start_vector()` (~line 1506) constructs FeatureVector with a kwarg for every field. All 8 new
fields get fallback 0.0 (z-scores and velocities are centered at 0; intraday_noise_ratio -> 1.0).
