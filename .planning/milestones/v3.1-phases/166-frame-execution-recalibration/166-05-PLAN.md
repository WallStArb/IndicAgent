<objective>
Wire BOTH candidates into `AlphaFrameWriter` (D-01b, D-01c, D-03) so Plan 166-06 can regenerate a
distinct OOS frame population per candidate for the gate to score. Add an `alpha.frame.geometry_source`
dispatch (global | per_cell_scalar | structural) driving which stop/target the writer snapshots
onto each frame.

Purpose: The gate compares candidates by scoring the frame populations they produce. The writer
is the single place frame geometry is chosen and snapshotted (DAG Invariant 3 — geometry computed
in the write pass, persisted via the existing batch flush, no second inline write path). `global`
must remain the default and byte-identical to current behavior (backward-compatible).

Design:
- `per_cell_scalar`: mirror the existing `hold_key` lookup pattern exactly — look up
  `alpha.frame.stop_atr_mult.{regime}.{tf}` / `alpha.frame.target_r_multiple.{regime}.{tf}` with a
  `_cfg(cfg, key, <global scalar>)` fallback; accumulate missing keys in a set logged once per
  partition. Feed the resolved multipliers into the existing `compute_frame_geometry` UNMODIFIED.
- `structural`: call `structural_confluence.resolve_structural_zone(features, direction, entry,
  stop_seed, atr)` to get a confluence stop price; when tier != "atr" derive the frame from that
  structural stop (target from the per-cell/global target_r_multiple applied to the structural
  stop distance); when tier == "atr" fall back to the scalar geometry. Preserve
  `compute_frame_geometry`'s `atr<=0` / `min_stop_price_fraction` ValueError-skip contract (todo
  162) for both modes — callers already catch and skip.
- All modes snapshot the chosen `stop_atr_mult`/effective values onto the `alpha_frames` row at
  scan time (Phase 142B snapshot discipline), never a live join at simulation time.
</objective>
