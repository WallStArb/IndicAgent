    - `_classify_broadcast` returns a three-way verdict, not a bool. Given per-`bar_ts` arrays where
      every group's cross-symbol spread is within epsilon AND the per-group representative values
      differ across at least two distinct `bar_ts` groups, the verdict is `broadcast`.
    - Given per-`bar_ts` arrays where every group's cross-symbol spread is within epsilon BUT every
      group's representative value is identical across all `bar_ts` groups (a globally-constant
      feature, e.g. an event flag that never fired in the window), the verdict is `inconclusive` —
      NOT `broadcast`. This is the `sweep_detected` / `manip_strength` false-positive case.
    - Given a single `bar_ts` group only, the verdict is `inconclusive` — one group carries no
      temporal evidence, so the guard cannot be satisfied even when the cross-symbol spread is zero.
    - Given any group whose cross-symbol spread exceeds epsilon, the verdict is `idiosyncratic`.
      This check runs FIRST: an idiosyncratic verdict is never downgraded to `inconclusive` by the
      temporal guard.
    - Given fewer than 2 finite values in every group, the verdict is `inconclusive`.
    - Given an empty input dict, the verdict is `inconclusive` (no evidence in either direction).
    - The JSONB merge helper produces an UPDATE whose SET clause merges rather than replaces: a row
      whose metadata already carries `tier`/`apr_namespace` retains both after the write.
