## Accomplishments
- `shrink_ic` implements `w = n_eff/(n_eff+k)` empirical-Bayes mixing with an explicit `n_eff <= 0` degenerate guard returning the prior untouched (no NaN, no raise, no divide-by-zero)
- `leave_one_out_group_prior` computes the peer-group prior excluding the cell being shrunk, correct and non-dividing-by-zero at the smallest real peer-group size (n=3, matching `cross_tf`/`macro` groups per D-06)
- `mean_variance_weights` added to `weights.py` alongside `derive_weights`/`cluster_deflate_weights`: computes `Sigma^-1.ic_shrunk` via `np.linalg.solve` (never `np.linalg.inv`), gated on `np.linalg.cond` (2-norm) against `condition_max`, returns `(None, cond)` on gate failure and raw uncapped/unsigned normalized weights otherwise
- All behaviors locked by 15 new green unit tests, written RED-first (both new test files failed on missing module/function before implementation)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Test premise error: near-singular matrix does not produce a literal `inf` condition number**
- **Found during:** Task 2 (mean_variance_weights GREEN verification)
- **Issue:** `test_non_finite_cond_returns_none` originally used a near-duplicate-row matrix (`[[1, 0.999999999, 0], [0.999999999, 1, 0], [0, 0, 1]]`) expecting `cond == inf`. In practice `np.linalg.cond` on a near-singular (but not exactly singular under floating point) matrix returns a very large finite number (`~5.96e16`), not `inf`. This is a test bug, not a `mean_variance_weights` bug — the finite-large-cond case is already correctly covered by the separate `test_ill_conditioned_returns_none_and_cond` test.
- **Fix:** Changed the non-finite test fixture to an exact all-zero `2x2` matrix, which `np.linalg.cond` correctly reports as `inf` (confirmed via direct interpreter check before editing).
- **Files modified:** `tests/unit/test_ensemble_mean_variance.py`
- **Verification:** `.venv/bin/pytest tests/unit/test_ensemble_mean_variance.py -v` — all 6 tests pass, including both the finite-large-cond and the genuinely-non-finite-cond gate paths.
- **Committed in:** `799ef9bc` (part of Task 2 GREEN commit)
