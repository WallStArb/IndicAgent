<objective>
Implement E2: wire the `mean_variance_weights()` function (from Plan 02) into `ensemble_trainer.py::_process_stratum` as an alternative to the binary cluster-deflation heuristic, selected by `alpha.ensemble.weight_method`. Use the Ledoit-Wolf covariance the trainer already computes every run but currently only uses for clustering. Gate on covariance condition number (D-08) with a logged fallback to the existing cluster-deflation path when ill-conditioned.

Purpose: Two 0.79-correlated features that escape the existing 0.80 cluster cutoff both get full weight today; `w ∝ Σ⁻¹·IC` down-weights them continuously by their true covariance contribution (Grinold-Kahn). This replaces the binary cap with continuous decorrelation. Because Σ⁻¹ on an ill-conditioned covariance produces enormous offsetting long/short weights on near-duplicate features (Pitfall 3), the condition-number gate is enforced, not advisory: on failure the stratum falls back to the proven cluster-deflation path and logs it (never a silent skip). E2 combines over `ic_shrunk` (E1's de-noised inputs, D-04) — it depends on Plan 03 having landed.

Output: `ensemble_trainer.py` weight_method branch, unit test for branch + fallback.
</objective>
