<objective>
Build the generic cross-sectional regime dispatcher `services/cross_sectional_regime_model.py` that
generalizes `equity_regime_model.py`: for each enabled `alpha.regime.groups` entry, resolve peer
symbols by tag_filter, fetch their bars, pre-scale window params via `_tf_window`, call
`REGISTRY[signal_type].compute()`, bucket into labels, and upsert `regime_group`-labelled rows to
`market_regimes`. Wire the `REGISTRY`, add the deprecation header to `equity_regime_model.py`, and
swap the corpus pipeline's step-4 slot to the new dispatcher.

CRITICAL CORRECTIONS applied (PATTERNS.md / RESEARCH.md):
- JSON config parsing: `cfg.get_sync("alpha.regime.groups", ...)` returns an ALREADY-PARSED
  `list[dict]` once the key is seeded (config_service.py:94-95 json.loads at cache-load time). The
  plan doc's `_parse_group_configs(raw: str)` and `str(cfg.get_sync(...))` are BUGS — fix them.
- This file family does NOT use `BaseBatch` — follow `equity_regime_model.py`'s plain argparse +
  `JOB_COMPLETED_TOTAL` `main()` pattern.
- NO `ProcessPoolExecutor` in the dispatcher (DB fetch is the bottleneck; label assignment is
  vectorized numpy).
- Pipeline edit is a same-slot script-name swap, NOT a step insertion (pipeline is already 8 steps).

Purpose: The dispatcher is the writer of group-scoped regime labels consumed by ic_engine (Plan 05).
Output: dispatcher + registry + deprecation header + pipeline swap + test.
