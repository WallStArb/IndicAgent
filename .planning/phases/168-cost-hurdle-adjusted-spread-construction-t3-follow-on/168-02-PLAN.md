def decile_legs(
    ranked_symbols: Sequence[str],
    feature_values: Sequence[float],
    decile_fraction: float,
) -> tuple[list[str], list[str]] | None:
    """Returns (short_leg, long_leg), or None if n < 2 * n_leg.
    n_leg = max(1, int(round(n * decile_fraction))).
    Raises ValueError on length mismatch or a None/non-finite feature value.
    Ranks by `sorted(zip(feature_values, ranked_symbols))` ascending — so ties break on
    (feature_value, symbol) ascending; short_leg = ranked[:n_leg], long_leg = ranked[-n_leg:].
    Both returned lists are therefore in ascending (value, symbol) order."""

def one_way_turnover(
    prev_long: frozenset[str], prev_short: frozenset[str],
    cur_long: frozenset[str], cur_short: frozenset[str],
) -> float | None:
    """mean(len(cur_long - prev_long)/n_leg, len(cur_short - prev_short)/n_leg) where
    n_leg = len(cur_long). Returns None (never 0.0) when both prev sets are empty."""

def validate_construction_config(
    decile_fraction: float,
    cost_bps: Sequence[int],
    null_shuffles: int,
    attribution_max_static_r2: float,
) -> None:
    """Raises ValueError naming the offending key and value. Never clamps."""

Add `hysteresis_legs()` to `services/cross_sectional_spread_tracker.py`, immediately after

`hysteresis_legs(prior_long: frozenset[str], prior_short: frozenset[str], ranked_symbols:
Sequence[str], feature_values: Sequence[float], decile_fraction: float, margin: float) ->
tuple[list[str], list[str]] | None`

Returning `(short_leg, long_leg)` — the same ordering convention as `decile_legs`, so the two are
drop-in interchangeable at every call site.

Algorithm, locked:
1. Validate `margin`: raise `ValueError` naming the value if `margin` is `None`, fails
   `math.isfinite`, or is negative. Fail loud, never clamp (module convention).
2. `ideal = decile_legs(ranked_symbols, feature_values, decile_fraction)`. This delegates ALL
   input validation (length mismatch, None/non-finite feature values) — do not re-implement it.
   If `ideal is None`, return `None`: the degeneracy rule is identical to the baseline's, so the
   eligible-bar set is identical between the two constructions by construction.
3. `n_leg = len(ideal_long)` where `ideal_short, ideal_long = ideal`.
4. Build `value_by_symbol = dict(zip(ranked_symbols, feature_values, strict=True))` and
   `present = set(ranked_symbols)`.
5. Force-exit absent holdings (Pitfall 3): `held_long = {s for s in prior_long if s in present}`,
   `held_short = {s for s in prior_short if s in present}`. A held symbol with no row this bar has
   no return series to attribute a position to; hysteresis must never override this.
6. If `held_long & held_short` is non-empty, raise `ValueError` naming the overlapping symbols —
   that is a corrupt prior state, not a recoverable condition.
7. Resolve the LONG leg first via the shared inner resolver with `direction=+1`,
   `held=held_long`, `blocked=held_short`. Then resolve the SHORT leg with `direction=-1`,
   `held=held_short`, `blocked=set(long_leg)`. This sequential-with-exclusion ordering makes
   long/short disjointness structural rather than merely asserted (Pitfall 4). Record the
   long-first asymmetry explicitly in the docstring as a deliberate, arbitrary-but-fixed
   tiebreak — a symbol held short cannot become a long challenger in the same bar without first
   exiting short.
8. Inner resolver contract, for a given `direction` (+1 means higher value is stronger, -1 means
   lower is stronger), `held` set, and `blocked` set:
   - Order key: sort every candidate by `(feature_value, symbol)` ascending — the identical tie
     convention `decile_legs` uses. For `direction=+1`, "strongest" is the LAST element of that
     ordering; for `direction=-1`, "strongest" is the FIRST. Never introduce a second tie rule.
   - Maintain the working leg as a list kept sorted weakest-first for the current `direction`
     (for `direction=+1`, ascending by `(feature_value, symbol)`; for `direction=-1`, descending).
     Under this representation the weakest member is always `leg[0]` and a displacement is a pop
     of index 0 followed by an ordered re-insert of the challenger. Initialize
     `leg = sorted(held, key=...)` for that direction.
   - If `len(leg) > n_leg`, trim weakest-first (pop index 0 repeatedly) down to `n_leg` — the
     universe shrank.
   - `challengers` = symbols in `present` that are in neither `held` nor `blocked`, ordered
     strongest-first for this `direction`.
   - Fill: while `len(leg) < n_leg` and challengers remain, admit the strongest remaining
     challenger unconditionally (an empty slot costs no displacement, so no margin applies),
     inserting it in weakest-first order.
   - Displace: while challengers remain, compare the strongest remaining challenger against
     `leg[0]` — the CURRENT weakest leg member, re-read from the mutated list on every iteration.
     If `direction * (value[challenger] - value[leg[0]]) > margin`, pop `leg[0]`, insert the
     challenger in weakest-first order, and consume that challenger; otherwise stop.
     EXPLICIT REQUIREMENT: the weakest member MUST be re-determined after every accepted
     displacement, never cached across iterations and never captured once before the loop. When a
     challenger displaces `leg[0]`, the second-weakest held member becomes the new `leg[0]` and is
     the comparison target for the NEXT challenger. Multiple displacements in a single bar are
     therefore legal and expected; comparing challenger N+1 against an already-evicted symbol, or
     against a fixed index into a list mutated underneath it, is a silent wrong answer that
     `test_hysteresis_legs_multiple_displacements_in_one_bar` exists to catch. State this
     re-evaluation requirement as a named invariant in the docstring.
     The loop terminates because each iteration either consumes exactly one challenger or breaks.
   - Return the leg sorted ascending by `(feature_value, symbol)` — matching `decile_legs`'
     output ordering so the two are byte-comparable in tests and in persisted `text[]` columns.
     (Note this is the *return* ordering; it differs from the weakest-first working ordering for
     `direction=-1`, so sort explicitly on return rather than returning the working list.)
9. Final defense-in-depth invariant: if `set(long_leg) & set(short_leg)` is non-empty, raise
   `ValueError` naming the symbols. Step 7 makes this unreachable; a raise here converts a future
   refactor bug from a silent wrong answer into a loud crash (CLAUDE.md).
