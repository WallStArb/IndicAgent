four-part gate live and record whatever it says.

Purpose: RESEARCH Pitfall 1 is the sharpest trap in this phase. `shuffled_ranking_null_p` is
memoryless: it permutes one bar's values and recomputes legs from scratch, per bar, per draw. The
hysteresis construction is stateful: this bar's legs depend on last bar's holdings. Swapping
`hysteresis_legs` into the existing null would compute hysteresis against the REAL unshuffled
prior legs while using SHUFFLED current ranks — a hybrid testing neither the real mechanism nor a
coherent null, running without error and producing a plausible but wrong `null_p`. D-04.4
requires this be reconfirmed, not inherited.

Output: a stateful null, a binding four-part `gate_delta_passes`, both partitions backfilled over
the identical window, and a real verdict artifact under `logs/construction_verdicts/` whose
result is transcribed into `docs/research/trade-construction-layer.md`.

  cover it in a test.

  degenerate bar formed no position, an unmeasurable-return bar did.
