## Summary

Simplified `SignalReplayAuditorAgent` to use the now-self-contained `signal_ledger` (no LATERAL JOIN), switched to true TTL-based candidate selection via `expires_at < NOW()`, enforced NULL zone DLQ behavior, and moved hardcoded constants to `Settings` with canary defaults.

## What Was Built

### Task 1: Settings fields
Added `replay_batch_size` (default 100) and `replay_interval_seconds` (default 300) to `src/config/settings.py`. These replace the triage-only hardcoded values (2000/30) with safe canary defaults. Operators can override via `REPLAY_BATCH_SIZE`/`REPLAY_INTERVAL_SECONDS` env vars.

### Task 2: Replay auditor overhaul (`services/signal_replay_auditor_agent.py`)
- **LATERAL JOIN removed**: `_fetch_unresolved` now reads `entry_zone_low`/`entry_zone_high` directly from `signal_ledger_full` (populated by Plans 02-03). Eliminated the fragile LEFT JOIN to `intelligence_features` + `jsonb_array_elements`.
- **Candidate filter**: `sl.expires_at < NOW()` (true TTL) replaces `sl.timestamp < NOW() - INTERVAL '2 minutes'` (fixed offset). Added `sl.expires_at IS NOT NULL` guard so NULL-expires rows are never silently treated as expired.
- **NULL zone DLQ**: `_build_signal_dict` now increments `SIGNAL_REPLAY_NULL_ZONE_TOTAL` counter and returns `None` (skip) when `entry_zone_low`/`entry_zone_high` are NULL. `_replay_signal` checks for `None` and returns `False`. No silent fallback to `entry_price`.
- **Settings-driven params**: `LIMIT $2` uses `self.settings.replay_batch_size`; `asyncio.wait_for` timeout uses `self.settings.replay_interval_seconds`.
- **Constants removed**: Module-level `REPLAY_INTERVAL_SECONDS = 30` and class-level `_BATCH_SIZE = 2000` deleted.
- **`_count_unresolved`** aligned: gauge query also uses `expires_at IS NOT NULL AND expires_at < NOW()` for consistency.

### Task 2b: New metric (`src/observability/metrics.py`)
Added `SIGNAL_REPLAY_NULL_ZONE_TOTAL` OTel counter for NULL zone skip events.
