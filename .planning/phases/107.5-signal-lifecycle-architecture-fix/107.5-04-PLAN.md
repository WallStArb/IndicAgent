  <action>
    Create `production/scripts/backfill_expires_at.py` as a standalone async script.

    The backfill is entirely self-contained within signal_ledger — no JOIN to other tables:

      UPDATE signal_ledger
      SET expires_at = timestamp + (ttl_bars * CASE feature_tf
          WHEN '1m'  THEN  60
          WHEN '5m'  THEN  300
          WHEN '15m' THEN  900
          WHEN '1h'  THEN  3600
          WHEN '4h'  THEN  14400
          WHEN '1d'  THEN  86400
          ELSE 60
          END) * INTERVAL '1 second'
      WHERE expires_at IS NULL
        AND ttl_bars IS NOT NULL
        AND feature_tf IS NOT NULL
        AND signal_id IN (
            SELECT signal_id FROM signal_ledger
            WHERE expires_at IS NULL
              AND ttl_bars IS NOT NULL
              AND feature_tf IS NOT NULL
            LIMIT 10000
        )

    Loop in 10k batches until rows_affected == 0. Sleep 50ms between batches.

    After loop, count signals where expires_at IS STILL NULL (ttl_bars IS NULL or feature_tf IS NULL — these are data quality issues, not backfill failures).

    Print reconciliation report:
      === EXPIRES_AT BACKFILL COMPLETE ===
      Before: {before_null_count} NULL expires_at rows (of {total} total)
      Updated: {total_updated} rows in {batch_count} batches
      Still NULL (missing ttl_bars or feature_tf): {still_null} rows
      After: {after_null_count} NULL expires_at rows remaining

    DATABASE_URL from environment, asyncpg.connect for simplicity.

    Run the script after the migration is applied (expires_at column must exist).
  </action>
