<objective>
Remove the LATERAL JOIN from `SignalReplayAuditorAgent._fetch_unresolved`, enforce NULL zone DLQ behavior in `_build_signal_dict`, and move `REPLAY_BATCH_SIZE`/`REPLAY_INTERVAL_SECONDS` to `Settings` with canary defaults.

Purpose: Fixes 1-3 established that signal records are self-contained (zone fields and expires_at are populated). The replay auditor no longer needs to reconstruct zone fields via a fragile LATERAL JOIN. This final fix makes the replay auditor a true canary: simple query, low batch size, slow cycle, only processes what the live tracker genuinely missed. NULL zones = data integrity error, not a fallback.

Output: Two files — the replay auditor (LATERAL JOIN removal, NULL guard, Settings-driven params) and Settings (two new fields).
</objective>

       Replace the current query (which has LEFT JOIN intelligence_features + LATERAL jsonb_array_elements) with a simplified direct query:

         SELECT sl.signal_id, sl.symbol, sl.timeframe, sl.timestamp, sl.direction,
                sl.market_entry_price, sl.ttl_bars, sl.status, sl.activated_at,
                sl.hmm_regime_at_fire, sl.garch_sigma_at_fire, sl.expires_at,
                COALESCE(sl.entry_price::float, sl.activation_price) AS entry_price,
                sl.stop_loss::float                                   AS stop_loss,
                sl.targets                                            AS targets,
                sl.entry_zone_low::float                             AS entry_zone_low,
                sl.entry_zone_high::float                            AS entry_zone_high
         FROM signal_ledger_full sl
         WHERE sl.exit_at IS NULL
           AND sl.status IN ('pending', 'active')
           AND sl.timestamp < NOW() - INTERVAL '2 minutes'
           AND sl.signal_schema_version = $1
         ORDER BY sl.timestamp ASC
         LIMIT $2

    3. UPDATE _build_signal_dict — NULL zone guard:
       Replace the current fallback:
         "entry_zone_low": (float(row["entry_zone_low"]) if row["entry_zone_low"] is not None else entry_price),

       With strict NULL check (D-19: no silent fallback):
         zone_low = row["entry_zone_low"]

         if zone_low is None or zone_high is None:

                 "replay_null_zone_skip",
                 signal_id=str(row["signal_id"]),
                 symbol=row["symbol"],

             return None  # returning None causes _replay_signal to skip this signal
