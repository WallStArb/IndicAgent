  <files>services/shadow_auditor_agent.py</files>
  <read_first>

  </read_first>
  <action>
    Add `AND COALESCE(is_shadow, FALSE) = FALSE` to all graduation queries reading signal_ledger:

    1. Find all queries that read signal_ledger for graduation stats:
       - Promotion check: queries computing win_rate, ev_r, n_resolved, bootstrap_ci
       - Demotion check: queries computing consecutive_negative_ev cycles
       - Any query aggregating pnl_r by setup_plugin

    2. For each query, add the shadow filter:
       - BEFORE: `WHERE setup_plugin = $1 AND outcome IS NOT NULL`
       - AFTER: `WHERE setup_plugin = $1 AND outcome IS NOT NULL AND COALESCE(is_shadow, FALSE) = FALSE`

    3. Use COALESCE instead of bare `is_shadow = FALSE`:
       - Rationale: Historical rows may have NULL is_shadow (added in v1.4, older rows may lack it)
       - `is_shadow = FALSE` excludes NULLs (silently drops historical data)
       - `COALESCE(is_shadow, FALSE) = FALSE` treats NULL as FALSE (includes historical live signals)
       - Decision: Use COALESCE for safety — we'd rather include historical live signals than accidentally exclude them

    4. Add comment: `-- Exclude shadow signals: COALESCE handles NULL for historical rows pre-v1.4`

    Preserve all existing SQL parameter binding and threshold checks.
  </action>
  <verify>
    grep -n "COALESCE(is_shadow, FALSE) = FALSE" services/shadow_auditor_agent.py | wc -l
    grep -n "SELECT.*signal_ledger" services/shadow_auditor_agent.py | while read line; do
      if ! echo "$line" | grep -q "is_shadow"; then
        echo "MISSING is_shadow filter: $line"
        exit 1
      fi
    done
  </verify>
  <done>
