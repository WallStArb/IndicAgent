<objective>
Wave 1 engine (D-01, D-12) — the TagCalibrator batch service. A generic `BaseBatch` oneshot that
measures the full instrument × measurable-tag matrix (F8 Simons inversion), applies run-level BH-FDR,
and decides keep/expire/discover per pair with hysteresis. It drives entirely off
`(symbol, factor_series, measurement_type)` from `tag_vocabulary` (D-12) and calls factor_math for
all statistics.

Purpose: This replaces human-asserted tags with measured, falsifiable OLS loadings — the core
deliverable (TAG-01). Requires Plan 02's schema/contract and Plan 03's factor_math.
Output: tag_calibrator.py + its decision-logic tests.
</objective>

Revised calibration loop (design doc §"Revised calibration loop", authoritative):
- pass 1 (measure): for each (symbol, tag) where measurement_type != 'definitional' AND
  symbol != tag.factor_series (F6.1) AND symbol has >= lookback_days tradeable daily bars — compute
  loading, raw HAC p-value, sample_n; collect (pair, p) into the run-level p-vector. Long-short
  factor_series (contains a hyphen, e.g. 'HYG-IEF') → build via long_short_daily_returns on the two
  legs. Sentinel 'SPY_REALIZED_VOL' → spy_realized_vol_factor. Single symbol → its own tradeable returns.
- pass 2 (correct once): bh_adjusted_p, passes_fdr = apply_bh_fdr(p_vector, fdr_alpha).
- pass 3 (decide): keep = passes_fdr AND |loading| >= tag_vocabulary.loading_threshold.
  keep+row exists → UPSERT empirical row, consecutive_fails=0. keep+no row → INSERT pending-OOS until
  discovery_oos_days of disjoint data confirm; gap annotation if no human assertion. fail+empirical
  row → consecutive_fails += 1; expire (valid_to=now()+annotation) only if >= expiry_consecutive_fails.
  fail+human-only row → never expired; annotate the measured contradiction.
- OTel: tag_calibration_total{tag, outcome} (labels {tag, outcome} ONLY — never per-symbol, F6.4);
  job_completed_total emitted by BaseBatch.run().
