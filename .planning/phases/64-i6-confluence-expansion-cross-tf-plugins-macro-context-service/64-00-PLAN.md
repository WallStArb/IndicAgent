Signature:
```python
def backtest_i6_plugin(
    plugin_class: type,
    start_date: datetime,
    end_date: datetime,
    symbols: list[str] | None = None,
    timeframes: list[str] | None = None,
) -> pd.DataFrame:
    """Backtest I6 plugin on historical data.

    Args:
        plugin_class: I6 plugin class (e.g., CrossTFMomentumDivergencePlugin)
        start_date: Backtest start date (UTC)
        end_date: Backtest end date (UTC)
        symbols: Optional symbol filter (default: all active contracts)
        timeframes: Optional timeframe filter (default: _STANDARD_TFS)

    Returns:
        DataFrame with columns:
        - ts (timestamp)
        - symbol (str)
        - tf (str)
        - {output_field}_value for each plugin output
        - pnl_r (float, from signal_ledger JOIN)
        - hmm_regime (int, from intelligence_features)

    Raises:
        ValueError: If plugin_class doesn't have compute_full() method
    """
```

Implementation steps:
1. Import asyncpg, connect to TimescaleDB
2. Query intelligence_features for I1-I5 inputs in date range
3. Group by (symbol, tf), build frames dict per bar
4. Instantiate plugin_class, call compute_full(frames) per bar
5. Collect outputs in list
6. Query signal_ledger for pnl_r outcomes via JOIN
7. Return combined DataFrame

CLI interface:
```bash
python tools/backtest_i6_plugin.py \
  --plugin CrossTFMomentumDivergencePlugin \
  --start 2025-10-01 \
  --end 2026-04-01 \
  --output backtest_results.csv
```

Error handling:
- If plugin.compute_full() raises: log error, skip bar, continue
- If symbol not in signal_ledger: set pnl_r = None
- If timeframe not in _STANDARD_TFS: skip

Performance:
- Use asyncpg connection pool (10 connections)
- Batch queries by symbol/tf to avoid memory blowout
- Progress bar: tqdm for bar count
</description>

Signature:
```python
@dataclass
class ValidationResults:
    """Validation results for I6 field backtest."""
    field_name: str
    n: int  # sample size
    ic: float  # information coefficient (pearsonr)
    p_value: float  # statistical significance
    passed: bool  # IC > 0.05 AND p < 0.01
    regime_results: dict[str, 'ValidationResults']  # per-regime breakdown

def validate_backtest_results(
    df: pd.DataFrame,
    field_name: str,
    min_ic: float = 0.05,
    alpha: float = 0.01,  # Bonferroni-corrected
    min_n: int = 30,
) -> ValidationResults:
    """Validate backtest results using IC + p-value.

    Args:
        df: Backtest DataFrame from backtest_i6_plugin()
        field_name: Field to validate (e.g., "ctf_momentum_divergence")
        min_ic: Minimum IC threshold (default: 0.05)
        alpha: Significance threshold (default: 0.01 for 5 tests)
        min_n: Minimum sample size (default: 30)

    Returns:
        ValidationResults with overall + regime-segmented statistics

    Validation criteria:
        - IC > min_ic (effect size)
        - p_value < alpha (statistical significance)
        - n >= min_n (sufficient data)
        - At least 1 regime passes (trending OR ranging OR volatile)
    """
```

Implementation steps:
1. Filter df to rows where field_name is not null
2. Compute overall pearsonr(field_value, pnl_r)
3. Filter by hmm_regime (0=ranging, 1/2=trending), compute per-regime IC
4. Return ValidationResults with passed flag

CLI interface:
```bash
python tools/validate_i6_backtest.py \
  --input backtest_results.csv \
  --field ctf_momentum_divergence \
  --min-ic 0.05 \
  --alpha 0.01
```

Output format:
```
Validation Results: ctf_momentum_divergence
Overall: IC=0.082, p=0.003, n=1247 ✓ PASSED
Regimes:
  hmm_regime=0 (ranging): IC=0.034, p=0.042, n=423 ✗ FAILED
  hmm_regime=1 (trending_up): IC=0.124, p=0.001, n=518 ✓ PASSED
  hmm_regime=2 (trending_down): IC=0.091, p=0.018, n=306 ✓ PASSED

Conclusion: Plugin shows strong signal in trending regimes, weak in ranging.
Recommendation: Deploy to shadow mode, monitor regime-specific performance.
```
