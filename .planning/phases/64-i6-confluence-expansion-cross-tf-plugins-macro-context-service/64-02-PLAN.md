       ```python
       #!/usr/bin/env python3
       """MacroContextComputeAgent — Thin orchestrator for macro factor plugins.

       Subscribes to market.bars. Updates bar cache for ALL symbols, but only
       triggers full factor recomputation when a macro-relevant instrument's bar
       arrives (MACRO_ALL_SYMBOLS gate — per D-22). Non-macro bars update the
       cache silently to keep prev_close tracking current.

       Publishes to intelligence.macro_context. Pipeline injects via frames["macro"].
       """
       ```
       - Class `MacroContextComputeAgent(BaseAgent)`:
         - `__init__`: metrics_port=9135, name="macro_context_compute_agent"
         - `self._bar_cache: dict[str, dict] = {}` — latest bar per symbol (with close + prev_close)
         - `self._prev_closes: dict[str, float] = {}` — track previous close per symbol
         - Import and store `MACRO_FACTORS` from registry
         - Import `MACRO_ALL_SYMBOLS` from `src.intelligence.macro.constants` — the recompute gate
         - Consumer group: `"macro_context_consumer"`
         - Subscribe to: `topic_market_bars(env_name)` and `topic_market_bars_htf(env_name)`

       - `async def _run(self)`:
         - Start consumer/producer
         - Message loop: for each bar message, call `_process_bar(payload)` — it handles both cache update and conditional recompute

       - `def _process_bar(self, payload: dict) -> None`:
         - Extract symbol, close price from payload
         - Always update cache: `_bar_cache[symbol] = {"close": close, "prev_close": self._prev_closes.get(symbol)}`
         - Always update `_prev_closes[symbol] = close`
         - **Efficiency gate (D-22):** only schedule recompute if `symbol in MACRO_ALL_SYMBOLS`. Return early otherwise. This prevents O(instruments × factors) work on every bar from non-macro symbols.

       - `async def _compute_and_publish(self) -> None`:
         - Run each factor in MACRO_FACTORS: `result = factor["compute"](self._bar_cache)`
         - Merge all results into single dict, skip None values
         - Add timestamp: `"computed_at": datetime.now(UTC).isoformat() + "Z"`
         - Publish to `topic_macro_context(self.env_name)` with key `"macro"`
         - NOTE: If all factors return None (macro instruments not yet subscribed — D-21), skip publish entirely rather than sending an empty payload.

       - Graceful SIGTERM/SIGINT handling via BaseAgent
       - structlog logging via `setup_service_logging("logs/macro_context_compute_agent.log")`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| market.bars -> MacroContextComputeAgent | Bar data from Kafka; could have missing fields or stale data |
| MacroContextComputeAgent -> intelligence.macro_context | Computed macro factors; consumed by pipeline for frames["macro"] injection |

| bar_cache -> factor plugins | In-memory cache; could have None prev_close for first bar of session |
