    2. Implement `compute_full(self, frames: dict[str, Any]) -> dict[str, Any]`:
       - Extract momentum bias from each available TF via `frames["intel_*"]`:
         - RSI direction: `(rsi_14 - 50) / 50` for [-1,+1] bias (from I1)

         - `htf_momentum < -0.2 and ltf_momentum > 0.1` -> `"bounce"`

       - Return `{"ctf_momentum_divergence": divergence, "ctf_momentum_regime": regime}`

    Create `tools/validate_i6_field.py` — a CLI script that queries `signal_ledger`, computes Pearson IC for a named `_shadow` field, and exits 0 only when the validation gate passes (IC > 0.05 AND p < alpha). This replaces the manual "check the DB" step before executing Plan 02.

    ```python
    #!/usr/bin/env python3
    """Automated I6 shadow field validation gate.

    Queries signal_ledger for signals with a named _shadow field,
    computes Pearson IC vs pnl_r, and exits 0 (pass) or 1 (fail).

    Validates BOTH statistical significance AND effect size (per D-25):
      - p < alpha (Bonferroni-corrected for n_tests)
      - |IC| > min_ic (default 0.05)

    Optionally segments by hmm_regime for regime-specific validation (per D-26).

    Usage:
        python tools/validate_i6_field.py --field ctf_momentum_divergence --min-n 30 --alpha 0.01 --min-ic 0.05
        python tools/validate_i6_field.py --field ctf_momentum_divergence --regime-segmented
    """
    ```

    Script logic:
    1. argparse: `--field` (required), `--min-n` (default 30), `--alpha` (default 0.01, Bonferroni for 5 tests), `--min-ic` (default 0.05), `--n-tests` (default 5, for Bonferroni correction), `--regime-segmented` (flag), `--db-url` (default from Settings)
    2. Connect to DB via asyncpg using `Settings().database_url`
    3. Query:
       ```sql
       SELECT
           (shadow->>$1)::float AS field_value,
           pnl_r,
           (features->>'hmm_regime')::int AS hmm_regime
       FROM signal_ledger
       WHERE shadow IS NOT NULL
         AND shadow ? $1
         AND pnl_r IS NOT NULL
         AND exit_at IS NOT NULL
       ```
       Use `$1` parameter binding for field name — never string interpolation into SQL.
    4. If `len(rows) < min_n`: print `FAIL: N={len(rows)} < min_n={min_n}`, exit 1
    5. Without `--regime-segmented`:
       - Compute `scipy.stats.pearsonr(field_values, pnl_r_values)` → `(ic, p_value)`
       - Check: `p_value < alpha` AND `abs(ic) > min_ic`
       - Print result and exit 0/1
    6. With `--regime-segmented`:
       - Split rows by hmm_regime (0=ranging, 1=uptrend, 2=downtrend)
       - Compute IC for each regime segment
       - Print per-regime results
       - Exit 0 if ANY regime passes both gates, exit 1 if none do
    7. Output format: `PASS: IC={ic:.4f}, p={p_value:.6f}, N={len(rows)}` or `FAIL: ...`

    Entry point: `asyncio.run(_main())`. Import from `src.config.settings` for DB URL. Use `asyncpg.connect()` directly (no pool — CLI tool, not a server).
  </action>
