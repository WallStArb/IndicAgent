       - Function `compute_usd_strength(bar_cache: dict[str, dict]) -> dict[str, float | None]`:
         - `bar_cache` keys are symbols, values are dicts with "close" and "prev_close"
         - For each FX pair in MACRO_FX_PAIRS, compute `pct_change = (close - prev_close) / prev_close`
         - USD-denominated pairs (EURUSD, GBPUSD): USD strength = `-pct_change` (inverse)
         - Inverted pairs (USDJPY, USDCHF): USD strength = `+pct_change` (direct)
         - Composite: `np.tanh(sum(weighted_changes) / len(available_pairs) * 100)` — soft saturation
         - Return `{"macro_usd_strength": score}` or `{"macro_usd_strength": None}` if no pairs available

    2. Create `src/intelligence/macro/yield_curve.py`:
       - Import `MACRO_RATE_FUTURES` from constants
       - `FACTOR_NAME = "yield_curve"`
       - Function `compute_yield_curve(bar_cache: dict[str, dict]) -> dict[str, float | None]`:
         - Short-end: avg pct_change of ZT, ZF (2Y, 5Y)
         - Long-end: avg pct_change of ZN, ZB (10Y, 30Y)
         - Slope change: `long_end_change - short_end_change` (positive = steepening in price terms)
         - Score: `np.tanh(slope_change * 1000)` — scaled for typical bond tick sizes
         - Return `{"macro_yield_curve_slope": score}` or None if insufficient data

    3. Create `src/intelligence/macro/flight_to_quality.py`:
       - Import `MACRO_FLIGHT_TO_QUALITY` from constants
       - `FACTOR_NAME = "flight_to_quality"`
       - Function `compute_flight_to_quality(bar_cache: dict[str, dict]) -> dict[str, float | None]`:
         - Expected signs: TLT up (+1), SPY down (-1), VX up (+1)
         - `EXPECTED_SIGNS = {"TLT": 1.0, "SPY": -1.0, "VX": 1.0}`
         - For each: `sign_agreement = expected_sign * np.sign(pct_change)`
         - Weight by magnitude: `weighted = sign_agreement * abs(pct_change)`
         - Score: `sum(weighted) / sum(abs_pct_changes)` — weighted agreement fraction in [-1,+1]
         - NEVER use `if all 3 agree -> 1.0` (per D-18 FORBIDDEN)
         - Return `{"macro_flight_to_quality": score}` or None if insufficient data
