<objective>
Draw the market-cap-stratified Russell 3000 sample at the size Plan 11 measured, onboard it,
backfill it at **1d only** (D-09), and promote symbols to 1d-compute-eligibility as their history
lands — the phase's actual breadth-scaling deliverable (D-01/D-02/D-03/D-09).

Purpose: the personal-scale edge determination program closed with the verdict that this corpus,
at effective breadth ~8.4, cannot carry the endgame, and prescribed single-name breadth expansion
as the primary lever — IR ≈ IC × √breadth, with IC small and stable (~0.03-0.06) and breadth the
dominant term. Every preceding plan in this phase exists to make this run safe: the memory fix so
ic_engine survives the scale, the governance split so hundreds of new names do not silently become
live-tradeable, the 1d eligibility dimension so a 1d-only cohort cannot contaminate the 5m/15m/1h
cross-sectional cells, the onboarding helper so none of them lands half-written, the stratified
sampler so the down-cap hypothesis is tested rather than assumed, and the pre-registered pilot gate
so the full backfill cost is only paid against a population that actually decorrelates.

Output: the drawn sample onboarded and backfilling at 1d, promoted on `compute_eligible_1d`, and a
reproducibility record tying the sample to the exact file, seed and parameters that produced it.

## Precondition: this plan does not run on a gate FAIL

Plan 15 evaluated D-10's two pre-registered thresholds against a 30-50 symbol pilot. If the verdict
was FAIL, Plan 11 left `alpha.universe.target_sample_size` at `0`, and Plan 08's sourcing CLI
returns exit code 1 with a `FAILED:` message at that value (`_async_main`, merged). That is the
guard working. The correct response is not to pick a number here, not to set the key by hand, and
not to route around the CLI — it is to stop, record that the phase closes without the full draw,
and hand the pivot recommendation in
`docs/research/phase174-down-cap-correlation-gate-verdict.md` back to the user.

## What "complete" means for Phase 174 — three tiers

D-09 changed the arithmetic here materially and the earlier four-timeframe framing no longer holds.
A 1d-only fetch costs roughly **one IBKR request per symbol** (`infra.ibkr.chunk_days.1d = 7300`,
one request covers a 20-year daily window) against a pacing budget of
`infra.ibkr.rate_limit_max_requests = 58` per `infra.ibkr.rate_limit_window_sec = 600.0`, i.e.
~348 requests/hour. The four-timeframe path costs roughly 67 requests per symbol over the same
window (5m at `chunk_days=150` alone is ~49). So a 1,000-symbol draw is on the order of **3 hours**
at 1d, against roughly **8 days** for the same draw across four timeframes.

That means tier (b) may genuinely be reachable inside this phase's window, where under the
four-timeframe plan it could not be. **Do not pre-declare which tier this plan reaches.** Run the
backfill, measure, and mark the table below from the observed state at sign-off.

| Tier | Name | What is true | Status at sign-off |
|------|------|--------------|--------------------|
| **(a)** | **Phase 174 implementation complete** | Sample drawn and recorded; every qualifying symbol onboarded across all four tables at `compute_eligible=false, compute_eligible_1d=false, live_tradeable=false`; 1d backfill launched under supervision; promotion tool run at least once | Claimed by this plan |
| (b) | Phase 174 data complete | 1d backfill finished for the sampled universe; promotion has set `compute_eligible_1d=true` for them | Marked reached or not-reached from the measured `backfill_status` state, with the date |
| (c) | Phase 174 empirical complete | `ic_engine` recompute finished over the expanded 1d corpus and effective breadth re-measured | Post-phase, a separate tracked run |

Until tier (c) lands, **~8.4 remains the last measured effective breadth**. A larger `instruments`
count is not a larger effective breadth, and this plan must not state or imply otherwise. The
precedent is exact: Phase 173 completed 2026-08-26 and its corpus recompute completed 2026-08-31,
tracked separately.

full-stack symbols and applying it to this cohort would hold every one of them forever. It stays in
force, unchanged, for the existing 128-name book and for Plan 10's gap-fill ETFs. This is the
concrete payoff of Plan 13's split: two cohorts, two predicates, neither weakened to accommodate
the other.
