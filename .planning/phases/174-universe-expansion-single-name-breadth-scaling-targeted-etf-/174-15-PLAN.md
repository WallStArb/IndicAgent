<objective>
Run D-10's pre-registered pilot gate: draw 30-50 down-cap symbols with the production sampler,
onboard and backfill them at 1d only, re-run Plan 14's diagnostic against them, and record the
verdict with its measured numbers — whichever way it lands.

Purpose: the existing 117-name book delivers ~3.1 independent bets out of 117 raw symbols, and
~2.1 in `high_bear`. Because `n_eff → 1/avg_corr` as N grows, adding more similarly-correlated
names cannot raise effective breadth past ~3.2 no matter how many are added. D-10 exists so the
phase finds out whether the down-cap population actually decorrelates *before* paying the full
backfill cost for a population that might deliver near-zero incremental breadth. That only works
if the gate is run on real pilot data, against thresholds fixed beforehand, with the failing
branch written down as concretely as the passing one.

Output: a pilot cohort in the corpus at 1d, a reusable promotion tool, and a verdict document that
either unblocks Plan 11's scale determination or tells it to stop.

## What each outcome means, decided before the data exists

| Gate outcome | What this plan does | What Plan 11 does next |
|---|---|---|
| **PASS** — unconditional ≤ 0.10 AND `high_bear` ≤ 0.30 | Records PASS with measured numbers | Proceeds to the 1d-cell scale determination and sets `alpha.universe.target_sample_size` |
| **FAIL** — either threshold missed | Records FAIL, names which threshold and by how much, writes the pivot recommendation | Leaves `alpha.universe.target_sample_size` at `0`; Plan 12's existing crash-loud guard then structurally blocks the full draw |

Neither branch is a failure of the phase. A FAIL is the gate doing exactly the job D-10 built it
for, and is a cheaper answer than a multi-thousand-symbol backfill that delivers nothing.
</objective>
