qualification-gated onboarding helper, backfill their full history across all four timeframes,

Plan 12 runs it at scale. It also closes the two exposure gaps RESEARCH.md re-verified live: zero
`fx_em`-tagged symbols and zero VIX-linked instrument of any kind.

script.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external ticker string → `instruments` table | Tickers chosen from third-party research become corpus members |
| IBKR gateway → `market_data_ohlcv` | Externally-fetched bars become the substrate for every downstream measurement |
| `compute_eligible` flag → every compute consumer | Flipping it admits a symbol into feature factory, ic_engine and the regime models |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-174-03 | Tampering | An unverified ticker string reaching `instruments` | mitigate | `onboard_instrument()` runs `qualify_instrument()` against the live gateway first and aborts the whole transaction on a `False` return; the script contains no direct `INSERT INTO instruments` and offers no qualification bypass |
| T-174-02 | Tampering | SQL injection via a symbol string | mitigate | Every write routes through Plan 03's parameterized helper; the promotion `UPDATE` in Task 3 uses `%(symbol)s` placeholders, never interpolation |
| T-174-28 | Tampering (measurement integrity) | Promoting a symbol to `compute_eligible` with partial or missing history, seeding a corpus-wide measurement with a truncated series | mitigate | Promotion is gated on all four `backfill_status` rows being `fetch_complete=true` AND on verified non-zero `market_data_ohlcv_tradeable` counts AND on the earliest timestamp being consistent with the recorded `listing_date`. Zero-row fetches are treated as failures, never promoted |
| T-174-29 | Denial of Service | A silent zero-row fetch reported as success, the failure shape the Corpus Pipeline Gotcha names | mitigate | Task 1 proves the gateway serves data with a real request before anything depends on it; Task 3's acceptance criteria assert non-zero counts per (symbol, timeframe) rather than trusting a clean exit code |
| T-174-01 | Elevation of Privilege | New symbols becoming live-streaming-eligible | mitigate | `live_tradeable=False` at onboarding and never set; a corpus-wide assertion that zero rows are `live_tradeable=true` is part of the acceptance criteria |
| T-174-30 | Denial of Service | Restoring the ib-gateway container without its log-rotation caps, recreating the 29GB-log incident | mitigate | Restart via `docker compose up -d` against the unmodified compose file; `docker inspect` confirms log options are present |
| T-174-SC | Tampering | package-manager installs | accept | No packages installed by this plan |
</threat_model>
