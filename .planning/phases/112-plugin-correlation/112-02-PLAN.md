<objective>
Build the weekly oneshot batch that measures plugin redundancy and auto-suppresses redundant plugins, plus its systemd timer and unit tests for the pure functions.

Purpose: This is the analytical core of the phase. It scans 90 days of signal_ledger, builds a plugin direction matrix, computes pairwise directional_r (agreement rate) AND signed_r (signed correlation), computes the effective independent plugin count from signed_r via participation ratio, writes both result tables (UPSERT + delete-stale for latest-snapshot semantics), and flips correlation_suppressed on inferior plugins that meet all three gates. Suppression is self-expiring through data starvation — no manual re-activation.
Output: `production/scripts/plugin_correlation_batch.py` plus the service + timer units and a pure-function unit test, following roll_batch.py exactly.
</objective>

    PURE FUNCTIONS (no DB, no I/O — independently testable):
    1. `build_direction_matrix(rows) -> tuple[np.ndarray, list[str]]`:
       - Group rows by `(feature_ts, symbol, timeframe)` (the bar key). Each group is one "bar event".
       - Columns = sorted unique setup_plugin names. Rows = bar events.
       - Cell value = the plugin's `direction` (integer +1/-1) for that bar, else 0 (Pitfall 5: absence of a row means did-not-fire = 0; initialize matrix to zeros, overwrite from rows where direction != 0).
       - Return (matrix [n_bars x n_plugins], plugin_names list).
    2. `compute_pairs(matrix, plugin_names, min_co_fire=30) -> list[dict]`:
       - For each plugin pair (i<j by name): `dir_a`, `dir_b` are the columns.
       - `co_fire_count = int(((dir_a != 0) & (dir_b != 0)).sum())` (Pitfall 7: bar-level joint events via vectorized masks).
       - `agree_count = int(((dir_a == dir_b) & (dir_a != 0)).sum())`.
       - `disagree_count = co_fire_count - agree_count` (both fired but opposite direction).
       - `directional_r = agree_count / co_fire_count` if co_fire_count > 0 else 0.0 (D-05 — agreement rate, range [0,1], drives the suppression gate).
       - `signed_r = (agree_count - disagree_count) / co_fire_count` if co_fire_count > 0 else 0.0 (Codex HIGH #3 — signed correlation, range [-1,1], drives effective_n). Equivalent to `2*directional_r - 1`.
       - Enforce canonical ordering `(a, b) = (min, max)` by name BEFORE appending (Pitfall 8 — code enforces, CHECK is backstop).
       - Skip pairs with `co_fire_count < min_co_fire` (D-04: 30) — not written to DB.
       - Return list of dicts: `{"plugin_a", "plugin_b", "directional_r", "signed_r", "co_fire_count"}`.
    3. `compute_effective_n(pairs, plugin_names) -> float`:
       - Build symmetric correlation matrix: `np.eye(n)`, fill `[i,j]=[j,i]=pair["signed_r"]` for each pair (Codex HIGH #3 — use signed_r, NOT directional_r, so anti-correlation lowers independence correctly).
       - `eigenvalues = eigvalsh(corr_matrix)` (symmetric — use eigvalsh not eig).
       - Clip: `eigenvalues = eigenvalues[eigenvalues > 1e-10]` (Pitfall 6: float-error negatives break the formula).
       - `total = eigenvalues.sum()`; `effective_n = 1.0 / ((eigenvalues / total) ** 2).sum()` (D-07 participation ratio).
       - Return float.
    4. `select_suppressions(pairs: list[dict], plugins: dict[str, dict]) -> tuple[set[str], set[str]]`:
