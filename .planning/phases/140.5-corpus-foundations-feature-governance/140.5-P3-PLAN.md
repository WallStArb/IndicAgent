    Class: FeatureRegistryService (not a dataclass; mutable singleton)

    Internal state: _features: dict[str, dict] (keyed by feature_name); _loaded: bool; _pool: asyncpg.Pool | None; _min_ic_sharpe_default: float

    Methods to implement:

    async def load(self, pool: asyncpg.Pool) -> None:
      Fetches all rows from feature_registry in a single query: SELECT feature_name, group_name, tier, status, min_ic_sharpe, min_ic_n, fdr_required, fdr_alpha FROM feature_registry.
      Populates self._features dict keyed by feature_name.
      Loads APR floor: SELECT config_value FROM config_state WHERE config_key = 'alpha.feature_registry.min_ic_sharpe_default' via the pool.
      Sets self._loaded = True.
      Raises RuntimeError if row count != 61 (drift guard: registry must always match FeatureVector fields count).
      Docstring note: "Row count gate checks total DB rows regardless of status. Alignment gate in callers must use get_all_features(), not get_active_features(), to match the FeatureVector dataclass regardless of lifecycle state."

    def load_sync(self, conn) -> None:
      Same as load() but using a psycopg2 conn (cursor.execute + fetchall pattern).
      Identical logic; needed by ic_engine.py which uses psycopg2 throughout.
      Same RuntimeError if row count != 61.
      Docstring note: "Row count gate checks total DB rows regardless of status. Alignment gate in callers must use get_all_features(), not get_active_features()."

    def get_active_features(self, tier: str | None = None) -> list[dict]:
      Returns list of feature dicts where status != 'deprecated'.
      If tier is not None, also filters by tier.
      Raises RuntimeError if not loaded.
      NOTE: Do NOT use this method for the startup alignment gate — it filters by status,
      which would cause the gate to fail when features are deprecated (correct behavior).
      Use get_all_features() for the alignment gate.

    def get_all_features(self, tier: str | None = None) -> list[dict]:
      Returns ALL features regardless of status (used for the startup alignment gate).
      If tier is not None, also filters by tier.
      Raises RuntimeError if not loaded.
      This is the correct method for comparing registry to FeatureVector dataclass fields:
      the alignment gate must pass even when some features have status='deprecated'.

    def get_feature(self, feature_name: str) -> dict | None:
      Returns feature dict or None if not found.

    def get_ic_sharpe_gate(self, feature_name: str) -> float:
      Returns feature['min_ic_sharpe'] if it is not None, else self._min_ic_sharpe_default.

    def get_status(self, feature_name: str) -> str | None:
      Returns feature['status'] or None if feature not found.

    FIRE-AND-FORGET TRANSITION LOGGING — TWO-METHOD PATTERN:
    The transition record write is async (requires asyncpg pool). Callers (ic_engine, ensemble_trainer)
    are in async contexts but should not await the write — it's a best-effort audit trail.
    The correct pattern: synchronous wrapper schedules the coroutine as a background task.
    A bare `async def record_transition()` that is not awaited creates a coroutine object
    that is immediately garbage-collected — the task never runs.

    async def _write_transition_record(self, feature_name: str, from_status: str, to_status: str,
                                        reason: str, ic_value: float | None,
                                        ic_sharpe: float | None, ic_n: int | None) -> None:
      The actual DB write coroutine. Inserts into feature_transition_log AND updates
      feature_registry SET status = to_status WHERE feature_name = feature_name.
      Uses self._pool for the asyncpg write.
      Called only via asyncio.create_task() from record_transition() — never awaited directly.

    def record_transition(self, feature_name: str, from_status: str, to_status: str,
                          reason: str, ic_value: float | None = None,
                          ic_sharpe: float | None = None, ic_n: int | None = None) -> None:
      Synchronous wrapper. Calls asyncio.create_task(self._write_transition_record(...)).
      This works because asyncio.create_task() requires a running event loop, which exists
      in all callers (ensemble_trainer is fully async; ic_engine callers that need this
      are also in async context).
      Returns None (caller ignores the Task — true fire-and-forget).
      IMPORTANT: This is NOT async def — it is def. An async def that is not awaited
      creates a dead coroutine object. A sync def calling asyncio.create_task() correctly
      schedules the background coroutine on the running loop.
