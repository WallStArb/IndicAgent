<objective>
Create market_regimes table. Build equity_regime_model.py oneshot service that computes cross-sectional equity regime labels from VIX proxy (SPY realized vol z-score) and breadth signals (% of 58 ETFs above 200MA). Populate market_regimes for all (tf, ts) combinations in the feature_vectors corpus. Wire ic_engine to join market_regimes AND compute cross-sectional IC pooling ALL 58 equity ETFs per (tf, regime) cell.

Purpose: Per-symbol HMM labels are incomparable across symbols — "trending_up" on SPY and TLT are independent states. IC stratification cannot pool observations cross-symbol without a shared regime label. At 58 equity ETFs, cross-sectional labels provide ~58x pooling depth per regime cell vs. per-symbol segmentation. The IC engine redesign produces cross-sectional IC rows (symbol='POOLED') in addition to per-symbol rows.
Output: market_regimes populated; IC stratification pools across all 58 equity ETFs within each regime cell when equity_model_enabled=true.
</objective>

    Create services/equity_regime_model.py as a oneshot batch service (analogous to regime_writer.py).

    Architecture: psycopg2 sync DB reads, ProcessPoolExecutor with one task per TF (4 tasks: 5m, 15m, 1h, 1d). No DB calls inside worker functions — all data fetched sync before dispatch, all results written sync after all workers complete. Workers receive plain Python dicts/lists (picklable), not DB connections.

    Module setup:
    - setup_service_logging("logs/equity_regime_model.log") at top level
    - _JOB = 'equity-regime-model'
    - DSN from Settings

    Data fetching (in main process before workers):
    1. Load APR keys from config_state: alpha.regime.vix_low_pct (float), alpha.regime.vix_high_pct (float), alpha.regime.breadth_bear (float), alpha.regime.breadth_bull (float)
    2. For each TF in ['5m', '15m', '1h', '1d']:
       a. Fetch SPY bars: SELECT timestamp, close, volume FROM market_data_ohlcv WHERE symbol='SPY' AND timeframe=$tf ORDER BY timestamp ASC (psycopg2)
       b. Fetch all ETF bars for breadth: SELECT symbol, timestamp, close FROM market_data_ohlcv WHERE timeframe=$tf AND contract_details->>'asset_class' = 'equity' AND is_active = true ORDER BY symbol, timestamp ASC
       c. Build VIX proxy per timestamp from SPY: realized_vol = rolling std of log_returns over 20 bars; vix_z = (realized_vol - rolling_mean(realized_vol, 252)) / rolling_std(realized_vol, 252); compute percentile rank of vix_z over full history
       d. Build breadth per timestamp: for each ts, compute fraction of ETFs where close > 200MA (200MA computed per symbol as rolling_mean(close, 200) over the full history — causal, no lookahead)
       e. Pass (ts_list, vix_pct_rank, breadth_fraction, APR thresholds) as plain dict to worker

    Worker function _compute_tf_regimes(params: dict) -> list[tuple]:
    - Inputs: ts_list, vix_pct_rank, breadth_fraction, vix_low_pct, vix_high_pct, breadth_bear, breadth_bull
    - For each timestamp:
      - vix_bucket: 'low' if vix_pct_rank < vix_low_pct, 'high' if > vix_high_pct, else 'mid'
      - breadth_signal: 'bull' if breadth_fraction > breadth_bull, 'bear' if < breadth_bear, else 'neutral'
      - regime_label: combine as f"{vix_bucket}_{breadth_signal}" → 9 possible labels (low_bull, low_neutral, low_bear, mid_bull, mid_neutral, mid_bear, high_bull, high_neutral, high_bear)
      - regime_prob_vector: {'vix_bucket': vix_bucket, 'breadth_signal': breadth_signal, 'vix_pct': float(vix_pct_rank), 'breadth_frac': float(breadth_fraction)} (JSONB dict, no json.dumps)
    - Returns list of (tf, ts, regime_label, regime_prob_vector_dict)
    - NO DB calls inside this function

    Dispatch and write (in main process):
    ```python
    with ProcessPoolExecutor(max_workers=4) as pool:
        futures = {pool.submit(_compute_tf_regimes, params[tf]): tf for tf in TFS}
        for future in as_completed(futures):
            tf = futures[future]
            rows = future.result()  # list of tuples
    ```

    Write results to market_regimes via psycopg2 execute_batch:
    ```sql
    INSERT INTO market_regimes (asset_class, tf, ts, regime_label, regime_prob_vector)
    VALUES ('equity', %(tf)s, %(ts)s, %(regime_label)s, %(regime_prob_vector)s::jsonb)
    ON CONFLICT (asset_class, tf, ts) DO UPDATE SET regime_label = EXCLUDED.regime_label, regime_prob_vector = EXCLUDED.regime_prob_vector
    ```
    Note: asyncpg is NOT used here; psycopg2 is used throughout following regime_writer pattern. Pass regime_prob_vector as json.dumps(dict) for psycopg2 (unlike asyncpg which accepts raw dict for JSONB). Exception: psycopg2 requires explicit JSON serialization via json.dumps for JSONB columns.

    Argument parsing: --tf (optional, default all 4 TFs), --workers (default 4), --dry-run (compute but don't write)

    Warmup skip: Skip first 252 bars per (symbol, TF) for 200MA and VIX z-score computation; these timestamps get regime_label='warmup' (or NULL — use NULL to match regime_writer behavior). Do not write warmup rows to market_regimes.
