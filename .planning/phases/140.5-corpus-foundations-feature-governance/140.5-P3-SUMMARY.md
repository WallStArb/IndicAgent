### FeatureRegistryService (src/intelligence/feature_registry_service.py)

Singleton service with dual load paths:

- `async def load(pool)` — asyncpg pool path (ensemble_trainer)
- `def load_sync(conn)` — psycopg2 connection path (ic_engine)
- Both raise `RuntimeError` if DB row count != 61 (drift guard)
- `get_active_features(tier=None)` — returns non-deprecated features only
- `get_all_features(tier=None)` — returns ALL features (correct for alignment gate)
- `get_ic_sharpe_gate(feature_name)` — per-feature override or APR global floor
- `get_status(feature_name)` — current status or None
- `record_transition(...)` — sync def calling `asyncio.create_task()` (fire-and-forget)
- `async _write_transition_record(...)` — actual DB write coroutine

16 unit tests passing: `tests/unit/intelligence/test_feature_registry_service.py`
