# Plan 02: Data Migration Script

Write `production/scripts/migrate_signal_ledger.py` — the batched Python migration script that copies 1,442,909 signal_ledger rows into signal_events + trade_frames.

This plan writes the script only. Plan 03 executes it.

## Task 1: Write migrate_signal_ledger.py

<read_first>
- `.planning/phases/129-database-migration/129-CONTEXT.md` (D-01 through D-06 — all column mappings)
- `docs/signals/signal-trade-separation-ADR.md` (schema tables section, frame_details JSONB fields)
- `production/migrations/137_3table_schema.sql` (authoritative column definitions and types)
- `src/core/database_manager.py` (DatabaseManager — connection string pattern to follow)
</read_first>

<action>
Create `production/scripts/migrate_signal_ledger.py`.

Required behavior:
1. Connect to DB using env var `PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent` pattern — use `psycopg2` (not asyncpg, since this is a script not a daemon) with `host='localhost', dbname='indicagent', user='postgres', password='postgres'`
2. Count total signal_ledger rows and print banner
3. Process in batches of 10,000 rows, ordered by `timestamp ASC, signal_id ASC`
4. For each batch:
   a. INSERT INTO signal_events (...) VALUES ... ON CONFLICT (signal_id, ts) DO NOTHING
   b. INSERT INTO trade_frames (...) VALUES ... ON CONFLICT (signal_id, entry_type) DO NOTHING
   c. COMMIT batch
5. Print progress every 10 batches (100K rows)
6. Print final count and elapsed time

Column mappings (must be exact per 129-CONTEXT.md D-01 and D-02):

**signal_events INSERT columns:**
- signal_id, ts (from timestamp), symbol, tf (from timeframe), setup_plugin
- direction: CASE WHEN direction = 1 THEN 'long' WHEN direction = -1 THEN 'short' END
- raw_confidence, calibrated_confidence, cis_score, weights_version
- hmm_regime_at_fire, plugin_regime_type, garch_sigma_at_fire
- is_shadow, is_backfill
- status: hardcoded 'expired' for all historical rows
- signal_schema_version: NULLIF(signal_schema_version, '')::int4 (text → int4, NULL if blank)
- ttl_bars, expires_at, signal_computed_at, feature_ts
- factor_scores, context_features, ctf_score, ctf_confirmed, zone_friction_score: all NULL

**trade_frames INSERT columns:**
- frame_id: gen_random_uuid() (generated in Python as str(uuid.uuid4()))
- signal_id (FK)
- signal_ts: from signal_ledger.timestamp (required FK anchor for hypertable composite PK)
- entry_type: hardcoded 'at_close'
- direction: same conversion as signal_events
- entry_price: entry_price::float8
- stop_price: stop_loss::float8
- target_price: (targets->>0)::float8 (first element of JSON array; NULL if targets NULL or empty)
- r_multiple: (target_price - entry_price) / NULLIF(entry_price - stop_price, 0) — compute in Python
- was_selected: was_selected
- ttl_bars, expires_at (from signal_ledger)
- frame_details: JSON object with all 12 stop architecture fields + 4 shadow fields:
  ```python
  {
      "stop_basis": row["stop_basis"],
      "stop_type_col": row["stop_type_col"],
      "structural_stop_distance_atr": row["structural_stop_distance_atr"],
      "adaptive_buffer_mult": row["adaptive_buffer_mult"],
      "stop_structure_type": row["stop_structure_type"],
      "stop_structure_age_bars": row["stop_structure_age_bars"],
      "chandelier_vol_source": row["chandelier_vol_source"],
      "trailing_stop_price": row["trailing_stop_price"],
      "trailing_stop_tightening_rate": row["trailing_stop_tightening_rate"],
      "entry_zone_low": float(row["entry_zone_low"]) if row["entry_zone_low"] else None,
      "entry_zone_high": float(row["entry_zone_high"]) if row["entry_zone_high"] else None,
      "shadow_tracking_start_ts": row["shadow_tracking_start_ts"].isoformat() if row["shadow_tracking_start_ts"] else None,
      "shadow_mae": row["shadow_mae"],
      "shadow_mfe": row["shadow_mfe"],
      "shadow_outcome": row["shadow_outcome"],
      "targets_raw": row["targets"],
  }
  ```
  Remove None values from the dict before inserting (psycopg2 Json adapter handles nulls, but sparse dicts are cleaner).

**--dry-run flag:** When present, SELECT only (no INSERTs), print estimated row count and sample of first row mapping, then exit. Use argparse.

**Error handling:** Wrap each batch in try/except. On error: log the batch start/end signal_ids and the error, rollback the batch, continue to next batch. Count failed rows and report at end. Do NOT abort the entire migration for one bad row.

**psycopg2 extras:** Use `psycopg2.extras.execute_values()` for batch inserts (efficient multi-row INSERT).

Script entry point: `if __name__ == "__main__": main()`

The script must be runnable as:
```bash
python production/scripts/migrate_signal_ledger.py
python production/scripts/migrate_signal_ledger.py --dry-run
```
</action>
