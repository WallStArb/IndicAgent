    `.venv/bin/python -u production/scripts/lifecycle_replay.py --reset --reset-after <14d-ago-ISO> --confirm --symbols QQQ,<ES_front>,<NG_front>,GBPUSD --workers 8`

    Step 3 — Measure the rate. A single combined query produces both metrics in one scan:
    `PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent -c "SELECT exit_reason, COUNT(*) AS cnt, ROUND(COUNT(*)*100.0/SUM(COUNT(*)) OVER (), 2) AS pct_of_all, ROUND(COUNT(*) FILTER (WHERE exit_reason='stopped_at_entry') * 100.0 / NULLIF(COUNT(*) FILTER (WHERE exit_reason IN ('stop_loss','stopped_at_entry')), 0), 2) AS stopped_pct_of_stop_exits FROM trade_executions te JOIN trade_frames tf ON te.frame_id=tf.frame_id JOIN signal_events se ON tf.signal_id=se.signal_id WHERE se.symbol IN ('QQQ','<ES_front>','<NG_front>','GBPUSD') AND se.ts >= '<14d-ago-ISO>' GROUP BY 1 ORDER BY 2 DESC;"`

    `stopped_pct_of_stop_exits` is identical in every row (it is a window aggregate over all rows). Read it from the `stop_loss` or `stopped_at_entry` row. The A2 threshold is < 5% of stop-type exits (not of all exits — using all exits as the denominator understates the rate). Capture stdout of all three steps.
