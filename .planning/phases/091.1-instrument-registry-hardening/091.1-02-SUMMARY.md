# 091.1-02 Summary: settings.py connection consolidation

Applied Fix 4 to `src/config/settings.py`.

## What was built

`get_active_contracts()` previously opened 3 sequential `psycopg2.connect()` calls. Consolidated into one `with psycopg2.connect(s.database_url) as conn:` block with 3 cursor operations:
1. Futures templates from `instruments WHERE asset_class='futures'`
2. Front-month contracts from `contract_metadata WHERE is_front_month=true`
3. Non-futures from `instruments WHERE is_active=true AND asset_class!='futures'`

Same queries, same semantics, one-third the connection overhead.
