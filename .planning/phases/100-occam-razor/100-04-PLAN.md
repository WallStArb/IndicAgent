import pytest
import asyncio
from datetime import UTC, datetime, timedelta

@pytest.mark.integration
async def test_occam_end_to_end(db_pool, alpha_swarm):
    """Full Occam pipeline: insert signals → run ORE → verify rejection."""

    agent_id = "test_occam_agent_v1"

    # Insert 100 synthetic signals with known bias (poor performance)
    now = datetime.now(UTC)
    signals = []
    for i in range(100):
        ts = now - timedelta(days=30) + timedelta(hours=i)
        # 60% losers, 40% winners (Sharpe < 0)
        pnl_r = -0.01 if i % 10 < 6 else 0.02
        signals.append({
            "signal_id": f"{agent_id}_{i}",
            "agent_id": agent_id,
            "timestamp": ts,
            "pnl_r": pnl_r,
            "outcome": "target_1" if pnl_r > 0 else "stopped_at_entry",
            "features_snapshot": {"existing_confidence": 0.5},
        })

    # Insert signal_ledger rows
    async with db_pool.acquire() as conn:
        for sig in signals:
            await conn.execute(
                """
                INSERT INTO signal_ledger
                (signal_id, agent_id, timestamp, pnl_r, outcome, features_snapshot)
                VALUES ($1, $2, $3, $4, $5, $6)
                """,
                sig["signal_id"], sig["agent_id"], sig["timestamp"],
                sig["pnl_r"], sig["outcome"], sig["features_snapshot"]
            )

        # Insert shadow_registry row
        await conn.execute(
            """
            INSERT INTO shadow_registry (component_name, component_type, is_shadow)
            VALUES ($1, 'swarm_agent', TRUE)
            ON CONFLICT (component_name) DO NOTHING
            """,
            agent_id
        )

    # Run ORE cycle
    await alpha_swarm._run_occam_razor_cycle()

    # Verify rejection
    async with db_pool.acquire() as conn:
        row = await conn.fetchrow(
            "SELECT * FROM shadow_registry WHERE component_name = $1",
            agent_id
        )

    assert row["is_shadow"] is True
    assert row["rejection_reason"] in ("baseline", "tie")
    assert row["last_occam_check"] is not None

    # Verify metrics emitted (via Prometheus scrape)
    # ... (metric verification)

```markdown
## Occam's Razor System

**Purpose:** Complexity-aware model selection for shadow ML agents. Rejects over-complex models when simpler baselines achieve statistically similar performance.

**Evaluation flow:**
1. Every 15 min (AlphaSwarm graduation cycle)
2. For each shadow ML agent:
   - Build simple baseline (LinearBaseline, RuleBaseline, RandomBaseline)
   - Query 30-day signal outcomes from `signal_ledger`
   - Compute Sharpe for both complex and baseline models
   - Bootstrap CI with complexity penalty
   - Reject if baseline wins or ties (UPDATE `shadow_registry`)

**Key files:**
- `src/intelligence/ai/baseline.py` — BaselineBuilder protocol + implementations
- `src/intelligence/ai/evaluators/occam_razor_evaluator.py` — Statistical test engine
- `services/alpha_swarm.py` — `_run_occam_razor_cycle()` integration

**Complexity formula:** `log(params + 1) × (1 + latency_ms / 1000) × (1 + train_time_ms / 60000)`

**Decision rule:**
- `ci_lower > 0` → complex wins (promote)
- `ci_upper < 0` → baseline wins (reject)
- CI spans 0 → tie (reject, prefer simpler)

**Metrics:**
- `occam_evaluations_total{agent_id, outcome}`
- `occam_rejections_total{agent_id, reason}`
- `occam_complexity_ratio{agent_id}`
- `occam_sharpe_delta{agent_id}`

**Gotchas:**
- Complexity data must exist in `ml_models` table — ORE raises RuntimeError if missing (D-06)
- Minimum 30 signals required — ORE skips with warning if n < 30 (D-07)
- Baseline builder must exist for agent prefix — ORE skips with debug log if None
- Rejection is reversible — re-evaluation can promote if conditions change
```

**Acceptance:**
- Section added after "Plugin System"

- Formula and decision rule documented
- Gotchas section includes D-06, D-07 guards
