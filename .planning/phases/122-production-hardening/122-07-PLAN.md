    CLI args (argparse):
    - --plugins: comma-separated plugin names; default all I7 (reads TIER_I7 from register_plugins)
    - --symbols: comma-separated symbols; default all active contracts from get_active_contracts(settings)
    - --since: ISO date string (e.g. 2026-01-01); optional
    - --workers: int, default 4

    - --dry-run: flag; reconstruct and run plugins but do not write to signal_ledger

    _reconstruct_intelligence_event(row: asyncpg.Record) -> IntelligenceEvent | None:
    - Reads columns: ts, symbol, tf, i1, i2, i3, i4, i5, smc, cross_timeframe_context, market_context, bar
    - Each JSONB column is already a dict when fetched via asyncpg (no json.loads needed)
    - Constructs IntelligenceEvent with:
      i1=I1Indicators(**(row["i1"] or {})),
      i2=I2Events(**(row["i2"] or {})),
      i3=I3Structure(**(row["i3"] or {})),
      i4=I4Context(**(row["i4"] or {})),
      i5=I5Patterns(**(row["i5"] or {})),
      smc=SMCContext(**(row["smc"] or {})),
      i6=I6Confluence(**(row["cross_timeframe_context"] or {})),
      bar=OHLCVBar(**(row["bar"] or {})),
      ts=row["ts"], symbol=row["symbol"], tf=row["tf"], source="feature_replay"
    - Returns None on any ValidationError or Exception (log warning, skip row)

    _SELECT_FEATURES_SQL constant:
    ```sql
    SELECT ts, symbol, tf, bar, i1, i2, i3, i4, i5, smc, cross_timeframe_context, market_context
    FROM intelligence_features
    WHERE symbol = $1 AND tf = $2
      AND ($3::timestamptz IS NULL OR ts >= $3)
    ORDER BY ts ASC
    ```

    async _replay_symbol_tf(conn, symbol, tf, since, plugins, dry_run) -> int:
    - Fetches rows via _SELECT_FEATURES_SQL
    - For each row: reconstruct event → if None skip; build frames dict for I7 evaluate; run each plugin; collect signals; call make_signal_id for each; if not dry_run: upsert to signal_ledger
    - Returns count of signals upserted
    - Frames dict structure (mirrors run_i7_and_persist in run_historical_pipeline.py): {"features": flat_features, "symbol": symbol, "tf": tf, "i1": row["i1"] or {}, "i2": row["i2"] or {}, "i3": row["i3"] or {}, ...}
    - Flat features for backward compat: merge all tier dicts into one dict

    _UPSERT_SIGNAL_SQL:
    - INSERT INTO signal_ledger (...) VALUES (...) ON CONFLICT (signal_id, timestamp) DO UPDATE SET setup_plugin=EXCLUDED.setup_plugin, ... (update mutable fields; preserve created_at)
    - Columns: signal_id, timestamp, symbol, timeframe, setup_plugin, signal_type, direction, entry_price, stop_loss, confidence, status, feature_ts, feature_tf, is_shadow, is_backfill, source
    - Use asyncpg executemany for batch

    async main():
    - Parse args, validate, resolve symbols and plugins
    - Create asyncpg pool (read from settings DB url)
    - asyncio.gather worker tasks per (symbol, tf) pair (up to --workers concurrent)
    - Print summary: total signals upserted, elapsed time, per-symbol counts
    - Log structured summary via structlog

    if __name__ == "__main__": asyncio.run(main())
