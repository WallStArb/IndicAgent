<objective>
Run the null-arm (scrambled-data) block-reliability control for the `volatility` axis at the
wider scope `171-FINAL-VERDICT.md` section 6 flags as untested: 15m and 5m timeframes, a larger
symbol sample, and a swept `vol_of_vol` window. Render one written GO/NO-GO verdict naming the
exact `n_components`, `vol_window`, and `vol_of_vol_window` values Phase 172 ships.

Purpose: this is the one gate Phase 171's own investigation says not to skip. Everything already
known about the volatility axis (+0.62 real-vs-null margin on `realized_vol`) was measured on the
same 8-to-17-symbol, 1d/1h sample used throughout that investigation. The corpus-write wave
(172-05) is blocked on this plan's verdict, and the shipped window values are blocked on this
plan's sweep: `171-FINAL-VERDICT.md` section 6 says `vol_of_vol`'s margin is thin at the 20-bar
window used everywhere else and solid from 60 up, so inheriting 20 unexamined would repeat the
exact mistake the whole investigation exists to correct.

Output: a results JSON in the phase evidence directory and a verdict document later plans read
instead of re-deriving.
</objective>
