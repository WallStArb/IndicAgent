<objective>
Add DB-level DLQ quarantine to prevent infinite retry loops from hiding behind silence.
After this plan: every DLQ message increments an in-memory rolling 24h counter keyed by
(agent, source_topic, error_type); when the count exceeds DLQ_MAX_RETRIES=3, the row
is stored with quarantined=TRUE and the dlq_quarantine_total OTel counter fires so
Grafana can alert.

Purpose: HEAL-04 (DLQ quarantine half). No re-delivery loop exists today; quarantine is
DB-level counting, not a Kafka dead-final topic (deferred per D-22).

Output: Migration 099 adds the column, DLQDrainAgent extended with occurrence counter +
DLQ_QUARANTINE_TOTAL increment, and the INSERT writes the new quarantined flag.
</objective>
