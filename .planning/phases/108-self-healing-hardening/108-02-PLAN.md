<objective>
Roll out `WatchdogSec=60` + `NotifyAccess=main` to all 25 daemon `.service` unit files
that are missing them, install ONLY those 25 updated unit files into `/etc/systemd/system/`,
reload systemd, and restart affected services so the new watchdog contract takes effect.

Purpose: systemd auto-restarts any daemon that fails to call sd_notify within 60s.
Combined with Plan 01's watchdog counters, this gives Grafana visibility into both
healthy heartbeats AND systemd-driven restarts of stalled daemons. Closes HEAL-01.

Audited unit count is 25 (RESEARCH.md). ROADMAP.md previously listed 27 from an
earlier estimate; this plan adopts the 25 audited figure as authoritative. Plan 07
documentation updates ROADMAP if needed.

Output: 25 modified unit files, ONLY those 25 installed under /etc/systemd/system/,
services restarted, `systemd-analyze verify` clean, pre-change baseline preserved
in the SUMMARY.
</objective>
