<objective>
Create IncrementalMixin class that owns the state contract for incremental plugins. The mixin provides compute_full() and compute_next() methods that automatically handle state threading, fallback-to-full logic, and _state attachment. Plugin authors implement only domain logic in _compute_full_core(), _compute_next_core(), and _seed_state(). Migrate ATR plugin as the reference implementation.

Purpose: The design doc identified 5 HIGH-severity bugs where incremental plugins either (1) read self._state instead of the state parameter, or (2) forget to return _state in compute_next. The mixin prevents both bugs by owning the state contract entirely. Plugins never touch the state parameter — the mixin passes a guaranteed-non-None state to _compute_next_core.

Output: IncrementalMixin class in mixins.py, comprehensive unit tests, and ATR plugin migrated to the mixin as proof of concept.
</objective>

    Add IncrementalMixin class to src/intelligence/plugins/mixins.py with the following contract:

    class IncrementalMixin:
      """Owns fallback-to-full and _state return contract for incremental plugins.

      Plugins implementing this mixin must provide:
      - _compute_full_core(frames) -> dict: Pure computation, returns outputs only (no _state)
      - _compute_next_core(frames, state) -> dict: Pure incremental computation, state is never None
      - _seed_state(frames) -> dict: Extract state from full computation for incremental seeding

      The mixin provides:
      - compute_full(frames, *, state=None): Calls _compute_full_core, attaches _state via _seed_state
      - compute_next(frames, *, state=None): Falls back to compute_full if not state, else calls _compute_next_core and attaches _state

      State threading guarantees:
      - _compute_next_core always receives non-None state dict
      - _state is always attached to output (executor validation never fails)
      - Plugins never need to write result["_state"] = state
      """

      def compute_full(self, frames: dict[str, Any], *, state: dict | None = None) -> dict[str, Any]:
          # Call _compute_full_core for pure outputs
          result = self._compute_full_core(frames)
          if not result:
              return {}
          # Attach seeded state for incremental persistence
          result["_state"] = self._seed_state(frames)
          return result

      def compute_next(self, frames: dict[str, Any], *, state: dict | None = None) -> dict[str, Any]:
          # Fallback to full if no state (guarantees correctness on cold start)
          if not state:
              return self.compute_full(frames)
          # State is guaranteed non-None here
          result = self._compute_next_core(frames, state)
          if isinstance(result, dict):
              result["_state"] = state
          return result

      # Abstract methods (must be implemented by subclass)
      def _compute_full_core(self, frames: dict[str, Any]) -> dict[str, Any]:
          raise NotImplementedError

      def _compute_next_core(self, frames: dict[str, Any], state: dict) -> dict[str, Any]:
          raise NotImplementedError

      def _seed_state(self, frames: dict[str, Any]) -> dict:
          raise NotImplementedError

    Update __all__ to include "IncrementalMixin". Add typing imports (Any, dict).
  </action>
