    - test_plugin_has_required_methods(plugin_class): Verify has _compute_full_core, _compute_next_core, _seed_state

    class TestMigratedPluginReplayParity:
    Full-vs-incremental replay test for each of the 6 migrated plugins (ATR already tested in plan 02).
    For each plugin:
    - Generate N=50 synthetic OHLCV bars (DataFrame with columns open, high, low, close, volume)
    - Run compute_full on all N bars to get reference output and reference state
    - Seed: run compute_full on first 20 bars to get seed state
    - Incremental: call compute_next for bars 21..50 one at a time (each with single-row DataFrame)
    - Verify the final incremental output values match compute_full on all 50 bars within tolerance 1e-6
    - test_adx_replay_parity(), test_stochastic_replay_parity(), test_williams_r_replay_parity(), test_mfi_replay_parity(), test_volume_zscore_replay_parity(), test_keltner_replay_parity()

      1. compute_full on 100-bar synthetic data (100 iterations, report mean)
      2. compute_next with seeded state (100 iterations, report mean)
      3. Assert compute_next mean is < 1ms (basic sanity -- incremental should be fast)
    - Print results via structlog or print for manual review
