Migrate 6 "easy" incremental plugins to IncrementalMixin: ADX, Stochastic, WilliamsR, MFI, VolumeZscore, Keltner. These are the cleanest candidates per the design doc (Phase C). All have straightforward state shapes and existing incremental implementations. Migration proves the mixin works across multiple state archetypes before expanding to complex plugins.

These 6 represent different state archetypes (Wilder's accumulator, rolling window min/max, deque history, EMA chain) proving the mixin's generality.

Output: 6 plugins migrated to IncrementalMixin with unchanged outputs (verified by existing tests), all using shared utilities where applicable.
