<objective>
Migrate I1 and I2 indicator plugins to use get_main_df() shared utility for OHLCV DataFrame extraction. This eliminates duplicated `frames.get("main")` guard logic across 28+ I1 plugins and promotes consistent min_bars validation.

Purpose: The design doc identified that 35+ non-I7 plugins have identical OHLCV extraction and validation logic: `df = frames.get("main"); if df is None or len(df) < min_bars: return {}`. Extracting this to get_main_df() reduces duplication and centralizes the guard pattern. Future changes to the validation logic touch one place.

Output: 7 I1/I2 plugins migrated to use get_main_df(). All have consistent OHLCV extraction pattern.
</objective>
