Create shared utility functions for common plugin patterns: Wilder's smoothing, EMA updates, and OHLCV DataFrame extraction. These functions eliminate code duplication across 28+ I1 plugins and provide a single source of truth for bug fixes.

Purpose: The design doc identified that Wilder's smoothing formula is copy-pasted in 7+ plugins (ATR, RSI, StochRSI, Supertrend, ADX, Chandelier, Keltner). The MFI bug from Phase 093 demonstrated why duplication is hazardous — the fix touched multiple files. By extracting to a shared function, future fixes touch one place.

Output: New src/intelligence/plugins/mixins.py module with wilders_update(), update_ema(), and get_main_df() functions, plus comprehensive unit tests.
</objective>

  <action>
    Create src/intelligence/plugins/mixins.py with three pure functions:

    1. wilders_update(prev: float, new_val: float, period: int) -> float
       - Computes Wilder's smoothing: (prev * (period - 1) + new_val) / period
       - Raises ValueError if period < 1
       - Handles NaN inputs: returns NaN if either input is NaN
       - Docstring with formula explanation and usage example from ATR plugin

    2. update_ema(current: float, prev_ema: float, span: int) -> float
       - Computes EMA: alpha * current + (1-alpha) * prev_ema where alpha = 2/(span+1)
       - Raises ValueError if span < 1
       - Handles NaN: returns NaN if current is NaN; returns prev_ema if only prev_ema is NaN
       - Docstring with alpha formula and example from MACD plugin

    3. get_main_df(frames: dict[str, Any], min_bars: int) -> pd.DataFrame | None
       - Extracts frames.get("main")
       - Returns None if df is None or len(df) < min_bars
       - Returns DataFrame otherwise
       - Similar to extract_ohlcv in plugin_utils.py but returns DataFrame not tuple
       - Docstring explaining the min_bars guard pattern

    All functions must be module-level (not class methods), pure (no side effects), and type-annotated. Use pandas for DataFrame type. Add __all__ = ["wilders_update", "update_ema", "get_main_df"].
  </action>
