  RESEARCH.md Pitfall 4's explicit warning sign ("a `passes_materiality` boolean that changes
  value purely because `discovery_oos_days` elapsed, with no new measurement having run -
  this would indicate the two gates got merged") over 175-PATTERNS.md line 132's contradicting

  cutover (D-02) can still calibrate its own bar.

  real gate, not dropped. Codex proposed five gate components; all five ship.

  mixes an APR-backed base seed (`alpha.tag_calibrator.materiality.null_arm_seed`, default 42)

  is deliberately NOT routed to `docs/foundation/apr-calibration-backlog.md` (which registers
  gate-shaped thresholds awaiting corpus calibration). Its description must warn that changing
  it invalidates every previously computed `null_arm_p_value`.
