<objective>
Pipeline integration for roll events: all 4 downstream services consume roll events from Kafka, indicator_service migrates plugin state with roll_gap adjustments, feature_writer writes roll boundary markers, and historical_backfill seeds contract_metadata roll chains. seed_roll_chain is fully unit-tested.

Purpose: Without downstream integration, detecting a roll in tws_daemon is useless — the pipeline continues processing the old contract, creating gaps in intelligence_features. This plan ensures the entire pipeline transitions seamlessly on roll detection.

Output: Updated 4 services + backfill script + comprehensive unit tests for plugin state migration, roll event consumption, and seed_roll_chain DB logic.

         ```python
         async def _handle_roll_event(self, event: dict):
             """Migrate plugin state on futures roll."""
             if event.get("event_type") != "roll":
                 return
             base_symbol = event["base_symbol"]
             old_symbol = event["old_symbol"]
             new_symbol = event["new_symbol"]
             roll_gap = event.get("roll_gap", 0.0)

             PRICE_SENSITIVE_PLUGINS = {"bollinger_bands", "keltner_channel", "donchian_channel"}

             for tf in ["1m", "5m", "15m", "1h"]:
                 old_key = f"{old_symbol}:{tf}"
                 new_key = f"{new_symbol}:{tf}"
                 if old_key not in self._i1_plugin_states:
                     continue

                 old_state = self._i1_plugin_states[old_key]
                 new_state = {}

                 for plugin_name, state in old_state.items():
                     if plugin_name in PRICE_SENSITIVE_PLUGINS:
                         # Deep copy and adjust price levels by roll_gap
                         adjusted = _adjust_price_state(state, roll_gap)
                         new_state[plugin_name] = adjusted
                     else:
                         # Volume-neutral: copy verbatim
                         new_state[plugin_name] = state.copy() if isinstance(state, dict) else state

                 self._i1_plugin_states[new_key] = new_state
                 del self._i1_plugin_states[old_key]
                 self._logger.info("roll_plugin_state_migrated", old=old_key, new=new_key, gap=roll_gap)
         ```
