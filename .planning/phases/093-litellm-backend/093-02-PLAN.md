<task id="3" name="Smoke test LiteLLMBackend against live Ollama">
<action>
Run the live smoke test inline:

```bash
.venv/bin/python - <<'EOF'
import asyncio, os
os.environ["OLLAMA_API_BASE"] = "http://localhost:11434"
from src.core.llm.litellm_backend import LiteLLMBackend
from unittest.mock import MagicMock

s = MagicMock()
s.ollama_enabled = True
s.ollama_model = "nemotron-3-nano:4b"
s.ollama_base_url = "http://localhost:11434"
s.ollama_num_ctx = 4096
s.openrouter_api_key = ""
s.openrouter_models = ""

backend = LiteLLMBackend(s)

async def run():
    result = await backend.generate(
        prompt='Return exactly: {"ok": true}',
        system="OUTPUT ONLY RAW JSON. NO PROSE. NO EXPLANATION. NO PREAMBLE. Begin your response with { and end with }.",
        max_tokens=50,
        timeout=30.0,
    )
    print(f"provider: {backend.last_provider_id}")
    print(f"result: {result}")
    print(f"tokens: {backend.last_token_usage}")
    assert result is not None, "Expected non-None result from Ollama"
    assert backend.last_provider_id == "ollama/nemotron-3-nano:4b", f"Wrong provider: {backend.last_provider_id}"

asyncio.run(run())
print("SMOKE TEST PASSED")
EOF
```

If smoke test fails (Ollama not running), check `docker exec ollama ollama ps` and `docker ps | grep ollama`.
