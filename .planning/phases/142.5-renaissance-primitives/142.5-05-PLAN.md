## Existing Distance Primitive Pattern

From `src/intelligence/feature_factory.py`:

```python
def _range_position(
    close: float,
    highs: np.ndarray,
    lows: np.ndarray,
    eps: float = 1e-10,
) -> float:
    """Close position within N-bar high-low range.

    Formula: (close - min(low_N)) / (max(high_N) - min(low_N))
    Returns 0.5 on degenerate range.
    """
    range_low = float(np.min(lows))
    range_high = float(np.max(highs))
    rng = range_high - range_low
    return (close - range_low) / (rng + eps)
```

This pattern uses numpy array operations on rolling windows and epsilon guards for degenerate ranges.

    ```python
        n = len(closes)
        if n == 0:
            return 0.5
        # Count closes less than current close
        rank = np.sum(closes < close)
        return rank / n
    ```

    **Efficiency ratio (2 primitives):**
    ```python
    def _efficiency_ratio(closes: np.ndarray, eps: float = 1e-10) -> float:
        """Kaufman Efficiency Ratio: abs(net_move) / sum(abs(bar_moves)).
        Range [0, 1]. 0 = pure chop, 1 = perfectly linear trend."""
        if len(closes) < 2:
            return 0.0
        net_move = abs(closes[-1] - closes[0])
        bar_moves = np.abs(np.diff(closes))
        total_movement = float(np.sum(bar_moves))
        return net_move / total_movement if total_movement > eps else 0.0
    ```

    ```python
        import numpy as np

        # Distance primitives: require ATR > 0
        highs = np.array([105.0, 108.0, 110.0, 112.0, 115.0])

        # ATR zero guard
        result = _dist_from_high(close, highs, 0.0)
    ```
