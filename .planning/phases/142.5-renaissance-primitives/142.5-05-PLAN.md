## Breakout Distance Primitive Catalog (14)

| Feature | Formula | APR |
|---|---|---|
| `dist_from_high_fast/slow` | `(rolling_high_N - C) / ATR` | `feature.breakout.dist_window_fast/slow` |
| `dist_from_low_fast/slow` | `(C - rolling_low_N) / ATR` | `feature.breakout.dist_window_fast/slow` |
| `range_pct_fast/slow` | `(rolling_high_N - rolling_low_N) / C` | `feature.breakout.range_window_fast/slow` |
| `new_high_flag` | `1 if C == rolling_high_N else 0` | `feature.breakout.dist_window_fast` |
| `new_low_flag` | `1 if C == rolling_low_N else 0` | `feature.breakout.dist_window_fast` |
| `stoch_k_fast/slow` | `(C - L_N) / (H_N - L_N)` | `feature.breakout.stoch_window_fast/slow` |
| `price_percentile_fast/slow` | rolling percentile rank of C_t | `feature.breakout.percentile_window_fast/slow` |
| `efficiency_ratio_fast/slow` | `abs(C_t - C_{t-N}) / sum(\|C_i - C_{i-1}\|)` | `feature.breakout.efficiency_window_fast/slow` |

Ranges: distances/range_pct unbounded positive; flags {0,1}; stoch_k/price_percentile/efficiency [0,1].

## Existing distance primitive pattern

`_range_position(close, highs, lows, eps=1e-10)` returns `(close - min(lows)) / (max(highs) - min(lows) + eps)`,
0.5 on degenerate range. Replicate the numpy-array + epsilon-guard style.
