## Alternative Volatility Estimators (3 primitives)

From signal-renaissance-primitives-ohlcv.md:

| Feature | Formula | APR Key |
|---|---|---|
| `parkinson_vol_z` | z-score of `ln(H/L)^2 / (4*ln(2))` | `feature.parkinson_vol.window` |
| `garman_klass_vol_z` | z-score of GK estimator | `feature.garman_klass_vol.window` |
| `yang_zhang_vol_z` | z-score of YZ estimator | `feature.yang_zhang_vol.window` |

**Formulas (from spec):**

Parkinson estimator (H/L only, no overnight gap):
```python
parkinson = (np.log(high / low) ** 2) / (4 * np.log(2))
```

Garman-Klass estimator (includes open drift within bar):
```python
gk = 0.5 * (np.log(high / low) ** 2) - (2 * np.log(2) - 1) * (np.log(close / open) ** 2)
```

Yang-Zhang estimator (includes overnight gap):
```python
# Overnight variance
var_overnight = (np.log(open / prev_close) ** 2)
# Open-to-close variance (GK)
var_oc = 0.5 * (np.log(high / low) ** 2) - (2 * np.log(2) - 1) * (np.log(close / open) ** 2)
# Yang-Zhang estimator (k ≈ 0.34)
k = 0.34 / (1 + k)  # Simplified: 0.34
yz = var_overnight + k * var_oc
```

## Volatility Dynamics Primitives (5 primitives)

From signal-renaissance-primitives-ohlcv.md:

| Feature | Formula | APR Key |
|---|---|---|
| `parkinson_vol_velocity` | `parkinson_vol_z_t - parkinson_vol_z_{t-1}` | None (no window) |
| `garman_klass_vol_velocity` | `garman_klass_vol_z_t - garman_klass_vol_z_{t-1}` | None |
| `yang_zhang_vol_velocity` | `yang_zhang_vol_z_t - yang_zhang_vol_z_{t-1}` | None |
| `vol_velocity_z` | z-score of rolling `atr_z` velocity | `feature.vol_velocity.window` |
| `intraday_noise_ratio` | `sum(\|ret_1m\|) / \|ret_1d\|` | `feature.intraday_noise.window` |

**Velocity Definition (from spec):**
First derivative (rate of change) of a volatility metric:
- Positive = vol accelerating (panic onset)
- Negative = vol decelerating (stabilization)
- Near zero = steady-state vol

**Intraday Noise Ratio (from spec):**
```python
# Ratio of intraday oscillation to net directional progress
intraday_sum = sum(abs(returns_in_session))
daily_ret = abs(close_first - close_last)
noise_ratio = intraday_sum / daily_ret
# High = chop (mean-reverting), Low = trend (directional progress)
```

    6. `_yang_zhang_vol_z(...) -> float`
       - Computes z-score of YZ values
       - Returns 0.0 on insufficient history
