## Return Distribution Primitives (7)

| Feature | Formula | APR Key |
|---|---|---|
| `ret_kurtosis_z_fast` | z-score of rolling kurtosis | `feature.ret_kurtosis.fast` |
| `ret_kurtosis_z_slow` | z-score of rolling kurtosis | `feature.ret_kurtosis.slow` |
| `ret_autocorr_1` | lag-1 autocorrelation | None (definitional) |
| `ret_autocorr_5` | lag-5 autocorrelation | None (definitional) |
| `updown_ratio_fast` | count(up bars) / count(down bars) | `feature.updown_ratio.fast` |
| `updown_ratio_slow` | count(up bars) / count(down bars) | `feature.updown_ratio.slow` |
| `streak_z` | z-score of directional streak length | `feature.streak.window` |

Pearson kurtosis: `mean(((ret - mean)/std)**4) - 3.0`. Streak: current directional run length,
z-scored over window.

## Realized Variance / Volatility Primitives (14)

| Feature | Formula | APR Key |
|---|---|---|
| `realized_var_ratio_fast` | realized_var_fast / realized_var_slow | `feature.realized_var.fast/slow` |
| `realized_var_ratio_slow` | same | same |
| `range_to_close` | `(H - L) / C` | None |
| `true_range_pct` | `TR / C` | None |
| `vol_of_vol` | Rolling std of atr_z | `feature.vol_of_vol.window` |
| `high_low_corr` | Correlation of H and L | `feature.high_low_corr.window` |
| `variance_ratio_fast` | `var(ret, N_fast) / (N_fast * var(ret, 1))` | `feature.variance_ratio.fast` |
| `variance_ratio_slow` | same | `feature.variance_ratio.slow` |
| `vol_asymmetry_z` | z-score of `std(ret\|up) / std(ret\|down)` | `feature.vol_asymmetry.window` |
| `bb_pct_b_fast` | `(C - lower_band_N) / (upper_band_N - lower_band_N)` | `feature.bb_pct_b.fast` |
| `bb_pct_b_slow` | same | `feature.bb_pct_b.slow` |
| `hv_z_fast` | z-score of `std(log(C_t/C_{t-1}), N_fast)` | `feature.hv.fast` |
| `hv_z_slow` | same | `feature.hv.slow` |
| `hv_ratio` | `hv_fast / rolling_mean(hv, N)` | `feature.hv.ratio_window` |

That is 14 primitives. VR test (Lo-MacKinlay), Bollinger %B (SMA ± 2σ) formulas verbatim in spec.
