**Kurtosis Formula (from spec):**
```python
# Pearson kurtosis (fourth moment)
kurt = float(np.mean(((returns - mean) / std) ** 4)) - 3.0
```

**Streak Formula (from spec):**
```python
# Current directional streak length
streak = 0
for i in range(len(closes)-1, 0, -1):
```

**Variance Ratio Formula (from spec):**
```python
# Variance ratio test (Lo-MacKinlay)
var_fast = np.var(returns[-fast_window:])
var_1 = np.var(returns)
vr = var_fast / (fast_window * var_1)
```

**Bollinger Bands Formula (from spec):**
```python
# Bollinger Bands %B
sma = np.mean(closes[-window:])
std = np.std(closes[-window:])
upper_band = sma + 2 * std
lower_band = sma - 2 * std
bb_pct_b = (close - lower_band) / (upper_band - lower_band)
```

    1. `_ret_kurtosis(returns: np.ndarray, window: int, eps: float = 1e-10) -> float`
       - Computes Pearson kurtosis over window: mean(((returns - mean) / std) ** 4) - 3.0
       - Returns 0.0 when len(returns) < window + 2 (kurtosis requires extra samples)
       - Use scipy.stats.kurtosis(fisher=False, bias=False) or manual computation

    2. `_ret_kurtosis_z(returns: np.ndarray, window: int, z_window: int, eps: float = 1e-10) -> float`
       - Computes rolling kurtosis values via _ret_kurtosis series
       - Returns z-score of current kurtosis vs z_window history
       - Returns 0.0 when len(returns) < window + 2 or insufficient z_window history

    3. `_ret_autocorr(returns: np.ndarray, lag: int, eps: float = 1e-10) -> float`
       - Computes lag-L autocorrelation: np.corrcoef(returns[:-lag], returns[lag:])[0, 1]
       - Returns 0.0 when len(returns) < lag + 2 or std(returns) < eps

    4. `_updown_ratio(closes: np.ndarray, window: int, eps: float = 1e-10) -> float`
       - Computes sum(up bars) / sum(down bars) over window
       - Uses np.diff(closes) > 0 for up bar detection
       - Returns 1.0 when down bar count < eps (no down bars)

    5. `_streak_length(closes: np.ndarray) -> int`
       - Computes current directional streak length (positive for up streaks, negative for down)
       - Scans backward from last close until direction reverses
       - Returns 0 for no streak (single bar)

    6. `_streak_z(closes: np.ndarray, window: int) -> float`
       - Computes z-score of current streak length vs streak history over window
       - Returns 0.0 when len(closes) < window

    Pattern: Use scipy.stats for correlation/kurtosis where available, manual fallback for edge cases.
    All functions return neutral value (0.0, 1.0) on cold start — no NaN/inf.

    1. `_realized_var_ratio(returns: np.ndarray, fast_window: int, slow_window: int, eps: float = 1e-10) -> float`
       - Computes var(returns[-fast_window:]) / var(returns[-slow_window:])
       - Returns 1.0 when len(returns) < slow_window or both vars < eps

    2. `_range_to_close(high: float, low: float, close: float, eps: float = 1e-10) -> float`
       - Computes (high - low) / close
       - Returns 0.0 when close < eps

    3. `_true_range_pct(high: float, low: float, close: float, prev_close: float, eps: float = 1e-10) -> float`
       - Computes max(high, prev_close) - min(low, prev_close) / close
       - Returns 0.0 when close < eps

    4. `_vol_of_vol(atr_z_values: np.ndarray, window: int) -> float`
       - Computes rolling std of atr_z_values over window
       - Returns 0.0 when len(atr_z_values) < window

    5. `_high_low_corr(highs: np.ndarray, lows: np.ndarray, window: int) -> float`
       - Computes np.corrcoef(highs[-window:], lows[-window:])[0, 1]
       - Returns 0.0 when len(highs) < window or std < eps

    6. `_variance_ratio(returns: np.ndarray, window: int, eps: float = 1e-10) -> float`
       - Computes var(returns[-window:]) / (window * var(returns))
       - Returns 1.0 when len(returns) < window or total var < eps

    7. `_vol_asymmetry(closes: np.ndarray, window: int, eps: float = 1e-10) -> float`
       - Splits returns into up bars (close > prev_close) and down bars
       - Computes std(up_returns) / std(down_returns)
       - Returns z-score of this ratio over window history
       - Returns 0.0 when len(closes) < window + 1 or either std < eps

    8. `_bb_pct_b(closes: np.ndarray, window: int) -> float`
       - Computes SMA ± 2*std for Bollinger Bands
       - Returns (close - lower_band) / (upper_band - lower_band)
       - Returns 0.5 when len(closes) < window or band width < eps

    9. `_hv_z(closes: np.ndarray, window: int, z_window: int, eps: float = 1e-10) -> float`
       - Computes std(log(closes / prev_close)) over window
       - Returns z-score vs z_window history
       - Returns 0.0 when len(closes) < window + 1 or insufficient z_window

    10. `_hv_ratio(hv_values: np.ndarray, window: int, eps: float = 1e-10) -> float`
        - Computes hv_fast / rolling_mean(hv_values[-window:])
        - Returns 1.0 when len(hv_values) < window or mean < eps

    Pattern: Use np.corrcoef for correlation, np.var for variance, np.std for std.
    All functions return neutral value (0.0, 1.0, 0.5) on cold start — no NaN/inf.
