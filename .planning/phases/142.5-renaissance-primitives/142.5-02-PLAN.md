## Temporal Coordinate Primitives (10 implemented here)

Codebase reality (verified 2026-07-06): only `dow_sin`, `dow_cos`, and `month_position` (a linear
0-1 value, NOT a sin/cos pair) exist. So of the spec's 6 sin/cos pairs, only the `dow` pair exists.
This plan adds 4 new pairs plus the `month` sin/cos pair (10 new features):

| Feature | Formula | New? | APR | Domain |
|---|---|---|---|---|
| `hour_of_day_sin/cos` | `sin/cos(2π * (hour + minute/60) / 24)` | NEW | None | calendar |
| `week_of_month_sin/cos` | `sin/cos(2π * ((day-1)//7 + 1) / 5)` | NEW | None | calendar |
| `day_of_month_sin/cos` | `sin/cos(2π * day / 31)` | NEW | None | calendar |
| `week_of_year_sin/cos` | `sin/cos(2π * isocalendar_week / 52)` | NEW | None | calendar |
| `month_sin/cos` | `sin/cos(2π * month / 12)` | NEW (only month_position existed) | None | calendar |

Formulas verbatim in docs/ideas/signal-renaissance-primitives-ohlcv.md lines 327-359. Cos variants
identical but use cos(). `dow_sin/cos` already exist and are NOT re-added.

## Volume Structure Primitives (12 — was mislabeled 10)

| Feature | Formula | APR Key |
|---|---|---|
| `vol_acceleration` | `V_t / V_{t-1}` | None |
| `dollar_vol_z` | z-score of `(V * C)` over N | `feature.dollar_vol.window` |
| `vol_range_ratio` | `V_t / (H - L)` normalized over N | `feature.vol_range_ratio.window` |
| `vol_trend_ratio` | `vol_MA_fast / vol_MA_slow` | `feature.vol_trend.fast`, `.slow` |
| `up_vol_ratio_fast` | `sum(V\|C>O) / sum(V)` over N | `feature.up_vol_ratio.fast` |
| `up_vol_ratio_slow` | same | `feature.up_vol_ratio.slow` |
| `vol_percentile` | rolling percentile rank of V_t | `feature.vol_percentile.window` |
| `vol_persistence` | lag-1 autocorrelation of V | `feature.vol_persistence.window` |
| `vol_std_z` | z-score of rolling std(V) | `feature.vol_std.window` |
| `mfi_fast` | Money Flow Index | `feature.mfi.fast` |
| `mfi_slow` | Money Flow Index | `feature.mfi.slow` |
| `obv_z` | z-score of OBV | `feature.obv.window` |

That is 12 primitives (vol_acceleration through obv_z). MFI: `100 * sum(tp*V | tp rising) / sum(tp*V)`,
tp = (H+L+C)/3. OBV: cumulative signed volume, z-scored over N.

## Existing calendar pattern

`dow_sin` uses `math.sin(2*pi*bar_ts.weekday()/7)`; `_month_position(bar_ts)` at ~line 455. Use
`math` (not numpy) for scalar trigonometry. month_sin uses `math.sin(2*pi*bar_ts.month/12)`.

## Cold-start contract (antigravity H1)

`_cold_start_vector()` (~line 1506) constructs FeatureVector with a kwarg for every field. EVERY new
field this plan adds MUST get a neutral fallback there. sin fields -> 0.0, cos fields -> 1.0, volume
primitives -> neutral (vol_acceleration 1.0, up_vol_ratio_* 0.5, vol_percentile 0.5, mfi_* 50.0,
others 0.0).
