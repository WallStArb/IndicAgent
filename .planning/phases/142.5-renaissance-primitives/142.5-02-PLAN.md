**Implementation formulas (from spec):**
```python
def hour_of_day_sin(dt: datetime) -> float:
    hour = dt.hour + dt.minute / 60
    return sin(2 * pi * hour / 24)

def week_of_month_sin(dt: datetime) -> float:
    week = (dt.day - 1) // 7 + 1
    return sin(2 * pi * week / 5)

def day_of_month_sin(dt: datetime) -> float:
    return sin(2 * pi * dt.day / 31)

def week_of_year_sin(dt: datetime) -> float:
    _, week, _ = dt.isocalendar()
    return sin(2 * pi * week / 52)
```

Cos variants identical but use cos() instead of sin().

## Volume Structure Primitives (10 primitives)

| Feature | Formula | APR Key |
|---|---|---|
| `vol_acceleration` | `V_t / V_{t-1}` | None (bar-relative) |
| `dollar_vol_z` | z-score of `(V * C)` over N | `feature.dollar_vol.window` |
| `vol_range_ratio` | `V_t / (H - L)` normalized over N | `feature.vol_range_ratio.window` |
| `vol_trend_ratio` | `vol_MA_fast / vol_MA_slow` | `feature.vol_trend.fast`, `.slow` |
| `up_vol_ratio_fast` | `sum(V\|C>O) / sum(V)` over N | `feature.up_vol_ratio.fast` |
| `up_vol_ratio_slow` | same | `feature.up_vol_ratio.slow` |
| `vol_percentile` | rolling percentile rank of V_t | `feature.vol_percentile.window` |
| `vol_persistence` | lag-1 autocorrelation of V | `feature.vol_persistence.window` |
| `vol_std_z` | z-score of rolling std(V) | `feature.vol_std.window` |
| `mfi_fast` | Money Flow Index | `feature.mfi.fast` |
| `mfi_slow` | Money Flow Index | `feature.mfi.slow` |
| `obv_z` | z-score of OBV | `feature.obv.window` |

**MFI Formula (from spec):**
```python
tp = (high + low + close) / 3
mfi = 100 * sum(tp * volume where tp rising) / sum(tp * volume)
```

**OBV Formula (from spec):**
```python
obv = cumulative sum of (+volume when close > prev_close, -volume when close < prev_close)
obv_z = z-score of rolling OBV over N bars
```
