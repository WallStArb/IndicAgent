## APR Namespace Convention

All Renaissance primitives use `feature.*` namespace:
- `feature.ret_lag.fast` — lagged return fast window
- `feature.mfi.fast` — money flow index fast window  
- `feature.breakout.lookback_fast` — breakout distance lookback window
