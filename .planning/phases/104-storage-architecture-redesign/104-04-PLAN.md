<objective>
Create the third pillar of the 3-store architecture: ml_signal_training. A nightly-materialized
hypertable with flat typed columns (no JSONB). Eliminates JSONB unnesting at query time during
ML training. The nightly systemd timer pre-joins intelligence_features.trading_signals with
signal_ledger lifecycle/outcomes and writes flat rows.

Purpose: Renaissance principle — access pattern drives schema. ML training is a bulk columnar read;
incompatible with OLTP point updates in signal_ledger. Pre-materialize the JOIN nightly so the
LightGBM trainer reads typed columns at full I/O bandwidth.
Output: New hypertable; nightly oneshot timer; materialize agent that handles initial INSERT and
outcome backfill for unresolved rows.
</objective>
