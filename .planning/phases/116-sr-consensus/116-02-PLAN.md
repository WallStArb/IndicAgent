    Bounds by direction:
    - `direction == 1` (resistance): `lo, hi = price, price + max_dist`, `specs = _RESISTANCE_SPECS`

    - Iterate `specs`: for each `(feat_key, name, default_str, tier, family)`, read `p = _fval(features, feat_key)`; skip if `p <= EPSILON or not (lo < p < hi)`; else append `ZoneCandidate(price=p, name=name, strength=_resolve_strength(features, name, default_str), source_tier=tier, source_family=family)`.
    - VP block identical to collect_candidates: `poc = _select_vp(features, tf, "poc_price", "poc_price_rolling")`; guard `if direction not in _VP_DIRECTION: raise ValueError(...)`; unpack `_VP_DIRECTION[direction]`; `companion = _select_vp(...)`; `hvn = _fval(features, hvn_key)`; append poc/companion/hvn candidates that satisfy `p > EPSILON and lo < p < hi` with strength `0.8 if name=="poc" else 0.7`, `source_tier="i4"`, `source_family=f"vp_{name}"`.
    - `return sorted(_dedup(raw, atr), key=lambda c: c.price)`.

    Body:

    - `diverse = [cl for cl in clusters if _source_diversity(cl) >= 2]`.
    - If `diverse`: `best = max(diverse, key=lambda cl: (_source_diversity(cl), sum(c.strength for c in cl)))`; return a new `ZoneCandidate(price=sum(c.price for c in best)/len(best), name="consensus", strength=float(_source_diversity(best)), source_tier="consensus", source_family="consensus")`.
