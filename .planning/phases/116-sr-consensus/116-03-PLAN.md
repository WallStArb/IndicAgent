<objective>
Create the `ctx_SRConsensus` I4 Wave-B plugin that runs the extended zone synthesis against `current_price +/- max_dist`, adds round-number candidates, and persists the best confluenced support/resistance levels to `intelligence_features` as 6 new fields.

Purpose: Completes the data flow. The multi-source synthesis previously died inside `frame_trade()`. `trade_framer` and `zone_engine` already check `sr_nearest_support`/`sr_nearest_resistance` first but the fields were always null, so both silently fell back to raw pivots. This plugin makes those fields carry real, proximity-gated, multi-source confluenced levels for all downstream consumers.

This plan depends on Plan 02's corrected `collect_sr_candidates` behavior: VP candidates are selected using `_SR_VP_DIRECTION` (not `_VP_DIRECTION`), so resistance calls correctly receive vah/nearest_hvn_above candidates and support calls correctly receive val/nearest_hvn_below candidates. The SRConsensus plugin does not need to do anything special — it inherits correct VP semantics through the `collect_sr_candidates` public API.

Output schema decision: All 6 output keys are ALWAYS emitted. When no candidate found on one side: `sr_nearest_support = None`, `sr_support_confluence_score = 0.0`, `sr_support_dist_atr = None`. A score of 0.0 means no confluence found; score > 0 means at least one source contributed.

Output: `I4Context` extended with 6 fields, new `src/intelligence/context/sr_consensus.py`, 4-location registration in `register_plugins.py`, and a new unit test file.
</objective>

    ```python
    df = frames.get("main")
    if df is None or len(df) < self.min_lookback:
        return {}

    features = {
        **(frames.get("i1") or {}),
        **(frames.get("i3") or {}),
        **(frames.get("i4") or {}),
        **(frames.get("smc") or {}),
    }
    current_price = float(df["close"].iloc[-1])
    features["timeframe"] = frames.get("timeframe", "")

    atr = get_atr(features)
    if not atr:
        return {}

    tf = features["timeframe"]
    max_dist = atr * MAX_STOP_ATR_MULTIPLIER_BY_TF.get(tf, MAX_STOP_ATR_MULTIPLIER_DEFAULT)

    support_candidates = collect_sr_candidates(features, -1, current_price, atr, max_dist)
    support_candidates += _round_number_candidates(current_price, atr, max_dist, -1)

    resistance_candidates = collect_sr_candidates(features, 1, current_price, atr, max_dist)
    resistance_candidates += _round_number_candidates(current_price, atr, max_dist, 1)

    sr_support = find_best_level(support_candidates, atr, current_price)
    sr_resistance = find_best_level(resistance_candidates, atr, current_price)

    # Always emit all 6 keys. When no candidate: price=None, score=0.0, dist_atr=None.
    # Score=0.0 means no confluence found; score>0 means at least one source contributed.
    return {
        "sr_nearest_support": sr_support.price if sr_support is not None else None,
        "sr_nearest_resistance": sr_resistance.price if sr_resistance is not None else None,
        "sr_support_confluence_score": float(sr_support.strength) if sr_support is not None else 0.0,
        "sr_resistance_confluence_score": float(sr_resistance.strength) if sr_resistance is not None else 0.0,
        "sr_support_dist_atr": abs(current_price - sr_support.price) / atr if sr_support is not None else None,
        "sr_resistance_dist_atr": abs(sr_resistance.price - current_price) / atr if sr_resistance is not None else None,
    }
    ```

    Module-level helper `_round_number_candidates(price: float, atr: float, max_dist: float, direction: int) -> list[ZoneCandidate]`:
    ```python
    if price <= EPSILON:
        return []
    magnitude = 10 ** math.floor(math.log10(price))
    grids = [(magnitude, 0.8), (magnitude / 10, 0.6), (magnitude / 20, 0.4)]
    if direction == 1:
        lo, hi = price, price + max_dist
    else:
        lo, hi = price - max_dist, price

    seen_levels: set[float] = set()  # dedup across grid sizes
    result: list[ZoneCandidate] = []
    for grid_size, strength in grids:
        if grid_size <= EPSILON:
            continue
        nearest_below = math.floor(price / grid_size) * grid_size
        nearest_above = math.ceil(price / grid_size) * grid_size
        for level in (nearest_below, nearest_above):
            if level > EPSILON and lo < level < hi and level not in seen_levels:
                seen_levels.add(level)
                result.append(ZoneCandidate(
                    price=level,
                    name=f"round_{grid_size:.0f}",
                    strength=strength,
                    source_tier="round",
                    source_family="round_number",
                ))
    return result
    ```
