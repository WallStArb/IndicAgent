<objective>
Create the `ctx_SRConsensus` I4 Wave-B plugin that runs the extended zone synthesis against `current_price +/- max_dist`, adds round-number candidates, and persists the best confluenced support/resistance levels to `intelligence_features` as 6 new fields.

Purpose: Completes the data flow. The multi-source synthesis previously died inside `frame_trade()`. `trade_framer` and `zone_engine` already check `sr_nearest_support`/`sr_nearest_resistance` first but the fields were always null, so both silently fell back to raw pivots. This plugin makes those fields carry real, proximity-gated, multi-source confluenced levels for all downstream consumers.

Output: `I4Context` extended with 6 fields, new `src/intelligence/context/sr_consensus.py`, 4-location registration in `register_plugins.py`, and a new unit test file.
</objective>

Define module-level `EPSILON = 1e-9`.

    Dataclass `SRConsensusPlugin`:
    - `name: str = "ctx_SRConsensus"`
    - `outputs: frozenset[str]` = frozenset of exactly the 6 field names from Task 1.
    - `min_lookback: int = 5`
    - `supports_incremental: bool = False`
    - `capability_tags: frozenset[str] = frozenset({"context"})`
    - `inputs: tuple[InputSpec, ...] = (InputSpec(symbol=".*", lookback=5),)`

    `compute_full(self, frames)`:
    - `df = frames.get("main")`; if `df is None or len(df) < self.min_lookback: return {}`.
    - Merge tiers: `features = {**(frames.get("i1") or {}), **(frames.get("i3") or {}), **(frames.get("i4") or {}), **(frames.get("smc") or {})}`.
    - `current_price = float(df["close"].iloc[-1])` (NOT features.get("close_price") — that key does not exist in tier sub-dicts).
    - `features["timeframe"] = frames.get("timeframe", "")` so collect_sr_candidates VP selection works.
    - `atr = get_atr(features)`; if `not atr: return {}`.
    - `tf = features["timeframe"]`; `max_dist = atr * MAX_STOP_ATR_MULTIPLIER_BY_TF.get(tf, MAX_STOP_ATR_MULTIPLIER_DEFAULT)`.
    - Support: `support_candidates = collect_sr_candidates(features, -1, current_price, atr, max_dist) + _round_number_candidates(current_price, atr, max_dist, -1)`.
    - Resistance: `resistance_candidates = collect_sr_candidates(features, 1, current_price, atr, max_dist) + _round_number_candidates(current_price, atr, max_dist, 1)`.
    - `sr_support = find_best_level(support_candidates, atr, current_price)`; `sr_resistance = find_best_level(resistance_candidates, atr, current_price)`.
    - Return the 6-field dict: support price + confluence score (0.0 when None) + dist_atr (`abs(current_price - sr_support.price)/atr` when present else None); resistance mirror (`abs(sr_resistance.price - current_price)/atr`). When a side is None: price=None, confluence_score=0.0, dist_atr=None — never synthetic.

    `compute_next(self, windows, *, state=None)`: `return self.compute_full(windows)`.

    Module-level helper `_round_number_candidates(price, atr, max_dist, direction) -> list[ZoneCandidate]`:
    - Return `[]` if `price <= EPSILON`.
    - `magnitude = 10 ** math.floor(math.log10(price))`; grids `[(magnitude, 0.8), (magnitude/10, 0.6), (magnitude/20, 0.4)]`.
    - Bounds: direction==1 -> `lo, hi = price, price + max_dist`; else `lo, hi = price - max_dist, price`.
    - For each `(grid_size, strength)` (skip if `grid_size <= EPSILON`): compute `nearest_below = math.floor(price/grid_size)*grid_size` and `nearest_above = math.ceil(price/grid_size)*grid_size`; for each level append `ZoneCandidate(price=level, name=f"round_{grid_size:.0f}", strength=strength, source_tier="round", source_family="round_number")` when `level > EPSILON and lo < level < hi`.

    There is no `_best_level` helper in this file. `find_best_level` from `zone_engine` (added in Plan 02) returns a `ZoneCandidate | None` directly — use its `.price` and `.strength` fields. Score = `sr_support.strength` when present; `0.0` when `sr_support is None`.

    Module-level singleton: `plugin = SRConsensusPlugin()`.

    Use `except ... as error:` if any try/except is added. No comments unless WHY is non-obvious. Do NOT register the plugin here — registration is Task 3.
