    **Gate 1: signal_events count within 2% of 1,036,513.**
    QUERY: SELECT COUNT(*) FROM signal_events;
    PASS if: result is between 1,015,783 and 1,057,243.

    **Gate 2: Distinct plugins = 35.**
    QUERY: SELECT setup_plugin, COUNT(*) as fires FROM signal_events GROUP BY 1 ORDER BY 2 ASC;
    PASS if: exactly 35 rows returned. Any row with COUNT(*)=0 cannot appear (the plugin would not be in signal_events).
    ALSO CHECK: CrossAssetDivergence must NOT be in the results (it is excluded as live-only per Phase 131 D-02).
    Any plugin not in the list with 0 fires is a bug — document it as a failing gate.

    **Gate 3: All active-contract symbols present (excluding FX model-gap instruments).**
    QUERY: SELECT symbol, COUNT(*) FROM signal_events GROUP BY 1 ORDER BY 1;
    FX model-gap exclusions per Phase 131 D-05: EURUSD (and any other FX instruments documented in Phase 131 as model-gap).
    PASS if: all other active-contract symbols appear with COUNT(*) > 0.
    To get the expected symbol list:
    PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent -c "SELECT symbol FROM instruments WHERE is_active=true AND asset_class != 'fx' ORDER BY 1;"
    Compare against signal_events symbols.

    **Gate 4: context_features coverage >= 99%.**
    QUERY:
    SELECT
        COUNT(*) as total,
        COUNT(context_features) as with_context,
        ROUND(100.0 * COUNT(context_features) / COUNT(*), 2) as coverage_pct
    FROM signal_events;
    PASS if: coverage_pct >= 99.00.

    **Gate 5: ctf_score distribution non-degenerate (>= 85% of non-null rows have ctf_score > 0.05).**
    QUERY:
    SELECT
        COUNT(*) FILTER (WHERE ctf_score IS NOT NULL) as non_null_count,
        COUNT(*) FILTER (WHERE ctf_score > 0.05) as above_threshold,
        ROUND(100.0 * COUNT(*) FILTER (WHERE ctf_score > 0.05) /
              NULLIF(COUNT(*) FILTER (WHERE ctf_score IS NOT NULL), 0), 2) as pct_above_threshold
    FROM signal_events;
    PASS if: pct_above_threshold >= 85.00.
    NOTE: Do NOT use a null check. ctf_score=0.0 (not NULL) is the broken pattern. The 316 cold-start bars (79 symbols x 4 TFs, bar 1 each) are expected to have ctf_score=0.0 and do not indicate a broken A7 fix.
    If pct_above_threshold < 85%, the A7 fix from Phase 131 is not working — this is a blocker.

    **Gate 6: stopped_at_entry rate < 5% of total executions.**
    NOTE 2026-06-20: After Phase 134, stopped_at_entry is in the `outcome` column (signal_outcome_type
    ENUM), NOT in exit_reason. The original query using `exit_reason LIKE 'stopped%'` is wrong.

    QUERY:
    SELECT
        outcome,
        COUNT(*) as count,
        ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (), 2) as pct_of_all_executions
    FROM trade_executions
    WHERE outcome IS NOT NULL
    GROUP BY 1 ORDER BY 2 DESC;
    PASS if: the `stopped_at_entry` row shows pct_of_all_executions < 5.00, OR `stopped_at_entry`
    does not appear (never fired). Any value >= 5% indicates bad entry geometry — a Phase 132 fix
    regression or schema wiring error.
    NOTE: Only valid after lifecycle_replay.py completes (lifecycle writes outcome, not backfill).

    **Gate 7: trade_frames is a hypertable.**

    PASS if: 1 row returned with hypertable_name='trade_frames'.

    **Gate 11: Per-symbol ctf_score breakdown (no symbol below 80% threshold).**
    QUERY:
    SELECT
        symbol,
        COUNT(*) FILTER (WHERE ctf_score IS NOT NULL) as non_null,
        COUNT(*) FILTER (WHERE ctf_score > 0.05) as above_threshold,
        ROUND(100.0 * COUNT(*) FILTER (WHERE ctf_score > 0.05) /
              NULLIF(COUNT(*) FILTER (WHERE ctf_score IS NOT NULL), 0), 2) as pct_above
    FROM signal_events
    GROUP BY symbol
    ORDER BY pct_above ASC;
    PASS if: every symbol shows pct_above >= 80.0. A symbol below 80% indicates a localized
    A7 fix failure for that instrument — document as a FAIL with the symbol name.
    NOTE: The global 85% gate (Gate 5) can pass even if one symbol is broken. This breakdown
    detects that failure.

    **Gate 12: Structural integrity — no orphan trade_frames.**
    QUERY:
    SELECT COUNT(*) FROM trade_frames tf
    WHERE NOT EXISTS (
        SELECT 1 FROM signal_events se WHERE se.signal_id = tf.signal_id
    );
    PASS if: result = 0. Any non-zero count means trade_frames rows exist without a parent signal.

    **Gate 13: Structural integrity — no trade_executions with missing frame reference.**

    WHERE NOT EXISTS (
        SELECT 1 FROM trade_frames tf WHERE tf.frame_id = te.frame_id AND tf.signal_ts = te.signal_ts
    );
    PASS if: result = 0. Any non-zero count means broken FK linkage after the hypertable migration.
