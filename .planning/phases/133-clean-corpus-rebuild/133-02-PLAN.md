    Locate all manual `await conn.execute("COMMIT")` and `await conn.execute("ROLLBACK")` calls

    `async with conn.transaction():`.

    CRITICAL: The context manager must wrap exactly one batch of `--commit-every N` signals,
    NOT the entire per-symbol loop. Wrapping the entire loop creates a multi-hour single
    transaction. The correct pattern:

    ```python
    for batch in chunks(signals, commit_every):
        async with conn.transaction():
            for signal in batch:
                # ... DB writes ...
    ```

    The context manager commits on clean exit, rolls back on exception — no finally block needed.
    Remove all manual `await conn.execute("COMMIT")` and `await conn.execute("ROLLBACK")` calls.
