into rowstore chunks, `compress_chunk()` per completed chunk, a float32 clamp driven by the live

Contract this plan creates (consumed by 186-14 and 186-25; state it in the `bulk_load` docstring):
- `BulkLoadSpec` frozen dataclass: `writer: str`, `target_table: str`, `time_column: str`,
  `tf: str`, `range_start: datetime`, `range_end: datetime` (half-open, both tz-aware UTC),
  `symbols: tuple[str, ...]` (stored sorted), `code_key: str` (per-kernel key, D-23, lowercase
  hex 32-64 chars), `apr_snapshot: Mapping[str, Any]`, `input_digest: str` (lowercase hex 32-64).
  Properties `apr_hash` (sha256 hex of canonical JSON: `sort_keys=True`, `separators=(",", ":")`,
  `default=str`), `symbols_hash` (sha256 hex of the `|`-joined sorted symbols), `batch_key`
  (sha256 hex of canonical JSON of writer, target_table, tf, range_start and range_end as
  `format_iso_ts`, symbols_hash, code_key, apr_hash, input_digest). Validation in
  `__post_init__` raises ValueError on naive datetimes, `range_start >= range_end`, empty
  symbols, or malformed hex.
- `BulkLoadResult` frozen dataclass: `batch_key: str`, `status: Literal["loaded", "skipped"]`,
  `row_count: int`, `chunks_compressed: int`.
- `BulkLoadRefused(RuntimeError)`: raised for every refusal (policy active, compressed chunk in
  range, another session holds the unit's lock, time column mismatch).
- `bulk_load(conn, spec, columns: Sequence[str], rows: Iterable[Sequence[Any]], *,
  compress_before: datetime | None = None) -> BulkLoadResult`. `conn` is a psycopg 3 sync
  connection, not in autocommit, with no open transaction holding uncommitted work; `bulk_load`
  commits (the provenance lifecycle needs its own commits). Async callers (186-14) run it on a
  dedicated psycopg connection via `asyncio.to_thread`; there is one primitive, not an asyncpg
  sibling.
- `completed_provenance_batch(conn, spec) -> dict | None`: the completed row for
  `spec.batch_key`, so a caller can skip computing a unit before paying for it (186-25 resume).
- `compress_completed_chunks(conn, target_table, before: datetime) -> int`: compresses every
  uncompressed chunk of `target_table` whose `range_end <= before`, one `compress_chunk(...,
  if_not_compressed => true)` per chunk, committing after each; returns the count.
- `provenance_batch.target_table` is immutable once written; a later rename-swap (186-27) records
  the mapping in its summary, it does not rewrite provenance rows.
