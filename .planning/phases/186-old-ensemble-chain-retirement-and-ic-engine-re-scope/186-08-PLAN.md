    Create `src/intelligence/features/causality_probe.py` (Ring 1, pure, no DB) implementing D-27 as truncation, the definition the decision states: for each probed row t, slice every input array to rows `[: t + 1]` along axis 0 (for `cross_sectional` kernels the `[row, symbol]` arrays are cut on axis 0, which truncates every symbol at once), recompute, cast both the truncated output and the full output's first t+1 rows to the kernel's dtype (float32 by default), and compare.
