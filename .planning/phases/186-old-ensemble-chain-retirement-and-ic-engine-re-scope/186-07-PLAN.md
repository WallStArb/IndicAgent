## Pre-stated design and decision rule (fixed before any run; D-18, R-08)

- Universe: `universe_symbols(dsn, "compute_eligible")` (233 names).
- Window: 15m S0 panel, `start` default `2016-01-01` (p90 first intraday bar is 2016-02-04, so
  the cross-section is thin before it; override via `--start`, recorded), `end_exclusive` =
  oos_start read from `config_state`. `build_panel` refuses anything later.
- Horizons (15m bars, matched clock): 10 (2.5 h, 30 5m bars) and 13 (half session, 39 5m bars).
  Targets: `forward_returns(panel.open, horizon, session=panel.session)` with no `closes`, so every
  target is a fixed-length intraday window inside one session (D-18); crossing rows are NaN.
- Alignment: 15m feature row at `bar_ts == panel.timestamps[t]` (known at the 15m close);
  5m feature row whose bar ends at that close, i.e. `bar_ts = t + 10 minutes` (verified against
  `bar_close_ts` at runtime; refuse if `bar_close_ts - bar_ts` is not 5 minutes on the sampled 5m
  rows). Never the 5m row with `bar_ts = t`.
- Feature set: `real` columns non-null at both 5m and 15m in the window, minus the excluded classes
  above; a feature whose 5m and 15m cross-sectional ranks are identical on more than 99% of
  (bar, name) cells is reported as `identical_across_tf` and not tested (calendar and HTF-broadcast
  columns).
- Statistic per (feature, horizon): per bar, cross-sectional ranks of the 5m value, 15m value and
  target over names with all three finite (skip bars with fewer than 30 names); partial rank IC of
  5m on target controlling for 15m (residualize both 5m rank and target rank on 15m rank by per-bar
  OLS, correlate residuals). Also report the plain 5m and 15m ICs. Average bar ICs to one value per
  session; t = HAC IC Sharpe over sessions (`_hac_sharpe_nd`, max_lag 5) times sqrt(sessions);
  two-sided p from the normal. BH at q = 0.05 over all tested (feature, horizon) cells.
- Cost: for each BH-significant cell, IC_min over the 2x2 (library rank, breadth) grid using the
  5m feature's own rank turnover at H on the 15m-close-sampled grid, bars per year = 252 x 26;
  the cell clears if |incremental IC| > IC_min at the most lenient grid point, and the minimum
  margin is reported. Statistics are gross; costs only decide (E18).
- Decision: `keep_5m` if at least one (feature, horizon) cell is BH-significant AND clears the cost
  hurdle; the 5m name set is exactly the features with a passing cell, and 5m features stay at the
  233 names that already have 5m features (the 931-name extension is a separate decision after
  todo 449 and the R-09 disk guard). Otherwise `drop_5m`: the rebuild covers 15m, 1h and 1d; raw
  5m bars keep ingesting either way.
