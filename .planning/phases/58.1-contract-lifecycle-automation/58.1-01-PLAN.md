    **Method 1: `session_window_for_date(self, target_date: date) -> tuple[datetime | None, datetime | None]`**

    Logic by session type:

    1. Check `target_date.weekday() not in self.trading_days` -> return `(None, None)`
    2. All-day session (`self.open_time == self.close_time`):
       - `start_utc = datetime(target_date.year, target_date.month, target_date.day, 0, 0, tzinfo=UTC)`
       - `end_utc = start_utc + timedelta(days=1)`
       - return `(start_utc, end_utc)`
    3. Same-day session (`self.open_time < self.close_time`):
       - Convert open_time and close_time from session timezone to UTC
       - `tz = ZoneInfo(self.timezone)`
       - `start_local = datetime.combine(target_date, self.open_time, tzinfo=tz)`
       - `end_local = datetime.combine(target_date, self.close_time, tzinfo=tz)`
       - return `(start_local.astimezone(UTC), end_local.astimezone(UTC))`
    4. Overnight session (`self.open_time > self.close_time`):
       - The session starts the previous calendar day in local time
       - `tz = ZoneInfo(self.timezone)`
       - `prev_day = target_date - timedelta(days=1)`
       - `start_local = datetime.combine(prev_day, self.open_time, tzinfo=tz)`
       - `end_local = datetime.combine(target_date, self.close_time, tzinfo=tz)`
       - return `(start_local.astimezone(UTC), end_local.astimezone(UTC))`

    Import `date` from `datetime` at the top (already has `_date` alias). Use `timedelta` (already imported).

    - Overnight: (24*60 - open_mins) + close_mins, minus break minutes
    - All-day: 1440

    session_minutes = total calendar span (same computation but WITHOUT subtracting breaks — this is the raw window duration)
    
    Wait, re-reading the design spec: "expected_bars = _expected_bars_for_date(session, any_trading_day)" and "session_minutes = minutes in session_window_for_date()". Then max_achievable = expected_bars / session_minutes.

    - session_minutes = total window duration from session_window_for_date
    - max_achievable = expected_bars / session_minutes

    For NYSE: active = 390 min, window = 390 min (6.5h * 60), max_achievable = 1.0

    ```python
    def max_achievable_pct(self) -> float:
        """Structurally achievable bar completeness from session geometry.
        
        Returns ratio of active trading minutes to total session window minutes.
        Sessions with no breaks -> 1.0. Sessions with encoded breaks < 1.0.
        """
        # Compute total window duration using session_window_for_date
        # Pick any trading day for computation
        for wd in range(7):
            if wd in self.trading_days:
                test_date = _date(2026, 3, 2 + wd)  # A Monday+ week
                break
        else:
            return 1.0  # No trading days defined — degenerate case
        
        start, end = self.session_window_for_date(test_date)
        if start is None or end is None:
            return 1.0
        
        total_window_minutes = (end - start).total_seconds() / 60
        if total_window_minutes <= 0:
            return 1.0
        
        # Compute active minutes (minus breaks)
        active_minutes = total_window_minutes
        for brk_start, brk_end in self.trading_breaks:
            brk_duration = (datetime.combine(_date(2000,1,2), brk_end) - 
                          datetime.combine(_date(2000,1,2), brk_start)).total_seconds() / 60
            active_minutes -= brk_duration
        
        if active_minutes <= 0:
            return 1.0
        
        return active_minutes / total_window_minutes
    ```
    
    This approach is clean: it uses session_window_for_date (which already handles session types) to get the raw window, then subtracts breaks.
