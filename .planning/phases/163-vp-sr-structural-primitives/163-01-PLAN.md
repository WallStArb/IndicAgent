<objective>
Establish the full data contract for the volume-profile (VP) structural primitives so downstream
wiring (Plan 02) and support/resistance (Plan 03) can compute against fixed, in-sync interfaces.

This closes the schema half of todo 153: the 4 original structural columns (`poc_dist_atr`,
`va_position`, `sr_support_dist`, `sr_resist_dist`) have been stuck at `FeatureCache` defaults
since v3 inception because nothing ever computed them. This plan adds the 12 new ATR-normalized VP
columns (per D-13 as corrected by D-16 — raw price levels like `poc_price`/`vah`/`val` are NOT
persisted, only ATR-distance / bounded fields), keeps the `ic_engine` drift gate satisfied, and
ports the session volume-profile histogram computation into a new `FeatureCache.update_session_vp()`
mutator.

Purpose: A single atomic contract change (DB columns + feature_registry rows + FeatureVector
dataclass + FEATURE_VECTOR_DOMAIN + persistence INSERT + APR keys + config fields) so no
intermediate state ever trips the `ic_engine` registry-vs-dataclass alignment gate.
Output: Migration 243, updated schemas/domain/persistence, new FeatureFactoryConfig fields, and a
working `update_session_vp()` mutator (computation only; Plan 02 wires it into compute paths).
</objective>
