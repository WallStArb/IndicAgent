## Decisions Made

- **`self.logger` naming**: Named the BaseAgent attribute `self.logger` (not `self.log`) to match the 20+ existing call sites in IndicatorComputeAgent. This avoids a 700+ line diff in Plan 02.
- **`asyncio.get_running_loop()`**: Used over deprecated `get_event_loop()` — Python 3.13 requires this when called inside a running event loop, which is always the case when `_register_signal_handlers()` is invoked from `start()`.
- **`@pytest.mark.asyncio` explicit**: pytest-asyncio 1.3.0 runs in STRICT mode regardless of `asyncio_mode=auto` in pytest.ini. All other async tests in the project use explicit mark — followed the same pattern.
- **BaseAgent.start() calls _run()**: Plan 02 will decide whether IndicatorComputeAgent restructures to route through `super().start()` + `_run()`, or calls `_register_signal_handlers()` directly and keeps its own `start()`.
