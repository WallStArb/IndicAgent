## Decisions Made

- **start() not routed through super()**: IndicatorComputeAgent.start() keeps its 60+ line implementation managing Kafka setup, DB warmup, and all async tasks. `_register_signal_handlers()` is called directly at the start of `start()`. `lag_task` is created in `start()` and cancelled in the `finally` block. Routing through `BaseAgent.start()` + `_run()` is deferred to a future hardening phase.
- **`_run()` raises NotImplementedError**: Satisfies the `@abc.abstractmethod` requirement while documenting that the class does not use `BaseAgent.start()` flow.
- **MarketAnalysisService tests skipped**: `services/market_analysis_service.py` no longer exists (consolidated into `feature_compute_agent` in v2.0). Tests preserved with `@pytest.mark.skip` to document the threading.Lock contract.
- **PERSISTENCE_CONSUMER_LAG set to 0**: `KafkaConsumerClient` has no partition end-offset API. Consistent with Phase 52.1 decision pattern used in `llm_writer_service`.
