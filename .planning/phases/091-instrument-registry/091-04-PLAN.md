  <action>
    Create `production/scripts/migrate_instruments.py`. Top-level module docstring explains purpose and idempotency. Script does:
    1. Load `Settings()` and capture `settings.contracts` (still exists at this point - Plan 091-04 removes it later in this same plan, but the script runs BEFORE the removal, in Task 1).
    2. Open one `asyncpg.connect(settings.database_url)`.
    3. Clean up legacy collision: `DELETE FROM instruments WHERE symbol = 'USD' AND contract_details->>'symbol' IN ('USDCHF','USDJPY')` - removes the row that was incorrectly keyed by base. Log the deleted row count.
    4. For each `c in settings.contracts`, execute the idempotent upsert: `INSERT INTO instruments (symbol, base, contract_details, is_active, updated_at) VALUES ($1, $2, $3::jsonb, $4, NOW()) ON CONFLICT (symbol) DO UPDATE SET contract_details = EXCLUDED.contract_details, is_active = EXCLUDED.is_active, updated_at = NOW()` with params `(c.symbol, c.base, c.model_dump(), True)`. Track inserted/updated counts via the RETURNING xmax pattern: `RETURNING (xmax = 0) AS inserted` - true means new row.
    5. After all upserts, run a safety guard: `SELECT COUNT(*) FROM instruments WHERE is_active=true`. If the count is 0, print `"FATAL: migration produced zero active instruments - aborting"` and call `sys.exit(1)`. This prevents a silent empty-DB scenario from propagating to the running pipeline.
    6. Print summary: total processed, inserted, updated, USDJPY-present check.
    7. Close connection. `asyncio.run(main())`.

    Run the script once against the live DB: `python production/scripts/migrate_instruments.py`. Verify USDJPY is present and the legacy `USD` row is gone. Run again immediately and confirm 0 inserts, all updates (proves idempotency).
  </action>
  <verify>
    First run: `python production/scripts/migrate_instruments.py` exits 0, prints non-zero processed count, USDJPY present. Second run: same command exits 0, prints 0 inserts. `PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent -c "SELECT COUNT(*) FROM instruments WHERE symbol='USD'"` returns 0. `PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent -c "SELECT symbol FROM instruments WHERE contract_details->>'asset_class'='fx' ORDER BY symbol"` returns EURUSD, GBPUSD, USDCHF, USDJPY.
  </verify>
