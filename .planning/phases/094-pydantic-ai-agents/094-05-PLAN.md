<threat_model>
Attack vectors analyzed for AlphaSwarm registration and shadow validation:

**1. Shadow Mode Promotion Bypass**
- Threat: Operator promotes shadow agent before n >= 100 inferences or confidence delta measured
- Mitigation: shadow_only=True hard-coded; promotion requires explicit code change + service restart
- Validation: Shadow validation test documents gate criteria; manual review enforced by ops process

**2. Dual Agent Registration Attack**
- Threat: Both SkepticComputeAgent and SkepticComputeAgentPydantic register; shadow results contaminate production
- Mitigation: shadow_only=True prevents agent from writing to signal_ledger; results logged to llm_calls only
- Validation: Shadow validation query filters by agent_id; skeptic_v2_pydantic results isolated

**3. Dependency Injection via requirements.txt**
- Threat: Malicious actor adds poisoned pydantic-ai version to requirements.txt
- Mitigation: requirements.txt is version-controlled; changes require PR review; comment notes exact version verification
- Validation: CI pipeline runs security audits on dependency changes

**4. Data Exfiltration via Shadow Validation Queries**
- Threat: Shadow validation queries expose sensitive trading patterns or regime data
- Mitigation: Queries limited to aggregate metrics (n, avg_confidence, parse_success_rate); no raw signals
- Validation: Test queries reviewed for data leakage; only summary stats exposed

**5. Benchmark Result Manipulation**
- Threat: Latency benchmark falsified to justify migration despite performance regression
- Mitigation: Benchmark runs on real inference calls; logged to llm_calls with timestamps; auditable
- Validation: Benchmark test documents query; operators can verify against production metrics

**6. BaseAIAgent Deletion Attack**
- Threat: Future refactor deletes BaseAIAgent, breaking unmigrated agents
- Mitigation: Verification task explicitly checks BaseAIAgent existence; AGENT-EXEC-05 prohibits deletion
- Validation: test_verify_base_aiagent_preserved raises failure if BaseAIAgent missing
</threat_model>
