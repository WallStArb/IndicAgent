Replace with the 4-factor intrinsic composite from RESEARCH.md:

```python
# Factor 1: Gap geometry — normalized over meaningful range [0.8, 2.5 ATR]
# Already gated at 0.8x minimum; score 0.0 at 0.8, 1.0 at 2.5+
geo_score = min(1.0, max(0.0, (gap_size_atr - 0.8) / 1.7))

# Factor 2: Volume conviction
vol_score = min(1.0, max(0.0, (vol_ratio - 1.0) / 2.0))  # 0.0 at 1x, 1.0 at 3x

# Factor 3: Session timing — early-session gaps are more meaningful
bars_since = float(features.get("bars_since_session_start") or 30)
# Best at open (0 bars), degrades linearly to 0.2 at 30+ bars
timing_score = max(0.2, 1.0 - bars_since / 30.0)

# Factor 4: Gap type quality
type_score = 0.8 if bias == "continuation" else 0.5

raw_conf = (
    0.40 * geo_score
    + 0.25 * vol_score
    + 0.20 * timing_score
    + 0.15 * type_score
)
```

Notes:
- `bars_since_session_start` uses `or 30` (not `if x is None`) to also handle zero-ish values that are falsy — use explicit `if features.get(...) is not None` guard if the session start bar can legitimately be 0.
- `vol_ratio` is the ratio of current volume to N-bar average — verify the variable name in the file before writing. If the file uses a different name (e.g., `volume_ratio`, `vol_multiple`), use the actual name.
- `bias` is the gap type string ("continuation" or "fade") — verify the variable name in the file.
- Pass raw_conf through `compose_confidence(raw_conf)`.
