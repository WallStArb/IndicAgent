**Primary formula (use if `ofi_ewma_5` is available):**
```python
# Normalize magnitude: 500 floor -> 0.0, 2000+ -> 1.0
magnitude_score = min(1.0, max(0.0, (abs(ofi_ewma_20) - _MIN_OFI_MAGNITUDE) / 1500.0))

# EWMA alignment: short-term confirms long-term direction
ofi_ewma5 = features.get("ofi_ewma_5")
if ofi_ewma5 is not None:
    ewma_aligned = (float(ofi_ewma5) * ofi_ewma_20 > 0)
    alignment_score = 1.0 if ewma_aligned else 0.3
else:
    alignment_score = 0.65  # neutral when unavailable

# Persistence beyond minimum: extra bars add confidence
persistence_score = min(1.0, max(0.0, (count - _MIN_CONSECUTIVE_BARS) / 10.0))

# Volume conviction
rel_vol = float(features.get("rel_volume", 1.0))
volume_score = min(1.0, max(0.0, (rel_vol - 1.0) / 1.5))

raw_conf = (
    0.40 * magnitude_score
    + 0.25 * alignment_score
    + 0.20 * persistence_score
    + 0.15 * volume_score
)
```

Pass raw_conf through `compose_confidence(raw_conf)` (already used in the file for final clamping to [0.0, 0.95]).
