Replace with the 4-factor intrinsic gradient formula from RESEARCH.md. Use the actual `_CVD_DIV_THRESHOLD` constant set in Task 1 as the normalization floor:

```python
# Factor 1: Divergence magnitude — normalized from threshold to strong
# Floor = _CVD_DIV_THRESHOLD, strong = threshold + 2.5
threshold = _CVD_DIV_THRESHOLD
div_mag_score = min(1.0, max(0.0, (abs(cvd_div) - threshold) / (threshold * 125.0 + 2.5)))
# Note: if threshold = 0.5, range is 0.0 at 0.5 -> 1.0 at 3.0
# Adjust the divisor so the upper bound is ~5x the threshold or 3.0, whichever applies

# Factor 2: Dual divergence (OFI also diverging simultaneously)
dual_score = 1.0 if dual_divergence else 0.3

# Factor 3: Persistence beyond minimum (_CONFIRMATION_BARS = 5)
extra_bars = max(0, count - _CONFIRMATION_BARS)
persistence_score = min(1.0, extra_bars / 5.0)  # 0.0 at bar 5, 1.0 at bar 10

# Factor 4: CVD slope alignment — cvd_slope_5bar confirms divergence direction
cvd_slope_raw = features.get("cvd_slope_5bar")
if cvd_slope_raw is not None:
    cvd_slope = float(cvd_slope_raw)
    slope_score = 1.0 if (cvd_slope * cvd_div > 0) else 0.2
else:
    cvd_slope = 0.0
    slope_score = 0.5  # neutral when unavailable

raw_conf = (
    0.40 * div_mag_score
    + 0.25 * dual_score
    + 0.20 * persistence_score
    + 0.15 * slope_score
)
```

Adjust the `div_mag_score` normalization divisor to match the actual threshold value set in Task 1. The normalization should produce 0.0 at the threshold and 1.0 at approximately 5x the threshold (or a fixed upper bound if the distribution showed a natural ceiling).
