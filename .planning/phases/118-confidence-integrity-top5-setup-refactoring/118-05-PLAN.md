<objective>
Refactor trad_DivergenceStack to strip the three extrinsic confidence modifiers (exhaustion_guard, ctf_score, hmm_regime_weight) and replace the post-hoc additive formula with a 4-factor intrinsic composite.

Purpose: DivergenceStack is NOT in Wave 0 scope — the Wave 0 plan did not list divergence_stack.py, but the research confirmed it has all three extrinsic modifier types (lines 241-253). They must be stripped here. The base intrinsic formula (weighted_score from 5 inputs / DIVERGENCE_CONFIDENCE_NORM) is already sound — it measures the breadth and weight of agreeing divergence indicators. The problem is the post-hoc additive layer on top. The 4-factor composite enhances the sound base by adding direction purity and persistence alongside the existing weighted score and breadth count.

Review-driven changes (REVIEWS.md):
- Persistence scoring: the original plan used `max_age` (oldest active divergence) which Codex (MEDIUM) flags as rewarding STALE components. Replace with a freshness-based score: a recently-confirmed divergence stack is higher quality than one whose components are all aging out. Use the MINIMUM (most recent) active age, inverted, so fresher -> higher. Document the rationale in a code comment.
- Clamp every factor to [0,1] before weighting (Codex LOW).
- The final Phase 118 verification grep MUST include divergence_stack.py (consensus #3) — handled in this plan's verification block.

A unique pattern in DivergenceStack: it returns a base_output dict of scoring fields even on no-signal (always-log). The signal.update(base_output) merge pattern must be preserved — do not return early without populating base_output.

Output: divergence_stack.py with three extrinsic modifiers stripped and 4-factor clamped freshness-aware confidence; unit tests.
</objective>

- `DIVERGENCE_CONFIDENCE_NORM` — the normalization constant (0.60 per research)
- `n_agreeing` — count of inputs that agree on direction
- `DIVERGENCE_MIN_AGREEING` — the minimum agreeing inputs gate
- `bull_weight`, `bear_weight` — computed before the signal block (lines ~197-206)
- the per-input age fields in `state` (research lists rsi_age, macd_age, vol_age, obv_age, cmf_age — confirm the real key names)

Replace `raw_div_conf = weighted_score / DIVERGENCE_CONFIDENCE_NORM` with the 4-factor composite (each factor clamped [0,1]):

- Factor 1 — base weighted score:
  - `base_score = min(1.0, max(0.0, weighted_score / DIVERGENCE_CONFIDENCE_NORM))`
- Factor 2 — direction purity:
  - `total_active_weight = bull_weight + bear_weight`
  - `if total_active_weight > 0: purity_score = max(bull_weight, bear_weight) / total_active_weight`
  - `else: purity_score = 0.5`  (0.5 = split, 1.0 = unanimous; already in [0.5,1.0] so naturally bounded — still wrap in min(1.0, max(0.0, ...)))
- Factor 3 — breadth:
  - `breadth_range = 5 - DIVERGENCE_MIN_AGREEING`
  - `breadth_score = min(1.0, max(0.0, (n_agreeing - DIVERGENCE_MIN_AGREEING) / breadth_range)) if breadth_range > 0 else 1.0`
- Factor 4 — persistence by FRESHNESS (Codex MEDIUM fix — recent divergence is stronger, NOT stale):
  - collect the ages of only the ACTIVE/agreeing inputs from `state` (skip inputs with age 0 / inactive)
  - `min_active_age = min(active_ages) if active_ages else 0`  (most-recently-confirmed component)
  - `persistence_score = max(0.0, 1.0 - min_active_age / 10.0)`  (1.0 when just confirmed this bar, decays to 0.0 by 10 bars; add a comment: "freshness, not max-age — a stale stack is lower quality")
  - if no active ages are tracked, default `persistence_score = 0.5`
- Weighted sum:
  - `raw_div_conf = 0.40 * base_score + 0.25 * purity_score + 0.20 * breadth_score + 0.15 * persistence_score`

Notes:
- `state` is already assigned earlier in `compute_full` (e.g. via `self._state.setdefault(state_key, {})`) — reuse the existing pattern; do not introduce a new state dict.

- `bull_weight` / `bear_weight` must be computed before this block — verify; use the real names if different.
- The `base_output` dict feeding always-log must still be populated before the signal return — do not break this.
