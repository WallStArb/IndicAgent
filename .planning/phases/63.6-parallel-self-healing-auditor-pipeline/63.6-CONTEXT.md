**Gathered:** 2026-04-10

<domain>
## Phase Boundary

Eliminate 826+ sequential DB roundtrips per 5-minute audit cycle by:
1. Vectorizing BarAuditorAgent and SignalAuditorAgent into batch SQL (UNNEST-based)
2. Expanding BarAuditorAgent self-healing to all TFs (currently 1m only)
3. Adding signal gap self-healing via new BarReplayAgent service
4. Parallelizing ServiceAuditorAgent systemd checks with asyncio.gather
5. Adding semaphore-bounded concurrent gap fill to BaseProviderAgent
6. Fixing monotonic _last_bar_ts guard in IntelligencePipelineAgent

This phase does NOT: change the hot path signal pipeline, modify schemas for existing topics, touch I1-I7 plugin logic, or change the signal_ledger schema.

</domain>

<decisions>
## Implementation Decisions

### New Module: src/core/audit_utils.py
- Pure async functions only — no Prometheus, no Kafka, no structlog imports
- Callers own all observability concerns
- Two public functions:
  - `batch_bar_completeness(pool, instruments, lookback_days=3) → list[BarCompletenessResult]`
  - `batch_signal_coverage(pool, instruments, coverage_tfs, lookback_days=1) → list[SignalCoverageResult]`
- Session window math (TradingSession boundaries) computed in Python, not SQL
- Use UNNEST arrays for the DB query — guarantees zero-bar sessions appear as rows with actual=0 (pure GROUP BY silently drops them)
- Exact SQL patterns specified in design doc — implement as written

### New Schema: SignalReplayRequest
- Location: `src/core/schemas/market_events.py`
- Fields: `request_id: UUID`, `symbol: str`, `tf: str`, `session_start: datetime`, `session_end: datetime`, `requested_at: datetime`
- All datetimes must be UTC-aware

### New Topic Function: topic_signal_replay_requests
- Location: `src/core/stream_keys.py`
- Pattern: `{env_prefix}.market.events.signal_replay_requests`
- Add docstring explaining consumer (BarReplayAgent) and producer (SignalAuditorAgent)

### BarAuditorAgent Changes
- Replace entire `_detect_gaps` body with single `batch_bar_completeness()` call
- Publish BarGapRequest for ALL TFs (1m, 5m, 15m, 1h, 4h) — not just 1m
- Dedup key: `(symbol, date_str, tf)` — must be per-TF to prevent infinite retry per TF independently
- Update completeness gauge to label with `tf`

### SignalAuditorAgent Changes
- Replace `_check_coverage` + `_check_pipeline_lag` methods with single `batch_signal_coverage()` call
- On `signal_count == 0` for a (symbol, tf) → publish `SignalReplayRequest` to `topic_signal_replay_requests`
- `_check_cis_distribution` method: leave unchanged
- `SignalCoverageGapEvent` Kafka publish: leave unchanged (audit trail)

### ServiceAuditorAgent Changes
- `_systemd_check_loop`: replace sequential `for` loop with `asyncio.gather`
- Use `return_exceptions=True` in gather call
- Skip entries where result is an Exception (log + continue)
- Remediation (`_evaluate_service`) remains ordered — parallelism is detection only
- `dag_order` field still respected

### BaseProviderAgent Changes
- `_MAX_CONCURRENT_GAP_FILLS = 3` (IBKR pacing limit — exceed → Error 162)
- Create `asyncio.Semaphore` inside `_gap_requests_loop` (not in `__init__`)
- Fire-and-track task pool using `tasks: set[asyncio.Task]`
- `task.add_done_callback(tasks.discard)` for auto-cleanup
- Drain all in-flight tasks on SIGTERM via `asyncio.gather(*tasks, return_exceptions=True)`
- `_fill_gap(req, sem)` is the new method wrapping existing fetch+publish logic

### IntelligencePipelineAgent Change (minimal)
- One-line fix in `_process_bar`:
  ```python
  # Before: self._last_bar_ts[key] = bar.ts.timestamp()
  # After:
  if bar.ts.timestamp() > self._last_bar_ts.get(key, 0):
      self._last_bar_ts[key] = bar.ts.timestamp()
  ```
- This is a correctness fix (monotonic guard) that replay exposes but should always have been the behavior

### New Service: BarReplayAgent

- Systemd unit name: `indicagent-bar-replay`
- Unit file location: installed to `/etc/systemd/system/` and template in `production/systemd/`

## Specific Ideas

### SQL Pattern for Batch Bar Completeness (from design doc)
```sql
SELECT
    ref.symbol, ref.tf, ref.session_start, ref.session_end, ref.expected,
    COUNT(m.timestamp) AS actual
FROM UNNEST($1::text[], $2::text[], $3::timestamptz[], $4::timestamptz[], $5::int[])
    AS ref(symbol, tf, session_start, session_end, expected)
LEFT JOIN market_data_ohlcv m
    ON  m.symbol    = ref.symbol
    AND m.timeframe = ref.tf
    AND m.timestamp >= ref.session_start
    AND m.timestamp <  ref.session_end
GROUP BY ref.symbol, ref.tf, ref.session_start, ref.session_end, ref.expected
```

### SQL Pattern for Batch Signal Coverage (from design doc)
```sql
SELECT
    ref.symbol, ref.tf, ref.session_start, ref.session_end,
    COUNT(s.feature_ts)                                                    AS signal_count,
    percentile_cont(0.50) WITHIN GROUP (ORDER BY s.pipeline_lag_ms)       AS p50,
    percentile_cont(0.95) WITHIN GROUP (ORDER BY s.pipeline_lag_ms)       AS p95
FROM UNNEST($1::text[], $2::text[], $3::timestamptz[], $4::timestamptz[])
    AS ref(symbol, tf, session_start, session_end)
LEFT JOIN signal_ledger s
    ON  s.symbol     = ref.symbol
    AND s.timeframe  = ref.tf
    AND s.feature_ts >= ref.session_start
    AND s.feature_ts <  ref.session_end
    AND s.pipeline_lag_ms IS NOT NULL
GROUP BY ref.symbol, ref.tf, ref.session_start, ref.session_end
```

### BaseProviderAgent Semaphore Pattern
```python
_MAX_CONCURRENT_GAP_FILLS: int = 3  # IBKR pacing: exceed this → Error 162

async def _gap_requests_loop(self) -> None:
    sem = asyncio.Semaphore(_MAX_CONCURRENT_GAP_FILLS)
    tasks: set[asyncio.Task] = set()
    try:
        async for _topic, _key, payload in gap_consumer.messages():
            if self._stop_event.is_set():
                break
            req = BarGapRequest.model_validate(payload)
            task = asyncio.create_task(self._fill_gap(req, sem))
            tasks.add(task)
            task.add_done_callback(tasks.discard)
    finally:
        if tasks:
            await asyncio.gather(*tasks, return_exceptions=True)
        await gap_consumer.stop()
```

### ServiceAuditorAgent asyncio.gather Pattern
```python
results = await asyncio.gather(
    *[self._check_systemd_state(spec.unit) for spec in _SORTED_REGISTRY],
    return_exceptions=True,
)
for spec, result in zip(_SORTED_REGISTRY, results):
    if isinstance(result, Exception):
        continue
    active, sub = result
    if active in ("failed", "inactive") or sub == "start-limit-hit":
        await self._evaluate_service(spec, active, sub, 0, False)
```

### Performance Impact (from design doc)
- Bar audit: 354 roundtrips/cycle → 1
- Signal audit: 472 roundtrips/cycle → 2
- Systemd check: ~12s → ~1s wall time
- Gap fill: 1 at a time → 3 concurrent
- HTF gap healing: never → yes (all TFs)
- Signal gap healing: never → yes (pipeline downtime case)
