### Task 2: BarReplayAgent + monotonic guard fix (TDD)

Created `services/bar_replay_agent.py` — a new AuditorAgent companion that closes the self-healing loop:

- `BarReplayAgent(BaseAgent)` at `metrics_port=9135`
- Consumes `SignalReplayRequest` from `topic_signal_replay_requests`
- Fetches from `market_data_ohlcv` using parameterized SQL (T-63.6-02-A: no interpolation)
- Routes: `tf == "1m"` → `topic_market_bars`, all other tfs → `topic_market_bars_htf`
- Dedup guard: `_replay_in_progress: set[str]` keyed on `symbol:tf:session_date`
- `asyncio.Semaphore(5)` caps concurrent DB fetches (T-63.6-02-B)
- SIGTERM: drains all in-flight tasks via `asyncio.gather` before exit
- All BarMessages published with `source=SOURCE_REPLAY` for provenance (T-63.6-02-E)
- Golden Signals: `bar_replay_requests_total`, `bar_replay_bars_published_total{symbol,tf}`, `bar_replay_errors_total`, `bar_replay_duration_seconds`

Applied 1-line monotonic guard fix in `intelligence_pipeline_agent.py`:
```python
# Before (unconditional):
self._last_bar_ts[key] = bar.ts.timestamp()

# After (monotonic — replay bars cannot regress live gap detector, T-63.6-02-C):
if bar.ts.timestamp() > self._last_bar_ts.get(key, 0):
    self._last_bar_ts[key] = bar.ts.timestamp()
```

14 unit tests pass covering all routing, dedup, empty DB, and payload content scenarios.

**Commit:** `537af8f5`
