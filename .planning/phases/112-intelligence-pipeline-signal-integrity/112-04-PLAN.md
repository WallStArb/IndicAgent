<objective>
Clean up the pipeline architecture so the wave executor, output queue, and worker manager are observable and starvation-free. Document and regression-test wave isolation. Eliminate the frames["features"] flat dual-write entirely (all plugins read typed tier outputs). Split the output queue into high/low priority with a configurable weighted-fair drain so journal traffic cannot starve intelligence/signals/winners. Turn the empty health-monitor stub into a real loop emitting worker-queue gauges, and enable the per-plugin circuit breakers that were shipped disabled.

Purpose: The flat features dual-write is a silent coupling that lets plugins read stale or wrong-tier data; wave isolation is assumed but never tested; the single output queue lets the high-volume journal stream starve signals under load; the circuit breakers exist but are disabled, so a misbehaving plugin can stall the whole bar. These are the architecture-integrity fixes (Phase 2).
Output: Wave isolation test, no-legacy-features test, two-queue OutputQueue, enabled circuit breakers, live health loop with worker gauges.
</objective>
