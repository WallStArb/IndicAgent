<objective>
Author reference-validation tests for every Tier 1 indicator in the intelligence pipeline against pandas-ta. Use the `assert_close_to_reference(ours, ref, *, atol, directional_min, warmup_bars, name)` helper from 093-01 with INDICATOR-SPECIFIC `warmup_bars` and `atol` values to handle recursive-EMA seeding differences.

Tolerance policy (per-indicator, NOT uniform):
- ATR (Wilder RMA): atol=1e-6, warmup_bars=28 — RMA seeding matches pandas-ta exactly after warmup
- MACD (double EMA, period 12/26 + 9 signal): atol=1e-4, warmup_bars=35 — initial seeding may differ by a few ticks
- RSI (Wilder EWM): atol=1e-6, warmup_bars=14
- Stochastic (simple rolling): atol=1e-6, warmup_bars=14
- MFI (simple rolling): atol=1e-6, warmup_bars=14
- CCI (rolling mean + MAD): atol=1e-6, warmup_bars=20
- Williams %R (simple rolling): atol=1e-6, warmup_bars=14
- ADX (double Wilder): atol=1e-4, warmup_bars=28
- Bollinger (rolling mean/std, ddof must match): atol=1e-6, warmup_bars=20
- VWAP (session-anchored): atol=1e-4, warmup_bars=0 — session boundaries can differ by 1 bar

Critical sub-task: investigate the ATR Wilder's smoothing convention discrepancy. Our implementation uses `ewm(alpha=1/p, adjust=False)`. pandas-ta uses `ewm(span=p)`. These differ — `alpha=1/p` is the textbook Wilder definition (which equals `span=2p-1`), while `span=p` is the standard EMA convention. Document which is correct, what TradingView/MT4/TA-lib use, and ensure the test compares against the same convention our production code uses.

Purpose: Renaissance principle — prove correctness, do not assert it. Every Tier 1 indicator must have a mathematical reference. This catches future regressions and validates today's behavior.

Output: 10 new test files + 1 investigation document. All tests pass.
