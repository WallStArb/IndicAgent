    1. Our ATR implementation uses `tr.ewm(alpha=1/p, adjust=False, min_periods=p).mean()` where p=14 (atr.py line 45).
    2. The textbook Wilder smoothing factor is `alpha = 1/N`, which equals `pandas.ewm(span=2N-1)`. So our ewm(alpha=1/14) == ewm(span=27).
    3. pandas-ta `ta.atr(length=14)` uses RMA (Wilder-style) by default — verify this in pandas-ta source by inspecting `pandas_ta.volatility.atr.atr` and `pandas_ta.overlap.rma`.
    4. TradingView, TA-lib, and the original Welles Wilder 1978 definition all use alpha=1/N (= span=2N-1). Therefore our implementation is mathematically correct.
    5. Conclusion: validate against `pandas_ta.atr(high, low, close, length=14)` directly (which uses RMA = Wilder = same convention as ours). Document explicit expectation: tolerance 1e-6.

Compare against `pandas_ta.atr(df.high, df.low, df.close, length=14)`. Use assert_close_to_reference with atol=1e-6, directional_min=0.999.
    - `test_atr_matches_pandas_ta_on_ranging(synthetic_ohlcv_ranging)` — same approach, ranging data.
    - `test_atr_incremental_matches_full(synthetic_ohlcv_trending)` — compute via compute_full on bars [0:100], then call compute_next bar-by-bar for bars [100:200] threading state through, then compute_full on bars [0:200]; assert final atr_14 values match to atol=1e-9 (this is a self-invariant, not vs reference).
