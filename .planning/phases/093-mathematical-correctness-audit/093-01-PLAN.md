    Create `tests/unit/intelligence/correctness/conftest.py` exposing these pytest fixtures and helpers:

    Fixtures (all session-scoped where possible):
    - `synthetic_ohlcv_trending` — 500-bar deterministic upward-trend OHLCV DataFrame with columns [open, high, low, close, volume]; seed numpy with 42; returns pandas.DataFrame indexed by UTC DatetimeIndex at 1-minute frequency.
    - `synthetic_ohlcv_ranging` — 500-bar mean-reverting OHLCV around a constant price (sine wave + noise), same schema, seed 43.
    - `synthetic_ohlcv_gap` — 200-bar OHLCV with a 5% gap up at bar index 100 (open[100] != close[99]).
    - `synthetic_ohlcv_zero_volume` — 100-bar OHLCV where volume column is all zeros.
    - `synthetic_ohlcv_single_bar` — 1-row OHLCV DataFrame.
    - `synthetic_ohlcv_flat` — 500-bar OHLCV where high=low=close=open=100.0, constant volume (for GARCH long-run variance convergence).

    Helper function (NOT a fixture, importable):
    - `assert_close_to_reference(ours: pd.Series | np.ndarray, reference: pd.Series | np.ndarray, *, atol: float = 1e-6, directional_min: float = 0.999, warmup_bars: int = 0, name: str = "") -> None`

      Behavior:
      1. Convert both inputs to pd.Series.
      2. Align by inner-join on index (or by position if no index).
      3. Drop the first `warmup_bars` entries from BOTH series (indicator-specific warm-up trim, in addition to dropping any remaining leading NaN).
      4. Drop any rows where either series is NaN.
      5. Compute `max_err = (ours - reference).abs().max()`. Assert `max_err <= atol`.
      6. Compute directional agreement EXPLICITLY as:
            ours_diff = ours.diff()
            ref_diff = reference.diff()
            mask = ours_diff.notna() & ref_diff.notna() & (ours_diff != 0) & (ref_diff != 0)
            agreement = (np.sign(ours_diff[mask]) == np.sign(ref_diff[mask])).mean()
         Assert `agreement >= directional_min`.
      7. On failure, raise AssertionError with diagnostic string: `f"{name}: max_err={max_err:.2e} (atol={atol}), directional_agreement={agreement:.4f} (min={directional_min})"`.

    Helper function:
    - `frames_from_ohlcv(df: pd.DataFrame) -> dict[str, pd.DataFrame]` — returns `{"main": df}` for the plugin protocol (compute_full takes frames dict).

    All synthetic fixtures must produce valid OHLC (high >= max(open, close), low <= min(open, close)).

    Do NOT add a fixture that hits the live database; correctness tests run with synthetic and fixture data only.
  </action>
