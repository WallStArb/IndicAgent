<objective>
Replace demonstrably wasteful hot-path operations with O(n) or vectorized equivalents, preserving numeric output to machine precision. Two surfaces:

1. BollingerSqueeze (bollinger_squeeze.py lines 70 and 157): replace `sorted(bandwidth_history)` + index lookup `sorted_list[int(len * 0.20)]` with `np.partition(list(bandwidth_history), k)[k]` where `k = int(len(bandwidth_history) * 0.20)`. This is the BIT-EQUIVALENT replacement (kth-element selection), O(n) instead of O(n log n). Do NOT use `np.percentile` — its interpolation methods are not guaranteed to return the same element as the original index lookup.

2. `.tolist()` in compute_next of MFI, Williams %R, Stochastic, CCI, and VolumeZscore: replace with `.to_numpy(copy=False)` or fully vectorized pandas operations. These are called every bar on warm windows; the conversion to a Python list is wasteful.

Add a numeric-equivalence test that drives each refactored plugin on synthetic OHLCV and confirms outputs are unchanged within atol=1e-9 from a pandas-ta reference (or from the pre-refactor compute_full path).

Purpose: Renaissance principle — efficiency only where demonstrably wasteful; never trade correctness for speed. Each change must be numerically identical to the original.

Output: 6 source files refactored + 1 numeric equivalence test, all tests pass.
