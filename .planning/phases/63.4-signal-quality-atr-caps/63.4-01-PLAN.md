<objective>
Fix two production signal-quality bugs bundled into one plan.

**Bug 1 — ATR Caps (Todo 003):** `ATR_TARGET_MAX_MULTIPLIER = 8.0` is applied uniformly to all
timeframes in `trade_framer.py`. On volatile futures (CL, GC) with 1m bars where ATR ≈ 1-2% of
price, 8× ATR pushes targets 8-16% away — never actionable. The fix is a per-TF cap dict
(1m→3×, 5m→5×, 15m→7×, 1h+→8×) applied inside `_collect_targets_long/_short`, which already
read `features.get("timeframe")` for VP logic.

**Bug 2 — detect_gaps coverage (Todo 009):** `detect_gaps()` in `historical_backfill.py` is
already session-aware via `generate_session_slots()` (uses `pandas_market_calendars` for
futures/NYSE). The todo pre-dates this implementation. The remaining work is test coverage:
`detect_gaps` has zero unit tests and the session-aware logic needs a regression guard to
prevent future regressions that would reintroduce false-positive gap detection on
overnight/weekend/holiday windows.

Purpose: Stop 1m signals from emitting unreachable targets on volatile futures. Document (in
tests) that session-aware gap detection is working and locked in.

Output: Two new test classes + constants + logic changes in `trade_framer.py`.
</objective>
