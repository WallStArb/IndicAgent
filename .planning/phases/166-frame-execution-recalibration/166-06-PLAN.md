(D-03.3).

- If Phase 163 is LIVE: all three arms (baseline, scalar, structural) are scored and compared.
- If Phase 163 is NOT LIVE: the structural arm halts (Task 2). This is a VALID, COMPLETE phase
  outcome — the phase completes with 2 of 3 arms (baseline + scalar) scored and the structural
  arm recorded in the verdict doc as "not evaluable — Phase 163 prerequisite unmet, run
  /gsd-execute-phase 163 then re-run only the structural arm." This is an informative stopping
  point, NOT a failure state and NOT a re-planning trigger (RESEARCH Open Question 1: Phase 163
  is a runtime-checked external prerequisite, deliberately not absorbed into Phase 166).

IRREVERSIBLE / HOLDOUT DISCIPLINE (RESEARCH Pitfall 5, D-04):
- Each candidate's in-sample calibration is FINALIZED before its frames touch OOS even once.
- Exactly ONE `--dry-run` per candidate precedes its single real gate run. More than one dry-run
  per candidate is a holdout leak — the gate script's per-gate_id dry-run sentinel (166-04)
  refuses a second dry-run without `--force`.
- Each gate_id is written exactly once, ever (the script's atomic re-check enforces this).

SEQUENCING: candidates run strictly sequentially (each overwrites the shared alpha_frames rows via
geometry_source), one full regenerate → simulate → score cycle per candidate before the next.
