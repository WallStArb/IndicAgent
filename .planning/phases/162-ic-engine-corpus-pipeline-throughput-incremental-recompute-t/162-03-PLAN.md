<objective>
Introduce the `ic_cell_fingerprints` table and a per-cell validity check that lets a re-run of the
80-symbol corpus with unchanged inputs skip fingerprint-valid cells entirely (fetch + compute, not
just the final insert) and recompute exactly the invalidated subset. A fingerprint mismatch must
REPLACE stale rows via DELETE-then-insert — the existing `ON CONFLICT DO NOTHING` write path would
otherwise silently discard the recompute and serve stale IC downstream into `ensemble_trainer` ->
`alpha_publisher`. This is the phase's highest-severity data-integrity surface (the 2026-07-12
checkpoint-staleness failure class, recurring cross-run).

Purpose: Close todo 134 core and absorb todo 122 (checkpoint APR drift) as a special case of the
fingerprint. Deliver the throughput win (skip the fetch, not just the write) with defense-in-depth
against silent staleness: code content-key + APR-snapshot key + upstream watermarks + a crash-loud
field-classification test.

Output: Migration 250 (`ic_cell_fingerprints`); an ICEngineConfig computational-vs-operational field
classification with a crash-loud test; per-table upstream watermark functions; a fingerprint
compose + `_fingerprint_is_valid` check wired into `main()` before `worker_args`; a DELETE-then-insert
invalidation path leaving the 3 INSERT constants untouched; `--refresh` and `--dry-run-validity` CLI
flags; deletion of the `.pkl` checkpoint system.
</objective>
