<objective>
Implement the universal zone width gate in `frame_trade()` to fix Root Crime 1 (47.6% of signals stop at entry because zones are sub-ATR). The narrow-zone problem is systemic across ALL zone sources (structural engine zones for CVDDivergence/GapAnalysis/AnchoredVWAPReversion, plus the three feature-coordinate fast paths supply_demand/fvg/ob), so the gate must sit at the single universal location after `_resolve_zone_bounds()` returns.

Purpose: Reject signals whose zone is too narrow to be real structure (`zone_too_narrow`) rather than widening invented structure. For zone trades, total stop distance from entry = zone_width + buffer, so the zone width gate IS the stop distance gate. A separate min_stop_distance_atr floor covers the non-zone ATR-fallback path. Both gates are APR-backed and ML-tunable.

Output: zone width gate + stop distance floor gate in trade_framer.py, config service wiring matching zone_engine.py, APR seed migration, unit tests.
</objective>
