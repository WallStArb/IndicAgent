> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move `src/intelligence/llm_providers.py` to `src/core/llm/providers.py` and extend `LLMChain.generate()` to accept a `call_type` parameter published to the `llm.calls` Kafka topic.

**Architecture:** `LLMChain` is already implemented with circuit breaker, retry, and 4 providers. This plan moves it to `src/core/` (making it a shared core utility, not intelligence-layer-specific), leaves a backward-compat re-export stub at the original path, and threads `call_type` through `generate()` so every LLM call is auditable.

**Tech Stack:** Python 3.11, asyncio, aiohttp, structlog, prometheus_client, aiokafka (via `src/core/kafka_utils.KafkaProducerClient`)

```python
class LLMChain:
    """Try each provider in order; return first non-None result.

    Optional Kafka audit: pass producer + settings to publish every call
    to the llm.calls topic for the LLM audit pipeline.
    """

    def __init__(
        self,
        providers: list[LLMProvider],
        producer: Any | None = None,
        settings: Any | None = None,
    ) -> None:
        self.providers = providers
        self.last_provider_id: str | None = None
        self._producer = producer
        self._settings = settings

    async def generate(
        self,
        prompt: str,
        system: str,
        max_tokens: int,
        timeout: float,
        call_type: str = "unknown",
    ) -> str | None:
        import time
        t0 = time.monotonic()
        result: str | None = None
        provider_id: str | None = None

        for provider in self.providers:
            r = await provider.generate(prompt, system, max_tokens, timeout)
            if r is not None:
                result = r
                provider_id = provider.provider_id
                self.last_provider_id = provider_id
                break

        self.last_provider_id = provider_id
        latency_ms = (time.monotonic() - t0) * 1000

        if self._producer is not None and self._settings is not None:
            try:
                from src.core.stream_keys import topic_llm_calls
                await self._producer.publish(
                    topic_llm_calls(self._settings.env_name),
                    {
                        "call_type": call_type,
                        "provider_id": provider_id or "none",
                        "succeeded": result is not None,
                        "latency_ms": round(latency_ms, 2),
                        "ts": datetime.now(UTC).isoformat(),
                    },
                )
            except Exception as e:
                logger.warning("llm_chain.kafka_publish_failed", error=str(e))

        return result
```
