## Section 4 Brief — What Needs to Be Designed

Section 4 covers the **data flow DAG** connecting all the tables:

**Live path (hot):**
```
SignalPipeline → MemoryEpisodeWriter.store() → asyncio.Queue
                                                     ↓ (background coroutine)
                                               EmbeddingWorker
                                                     ↓
                                          memory_episodes_raw
```

**Nightly batch (cold, ordered DAG):**
```
Step 1: EpochJob — distributional shift check → memory_system_state (manual gate in Phase 097)
Step 2: RegimeTransitionJob — regime changes → memory_regime_transitions  
Step 3: BackfillJob — signal_outcomes JOIN → memory_episodes_labeled
Step 4: PromotionJob — cohort stats + gates → memory_calibration_promoted + memory_calibration_spc
```

**Orchestrator:** Single `production/scripts/memory_batch.py` (matches roll_batch.py pattern). Steps run sequentially; if step N fails, steps N+1+ do not run.

**Systemd:** `indicagent-memory-batch.service` + `.timer` (nightly 9pm — after session close, before ml-training at 11pm).

**Read path (agents via MemoryClient):**
```
recall()         → memory_episodes_labeled (HNSW, ef_search=100)
calibration()    → memory_calibration_promoted (latest non-quarantined row)
regime_history() → memory_regime_transitions (open row WHERE ts_end IS NULL)
narrative_facts()→ Mem0 (asyncio.to_thread)
annotations()    → Mem0 (asyncio.to_thread)
```

Apply Renaissance framing: DAG must be strictly ordered, idempotent, observable (OTel job_completed_total per step), and the EmbeddingWorker must never block the signal hot path.
