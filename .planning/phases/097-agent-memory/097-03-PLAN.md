    Create src/core/memory/backends/episodic.py with class PgvectorEpisodicBackend implementing the EpisodicBackend Protocol. Constructor takes an asyncpg pool, epoch_decay (default 0.3 from config), over_fetch_multiplier (default 3), ef_search (default 100), current_epoch_provider (a callable/value supplying the live current_regime_epoch).

    async recall(embedding, agent_id, symbol, hmm_regime, entry_type, regime_epoch, limit) -> list[Episode]:
    - Acquire a connection; execute `SET LOCAL hnsw.ef_search = 100` (D-11) inside a transaction on the SAME connection before the vector query. `SET LOCAL` (not `SET`) scopes the parameter to the transaction and does not persist into the pool connection state.
    - Query memory_episodes_labeled ORDER BY embedding <=> $1::vector (cosine distance) LIMIT limit * over_fetch_multiplier, filtered by cohort columns (agent_id, symbol, hmm_regime, entry_type) when provided — this is the MEM-02 scoping (hmm_regime maps to regime_type, entry_type maps to setup_type). Select similarity as 1 - (embedding <=> $1::vector). Pass the embedding as a Python list[float]; asyncpg will send it as text; append `::vector` cast in the SQL to parse it (pgvector codec is not registered by default in asyncpg).
    - Epoch decay: delta = max(0, current_epoch - row.regime_epoch) — clamped to prevent negative delta on anomalous data. epoch_weight = epoch_decay ** delta.
    - In Python, compute epoch_weight per row: 1.0 if row.regime_epoch == current_epoch, else epoch_decay ** (current_epoch - row.regime_epoch) clamped to >= 0. Rerank by similarity * epoch_weight descending, take top `limit`.
    - Map each row to an Episode (stringify UUID id/signal_id, pass payload dict directly — asyncpg returns dict for JSONB, no json.loads).
    - Wrap the whole method body in asyncio.wait_for(..., timeout=timeout_ms/1000) (40ms). On TimeoutError or any Exception: log warning, return [] (never raise). This is the structural graceful-degradation contract (D-13/D-19).
