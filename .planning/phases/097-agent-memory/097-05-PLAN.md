Each successful step emits status="success".

    Step 1 EpochJob (job="memory-epoch"): SELECT from memory_calibration_spc WHERE ks_alarm = TRUE since last run; log findings. Auto-increment rule: if the same (agent_id, stat_name) cohort has ks_alarm=TRUE for 3 or more consecutive nightly runs (check the last 3 rows in memory_calibration_spc for that cohort ordered by ts DESC — the SPC hypertable time column is `ts`, not `run_ts`), auto-increment memory_system_state.current_regime_epoch by 1, log the trigger (agent_id, stat_name, consecutive_alarm_count, old_epoch, new_epoch). The manual override path remains — operators may increment epoch at any time via direct SQL UPDATE. This prevents epoch staleness during high-volatility periods when operator review is delayed.

    Step 2 RegimeTransitionJob (job="memory-regime"): read signal_ledger (via signal_ledger_full view) for HMM regime flips since last run; close open memory_regime_transitions rows (set ts_end, duration_bars, duration_seconds); open a new row for the current regime per (symbol, timeframe) respecting the mem_reg_open unique constraint; compute transition_probs only when transition_n >= 30 (else NULL); compute win_rate only when signal_count >= 30 (else NULL). The chk_transition_probs_sum constraint requires probs sum to 1.0 +/- 0.001.

    Step 3 BackfillJob (job="memory-backfill"): JOIN signal_outcomes to memory_episodes_raw on signal_id WHERE raw.outcome IS NULL AND raw.embedding IS NOT NULL AND so.outcome IS NOT NULL; INSERT INTO memory_episodes_labeled (... pnl_r, mae, mfe, bars_in_trade ...) ON CONFLICT (id) DO NOTHING (idempotent, append-only). Separately UPDATE n_eligible on raw rows retrospectively counting eligible bars from market_data_ohlcv + signal_ledger (C-02). Emit a gauge memory_episodes_labeled with the post-run labeled count.

    Step 4 PromotionJob (job="memory-promote"): GROUP memory_episodes_labeled by (agent_id, symbol, hmm_regime, entry_type, regime_epoch); SKIP cohorts with sample_n < 30 (C-03 — also the DB CHECK is a backstop). n_eligible write-ordering guard (F6): before computing any statistics for a cohort, count the fraction of episodes in the cohort window where n_eligible IS NULL; if that fraction exceeds 0.20 (>20% of rows have NULL n_eligible), SKIP the cohort for this run, increment memory_promotion_skipped_n_eligible counter (label: agent_id), and log the skip — this prevents promoting with systematically missing selection bias estimates (p_signal = sample_n / n_eligible is NULL when n_eligible is NULL). For each surviving cohort compute: Brier decomposition (reliability/resolution/skill_score, base_rate), information_coefficient + ic_t_stat + ic_p_value, calibration_error + variance, circular block bootstrap CI (store bootstrap_block_length, derived as max(5, int(round(sample_n ** (1/3)))) — NOT standard bootstrap (temporal correlation, D-15). Any deviation from this formula must be documented in code comments). Apply Benjamini-Hochberg FDR across all cohorts this run (store p_value_raw, p_value_corrected, n_hypotheses_tested). Test feedback-loop amplification: H0 memory_assisted episodes have same outcome rate as non-assisted; store feedback_loop_p; set feedback_loop_quarantine + quarantine_review_at when significant (C-04). Write correction_factor only when stable across rolling sub-windows (correction_factor_stable). INSERT append-only into memory_calibration_promoted, and INSERT SPC rows into memory_calibration_spc. Emit counters memory_cohorts_promoted_total, memory_cohorts_quarantined_total, and memory_promotion_skipped_n_eligible.

    main() MUST call flush_and_shutdown_metrics() in a finally block before process exit (oneshot OTLP drain contract). Exit code 0 on full success, non-zero if any step failed.
