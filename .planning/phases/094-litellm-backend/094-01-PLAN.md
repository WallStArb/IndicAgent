<objective>
Create `LiteLLMBackend` — the LiteLLM-based replacement for `LLMChain` + its provider classes. This plan uses TDD: write failing tests first, then implement to make them pass.

**Critical interface constraint:** `LiteLLMBackend.generate()` must return `str | None` (same as `LLMChain.generate()`) — NOT a tuple. `LLMProviderChain._generate_inner()` reads `self._inner.last_provider_id` as a side-effect attribute, not from the return value. Returning a tuple would silently corrupt `chain.py` (response check `if response is None` never fires; `len(response)` fails with TypeError).

**Behavior preservation:** The old OllamaProvider set `think=False`, `options.num_ctx`, and stripped `<think>` tags. LiteLLMBackend must replicate all three behaviors to avoid regression in production Ollama output.
</objective>

<threat_model>
ASVS L1 threats for this plan:

- **Environment variable injection (mitigated):** `OLLAMA_API_BASE` and `OPENROUTER_API_KEY` set via `os.environ.setdefault()` — won't overwrite operator-set values. Values come from Settings, not user input.
- **Circuit breaker DoS bypass (mitigated):** Module-level `_OLLAMA_CB` and `_REMOTE_CB` are shared across all `LiteLLMBackend` instances; an attacker cannot instantiate a fresh breaker with no failure history.
- **Secrets in logs (mitigated):** `error=str(exc)[:120]` in the exception handler truncates; no API keys appear in exceptions from LiteLLM.
- **Dependency supply chain (mitigated):** `litellm>=1.40.0,<2.0.0` pins to the v1 stable series. Upper bound prevents pulling a v2.0 breaking release automatically.
- **LiteLLM telemetry/logging (mitigated):** LiteLLM sends telemetry and logs prompts by default. Disable in `_configure_litellm()` via `litellm.telemetry = False` and `litellm.success_callback = []` to prevent prompt leakage and external network calls.
- **Ollama chain-of-thought leakage (mitigated):** Pass `think=False` to suppress reasoning tokens from reaching the response string. Strip residual `<think>...</think>` tags via `_strip_thinking_tags()` as a defense-in-depth measure.
</threat_model>

<task id="3" name="Implement LiteLLMBackend">
<action>
Create `src/core/llm/litellm_backend.py`.

**Module-level circuit breakers:**
```python
_OLLAMA_CB = PluginCircuitBreaker(CircuitBreakerConfig(
    failure_threshold=5, recovery_timeout=60,
    success_threshold=1, max_half_open_calls=3,
    failure_window=120, performance_threshold_ms=120000.0
))
_REMOTE_CB = PluginCircuitBreaker(CircuitBreakerConfig(
    failure_threshold=3, recovery_timeout=300,
    success_threshold=2, max_half_open_calls=3,
    failure_window=60, performance_threshold_ms=60000.0
))
```

**Class docstring** must state: "NOT thread-safe at the instance level. One instance must be created per LLMProviderChain — never shared across concurrent callers. Mutable instance attributes last_provider_id and last_token_usage are reset and written per-call with no locking."

**`__init__(settings)`:**
- Sets `self.providers: list[str]` via `_build_providers()`:
  - Ollama: `f"ollama/{settings.ollama_model}"` if `settings.ollama_enabled`
  - OpenRouter: `f"openrouter/{model}"` for each comma-separated entry in `settings.openrouter_models` if `settings.openrouter_api_key` is set
- Stores `self._settings = settings` for use in `_build_extra_kwargs()`
- Calls `_configure_litellm()`:
  - `os.environ.setdefault("OLLAMA_API_BASE", settings.ollama_base_url)`
  - `os.environ.setdefault("OPENROUTER_API_KEY", api_key)` if present
  - `litellm.telemetry = False`
  - `litellm.success_callback = []`
- Initializes `self.last_provider_id: str | None = None` and `self.last_token_usage: dict | None = None`

**`generate(self, prompt, system, max_tokens, timeout) -> str | None`:**
- Resets `last_provider_id = None`, `last_token_usage = None` at the top
- Iterates providers; checks `cb.allow_request()` (skip if False)
- Calls `await acompletion(model=provider, messages=[...], max_tokens=max_tokens, timeout=timeout, **self._build_extra_kwargs(provider))`
- On success: `cb.record_success()`, sets `self.last_provider_id = provider`, `self.last_token_usage = self._normalize_usage(response.usage)`
- Extracts content: `content = response.choices[0].message.content`
- Strips thinking tags: `content = self._strip_thinking_tags(content)`
- Returns `content`
- On exception: `cb.record_failure()`, logs warning with `error=str(exc)[:120]`; continues to next provider
- Returns `None` after all providers exhausted

**`_build_extra_kwargs(provider) -> dict`:**
Returns provider-specific kwargs to pass to acompletion:
- For ollama (`provider.startswith("ollama/")`): `{"think": False, "options": {"num_ctx": self._settings.ollama_num_ctx}}`
- For openrouter: `{}` (OpenRouter uses standard kwargs only)

**`_strip_thinking_tags(text: str) -> str`:**
Static method. Strips `<think>...</think>` blocks (including newlines within). Use `re.sub(r"<think>.*?</think>", "", text, flags=re.DOTALL).strip()`. Returns cleaned text.

**`_normalize_usage(usage) -> dict | None`:**
Static method. If `usage` is None return None. If it has a `total_tokens` attribute (Pydantic model), extract via `.prompt_tokens`, `.completion_tokens`, `.total_tokens`. If it is a dict, extract via keys. Returns `{"prompt_tokens": int, "completion_tokens": int, "total_tokens": int}` or None if extraction fails.

**`_circuit_breaker_for(provider) -> PluginCircuitBreaker`:**
Returns `_OLLAMA_CB` if `provider.startswith("ollama/")` else `_REMOTE_CB`.

Run `.venv/bin/pytest tests/unit/test_litellm_backend.py -v` — all 10 tests must pass.
