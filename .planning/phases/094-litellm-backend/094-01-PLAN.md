<objective>
Create `LiteLLMBackend` — the LiteLLM-based replacement for `LLMChain` + its provider classes. This plan uses TDD: write failing tests first, then implement to make them pass.

**Critical interface constraint:** `LiteLLMBackend.generate()` must return `str | None` (same as `LLMChain.generate()`) — NOT a tuple. `LLMProviderChain._generate_inner()` reads `self._inner.last_provider_id` as a side-effect attribute, not from the return value. Returning a tuple would silently corrupt `chain.py` (response check `if response is None` never fires; `len(response)` fails with TypeError).
</objective>

<threat_model>
ASVS L1 threats for this plan:

- **Environment variable injection (mitigated):** `OLLAMA_API_BASE` and `OPENROUTER_API_KEY` set via `os.environ.setdefault()` — won't overwrite operator-set values. Values come from Settings, not user input.
- **Circuit breaker DoS bypass (mitigated):** Module-level `_OLLAMA_CB` and `_REMOTE_CB` are shared across all `LiteLLMBackend` instances; an attacker cannot instantiate a fresh breaker with no failure history.
- **Secrets in logs (mitigated):** `error=str(exc)[:120]` in the exception handler truncates; no API keys appear in exceptions from LiteLLM.
- **Dependency supply chain (accepted):** `litellm>=1.40.0` is a published PyPI package. Pin at `>=1.40.0` as specified in the existing spec; no lockfile change needed beyond requirements.txt.
- **LiteLLM telemetry/logging (mitigated):** LiteLLM sends telemetry and logs prompts by default. Disable in `_configure_litellm()` via `litellm.telemetry = False` and `litellm.success_callback = []` to prevent prompt leakage and external network calls.
</threat_model>

<task id="3" name="Implement LiteLLMBackend">
<action>
Create `src/core/llm/litellm_backend.py`. Module-level circuit breakers:
- `_OLLAMA_CB = PluginCircuitBreaker(CircuitBreakerConfig(failure_threshold=5, recovery_timeout=60, success_threshold=1, max_half_open_calls=3, failure_window=120, performance_threshold_ms=120000.0))`
- `_REMOTE_CB = PluginCircuitBreaker(CircuitBreakerConfig(failure_threshold=3, recovery_timeout=300, success_threshold=2, max_half_open_calls=3, failure_window=60, performance_threshold_ms=60000.0))`

`LiteLLMBackend` class docstring must state: "NOT thread-safe at the instance level. One instance must be created per LLMProviderChain — never shared across concurrent callers. Mutable instance attributes last_provider_id and last_token_usage are reset and written per-call with no locking."

`LiteLLMBackend.__init__(settings)`: sets `self.providers: list[str]` via `_build_providers()` (ollama model string `f"ollama/{settings.ollama_model}"` if enabled; openrouter model strings `f"openrouter/{model}"` for each comma-separated entry in `settings.openrouter_models` if `settings.openrouter_api_key` is set); calls `_configure_litellm()` which sets `os.environ.setdefault("OLLAMA_API_BASE", settings.ollama_base_url)` and `os.environ.setdefault("OPENROUTER_API_KEY", api_key)` if present, AND sets `litellm.telemetry = False` and `litellm.success_callback = []`; initializes `self.last_provider_id: str | None = None` and `self.last_token_usage: dict | None = None`.

`generate(self, prompt, system, max_tokens, timeout) -> str | None`: resets `last_provider_id = None`, `last_token_usage = None` at the top of each call; iterates providers; checks `cb.allow_request()` (skip if False); calls `await acompletion(model=provider, messages=[{"role":"system","content":system},{"role":"user","content":prompt}], max_tokens=max_tokens, timeout=timeout)` plus `num_ctx=settings.ollama_num_ctx` for ollama; on success sets `cb.record_success()`, `self.last_provider_id = provider` (the LiteLLM model string, e.g. `"ollama/nemotron-3-nano:4b"`), `self.last_token_usage = self._normalize_usage(response.usage)`; returns `response.choices[0].message.content`; on exception calls `cb.record_failure()` and logs warning; returns `None` after all providers exhausted (last_provider_id remains None).

`_normalize_usage(usage) -> dict | None`: static method. If `usage` is None return None. If it has a `total_tokens` attribute (Pydantic model), extract via `.prompt_tokens`, `.completion_tokens`, `.total_tokens`. If it is a dict, extract via keys. Returns `{"prompt_tokens": int, "completion_tokens": int, "total_tokens": int}` or None if extraction fails.

`_circuit_breaker_for(provider) -> PluginCircuitBreaker`: returns `_OLLAMA_CB` if `provider.startswith("ollama/")` else `_REMOTE_CB`.
</action>
