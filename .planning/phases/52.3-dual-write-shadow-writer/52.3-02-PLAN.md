<objective>
Fix the metric label bug in FeatureSnapshotWriterAgent that causes continuous "histogram metric is missing label values" error log spam on every consume loop iteration.

Purpose: PERSISTENCE_BATCH_LATENCY and PERSISTENCE_CONSUMER_LAG are defined in metrics.py with a required `agent_id` label but are called without `.labels(agent_id=...)` at lines 124, 125, and 131 of feature_snapshot_writer_agent.py. This causes a Prometheus client exception on every iteration, caught by the generic error handler, producing log pollution that masks real errors. The fix is three call-site updates to add `.labels(agent_id="feature_snapshot_writer")` before `.observe()` and `.set()`.

Output: Clean service startup with no metric label errors; labeled metrics recorded correctly in Prometheus.
</objective>
