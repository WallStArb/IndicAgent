| Boundary | Description |
|----------|-------------|
| HTTP client → /api/vocabulary/{namespace} | Untrusted `namespace` path parameter crosses into a DB query here |
| route handler → DB | Read-only SELECT via parameterized asyncpg query |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-161-01 | Tampering | namespace path param → SQL | mitigate | Parameterized query `WHERE namespace = $1` via asyncpg; namespace never string-interpolated into SQL (ASVS V5) |
| T-161-07 | Information Disclosure | error responses | mitigate | try/except returns a controlled 404/empty payload; raw SQL/exception text is logged via logger.warning, not returned to the client (drift.py pattern) |
| T-161-08 | Denial of Service | unbounded result set | accept | Result is bounded by namespace size (≤ 9 rows); no user-controlled pagination or scan width |
| T-161-SC | Tampering | package installs | accept | No new packages (fastapi already vendored) |
</threat_model>
