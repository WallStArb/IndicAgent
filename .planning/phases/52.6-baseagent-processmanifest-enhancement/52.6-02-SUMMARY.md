# Phase 52.6 Plan 02: BaseAgent Enhanced Lifecycle Contract Summary

One-liner: Enhanced BaseAgent with metrics auto-start, OTel tracer, _setup/_teardown hooks, running property, topic declarations, exception capture, and DLQ stub — zero breaking changes to existing agents.

## What Was Built

`src/core/agent/base.py` received 7 new capabilities required by Plan 03 (ProcessManifest) and the full Renaissance DAG standard:

| Capability | Implementation |
|---|---|
| `metrics_port` parameter | `__init__(self, name, metrics_port=None)` → `self._metrics_port` |
| OTel tracer | `self.tracer = get_tracer(name)` in `__init__` |
| `_setup()` hook | No-op async method called before `_run()` in `start()` |
| `_teardown()` hook | No-op async method called in `finally` block after `_run()` |
| `running` property | `not self._stop_event.is_set()` |
| Topic declarations | `topics_consumed`, `topics_produced` → `[]`; `lag_threshold_messages` → `1000` |
| `_send_to_dlq()` stub | Logs `agent.dlq_discard` with payload keys and error string |
| Structured exception capture | `except Exception:` → `logger.exception("agent.run_failed")` → `raise` |
| Metrics auto-start | `start_metrics_server(port=self._metrics_port)` when not None |

## Lifecycle Ordering (D-06)

```
start():
  1. _register_signal_handlers()
  2. start_metrics_server(port) if metrics_port set
  3. logger.info("agent.starting")
  4. await _setup()           ← NEW (before lag_task)
  5. lag_task = create_task(_report_consumer_lag())
  6. try: await _run()
     except Exception: logger.exception("agent.run_failed"); raise
  7. finally:
       lag_task.cancel()
       await _teardown()      ← NEW (in finally)
       await stop()
```
