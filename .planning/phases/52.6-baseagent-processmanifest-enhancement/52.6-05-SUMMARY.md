## Decisions Made

1. **Source inspection for IntelligenceComputeAgent tests** — `intelligence_compute_agent.py` imports `services.indicator_service` at module level, which doesn't exist on the module path. Rather than mock the entire import chain, structural tests use AST/text inspection (same tests, no runtime import needed). This is consistent with the `__new__` injection pattern used elsewhere in service_tests — avoids cross-module import failures without reducing coverage.

2. **config-before-super pattern** — Both migrations load config before `super().__init__()` to extract `metrics_port`. This is the established pattern from Plans 02-04 and required because `BaseAgent.__init__` needs `metrics_port` at construction time.

3. **init_tracing is a no-op until Phase 52.7** — Adding `init_tracing()` to all four `__main__` blocks means spans flow automatically once `OTEL_EXPORTER_OTLP_ENDPOINT` is set in systemd unit files (Phase 52.7). No behavioural change until then — correct per D-16.

4. **FeatureWriterAgent._env_name (underscore prefix)** — FeatureWriterAgent stores the environment name as `_env_name` (private prefix) rather than `env_name` (public). The `TestFeatureWriterAgentLifecycle` setup_method sets `self.agent._env_name = "development"` accordingly.
