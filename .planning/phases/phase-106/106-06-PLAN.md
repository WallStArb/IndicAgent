    - All write paths to _plugin_states (update, update_batch, or equivalent)
    - Checkpoint serialization: write_checkpoint() and load_checkpoint()/restore()

    Implement the secondary index:

    1. In __init__, add:
       self._states_by_key: dict[tuple[str, str], dict[str, dict]] = {}

    2. In every write path (update(), update_batch(), or equivalent methods):
       After writing to self._plugin_states[(plugin_name, symbol, tf)] = state, also:
         key = (symbol, tf)
         if key not in self._states_by_key:
             self._states_by_key[key] = {}
         self._states_by_key[key][plugin_name] = state

    3. In get_all_states_for(symbol, tf) (replace O(N) comprehension):
       return dict(self._states_by_key.get((symbol, tf), {}))
       The return is a copy to prevent external mutation of the index.

    4. In any clear_symbol / evict_symbol / remove method:
       Also clear from secondary index:
         self._states_by_key.pop((symbol, tf), None)

    5. Checkpoint restore (in load_checkpoint() or restore() method):
       _states_by_key must NOT be serialized to disk (it is a derived cache).
       After loading _plugin_states from file, rebuild the secondary index:
         self._states_by_key = {}
         for (plugin_name, symbol, tf), state in self._plugin_states.items():
             key = (symbol, tf)
             if key not in self._states_by_key:
                 self._states_by_key[key] = {}
             self._states_by_key[key][plugin_name] = state
       Note: adapt tuple unpacking to match the actual key structure in _plugin_states.
       If the key is a different shape (e.g., a named tuple, or (symbol, tf, plugin_name)
       ordering), read the file carefully and adapt.

    The existing unit tests for PluginStateManager cover this — run them to confirm.
