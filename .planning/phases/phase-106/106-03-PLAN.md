<objective>
Fix the code reuse regressions that cause silent data loss or correctness bugs.
Three services bypass the JSONB codec setup wrapper (risking double-serialization
of jsonb columns). ctx_writer silently skips its final buffer flush on shutdown.
llm_writer accumulates uptime forever and its stall watchdog is permanently blind.
bar_aggregator reinvents the base class retry loop with a diverging backoff schedule
(thundering herd risk on mass restart).

Purpose: These are correctness bugs, not cosmetic issues. Each causes silent data
quality degradation. Fix before v2.8 while the codebase is small.
Output: bar_aggregator uses circuit_breaker=True; 3 JSONB bypasses fixed via
create_db_pool; ctx_writer teardown safe; llm_writer health monitor and stall
watchdog corrected; BaseWriterAgent teardown hardened with auto-close hooks.
</objective>

       In BaseWriterAgent._teardown(), after the flush logic completes, add:
         if hasattr(self, "_consumer") and self._consumer is not None:

         if hasattr(self, "_db") and self._db is not None:
             try:
                 await self._db.close()
             except Exception:
                 pass
         if hasattr(self, "_pool") and self._pool is not None:
             try:
                 await self._pool.close()

       (the flush before this block is the load-bearing step; close errors are non-critical).
