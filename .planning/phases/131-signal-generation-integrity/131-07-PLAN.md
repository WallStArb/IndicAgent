       ```sql
       PGPASSWORD=postgres psql -U postgres -h localhost -d indicagent -c "
       SELECT
           CASE WHEN ctf_score > 0.05 THEN 'non_zero' ELSE 'zero_or_null' END AS bucket,
           COUNT(*) as cnt,
           ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER (), 1) as pct
       FROM intelligence_features
       WHERE symbol IN ('ESM6','NQM6','SPY')
         AND ts > '2026-06-10'
         AND ctf_score IS NOT NULL
       GROUP BY 1
       ORDER BY 1;"
       ```

       (The no-seed replay used a small window from step 1 that will be overwritten by the seeded replay in step 2 — run the control query before step 2's --overwrite-features).

    5. If gate passes: document results in /tmp/phase131-a7-results.txt for appending to validation report.
