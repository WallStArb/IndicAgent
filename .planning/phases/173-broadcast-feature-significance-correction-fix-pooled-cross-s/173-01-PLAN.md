  <behavior>
    - `_classify_broadcast` returns a three-way verdict, not a bool. Given per-`bar_ts` arrays where
      every group's cross-symbol spread is within epsilon AND the per-group representative values
      differ across at least two distinct `bar_ts` groups, the verdict is `broadcast`.
    - Given per-`bar_ts` arrays where every group's cross-symbol spread is within epsilon BUT every
      group's representative value is identical across all `bar_ts` groups (a globally-constant
      feature, e.g. an event flag that never fired in the window), the verdict is `inconclusive` —
      NOT `broadcast`. This is the `sweep_detected` / `manip_strength` false-positive case.
    - Given any group whose cross-symbol spread exceeds epsilon, the verdict is `idiosyncratic`.
    - Given fewer than 2 finite values in every group, the verdict is `inconclusive`.
    - The JSONB merge helper produces an UPDATE whose SET clause merges rather than replaces: a row
      whose metadata already carries `tier`/`apr_namespace` retains both after the write.
  </behavior>
  <action>
    Three changes to `scripts/ops/alpha/ops_broadcast_feature_audit.py`:

    (a) Replace the module constant `_BROADCAST_EPSILON = 1e-9` with a read of the APR key
    `alpha.ic.broadcast_variance_threshold` (default `1e-9` in the `get_sync`/`get` call, per
    CLAUDE.md's `ConfigService.get(key, default=X)` mandate). Delete the constant. The existing
    `epsilon=` parameter on `_classify_broadcast` stays — the APR read happens once in `main()` and
    is passed down, keeping the classifier a pure function.

    (b) Change `_classify_broadcast` from returning `bool` to returning a verdict string, one of
    `"broadcast"`, `"idiosyncratic"`, `"inconclusive"`. The new `inconclusive` arm is the
    temporal-variance guard: after confirming every `bar_ts` group's cross-symbol spread is within
    epsilon, additionally require that the per-group representative values (take the first finite
    value of each group) are NOT all equal within epsilon across the sampled `bar_ts` groups. A
    genuinely broadcast feature such as `dow_sin` varies over `bar_ts` even though it is constant
    across symbols; a never-fired event flag such as `sweep_detected` is constant on BOTH axes and
    carries zero evidence of broadcast structure. Groups with fewer than 2 finite values are still
    skipped for the cross-symbol check but their representative value still counts toward the
    temporal check.

    Update the caller loop in `main()` (currently the `if/elif` at lines ~180-187) to bucket into
    three lists and print three sections. Keep the existing `Insufficient data` bucket (total finite
    values below `min_symbols`) as a separate, earlier check — it is a different condition from the
    new `inconclusive` verdict and both must remain distinguishable in the report.

    (c) Add a `--persist` flag (default off — the script stays read-only unless asked). When set,
    after classifying all tfs, compute a CONSENSUS verdict per feature across every tf the run
    covered: a feature is persisted `broadcast=true` only if its verdict is `broadcast` in at least
    one tf and `idiosyncratic` in NO tf. A feature `idiosyncratic` anywhere is persisted
    `broadcast=false`. A feature `inconclusive` everywhere is persisted `broadcast=false` with an
    accompanying `broadcast_evidence` value of `inconclusive` so the abstention is legible rather
    than indistinguishable from a measured negative.

    Print, at the end of a `--persist` run, the count of rows updated per verdict bucket, and
