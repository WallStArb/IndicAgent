- order_queue(rows, config, today) -> list[CoverageRow]: drops rows whose first rank element is True (excluded) and sorts the rest ascending by rank. Pure; no I/O.
- PriorityQueue: constructed with (config, candidates: list[tuple[str, str]], today). async load(pool) reads, with one asyncpg query each, ohlcv_coverage for every candidate symbol (all timeframes, so proven depth sees 1d even when 1d is out of scope), fresh ohlcv_provider_head rows for provider 'ibkr', and fresh ohlcv_empty_history rows (reverify age from APR via the same key _empty_history.load_reverify_days reads; raise if unset). async next(pool, visited: set[tuple[str, str]]) -> CoverageRow | None reloads (cheap: a few thousand rows), orders, and returns the first item not in visited; None when exhausted. The fetcher passes visited so each item is processed at most once per run even if it still ranks first after its fetch. Also a sync ranked_snapshot(...) used by the dry run, returning the ordered rows with their rank tuples and components (sla_breach, tf_class, gap_days, staleness_days) for reporting.

All thresholds come from QueueConfig (APR); the only literals are schema identifiers and the provider name 'ibkr'.
