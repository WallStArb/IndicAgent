| ops script / operator -> ConceptRegistryService | untrusted comparison outcome (won, eval_metric, eval_n, corpus_build_ref) crosses into a status-mutating writer |

| T-160-02 | Elevation of Privilege | automated path targeting 'deprecated' | mitigate | pure core returns 'noop_deprecated'; service can only ever write candidate -> active (trigger_reason='promotion'), structurally cannot target deprecated or write annotation content (invariant 1) |

| T-160-04 | Denial of Service | re-eval churn against same/insufficient evidence | mitigate | invariant 2 same-corpus block + F3 evidence-mass floor + invariant 7 effective-N floor, all in the pure core before any write |
