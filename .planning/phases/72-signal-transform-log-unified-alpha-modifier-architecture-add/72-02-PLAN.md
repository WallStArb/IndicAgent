Create `src/intelligence/swarm/graduation.py` as DB-ignorant pure functions module. This is a refactor of `scripts/validate_skeptic.py` with two semantic changes:

1. **Sign flip:** Where validate_skeptic uses `failure_probability` (high = bad), graduation.py uses `multiplier` (high = good). Therefore:
   - Spearman: `rho >= GATE_SPEARMAN_RHO` (was `rho <= -0.15`)
   - Expected shortfall: bottom decile = lowest multipliers (was top decile = highest failure_prob); gate stays `cvar <= -0.5`
   - Value add: filter is `multiplier > 0.5` (was `failure_prob < 0.5`)

2. **Input columns:** DataFrame has `multiplier` and `pnl_r` columns (not `failure_prob`).

def _correlated_df(n: int = 100, rho: float = 0.8) -> pd.DataFrame:

def test_gate_constants_positive():
