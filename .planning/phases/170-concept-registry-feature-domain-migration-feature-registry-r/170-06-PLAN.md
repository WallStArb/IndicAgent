POSITIVE per-run fact, `registry_dual_write_verified`, that only this code can produce. Its
`metric_value` and `subject` carry how much was actually compared, so Plan 08 can also tell a
substantive comparison apart from a run that happened to transition nothing.

in the same change. It is the sole authorising evidence for a one-way door.
