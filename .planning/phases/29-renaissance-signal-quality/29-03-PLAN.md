Implement alpha decay (QUAL-02) and signal freshness decay (QUAL-03) — two continuous confidence reduction mechanisms that express diminishing information value rather than discarding signals.

Purpose: Renaissance information preservation — signals don't expire, they decay. A repeated signal fire is real information at reduced value. A long-held active signal is real but less timely.
Output: `_setup_last_fire` dict in signal_generator_service applies per-setup decay before aggregate(); `signal_lifecycle_service` applies exponential freshness decay in-memory per bar.
</objective>

    ```python
    self._setup_last_fire: dict[tuple[str, str, str, int], dict] = {}

    # value: {"bar_count": int} — incremented each bar for tracking
    ```

    In the signal evaluation loop, AFTER cooldown check (QUAL-04 from plan 29-02) but BEFORE calling aggregate():
    For each signal in `fired`, apply alpha decay by mutating its confidence:
    ```python
    key = (symbol, tf, sig["setup_plugin"], sig.get("direction", 0))
    last = self._setup_last_fire.get(key)
    if last is not None:
        bars_since = last.get("bars_since", 0)
        half_life = ALPHA_HALF_LIFE_BARS.get(tf, 6)
        multiplier = max(0.0, 1.0 - bars_since / half_life)
        sig["confidence"] = round(float(sig.get("confidence", 0.0)) * multiplier, 4)
    ```

    After publishing a signal (or accepting it into fired), record:
    ```python
    self._setup_last_fire[key] = {"bars_since": 0}
    ```

    On each bar evaluation start: increment `bars_since` for all entries in `_setup_last_fire`
    that match current (symbol, tf).

    CRITICAL per RESEARCH.md Pitfall 2: Apply alpha decay to confidence BEFORE calling
    `aggregate()`. Do not add a `setup_last_fire` parameter to `_build_all_ranked()`.

    **Task 2: Freshness decay in signal_lifecycle_service.py**

    Add import: `import math`

    Add constant:
    ```python
    FRESHNESS_HALF_LIFE_BARS: dict[str, int] = {"1m": 20, "5m": 10, "15m": 6, "1h": 4}
    # Tune after 90 days outcome data.
    ```

    In the per-bar active signal evaluation loop, compute effective_confidence in-memory:
    ```python
    half_life = FRESHNESS_HALF_LIFE_BARS.get(timeframe, 10)
    lambda_decay = math.log(2) / half_life
    bars_since = _bars_elapsed(signal_timestamp, current_bar_time, timeframe)
    freshness = math.exp(-lambda_decay * bars_since)
    effective_confidence = round(stored_confidence * freshness, 4)
    ```

    Use `effective_confidence` for lifecycle evaluation (e.g., passing confidence to downstream
    evaluation logic). NEVER write `effective_confidence` back to `signal_ledger` — the original
    confidence at fire time is ground truth for ML training.
