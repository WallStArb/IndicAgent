<!-- CUSUM algorithm (from RESEARCH.md code examples) -->
```python
def _compute_cusum(pnl_r_series: list[float], mu0: float, sigma0: float,
                   k: float = 0.5, h: float = 4.0) -> tuple[float, float, str]:
    """Returns (S_pos, S_neg, severity). Page's CUSUM."""
    s_pos, s_neg = 0.0, 0.0
    for pnl in pnl_r_series[20:]:  # skip baseline window
        x_n = (pnl - mu0) / max(sigma0, 0.5)
        s_pos = max(0.0, s_pos + x_n - k)
        s_neg = max(0.0, s_neg + (-x_n) - k)
    if s_neg >= 2 * h:
        return s_pos, s_neg, "critical"
    if s_neg >= h:
        return s_pos, s_neg, "warning"
    if s_pos >= h:
        return s_pos, s_neg, "info"  # winning streak — note, not penalized
    return s_pos, s_neg, "none"
```

CUSUM → perf_multiplier (from CONTEXT.md locked decisions):
- Multiplicative adjustment: `new_multiplier = current_multiplier * cusum_adjustment_factor`
- `cusum_adjustment_factor`: "warning" → 0.85, "critical" → 0.70 (same penalty scale as KS)
- Floor: max(0.30, new_multiplier) — never collapse a setup below 30%
- CUSUM adjustment is applied AFTER base perf_multiplier from setup_performance table
- CRITICAL: Do NOT have drift_monitor_service write directly to setup_performance table or
  Redis weights key. Instead: CUSUMMonitor writes CUSUM state to Redis drift:cusum:{plugin};
  setup_performance_updater.run_setup_performance_update() reads drift:cusum:* keys and
  applies multiplicative adjustment to perf_weights before writing to Redis weights key.

    ```python
    CUSUM_ADJUSTMENT = {"warning": 0.85, "critical": 0.70}
    CUSUM_MULTIPLIER_FLOOR = 0.30

    # Read all CUSUM drift states from Redis
    for plugin in list(perf_weights.keys()):
        cusum_key = stream_keys.drift_cusum(env_prefix, plugin)
        raw = await redis_client.get(cusum_key)
        if raw:
            severity = raw.decode() if isinstance(raw, bytes) else raw
            factor = CUSUM_ADJUSTMENT.get(severity, 1.0)
            perf_weights[plugin] = max(
                CUSUM_MULTIPLIER_FLOOR,
                round(perf_weights[plugin] * factor, 4)
            )
    ```
