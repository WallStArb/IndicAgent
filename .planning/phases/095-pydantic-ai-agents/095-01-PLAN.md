Create `src/core/ai/agent_deps.py` with a frozen dataclass:

```python
"""AgentDeps — typed dependency container for Pydantic AI agents.

Passed to pydantic_ai.Agent.run(prompt, deps=deps) and accessed inside agent
tools via RunContext[AgentDeps]. Core-level (not intelligence-layer) so any
agent group can depend on it.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import TYPE_CHECKING, Any

if TYPE_CHECKING:
    from src.core.ai.context import AIContext
    from src.core.llm.chain import LLMProviderChain


@dataclass(frozen=True)
class AgentDeps:
    """Frozen dependency container for Pydantic AI agent runs.

    Attributes:
        signal_context: The typed market context for this inference.
        llm_chain: IndicAgent LLM chain (circuit breaker, rate limiter, audit).
        db_pool: Optional asyncpg pool for DB-reading tools. Default None.
        memory_client: Optional episodic-memory client. Phase 097 (Zep) wires this. Default None.
    """

    signal_context: "AIContext"
    llm_chain: "LLMProviderChain"
    db_pool: Any | None = None
    memory_client: Any | None = None
```

Use `TYPE_CHECKING` imports for `AIContext` and `LLMProviderChain` (string annotations) to avoid any import cycle — `chain.py` and `context.py` both pull in heavy modules. Keep `db_pool` and `memory_client` as `Any | None` to avoid importing asyncpg / a memory SDK at this layer.
