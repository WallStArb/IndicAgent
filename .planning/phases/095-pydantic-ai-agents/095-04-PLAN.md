Attack vectors analyzed for SkepticComputeAgentPydantic:

**1. LLM Prompt Injection via instructions parameter**
- Threat: Adversarial LLM ignores "OUTPUT ONLY RAW JSON" instruction, injects prose preamble
- Mitigation: NativeOutput enforces JSON structure; prose rejected by schema validation; retries up to 3 times
- Validation: Shadow validation (Plan 05) measures parse_success = 100%; failures trigger alerts

**2. Transfer Function Manipulation**
- Threat: Adversarial LLM returns failure_probability or confidence outside [0,1] to break multiplier calc
- Mitigation: SkepticResult Field(ge=0.0, le=1.0) rejects before transfer function; multiplier computed post-validation
- Validation: test_to_agent_output_clamps_multiplier verifies (1.0-1.0)*1.0 = 0.0 case

**3. NativeOutput Bypass via model override**
- Threat: Malicious caller passes model= to Agent() constructor, bypassing NativeOutput
- Mitigation: SkepticComputeAgentPydantic.__init__ controls Agent construction; external callers cannot override
- Validation: Unit test verifies NativeOutput(SkepticResult) in Agent configuration

**4. Data Exfiltration via payload**
- Threat: AgentOutput.payload leaks internal state (LLM internals, context dumps)
- Mitigation: Payload limited to SkepticResult fields only; no raw LLM output exposed
- Validation: test_to_agent_output_transfer_function verifies payload contains only required fields

**5. Shadow Mode Promotion Bypass**
- Threat: Operator promotes shadow agent before n >= 100 inferences measured
- Mitigation: shadow_only=True by default; promotion requires explicit code change + service restart
- Validation: Plan 05 shadow validation test documents gate criteria; manual review required

**6. Memory Exhaustion via pydantic_ai.Agent state**
- Threat: Agent holds references to large contexts, never garbage collected
- Mitigation: Agent state per-request (run deps=); no persistent state between calls
- Validation: Existing latency_budget_ms enforcement (120s) catches slow memory leak patterns

**7. Dependency Ordering (CRITICAL FIX)**

- Mitigation: FIXED - pydantic-ai added to requirements.txt in Plan 04 before runtime import
- Validation: User setup step verifies dependency installation before code creation

**8. Inheritance Mismatch (CRITICAL FIX)**
- Threat: _to_agent_output() calls _build_multiplier_output() which doesn't exist on BaseAIAgent
- Mitigation: FIXED - SkepticComputeAgentPydantic extends PydanticAIAdapter only, manually constructs AgentOutput
- Validation: Unit test verifies AgentOutput construction without BaseMultiplierAgent methods

**9. deps_type=None Violation (CRITICAL FIX)**
