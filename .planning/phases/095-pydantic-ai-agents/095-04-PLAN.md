<objective>
Add the universal typed-execution path to `BaseAIWorker`: a `result_type: ClassVar` opt-in, a `_default_max_tokens: ClassVar`, an `__init_subclass__` guard that validates `result_type` at class-definition time, and an `async def _run_typed()` that constructs a `WorkerContext`, builds a per-call `LLMAdapter`, runs a `pydantic_ai.Agent(output_type=self.result_type)`, and returns the validated `result_type` instance.

Purpose: D-10/D-11/D-12/D-13. Universal opt-in for all AI agents (alpha, narrative, risk) without per-subclass base changes. Timeout is always derived from `self._timeout_s` so the latency budget is impossible to forget. `max_tokens=None` is resolved to `_default_max_tokens` before the adapter is built (REVIEWS MEDIUM - chain.generate requires an int). Misconfiguration fails loud: calling `_run_typed` with `result_type is None` raises RuntimeError, and setting `result_type` to a non-BaseModel class is caught at class-definition time via `__init_subclass__` (REVIEWS LOW - earlier than first call). Agents that never opt in keep identical runtime behavior (AGENT-EXEC-05).

Output: the four additions on `BaseAIWorker`; unit tests for happy path (mocked adapter/agent), RuntimeError on None, the `__init_subclass__` guard, max_tokens=None resolution and explicit override, timeout derivation, and audit-context construction. `_llm_generate` and `_llm_generate_structured` are NOT modified.
</objective>
