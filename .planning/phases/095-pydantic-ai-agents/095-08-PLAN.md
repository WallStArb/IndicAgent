<threat_model>
Attack vectors analyzed for promotion/demotion gates:

**1. Promotion Gaming via Cherry-Picking**
- Threat: Agent cherry-picks favorable regime data to pass promotion gates
- Mitigation: PromotionGate requires sustained fitness across >=3 regimes; variance gate prevents cherry-picking
- Validation: Unit tests verify regime diversity check; integration tests validate multi-regime requirement

**2. Novelty Spoofing via Decorrelation**
- Threat: Agent adds noise to decorrelate from live agents without improving predictions
- Mitigation: Novelty gate requires decorrelation AND sustained accuracy; accuracy prevents random noise
- Validation: Integration tests verify agents with high decorrelation but low accuracy fail promotion

**3. Correlation Attack via Copycat Agents**
- Threat: Malicious agent copies live agent behavior to inflate correlation metrics
- Mitigation: DemotionGate triggers on correlation rise with live agents; copycats demoted quickly
- Validation: Unit tests verify correlation threshold triggers demotion

**4. Regime Shift Exploitation**
- Threat: Agent exploits regime transition to pass promotion then fails in new regime
- Mitigation: Regime specificity gate requires performance across regime boundaries; demotion on regime shift
- Validation: Integration tests simulate regime shifts; verify demotion triggers

**5. Genome Poisoning via Soft Death**
- Threat: Adversarial agent preserves corrupted genome in agents/ directory for resurrection
- Mitigation: Genome serialization validates structure; resurrection requires human review approval
- Validation: Unit tests verify genome roundtrip; resurrection workflow gated by human review

**6. Human Review Bypass**
- Threat: Automated promotion without human review bypasses governance
- Mitigation: PromotionGate returns (can_promote, reason); human_review_required flag always true for promotions
- Validation: Integration tests verify promotion blocks without human approval flag
</threat_model>

    import structlog

    from src.core.ai.agent_genome import AgentGenome

    logger = structlog.get_logger(__name__)

    @dataclass
    class PromotionGate:
        """Automated promotion criteria for agent advancement.

        Agents must meet ALL criteria to be eligible for promotion:
        1. Sustained composite fitness across >=3 market regimes
        2. Novelty confirmed (decorrelation from existing live agents)
        3. Stability: low fitness variance across audit cycles
        4. Minimum sample size (n >= 100 predictions)

        Final promotion requires human review to evaluate agent's "why",
        not just "what". Returns (can_promote, reason, human_review_required).
        """

        min_regimes: int = 3
        min_predictions: int = 100
        min_fitness_threshold: float = 0.05  # Composite fitness > 5%
        max_variance_threshold: float = 0.02  # Fitness variance < 2%
        max_correlation_threshold: float = 0.7  # Decorrelation from live agents

        def can_promote(
            self,
            agent_id: str,
            fitness_metrics: dict[str, float],
            regime_performance: dict[str, dict[str, float]],
            live_agent_correlations: dict[str, float],
        ) -> tuple[bool, str | None, bool]:
            """Check if agent meets automated promotion criteria.

            Args:
                agent_id: Agent identifier
                fitness_metrics: Composite fitness metrics (accuracy, novelty, calibration, etc.)
                regime_performance: Performance per regime (e.g., {"bull": {"sharpe": 1.5}, "bear": {...}})
                live_agent_correlations: Correlation with each live agent (agent_id -> correlation)

            Returns:
                (can_promote, reason, human_review_required)
                - can_promote: True if all automated criteria met
                - reason: Human-readable explanation (deny reason or promotion rationale)
                - human_review_required: Always True for promotions (governance gate)
            """
            # Criterion 1: Minimum sample size
            n_predictions = fitness_metrics.get("n_predictions", 0)
            if n_predictions < self.min_predictions:
                return False, f"Insufficient predictions: {n_predictions}/{self.min_predictions}", True

            # Criterion 2: Sustained composite fitness across >=3 regimes
            regimes_with_data = len(regime_performance)
            if regimes_with_data < self.min_regimes:
                return False, f"Insufficient regime coverage: {regimes_with_data}/{self.min_regimes}", True

            # Check composite fitness in each regime
            for regime, metrics in regime_performance.items():
                composite_fitness = metrics.get("composite_fitness", 0.0)
                if composite_fitness < self.min_fitness_threshold:
                    return False, f"Low fitness in {regime}: {composite_fitness:.3f} < {self.min_fitness_threshold}", True

            # Criterion 3: Stability (low fitness variance)
            fitness_variance = fitness_metrics.get("fitness_variance", 1.0)
            if fitness_variance > self.max_variance_threshold:
                return False, f"High fitness variance: {fitness_variance:.3f} > {self.max_variance_threshold}", True

            # Criterion 4: Novelty (decorrelation from live agents)
            for live_agent_id, correlation in live_agent_correlations.items():
                if correlation > self.max_correlation_threshold:
                    return False, f"High correlation with {live_agent_id}: {correlation:.2f} > {self.max_correlation_threshold}", True

            # All automated criteria passed
            rationale = (
                f"Agent {agent_id} passes promotion gates: "
                f"{n_predictions} predictions across {regimes_with_data} regimes, "
                f"composite fitness > {self.min_fitness_threshold}, "
                f"variance < {self.max_variance_threshold}, "
                f"decorrelated from {len(live_agent_correlations)} live agents"
            )
            return True, rationale, True

    from __future__ import annotations
    from dataclasses import dataclass
    from typing import Any
    import structlog

    from src.core.ai.agent_genome import AgentGenome

    logger = structlog.get_logger(__name__)

    @dataclass
    class DemotionGate:
        """Demotion triggers for underperforming agents.

        Agents are demoted if ANY trigger fires:
        1. Composite fitness drops below threshold (consecutive cycles)
        2. Statistical significance drops (confidence intervals widen)
        3. Correlation with existing agents rises (loss of novelty)
        4. Regime shift performance collapse (performance delta > threshold)

        Soft death: Genome preserved to agents/ directory before demotion
        for potential resurrection or gene bank extraction.
        """

        fitness_decay_threshold: float = -0.05  # Composite fitness < -5%
        correlation_rise_threshold: float = 0.8  # Correlation > 0.8 with live agent
        regime_shift_delta_threshold: float = 0.15  # Performance drop > 15% on regime change
        consecutive_cycles_to_demote: int = 3  # Must fail for 3 consecutive cycles

        def should_demote(
            self,
            agent_id: str,
            current_fitness: float,
            fitness_history: list[float],
            live_agent_correlations: dict[str, float],
            regime_performance_delta: float | None = None,
        ) -> tuple[bool, str | None]:
            """Check if agent should be demoted.

            Args:
                agent_id: Agent identifier
                current_fitness: Current composite fitness score
                fitness_history: Last N fitness scores (for consecutive failure detection)
                live_agent_correlations: Current correlation with live agents
                regime_performance_delta: Performance change on regime shift (optional)

            Returns:
                (should_demote, reason)
                - should_demote: True if any demotion trigger fired
                - reason: Human-readable explanation of which trigger fired
            """
            # Trigger 1: Composite fitness decay (consecutive cycles)
            consecutive_failures = 0
            for fitness in fitness_history[-self.consecutive_cycles_to_demote:]:
                if fitness < self.fitness_decay_threshold:
                    consecutive_failures += 1

            if consecutive_failures >= self.consecutive_cycles_to_demote:
                return (
                    True,
                    f"Fitness decay for {consecutive_failures} cycles: "
                    f"{current_fitness:.3f} < {self.fitness_decay_threshold}"
                )

            # Trigger 2: Statistical significance drop (confidence interval widening)
            # Note: This would be computed from fitness_metrics.bootstrap_ci_width
            # Simplified here as fitness < 0 (negative expected returns)
            if current_fitness < 0:
                return True, f"Negative expected returns: {current_fitness:.3f}",

            # Trigger 3: Correlation rise with live agents (loss of novelty)
            for live_agent_id, correlation in live_agent_correlations.items():
                if correlation > self.correlation_rise_threshold:
                    return (
                        True,
                        f"High correlation with {live_agent_id}: "
                        f"{correlation:.2f} > {self.correlation_rise_threshold}"
                    )

            # Trigger 4: Regime shift performance collapse
            if regime_performance_delta is not None:
                if abs(regime_performance_delta) > self.regime_shift_delta_threshold:
                    return (
                        True,
                        f"Regime shift performance collapse: "
                        f"{regime_performance_delta:.2f} drop"
                    )

            return False, None
