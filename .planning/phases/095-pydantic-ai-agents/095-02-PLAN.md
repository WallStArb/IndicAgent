<objective>
Add a `response_format` parameter to `LLMProviderChain.generate()` and thread it through `LiteLLMBackend.generate()` to `acompletion()`. This is the prerequisite for the `LLMAdapter` (Plan 03) to enforce grammar-constrained structured output at generation time via Ollama.

Purpose: RESEARCH.md Pitfall 1 — the JSON schema extracted from pydantic-ai's output tools must reach Ollama as `response_format` or the model produces prose that fails validation. `chain.generate()` currently has no such parameter. This plan adds it without altering existing behavior for callers that omit it.

Output: `chain.generate()` and `litellm_backend.generate()` accept `response_format: dict | None = None`; the kwarg is only passed to `acompletion()` when non-None; full test coverage.
</objective>
