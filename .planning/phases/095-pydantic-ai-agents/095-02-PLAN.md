<threat_model>
Attack vectors analyzed for PydanticAIAdapter bridge:

**1. LLM Prompt Injection via user_prompt**
- Threat: Adversarial AIContext content (str(context)) attempts prompt injection
- Mitigation: Context controlled by pipeline; agent prompts are read-only inputs
- Validation: Existing BaseAIAgent._llm_generate() already sanitizes prompts

**2. Structured Output Parsing Attacks (adversarial JSON)**
- Threat: Malicious LLM returns malformed or oversized JSON to crash parser
- Mitigation: Pydantic AI's NativeOutput enforces schema; validation errors caught by structured output layer
- Validation: Pydantic validators on result models (e.g., SkepticResult) clamp ranges, coerce types

**3. Resource Exhaustion (LLM timeout, memory leaks)**
- Threat: Long-running LLM calls exhaust latency_budget_ms or leak memory
- Mitigation: BaseAIAgent enforces latency_budget_ms (120s for Skeptic); CircuitBreaker opens on failures
- Validation: Existing timeout enforcement preserved via BaseAIAgent._compute() contract

**4. Dependency Injection via pydantic_agent parameter**
- Threat: Subclass passes malicious pydantic_agent with poisoned behavior
- Mitigation: PydanticAIAdapter is internal adapter; only instantiated by trusted SkepticComputeAgentPydantic
- Validation: Unit tests verify protocol compliance; production instantiation controlled

**5. Data Exfiltration via result output**
- Threat: AgentOutput.payload contains sensitive internal state
- Mitigation: Payload already logged to llm_calls table; no new fields exposed
- Validation: Existing audit trail preserved via _llm_generate(); AgentOutput schema unchanged

**6. Audit Trail Bypass (CRITICAL FIX)**
- Threat: Original plan bypassed BaseAIAgent._llm_generate(), losing audit publishing to llm_calls
- Mitigation: FIXED - PydanticAIAdapter routes through _llm_generate() or adds replacement audit emission
- Validation: Unit test verifies llm_calls audit context populated

**7. Async Coroutine Bug (CRITICAL FIX)**
- Threat: Original _compute() returned `self._to_agent_output(...)` without await, returning coroutine
- Mitigation: FIXED - Use `return await self._to_agent_output(result, context)`
- Validation: Unit test verifies _compute() returns AgentOutput, not coroutine
</threat_model>

    from __future__ import annotations

    from typing import TYPE_CHECKING, Any

    from src.core.ai.base_agent import BaseAIAgent
    from src.core.ai.context import AIContext
    from src.core.ai.output import AgentOutput
    from src.intelligence.ai.adapters.agent_deps import AgentDeps

    if TYPE_CHECKING:
        from pydantic_ai import Agent, RunContext

    class PydanticAIAdapter(BaseAIAgent):
        """Adapter that wraps pydantic_ai.Agent in BaseAIAgent protocol.

        Preserves existing infrastructure (timing, timeout, metrics, OTel, audit trail)
        while delegating computation to Pydantic AI agent. Subclasses implement
        _to_agent_output() to convert result-specific types to AgentOutput.

        FIXED per review:
        - Uses await on _to_agent_output() (async bug fix)
        - Routes through _llm_generate() for audit trail preservation
        - Accepts llm_chain, db_pool, memory_client in constructor
        """

        def __init__(
            self,
            pydantic_agent: Agent,
            llm_chain: Any,
            db_pool: Any | None = None,
            memory_client: Any | None = None,
            **kwargs: Any,
        ) -> None:
            super().__init__(**kwargs)
            self._pydantic_agent = pydantic_agent
            self._llm = llm_chain
            self._db_pool = db_pool
            self._memory_client = memory_client

        async def _compute(self, context: AIContext) -> AgentOutput:
            """Delegate to Pydantic AI agent, convert result to AgentOutput.

            FIXED: Now awaits _to_agent_output() to return AgentOutput, not coroutine.
            Routes through _llm_generate() to preserve audit trail (llm_calls table).
            """
            deps = self._build_deps(context)

            # Build user prompt (subclass can override via _build_user_prompt)
            user_prompt = self._build_user_prompt(context)
            system_prompt = self._build_system_prompt()

            # Call LLM through _llm_generate() for audit trail preservation
            # This publishes to llm_calls table with call_id, parse_success, etc.
            raw_response, call_id = await self._llm_generate(
                context,
                prompt=user_prompt,
                system=system_prompt,
                max_tokens=500,
                timeout=self.latency_budget_ms / 1000.0,
            )

            if not raw_response:
                return self._neutral(error="LLM returned empty response", latency_ms=0.0)

            # Parse response as SkepticResult (Pydantic AI structured output)
            try:
                # For now, use existing JSON parsing until Pydantic AI integrated
                # Subclass will override with NativeOutput parsing
                result = self._parse_response(raw_response)
            except Exception as exc:
                await self._report_parse_failure(call_id)
                return self._neutral(error=f"Parse failed: {exc}", latency_ms=0.0)

            # FIXED: Await the async conversion method
            return await self._to_agent_output(result, context)

        def _build_deps(self, context: AIContext) -> AgentDeps:
            """Build dependency container for Pydantic AI run."""
            return AgentDeps(
                signal_context=context,
                llm_chain=self._llm,
                db_pool=self._db_pool,
                memory_client=self._memory_client,
            )

        def _build_user_prompt(self, context: AIContext) -> str:
            """Build user prompt from context (subclass can override).

            Default: string representation of context. Skeptic will override with
            build_skeptic_prompt() for prompt parity with legacy agent.
            """
            return str(context)

        def _build_system_prompt(self) -> str:
            """Build system prompt (subclass can override).

            Default: strict JSON output message.
            """
            return (
                "OUTPUT ONLY RAW JSON. NO PROSE. NO EXPLANATION. NO PREAMBLE. "
                "Your entire response must be a single JSON object starting with { and ending with }. "
                "Begin your response with { and end with }. No prose before or after the JSON."
            )

        def _parse_response(self, raw_response: str) -> Any:
            """Parse raw LLM response (subclass must override for Pydantic AI).

            Default: returns raw string. Subclass will use Pydantic AI's
            NativeOutput parsing here.
            """
            return raw_response

        async def _to_agent_output(
            self, result: Any, context: AIContext
        ) -> AgentOutput:
            """Convert Pydantic AI result to canonical AgentOutput.

            Subclasses must override to apply transfer functions and
            populate payload with agent-specific fields.

            This method MUST be async and awaited (fixed per review).
            """
            raise NotImplementedError(
                f"{self.__class__.__name__} must implement _to_agent_output()"
            )
