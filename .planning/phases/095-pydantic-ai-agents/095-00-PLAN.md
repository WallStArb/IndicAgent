<threat_model>
Attack vectors analyzed for multi-tenant agent execution:

**1. Cross-Tenant Data Exfiltration**
- Threat: Agent for tenant A accesses tenant B's signals or context
- Mitigation: UserContext.tenant_id isolated per request; agents cannot see other tenants
- Validation: Unit tests verify tenant_id propagation through compute() calls

**2. Quota Exhaustion Attacks**
- Threat: Malicious user exhausts request quota, Denial of Service for other users
- Mitigation: AgentLimits enforces per-user quotas before compute; shared semaphore for global capacity
- Validation: Integration tests verify quota rejection when limits exceeded

**3. Cost Escalation via LLM Calls**
- Threat: User generates excessive LLM calls to exhaust cost quota
- Mitigation: Cost tracking per user in llm_calls; AgentLimits.check_cost_quota() before LLM calls
- Validation: Unit tests verify cost quota enforcement before _llm_generate()

**4. Permission Bypass via Agent Swarms**
- Threat: User without permission accesses restricted agent via swarm routing
- Mitigation: UserContext.permissions checked before agent registration; per-agent access control
- Validation: Service registration tests verify permission gating

**5. Audit Trail Contamination**
- Threat: user_id or tenant_id missing from llm_calls, breaking per-user analytics
- Mitigation: Migration adds NOT NULL DEFAULT 'system' for user_id; required parameter in _llm_generate()
- Validation: Migration test verifies user_id populated in all new llm_calls rows

**6. Feature Gate Bypass**
- Threat: Multi-tenant code executes when ENABLE_MULTI_TENANT=false
- Mitigation: Feature gate checked at runtime; single-tenant path uses hardcoded default user
- Validation: Unit tests verify single-tenant mode unchanged with feature disabled
</threat_model>

    from dataclasses import dataclass

    @dataclass(frozen=True)

        """User context for multi-tenant agent execution.

        Provides per-user identification, quotas, permissions, and cost tracking.
        Threaded through AgentDeps to all agents for multi-tenant awareness.

        In single-tenant mode (ENABLE_MULTI_TENANT=false), uses hardcoded defaults.
        """

        user_id: str
        tenant_id: str | None = None
        request_quota: int = 1000  # Requests per day
        cost_quota_usd: float = 100.0  # Budget limit in USD
        concurrency_limit: int = 5  # Max concurrent requests
        permissions: frozenset[str] = frozenset()  # Agent access control
        metadata: dict[str, Any] | None = None  # Extensible user properties

        @classmethod
        def system(cls) -> "UserContext":
            """Create system user context for single-tenant mode."""
            return cls(
                user_id="system",
                tenant_id=None,
                request_quota=10_000,  # Higher limit for system
                cost_quota_usd=1000.0,
                concurrency_limit=50,
                permissions=frozenset(["*"]),  # All agents
            )

        @classmethod
        def from_request(cls, user_id: str, **kwargs: Any) -> "UserContext":
            """Create UserContext from request parameters (multi-tenant mode).

            In production, this would load quotas from database or auth service.
            """
            return cls(user_id=user_id, **kwargs)

    from __future__ import annotations
    from dataclasses import dataclass
    from typing import Any
    import structlog

    from src.core.ai.user_context import UserContext

    logger = structlog.get_logger(__name__)

    @dataclass
    class AgentLimits:
        """Per-user quota enforcement for multi-tenant agent execution.

        Tracks request counts, costs, and concurrent executions per user.
        Enforces quotas before agent compute() to prevent overages.
        """

        user_context: UserContext
        requests_today: int = 0
        cost_today_usd: float = 0.0
        concurrent_requests: int = 0

        def can_execute(self) -> tuple[bool, str | None]:
            """Check if user can execute agent (within quotas).

            Returns (allowed, reason_denyed). If allowed=True, reason is None.
            """
            # Check request quota
            if self.requests_today >= self.user_context.request_quota:
                return False, f"Request quota exceeded: {self.requests_today}/{self.user_context.request_quota}"

            # Check cost quota
            if self.cost_today_usd >= self.user_context.cost_quota_usd:
                return False, f"Cost quota exceeded: ${self.cost_today_usd:.2f}/${self.user_context.cost_quota_usd:.2f}"

            # Check concurrency
            if self.concurrent_requests >= self.user_context.concurrency_limit:
                return False, f"Concurrency limit exceeded: {self.concurrent_requests}/{self.user_context.concurrency_limit}"

            return True, None

        def check_permissions(self, agent_id: str) -> bool:
            """Check if user has permission to execute agent."""
            # Wildcard permission grants all agents
            if "*" in self.user_context.permissions:
                return True

            # Explicit agent permission
            if agent_id in self.user_context.permissions:
                return True

            logger.warning(
                "agent_permission_denied",
                user_id=self.user_context.user_id,
                agent_id=agent_id,
                permissions=list(self.user_context.permissions),
            )
            return False

        def record_request(self, cost_usd: float = 0.0) -> None:
            """Record executed request (updates counters)."""
            self.requests_today += 1
            self.cost_today_usd += cost_usd

        def record_completion(self, cost_usd: float = 0.0) -> None:
            """Record request completion (updates cost and releases concurrency slot)."""
            self.cost_today_usd += cost_usd
            self.concurrent_requests = max(0, self.concurrent_requests - 1)

    Simple in-memory enforcement. For production, persist to database with
    TTL-based daily reset. Track costs in llm_calls table for audit.
