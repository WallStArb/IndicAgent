3. Add the method:
   ```python
   async def _run_typed(
       self,
       context: AIContext,
       prompt: str,
       system: str,
       max_tokens: int,
       timeout: float,
   ) -> BaseModel:
       """Run via Pydantic AI with typed structured output + audit trail.

       Requires result_type to be set on the subclass. Builds the same
       audit_context as _llm_generate, constructs LLMAdapter (which
       publishes to llm.calls), an Agent with deps_type=AgentContext, and runs it.
       Returns the validated result model (result.output).
       """
       if self.result_type is None:
           raise RuntimeError(
               f"{self.__class__.__name__}._run_typed called but result_type is None. "
               "Set result_type on the subclass or use _llm_generate for the legacy path."
           )
       from pydantic_ai import Agent

       call_id = str(uuid4())
       audit_context: dict[str, Any] = {
           "call_id": call_id,
           "called_at": format_iso_ts(datetime.now(UTC)),
           "symbol": context.symbol,
           "signal_id": str(context.signal_id) if context.signal_id else None,
           "group_name": self.group,
           "agent_id": self.agent_id,
           "prompt_version": self.prompt_version,
           "timeframe": context.timeframe,
           "prompt": prompt,
           "succeeded": True,
           "parse_success": True,
       }
       if context.smc is not None:
           regime = getattr(context.smc, "hmm_regime", None)
           if regime is not None:
               audit_context["regime"] = str(int(regime))

       model = LLMAdapter(self._llm, audit_context)
       agent = Agent(
           model=model,
           output_type=self.result_type,   # VERIFY kwarg name against installed API
           deps_type=AgentContext,
           system_prompt=system,            # VERIFY kwarg (system_prompt vs instructions)
       )
       deps = AgentContext(
           signal_context=context,
           llm_chain=self._llm,
           db_pool=getattr(self, "_db_pool", None),
       )
       result = await agent.run(prompt, deps=deps)
       return result.output   # VERIFY attribute (result.output vs result.data)
   ```
   Replace the `# VERIFY` kwargs/attributes with the names confirmed against the installed pydantic-ai version (see <read_first>). Per RESEARCH Pitfall 3, prefer passing the JSON-enforcement system text via the Agent's system-prompt/instructions mechanism rather than overriding it at run time.

Do NOT modify any existing method or ClassVar on `BaseAIAgent`.

<threat_model>
- **Audit bypass**: `_run_typed` builds the audit_context and hands it to `LLMAdapter`, which publishes it (Plan 02). No path through `_run_typed` reaches an LLM without an audit_context. Pydantic AI auto-retries re-enter `LLMAdapter.request()`, each producing an audit row sharing `call_id`.
- **Silent legacy fallback**: `_run_typed` raises RuntimeError if `result_type is None` rather than silently falling back — failure is loud (test `test_run_typed_raises_when_result_type_none`).
- **Zero breaking changes**: `result_type` defaults to None and existing agents never call `_run_typed`; `_llm_generate` and all other existing `BaseAIAgent` methods are byte-for-byte unchanged (test `test_legacy_llm_generate_untouched`). `BaseMultiplierAgent` methods (`_parse_multiplier_response`, `_build_multiplier_output`) are untouched — they live on the subclass.
- **pydantic-ai API drift**: <read_first> mandates verifying `output_type`/`system_prompt`/`result.output` kwarg+attr names against the installed `>=1.0,<2` before coding.
- **Prompt injection**: prompt comes from pipeline-built context; system text passed via Agent system prompt per RESEARCH Pitfall 3 to avoid conflicting Pydantic AI system messages.
- **Shadow leak / Ollama version**: handled in Plans 04/05.
</threat_model>
