- Mitigation: NativeOutput enforces schema; Field(ge=0.0, le=1.0) REJECTS out-of-range floats; field_validator coerces types
- Validation: Unit tests verify None/single/list coercion; rejection tests verify ValidationError on invalid floats

**2. Field Coercion Attacks via risk_factors**
- Threat: Malicious LLM passes non-string types (dict, list, int) to risk_factors
- Mitigation: @field_validator(mode='before') converts all inputs to list[str]; reject non-serializable types
- Validation: test_skeptic_result_coerce_to_list_list verifies mixed-type lists are stringified

**3. Denial of Service via reasoning field**
- Threat: LLM generates megabyte-sized reasoning field to exhaust memory
- Mitigation: max_length=500 caps reasoning size; Pydantic ValidationError on overflow
- Validation: Unit test with 501-char string should raise ValidationError

**4. Confidence/Probability Overflow (CLARIFIED BEHAVIOR)**
- Threat: LLM returns values > 1.0 or < 0.0 to break transfer function
- Mitigation: Field(ge=0.0, le=1.0) REJECTS invalid values via ValidationError (does NOT clamp)
- Validation: test_skeptic_result_float_bounds_reject verifies ValidationError on out-of-range values

**5. Type Confusion via Optional Fields**
- Threat: Omitted fields default to None; downstream code assumes list/str
- Mitigation: risk_factors has default_factory=list; reasoning defaults to ""; float fields required (no defaults)
- Validation: test_skeptic_result_valid_input verifies all fields present

    from pydantic import BaseModel, Field, field_validator, ValidationError

    class SkepticResult(BaseModel):
        """Result model for Skeptic agent with NativeOutput enforcement.

        Float validation is STRICT: rejects out-of-range values via ValidationError.
        This differs from legacy _validate_skeptic_fields() which clamps values.

        For legacy parity, use _validate_skeptic_fields() before constructing
        SkepticResult. For strict Pydantic AI behavior, let validation reject.
        """

        failure_probability: float = Field(ge=0.0, le=1.0)
        confidence: float = Field(ge=0.0, le=1.0)
        risk_factors: list[str] = Field(default_factory=list)
        reasoning: str = Field(default="", max_length=500)

        @field_validator("risk_factors", mode="before")
        @classmethod
        def coerce_to_list(cls, v: object) -> list[str]:
            """Handle LLM output variations: None, single value, or list."""
            if v is None:
                return []
            if not isinstance(v, list):
                return [str(v)]
            return [str(x) for x in v]
