<threat_model>
Attack vectors analyzed for AgentGenome foundation:

**1. Genome Provenance Forgery**
- Threat: Malicious actor creates agent with fake genome_id claiming false ancestry
- Mitigation: genome_id is SHA256 hash of chromosome content, cannot be forged
- Validation: Unit tests verify genome_hash() is deterministic and collision-resistant

**2. Lineage Obfuscation**
- Threat: Agent obscures parent_ids to hide problematic ancestry or data leakage sources
- Mitigation: parent_ids is required field; empty list indicates generation 0; cannot be hidden
- Validation: Registration checks parent_ids exist in gene bank; unknown parents rejected

**3. Chromosome Tampering**
- Threat: Agent modifies chromosome content without updating hash, creating provenance mismatch
- Mitigation: Genome is frozen dataclass; chromosome hashes computed at construction time
- Validation: Genome verification recomputes hashes and checks match

**4. Gene Bank Pollution**
- Threat: Low-quality genome segments flood gene bank, making recombination ineffective
- Mitigation: Only segments from statistically successful agents added to gene bank
- Validation: Gate to gene bank requires minimum fitness threshold and resolution count

**5. Proliferation Attack**
- Threat: Automated agent spawning creates unlimited offspring, exhausting compute resources
- Mitigation: Replication is privilege gated by fitness (Plan 08); no automatic reproduction
- Validation: Promotion gates verify fitness before granting reproductive rights

**6. Archive Contamination**
- Threat: Harmful agents preserved in frozen archive could be accidentally resurrected
- Mitigation: Hard death flag for harmful agents; resurrection requires explicit human approval
- Validation: Archive search includes risk assessment metadata
</threat_model>

        """Base class for genome chromosomes.

        A chromosome is a heritable unit of the agent genome. Each chromosome
        represents a different aspect of the agent (prompts, config, tools, etc.)
        and can mutate independently.
        """
        
        def hash_content(self) -> str:
            """Hash the chromosome content for reproducible identification."""
            raise NotImplementedError(f"{self.__class__.__name__} must implement hash_content()")

    @dataclass(frozen=True)
    class SystemPromptChromosome(GenomeChromosome):
        """System prompt chromosome - the agent's reasoning strategy.
        
        Mutations: rewording prompt sections, adding/removing reasoning steps,
        shifting analytical frame, changing persona or role.
        """
        prompt_template: str
        instructions: str
        framework: str  # e.g., "chain-of-thought", "reactive", "deliberative"
        
        def hash_content(self) -> str:
            """Hash prompt content for chromosome identification."""
            content = f"{self.prompt_template}:{self.instructions}:{self.framework}"
            return hashlib.sha256(content.encode()).hexdigest()[:16]

    @dataclass(frozen=True)
    class ConfigChromosome(GenomeChromosome):
        """Configuration chromosome - agent parameters and thresholds.
        
        Mutations: nudge confidence threshold ±5%, swap timeframe priority,
        adjust lookback windows, modify signal weights, change filter thresholds.
        """
        confidence_threshold: float
        timeframe_weights: dict[str, float]  # {"5m": 0.5, "15m": 0.3, "1h": 0.2}
        lookback_days: int
        filters: dict[str, Any]  # Volatility gates, regime filters
        
        def hash_content(self) -> str:
            """Hash config content for chromosome identification."""
            content = f"{self.confidence_threshold}:{self.timeframe_weights}:{self.lookback_days}"
            return hashlib.sha256(content.encode()).hexdigest()[:16]

    @dataclass(frozen=True)
    class ToolSetChromosome(GenomeChromosome):
        """Tool set chromosome - which data sources and analysis tools agent uses.
        
        Mutations: add new data feed, remove underperforming indicator, reorder
        tool call priority, enable/disable analysis tools.
        """
        enabled_tools: frozenset[str]  # e.g., frozenset(["rsi", "macd", "vwap"])
        tool_priority: dict[str, int]  # Tool name -> execution order
        data_sources: frozenset[str]  # External APIs and data feeds
        
        def hash_content(self) -> str:
            """Hash tool set for chromosome identification."""
            tools_str = ",".join(sorted(self.enabled_tools))
            content = f"{tools_str}:{self.data_sources}"
            return hashlib.sha256(content.encode()).hexdigest()[:16]

    @dataclass(frozen=True)

        Mutations: tighten regime filter, add volatility guard, relax false-positive

        """
        regime_filter: str | None  # e.g., "trending_only", "exclude_fomc_weeks"
        volatility_guard: float  # Max VIX threshold before shutdown
        position_limits: dict[str, float]  # Max position size per symbol
        false_positive_screen: bool  # Whether to apply skepticism to own signals
        
        def hash_content(self) -> str:
            """Hash rules for chromosome identification."""
            content = f"{self.regime_filter}:{self.volatility_guard}:{self.false_positive_screen}"
            return hashlib.sha256(content.encode()).hexdigest()[:16]

    def compute_genome_hash(chromosomes: dict[str, GenomeChromosome]) -> str:

        The genome_id is SHA256 of concatenated chromosome hashes. This ensures

        precise provenance tracking.

        # Concatenate all chromosome hashes
        combined_hashes = ":".join(chrom.hash_content() for _, chrom in sorted_chromosomes)
        
        # Hash the combined string
        return hashlib.sha256(combined_hashes.encode()).hexdigest()

    @dataclass(frozen=True)
    class AgentGenome:
        """Genome identification and lineage tracking for evolvable agents.
        
        Every agent variant has a unique genome_id computed from its chromosome
        hashes. This provides deterministic provenance tracking for eAI evolution.
        
        Per eAI research: "No agent is deployed without known provenance."
        """
        genome_id: str  # SHA256 hash of all chromosome hashes
        parent_ids: list[str]  # Ancestry chain (empty for generation 0)
        generation: int  # Distance from original agent (0 = seed)
        created_at: datetime
        
        # Chromosomes (heritable components)
        system_prompt: SystemPromptChromosome
        config: ConfigChromosome
        tool_set: ToolSetChromosome
        rules: RulesChromosome
        
        def __post_init__(self) -> void:
            """Validate genome on construction.
            
            Ensures genome_id matches actual chromosome hashes and parent_ids
            refer to existing genomes.
            """
            # Verify genome_id matches computed hash
            computed_id = self._compute_genome_id()
            if computed_id != self.genome_id:
                raise ValueError(f"Genome ID mismatch: provided {self.genome_id} != computed {computed_id}")
            
            # Verify generation matches parent_ids depth
            if self.parent_ids:
                expected_gen = max([_get_generation(parent_id) for parent_id in self.parent_ids]) + 1
            else:
                expected_gen = 0
            
            if self.generation != expected_gen:
                raise ValueError(f"Generation mismatch: provided {self.generation} != expected {expected_gen}")

        def _compute_genome_id(self) -> str:
            """Compute genome ID from chromosome hashes."""
            chromosomes = {
                "system_prompt": self.system_prompt,
                "config": self.config,
                "tool_set": self.tool_set,
                "rules": self.rules,
            }
            return compute_genome_hash(chromosomes)

        def mutate_system_prompt(self, new_prompt: str) -> "AgentGenome":
            """Create offspring with mutated system prompt chromosome.
            
            This implements the "random mutation" operator from eAI research.
            Offspring generation is incremented and parent tracking updated.
            """
            import copy
            new_chromosome = SystemPromptChromosome(
                prompt_template=new_prompt,
                instructions=self.system_prompt.instructions,
                framework=self.system_prompt.framework,
            )
            
            return replace(
                self,
                genome_id=self._compute_genome_id(),  # Recompute after mutation
                parent_ids=[self.genome_id],  # Single parent
                generation=self.generation + 1,
                created_at=datetime.now(UTC),
                system_prompt=new_chromosome,
            )

        def recombine(self, other: "AgentGenome") -> "AgentGenome":
            """Create offspring via sexual recombination with another agent.
            
            Implements the "sexual recombination" operator from eAI research.
            Offspring inherits chromosome segments from both parents.
            """
            import random
            
            # Randomly select chromosomes from each parent
            new_system = self.system_prompt if random.random() < 0.5 else other.system_prompt
            new_config = self.config if random.random() < 0.5 else other.config
            new_tools = self.tool_set if random.random() < 0.5 else other.tool_set
            new_rules = self.rules if random.random() < 0.5 else other.rules
            
            return AgentGenome(
                genome_id="",  # Will be computed in __post_init__
                parent_ids=sorted([self.genome_id, other.genome_id]),
                generation=max(self.generation, other.generation) + 1,
                created_at=datetime.now(UTC),
                system_prompt=new_system,
                config=new_config,
                tool_set=new_tools,
                rules=new_rules,
            )

                "parent_ids": self.parent_ids,
                "generation": self.generation,

                    "confidence_threshold": self.config.confidence_threshold,
                    "timeframe_weights": dict(self.config.timeframe_weights),
                    "lookback_days": self.config.lookback_days,
                    "filters": self.config.filters,
                    "hash": self.config.hash_content(),
                },
                "tool_set": {
                    "enabled_tools": list(self.tool_set.enabled_tools),
                    "tool_priority": dict(self.tool_set.tool_priority),
                    "data_sources": list(self.tool_set.data_sources),
                    "hash": self.tool_set.hash_content(),
                },
                "rules": {
                    "regime_filter": self.rules.regime_filter,

                    "position_limits": dict(self.rules.position_limits),
                    "false_positive_screen": self.rules.false_positive_screen,
                    "hash": self.rules.hash_content(),
