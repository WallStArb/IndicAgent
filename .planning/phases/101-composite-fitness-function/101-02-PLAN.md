<objective>
Build the accuracy dimension (FIT-01) and calibration dimension (FIT-03) as pure, side-effect-free calculator functions in `src/intelligence/ai/fitness/`. Accuracy maps the bootstrap CI lower bound on `pnl_r` to [0,1] via the exact anchored linear clamp `clamp(0.5 + ci_lower, 0, 1)`; calibration maps `1 - Brier(confidence, win_outcome)` to [0,1]. Both return `None` below their minimum N gate so the composite stays NULL until the dimension is evaluable.

Purpose: These two dimensions share a data shape (resolved signals with pnl_r/outcome/confidence) but measure different things — accuracy = outcome quality, calibration = stated-probability quality. TDD here because each has a clean `input -> expected output` contract.
Output: accuracy.py, calibration.py, and a shared test file.
</objective>
