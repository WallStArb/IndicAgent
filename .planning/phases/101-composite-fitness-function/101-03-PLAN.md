<objective>
Build the regime specificity dimension (FIT-04) and the efficiency dimension (FIT-05) as pure calculators. Regime score = the fraction of distinct `hmm_regime_at_fire` regimes (with enough samples) in which the agent clears a per-regime accuracy floor — directly measuring the eAI "knows its limits" property. Efficiency score = `1 - clamp(median_tokens / token_ceiling, 0, 1)`, with the I7-plugin (no LLM cost) convention returning 1.0.

Purpose: Both dimensions are pure and parallelizable with plan 02. Regime needs per-regime grouping and a min-regimes gate (D-06); efficiency needs a token-ceiling normalization (chosen standalone formula from RESEARCH Open Question 2, avoiding the circular fitness-per-token dependency).
Output: regime.py, efficiency.py, and a shared test file.
</objective>
