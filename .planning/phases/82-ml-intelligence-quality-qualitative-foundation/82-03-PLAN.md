<objective>
Build the offline HMM training pipeline: `HMMTrainingComputeAgent` runs Baum-Welch via `hmmlearn.GaussianHMM` on `intelligence_features` (per-TF pooled, excluding backfill), writes four `config/hmm_parameters_{tf}.json` files, and emits SIGUSR1 to the intelligence pipeline so live instances reload parameters.

Purpose: Separation of concerns — training (compute) is a separate oneshot service from inference (the four HMM plugin instances from Plan 02).
Output: Trained parameter files + systemd oneshot service+timer + entry to live-reload.
</objective>

    Create `src/intelligence/services/hmm_training_compute_agent.py`:
    - Class `HMMTrainingComputeAgent` with constructor accepting `db_manager`, `settings`, `target_tfs: tuple[str, ...] = ("1m", "5m", "15m", "1h")`, and an optional `lookback_days: int` (default e.g. 30 for 1m, 60 for higher TFs — implement as a small mapping inside the class).
    - Method `async def run(self) -> dict[str, str]`: For each TF, query `intelligence_features` for that TF, excluding `is_backfill = TRUE`, selecting the observation feature columns used by `HMMRegimePlugin._build_observation()` — replicate the exact feature set (returns, volume z-score, volatility, OFI signal, directional bias).     - Build observation matrix as `numpy.ndarray` shape (T, n_features).
    - Fit `hmmlearn.hmm.GaussianHMM(n_components=3, covariance_type="diag", n_iter=50)` on the observation matrix.
    - Serialize `transmat_`, `means_`, `covars_` (variances when `covariance_type="diag"`) into JSON dict matching the keys read by `_load_parameters()` in `hmm_regime.py` (inspect that function and mirror keys: `transition_matrix`, `emission_means`, `emission_variances`).
    - Atomic write: write to `config/hmm_parameters_{tf}.json.tmp`, then `os.rename` to the final path.
    - Return a dict mapping TF -> file path written.
    - Method `def emit_sigusr1(self) -> None`: Use `subprocess.run(["systemctl", "kill", "--signal=SIGUSR1", "indicagent-intelligence-pipeline.service"], check=False)` and log result. Skip silently if systemctl is unavailable (development mode) but log a warning.
    - Method `async def start(self) -> None`: orchestrates `run()` then `emit_sigusr1()`. Returns when done. Logs counts per TF and final outcome via `structlog` using `setup_service_logging("logs/hmm_training_compute_agent.log")`.
    - Skip training for any TF whose observation count is below a hardcoded minimum (e.g. 500 rows); log skip reason; do NOT crash the run.
    - Filter out rows with NaN in any observation column before fitting.
