<objective>
Build the SCORE-02 OOS Gate 1 (signal proof) scorer: a standalone one-shot script that
measures whether alpha_score predicts forward returns out-of-sample. It is structurally a
sibling of ops_oos_holdout_eval.py but scores ensemble_alpha via ensemble_ic_engine.py's
EXACT IC helper set (Fisher-z, not the newer circular-block bootstrap) so its OOS numbers are
apples-to-apples with the single existing in-sample alpha_ensemble_ic row. This plan BUILDS
and tests the script; the actual one-shot run is Wave 3's deliverable in plan 148-05.

Purpose: Gate 1 answers "is there real signal at all," the foundational question this whole
measurement pipeline exists to settle. Output: the script plus GREEN unit tests.
</objective>
