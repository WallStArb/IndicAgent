Enhance shadow_registry with comprehensive Occam audit columns, implement idempotent rejection flow with structured reason codes, and wire ORE into AlphaSwarm's graduation loop.

Purpose: Reviewers flagged that (a) setting is_shadow=TRUE on an already-shadow model doesn't capture rejection state, (b) no idempotency guard means the 15-min loop re-rejects the same agent, (c) rejection reasons were free-text. This plan adds proper audit columns, structured reason codes, and idempotency.

Output: Migration, OTel metrics, AlphaSwarm integration with rejection flow, golden dataset test.

```sql
BEGIN;

-- D-05 enhanced: comprehensive Occam audit trail
ALTER TABLE shadow_registry
  ADD COLUMN IF NOT EXISTS rejection_reason TEXT,
  ADD COLUMN IF NOT EXISTS complexity_score FLOAT,
  ADD COLUMN IF NOT EXISTS last_occam_check TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS occam_status TEXT DEFAULT 'pending'
    CHECK (occam_status IN ('pending', 'evaluated', 'rejected', 'insufficient_data')),
  ADD COLUMN IF NOT EXISTS occam_ci_lower FLOAT,
  ADD COLUMN IF NOT EXISTS occam_ci_upper FLOAT,
  ADD COLUMN IF NOT EXISTS occam_sharpe_delta FLOAT,
  ADD COLUMN IF NOT EXISTS occam_baseline_id TEXT,
  ADD COLUMN IF NOT EXISTS occam_rejected_at TIMESTAMPTZ;

COMMENT ON COLUMN shadow_registry.rejection_reason IS
    'Structured reason: REJECTED_LOW_SHARPE, REJECTED_COMPLEXITY, REJECTED_TIE, or INSUFFICIENT_DATA';
COMMENT ON COLUMN shadow_registry.occam_status IS
    'Occam evaluation state: pending, evaluated, rejected, insufficient_data';
COMMENT ON COLUMN shadow_registry.occam_ci_lower IS
    'Lower bound of penalized Sharpe delta CI from last Occam evaluation';
COMMENT ON COLUMN shadow_registry.occam_ci_upper IS
    'Upper bound of penalized Sharpe delta CI from last Occam evaluation';
COMMENT ON COLUMN shadow_registry.occam_sharpe_delta IS
    'Raw Sharpe delta (complex - baseline) from last Occam evaluation';
COMMENT ON COLUMN shadow_registry.occam_baseline_id IS
    'Baseline builder type used for last Occam evaluation';
COMMENT ON COLUMN shadow_registry.occam_rejected_at IS
    'Timestamp when Occam evaluation rejected the complex model';

CREATE INDEX IF NOT EXISTS idx_shadow_registry_occam_status
  ON shadow_registry (occam_status) WHERE occam_status IS NOT NULL;

COMMIT;
```
