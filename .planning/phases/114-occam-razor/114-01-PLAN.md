Create `src/intelligence/ai/evaluators/baseline.py` with the following structure:

1. **BaselineResult dataclass** with fields: `predictions: NDArray[np.float64]`, `complexity_score: float`, `metadata: dict[str, Any]` (contains keys `n_params: int`, `model_type: str`). frozen=True.

2. **BaselineBuilder Protocol** with three explicit methods:
   - `fit(features: NDArray[np.float64], targets: NDArray[np.float64]) -> None` — train the baseline. MUST raise `ValueError` with message containing "zero variance" if `targets.std() < 1e-9`. MUST raise `ValueError` with message containing "NaN" if either input contains NaN. MUST raise `ValueError` with message containing "insufficient" if `len(targets) < 10`.
   - `predict(features: NDArray[np.float64]) -> NDArray[np.float64]` — return probability-like scores in [0, 1]. MUST raise `RuntimeError` with message containing "not fitted" if called before `fit()`.
   - `metadata() -> dict[str, Any]` — return dict with keys `n_params: int`, `model_type: str`, `complexity_score: float`.

3. **LinearBaseline** implementing BaselineBuilder:
   - Uses `sklearn.linear_model.LogisticRegression(penalty='l2', C=1.0, max_iter=1000, random_state=42)`
   - In `fit()`: wrap `model.fit()` in try/except catching sklearn convergence warnings. On `ConvergenceWarning`, log warning via structlog but proceed (model is still usable). Guard zero variance and NaN before fitting.
   - `predict()` returns `model.predict_proba(features)[:, 1]`
   - `complexity_score = np.log(n_features + 1 + 1)` where +1 for intercept
   - Stores fitted model on `self._model`, fitted flag on `self._fitted: bool`

4. **RuleBaseline** implementing BaselineBuilder:
   - In `fit()`: validates inputs (NaN, zero-variance, min samples), stores `self._threshold: float = float(np.median(features[:, 0]))` if features.ndim == 2 and features.shape[1] > 0, else 0.5
   - `predict()` returns `(features[:, 0] > self._threshold).astype(np.float64)`
   - `complexity_score = np.log(2)` (1 parameter: the threshold)
   - `metadata()` returns `n_params=1, model_type='rule'`

5. **RandomBaseline** implementing BaselineBuilder:
   - In `fit()`: validates inputs only (stores nothing — random model ignores data)
   - `predict()` returns `np.random.default_rng(42).uniform(0, 1, size=len(features))`
   - `complexity_score = 0.0`
   - `metadata()` returns `n_params=0, model_type='random'`

6. **_BASELINES registry** as module-level `dict[str, type[BaselineBuilder]]`:
   - `"ml_"` -> `LinearBaseline`
   - `"correlation_"` -> `RuleBaseline`
   - `"regime_"` -> `RandomBaseline`
   - `"counterfactual_"` -> `RuleBaseline`

7. **get_baseline(agent_id: str) -> BaselineBuilder | None**:
   - Iterates `_BASELINES.items()`, returns first match where `agent_id.startswith(prefix)`.
   - Returns None if no prefix matches (caller skips with warning per D-01 fallback).

```sql
BEGIN;

ALTER TABLE ml_models
  ADD COLUMN IF NOT EXISTS param_count INTEGER DEFAULT 0,
  ADD COLUMN IF NOT EXISTS inference_latency_ms FLOAT DEFAULT 0.0,
  ADD COLUMN IF NOT EXISTS training_time_ms FLOAT DEFAULT 0.0;

COMMENT ON COLUMN ml_models.param_count IS
    'Number of trainable parameters for complexity_score = log(params+1) * (1+lat/1000) * (1+train/60000)';
COMMENT ON COLUMN ml_models.inference_latency_ms IS
    'Rolling average inference latency in ms for complexity score computation';
COMMENT ON COLUMN ml_models.training_time_ms IS
    'Rolling average training time in ms for complexity score computation';

COMMIT;
```
