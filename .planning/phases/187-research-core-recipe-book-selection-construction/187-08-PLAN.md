<objective>
The fourth part of the book (design 4.4) and the E17 memory rule for fitted books (design 4.5, todo 448 item 2, todo 442 item 2). Today run_book passes `memory_sessions = max(slot_histories)`, which ignores the ridge's training reach and any partial adjustment; `book_memory_rows` covers the shift diagnostic only. After this plan, L = member memory + combiner training reach + horizon reach, from one function.

The horizon rule is `w_t = w_(t-1) + kappa * (w*_t - w_(t-1))` (Garleanu and Pedersen 2013), applied to the construction's target weights row by row in panel order, across session boundaries (causal: w_t reads w*_s for s <= t only), with target 0 on rows without a position. Kappa is a cost device pinned in the spec before the attempt and never tuned on outcomes (design 4.4, glossary `horizon rule`); deriving it from the cost model and signal autocorrelation is attempt 2's pre-registration, not this plan. Discovery books leave it unset (kappa = 1).

Behavior change disclosure: for an equal-weight book with kappa = 1, L is unchanged (training_rows = 0, reach 0). For a ridge book, L grows by ceil(training_rows / bars_per_session) sessions. That is a behavior change of the E17 statistic for ridge books (book_v1 was refused before any statistic, so no recorded verdict moves); it lands in its own commit with a methodology-change-ledger note under E17 citing design 4.5.
