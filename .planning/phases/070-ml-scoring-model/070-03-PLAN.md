<objective>
Build the offline LightGBM training pipeline: (a) feature_builder.py — a pure-function module that queries signal_ledger + intelligence_features and returns a polars DataFrame ready for LightGBM, and (b) MLTrainingComputeAgent — a systemd oneshot service that nightly runs the delta gate, segments by hmm_regime, trains with walk-forward CV, computes SHAP, registers artifacts via ModelRegistry, and signals the alpha swarm to reload via SIGUSR1.

Purpose: Establish the supply side of the ML scoring system — produces promoted model artifacts that the inference agent (Plan 04) consumes. Designed to run in shadow_only mode until promotion gate (manual / future automation) approves a model.

Output: Feature builder module + training agent module + systemd oneshot entrypoint.
</objective>

<threat_model>
ASVS L1 considerations:
- **V1.4 Trust boundary**: Training reads from internal DB (asyncpg connection, no external network input). MLflow artifact storage at localhost:5000 (loopback only — no external exposure).
- **V5 Input validation**: SQL parameters use $N placeholders (no string interpolation). signal_schema_version is filtered via parameterized value (the imported constant, never user-supplied).
- **V7 Error handling**: Training failure must NOT crash the systemd unit's exit code in a way that prevents subsequent timer fires. Catch top-level exception, log, exit 0 (oneshot success) so timer fires again next night.
- **V8 Data protection**: Model artifacts written to MLflow at loopback URI. No PII in features.
- **V13 API/Web service**: No new API surface; this is a batch job.
- **Threat: Lookahead contamination** — Mitigation: SQL clause `f.ts < sl.activated_at` enforced in feature_builder.py SQL; walk-forward CV uses temporal sort + index-based split (no shuffle).
- **Threat: Concurrent training runs** — Mitigation: systemd Type=oneshot semantics prevent overlap with a running unit. Acceptable.
- **Threat: Disk exhaustion via SHAP artifacts** — Mitigation: SHAP stored as JSON feature-importance summary (small), not full per-sample SHAP matrices.
</threat_model>
