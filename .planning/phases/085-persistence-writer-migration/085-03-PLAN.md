<objective>
Migrate the three positional-tuple offenders identified in the PERSIST-05 audit to the named-field
`_to_row()` helper pattern. `swarm_ledger_writer_agent` was audited and found clean — no migration
needed there.

The named-field helper pattern: a private method on the writer class that takes named arguments and
returns the positional tuple, with a one-line comment per position. Callers pass named args; the helper
maps field name to position explicitly so any reviewer can audit without counting commas.

Reference template: `services/contract_metadata_writer_agent.py` named `conn.execute()` style and
`services/feature_writer_agent._record_to_insert_params()` (lines 158-203).

Purpose: Fleet-wide consistency — one pattern, zero exceptions. Reviewers audit row construction
without memorizing argument positions.

Output: Three writers with named `_to_row()` helper methods; call sites updated to use them.
</objective>
