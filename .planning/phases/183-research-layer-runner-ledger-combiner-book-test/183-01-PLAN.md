portfolio.py
- `RANK_VOL_NEUTRAL_ARM = "rank_vol_neutral"`
- `trailing_vol(returns: np.ndarray, *, window_rows: int, min_finite: int) -> np.ndarray` [n, m]: sample sd (ddof 1) of each name's finite values over rows (t - window_rows, t], NaN where fewer than `min_finite` finite values or sd <= 0. Uses only rows <= t (causal).
- `rank_vol_neutral_weights(alpha: np.ndarray, *, vol: np.ndarray, direction: float, coverage_floor: int) -> tuple[np.ndarray, np.ndarray]` returns (weights [n, m] with 0 where no position, has_position bool [n]).
- `rank_vol_neutral_returns(alpha, fwd_ret, plan, *, vol, direction, coverage_floor) -> dict[str, np.ndarray]` returns `{RANK_VOL_NEUTRAL_ARM: r}`, r[t] = sum_i w[t, i] * nan_to_num(fwd_ret[t, i]) where has_position, NaN otherwise. Ignores `plan` (may be None). Picklable through functools.partial.

evaluate.py
- `aggregate_sessions(r: np.ndarray, trade: np.ndarray, bars_per_session: int) -> tuple[np.ndarray, np.ndarray]` returns (per-session sums over rows that are in `trade` and finite, NaN for a session with no such row; session_trade bool [S] true when any row of the session is in `trade`).
- `scored_sharpe(r: np.ndarray, trade: np.ndarray, *, periods_per_year: int, bars_per_session: int, session_scoring: bool) -> float`: `annualized_sharpe(r, trade, periods_per_year)` when off; `annualized_sharpe(*aggregate_sessions(r, trade, bars_per_session), SESSIONS_PER_YEAR)` when on.
- `evaluate(..., session_scoring: bool = False)` new keyword-only argument, last in the signature.
- `EvaluationResult.excess_se: np.ndarray | None = None` new trailing field, [J] standard deviation of the stationary-bootstrap Sharpe draws (D-09 standard error).
