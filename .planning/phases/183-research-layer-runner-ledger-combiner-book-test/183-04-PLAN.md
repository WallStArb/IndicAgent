<interfaces>
Contract this plan creates (plans 06 and 08 import exactly these names).

combiner.py
- `@dataclass(frozen=True) class RidgeSpec: window_rows: int; refit_rows: int; penalty: float; embargo: int; min_obs: int` (the runner converts the book spec's sessions to rows; embargo = panel.fwd_span(horizon))
- `def refit_positions(n: int, spec: RidgeSpec) -> np.ndarray`: first refit row p0 = spec.window_rows + spec.embargo - 1 (the first row whose training window, rows < p - embargo + 1, can hold window_rows rows), then every refit_rows rows, all < n
- `def walk_forward_ridge(stack: np.ndarray, target: np.ndarray, spec: RidgeSpec) -> np.ndarray`
  - stack [n, m, K] (float32 or float64 member alphas), target [n, m] (the S1 residual forward return); returns combined [n, m] float64
  - per refit row p: training rows s in [max(0, hi - window_rows), hi) with hi = p - embargo + 1; observations are (s, i) pairs where target[s, i] and every stack[s, i, :] are finite (complete cases, D-22); one coefficient vector pooled across names
  - with c observations, mu = mean of x, cov = second moment minus outer(mu, mu), sd = sqrt(diag(cov)); b = solve(cov / outer(sd, sd) + penalty * I, (sxy / c - mu * sy / c) / sd)
  - prediction rows [p, next refit): combined[t, i] = ((stack[t, i] - mu) / sd) @ b, NaN where any member is NaN (no fill, D-22)
  - a fold with c < min_obs, or any sd == 0, or a non-finite solve predicts NaN for its block; rows before the first refit are NaN
  - moments come from per-row prefix sums (count, sum x, sum xx', sum xy, sum y) accumulated in float64 in row chunks, differenced per fold (research code example 2)

power.py
- `def b_max(n_shifts: int, alpha_level: float, budget_m: int) -> int`: the largest integer b >= -1 with (1 + b) / (1 + n_shifts) < alpha_level / budget_m, computed with fractions.Fraction(str(alpha_level)); -1 means no count passes. Equals ceil((alpha/M)(1+K)) - 2 (6 at K = 4461, alpha 0.05, M 30)
- `@dataclass(frozen=True) class ReplicateOutcome: passed: bool; exceedances: int; visited: int; aborted: bool = False`
- `def replicate_passes(s_obs: float, shifts: np.ndarray, shifted_sharpe: Callable[[int], float], bmax: int, rng: np.random.Generator, stop: Callable[[], bool] | None = None, stop_check_every: int = 1) -> ReplicateOutcome`: visit shifts in rng.permutation order, count shifted_sharpe(k) >= s_obs, return passed False as soon as the count exceeds bmax; passed True after the last shift; if `stop` returns True at a check point, return aborted True (not counted by callers)
- `@dataclass(frozen=True) class PowerDecision: powered: bool; passes: int; failures: int; replicates: int; min_power: float; decided_after: int`
- `def curtail(outcomes: Iterable[ReplicateOutcome], *, replicates: int, min_power: float) -> PowerDecision`: consumes outcomes (ignoring aborted ones) until decided: powered when passes >= need, need = ceil(min_power * replicates) computed exactly (Fraction); not powered when failures > replicates - need; raises ValueError if the iterable ends undecided
