synthetic.py
- `@dataclass(frozen=True) class SyntheticSpec: bars_per_session: int; participation_ratio: float; n_common_factors: int; plant_lags_sessions: int`
- `loading_scale_for_pr(n_names: int, n_factors: int, participation_ratio: float) -> float`: s such that the covariance I + s * Q Q' (Q orthonormal m x k) has participation ratio (sum lambda)^2 / sum lambda^2 equal to the target; closed form from the quadratic in (1 + s); ValueError when the target is not attainable (outside [m / (1 + ...), m])
- `generate_residual_panel(spec: SyntheticSpec, finite_mask: np.ndarray, *, plant_coef: float, seed: int) -> tuple[np.ndarray, np.ndarray]` returns (resid_bar [n, m] float64, target [n, m] float64): slot-level residual u[d, j, i] = e[d, j, i] + plant_coef * mean_{k=1..L} u[d-k, j, i] (L = plant_lags_sessions; e = common low-rank component scaled by loading_scale_for_pr plus unit idiosyncratic noise), cross-sectionally demeaned per slot; split into its two bars with an independent split so bar 2j + bar 2j+1 == u exactly; NaN wherever finite_mask is False; target at slot j's placement row (d * bps + 2j - 1, slot 0 on the previous session's last row) equals u[d, j, i], NaN if either bar of the slot is masked, NaN on non-placement rows
- `combo_rank_ic(stack: np.ndarray, target: np.ndarray, *, coverage_floor: int) -> float`: population-best linear combination (pooled OLS of target on the standardized members over all complete-case placement rows, in-sample), then the mean over rows with at least coverage_floor complete names of the cross-sectional Spearman correlation of the combination with the target (D-19)
- `@dataclass(frozen=True) class CalibratedPlant: plant_coef: float; achieved_ic: float; ic_se: float; iterations: int`
- `calibrate_plant(spec, finite_mask, *, members: Sequence[tuple[Callable, dict]], coverage_floor: int, target_ic: float, tolerance: float, n_panels: int, seed: int) -> CalibratedPlant`: bisection on plant_coef with common random numbers (the same n_panels seeds at every step) until |mean combo_rank_ic - target_ic| <= tolerance; raises if not bracketed
- `synthetic_price_panel(spec, *, n_sessions: int, n_names: int, plant_coef: float, seed: int, start: str, missing_fraction: float) -> Panel`: raw returns = market + group + the residual-space panel, converted to open/close/volume, 15-minute UTC timestamps on weekdays from `start`; for the S1 fidelity check and synthetic CLI runs
