- `declared_memory_rows(slot_history_sessions: int, bars_per_session: int, factor_spec: FactorSpec = VINTAGE_1) -> int` = (slot_history_sessions + factor_spec.window_sessions + factor_spec.refit_sessions) * bars_per_session (prereg section 3)

families/intraday_periodicity.py
- `slot_returns(resid_bar_returns: np.ndarray, *, bars_per_session: int) -> np.ndarray` [S, J, m], J = bars_per_session // 2 (bars_per_session must be even): bar 2j plus bar 2j+1 of each session, NaN if either is NaN
- `place_slot_alpha(slot_alpha: np.ndarray, *, bars_per_session: int, n_rows: int) -> np.ndarray` [n, m]: slot j of session d goes to row d * bars_per_session + 2j - 1; slot 0 of session d goes to the previous session's last row (d >= 1; slot 0 of session 0 has no row); every other row NaN. slot_alpha has shape [S + 1, J, m] where index S is the session after the panel (its slot 0 lands on the panel's last row)
- `same_slot_mean(resid_bar_returns, *, bars_per_session: int, coverage_floor: int, window_sessions: int) -> np.ndarray` [n, m]: for slot j of session d, mean of that name's slot j residual returns over sessions d - window_sessions .. d - 1 over finite values, NaN when fewer than (window_sessions + 1) // 2 are finite (ceil(w / 2) in integer arithmetic); placed as above; NaN where resid_bar_returns at the placement row is not finite; then centred_rank with coverage_floor. P1 = window 1, P2 = 5, P3 = 20, P4 = 40
