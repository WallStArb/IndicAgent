A refused serve that displaced the vendor's own value is held (D-191-I); selecting it counts `refused_value_selected`, holding it in canonical counts `refused_value_in_canonical` (with the exception that canonical took the value from a later applied serve: GE 2021-11-05, 19 slots). Verdict: 0 only when canonical equals the selection exactly; 1 for real differences, a refused value in canonical, or canonical labels outside the vendor map (new count); 3 for explained residue. Tests replace the pending-only check.
