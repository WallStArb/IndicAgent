Design:
- Migration 443 widens `ohlcv_load` from "Tradier 1d" to the write record of every canonical writer and
  gives `ohlcv_revision` an `origin` column (spec section 3: one parent for all timeframes, one revision
  table). It seeds `threshold.bar_integrity.max_revision_ratio`, which generalizes
  `infra.tradier.max_changed_bar_ratio` (the old key keeps its reader until 185-38 and is retired by
  185-43).
- The grid stage's old values go to `ohlcv_revision`: a changed or removed derived row with origin
  `load`; a stored vendor row whose value the archive does not hold, at the moment the derived grid
  replaces it, with origin `archive_segment` (the old value of the market_data_ohlcv key). The verify
  becomes a value match: every stored vendor row being removed has an equal archive row or an equal
  revision row from this transaction.
- The grid stage stops deleting and rewriting unchanged segments (spec section 4). Derived rows are
  classified against stored rows by the pure contract; only new and changed rows are written, stale
  derived rows (a slot no longer derived) are removed with their old value recorded.
- Ownership predicates: widening ohlcv_load would make every grid or intraday load row look like a
  Tradier ownership claim to the four readers of `outcome = 'loaded'`. Each gains `AND source =
  'tradier'` in this plan, before any non-Tradier row exists: `_SELECT_DAILY_CHANGED_SINCE_SQL` in
  bar_derivation.py (also imported by the phase 189 fetcher as `_DAILY_SOURCE_PROBE_SQL`, so the fetcher
  inherits the fix without a 189 edit), the loader's `TRADIER_OWNED_SQL` format and its candidate query
  (about lines 108 and 305), and D7's `_tradier_refused` read (about line 894). New writers in this plan
  use outcome `applied` or `refused`, never `loaded`.

New pure contract (this plan):
- `BarValues = tuple[float | None, float | None, float | None, float | None, int | None, str]` (open, high, low, close, volume, source).
- `WriteDelta(new: dict[K, BarValues], changed: dict[K, tuple[BarValues, BarValues]] (new, old), unchanged: int, removed: dict[K, BarValues])`.
- `classify(incoming: Mapping[K, BarValues], stored: Mapping[K, BarValues], *, removal_scope: Collection[K] | None = None) -> WriteDelta`: exact equality, None equals None, NaN never appears (missing is None). `removed` is computed only for stored keys inside `removal_scope` that are absent from incoming (derivation stages pass their whole output range; an ingress chunk passes None because a missing bar in an answer is not a deletion).
- `revision_ratio(delta, n_stored: int) -> float` = (len(changed) + len(removed)) / n_stored, 0.0 when n_stored is 0.
- `should_refuse(delta, n_stored, max_ratio: float, *, min_stored: int, waived: bool) -> bool`: False when waived or n_stored < min_stored.
