<interfaces>
Schema this plan creates (plans 03, 09, 13, 14, 15, 17, 19, 20, 21, 22, 24 are written against these names):

ohlcv_request (plain table, append-only):
- request_id uuid PRIMARY KEY (generated by the provider, uuid4)
- fetch_run_id uuid NOT NULL (one per job invocation; TRADES and ADJUSTED_LAST pair only within one run)
- symbol text NOT NULL REFERENCES instruments(symbol) ON DELETE RESTRICT
- timeframe text NOT NULL
- source text NOT NULL CHECK (source IN ('ibkr'))
- route text NOT NULL CHECK (route ~ '^[A-Z_]{2,16}$')   -- 'SMART' or a venue code ('NYSE','ARCA','ISLAND','AMEX','BATS'); 'LEGACY_IMPORT' for rows imported from market_data_ohlcv
- what_to_show text NOT NULL CHECK (what_to_show IN ('TRADES','ADJUSTED_LAST'))
- primary_exchange text NULL (qualified contract's primaryExchange at request time)
- window_start timestamptz NULL, window_end timestamptz NOT NULL
- ib_req_id integer NULL
- outcome text NOT NULL CHECK (outcome IN ('bars','no_data','timeout','failed','legacy_import'))
- error_code integer NULL, error_text text NULL
- n_bars integer NOT NULL CHECK (n_bars >= 0)
- client_id integer NULL, caller text NOT NULL (job name, e.g. 'historical-pipeline', 'venue-study')
- requested_at timestamptz NOT NULL, answered_at timestamptz NOT NULL
- indexes: (symbol, timeframe, route, what_to_show, answered_at DESC); (fetch_run_id)

ohlcv_observation (plain table, append-only):
- request_id uuid NOT NULL REFERENCES ohlcv_request(request_id) ON DELETE RESTRICT
- symbol text NOT NULL, timeframe text NOT NULL CHECK (timeframe = '1d'), bar_date date NOT NULL
- open, high, low, close double precision NOT NULL (finite CHECK like dividend_events_finite)
- volume bigint NULL
- source text NOT NULL, route text NOT NULL, what_to_show text NOT NULL (denormalized from the request per D-05)
- fetched_at timestamptz NOT NULL
- PRIMARY KEY (request_id, bar_date)
- index (symbol, bar_date, route, what_to_show, fetched_at DESC)

View ohlcv_venue_head: per (symbol, route) with route <> 'SMART' and route <> 'LEGACY_IMPORT' and what_to_show = 'TRADES': first_bar_date, last_bar_date, n_bars, plus smart_head_date = min(bar_date) over SMART TRADES observations for the symbol (NULL if none), and a boolean pre_move = last_bar_date < smart_head_date or smart_head_date IS NULL.

Roles: ohlcv_observation_writer NOLOGIN, bar_derivation_writer NOLOGIN (created with IF NOT EXISTS guards; later migrations re-guard before granting).

APR seeds (infra.*, [initial_estimate]): infra.bar_campaign.client_ids json [47,48,49] (46 and 40 belong to the todo 449 chain, 45 to the nightly; D-30); infra.ibkr_history_lease.nightly_wait_minutes int 60 (a bulk holder yields within one (symbol, tf) unit, about 18 minutes worst case; D-29); infra.ibkr_history_lease.priority_wait_minutes int 240; infra.ohlcv_observation.copy_batch_rows int 50000.

Writer module API (services/ohlcv_observation_writer.py):
- `def new_fetch_run_id() -> str` (uuid4 string)
- `class ObservationSink` (sync, psycopg 3): `__init__(self, conn, *, caller: str)`; `on_request(self, record: RequestRecord) -> None` and `on_observation(self, record: RequestRecord, bars: list[OHLCVBar]) -> None` buffer in memory; `flush(self) -> tuple[int, int]` writes buffered requests then observations with `cursor.copy(... FROM STDIN)` and `copy.write_row` inside one transaction that begins with `SET LOCAL ROLE ohlcv_observation_writer`, clears buffers, returns (n_requests, n_observations); `pending(self) -> int`.
- `class AsyncObservationSink` (asyncpg): same methods, `async def flush(self, conn)` using `conn.copy_records_to_table`.
- `RequestRecord` and `OHLCVBar` come from `src/providers/base.py` (RequestRecord is added by plan 03; this plan imports it under `TYPE_CHECKING` and duck-types attribute access so plans 02 and 03 run in parallel; field names below are the contract):
  RequestRecord fields: request_id: str, fetch_run_id: str, symbol: str, timeframe: str, route: str, what_to_show: str, primary_exchange: str | None, window_start: datetime | None, window_end: datetime, ib_req_id: int | None, outcome: str, error_code: int | None, error_text: str | None, n_bars: int, client_id: int | None, requested_at: datetime, answered_at: datetime.
- bar_date for an observation = the bar's timestamp converted to its UTC date (1d bars are stamped 00:00 UTC in this repo).
