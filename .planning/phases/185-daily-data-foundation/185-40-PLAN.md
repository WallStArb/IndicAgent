<objective>
The intraday half of the computed integrity report (`docs/plans/2026-10-06-data-layer-integrity-design.md`
sections 5 and 6, step 4; owner-approved 2026-10-06). 185-33 built the verdict writer and the 1d checks;
this plan adds the five intraday checks to the same writer, so 189-10's pilot and the 5m backfill are
judged by the same rows the gates read (185-41).

Rules:
- slot_coverage: expected slots come from the NYSE calendar with half days and DST
  (src/intelligence/bars/sessions.py) over regular trading hours from the name's first 5m bar; answered
  means a stored real bar, a stored zero-volume provider bar, or a slot inside a window an `ohlcv_request`
  answered `bars` or `no_data` for. Per calendar year, the verdict fails if any year is below the floor;
  metric_value is the worst year.
- grid_parity: derived 15m and 1h rows against archived vendor rows bucket by bucket on the archive's
  keys; 15m must match exactly on every shared bucket; 1h compared on matching buckets only (the vendor's
  1h grid lacks the 09:30 half hour on 39 of 231 measured names). Names with no archive rows pass with
  metric_value NULL and the detail says so.
- stray_vendor_rows: rows with timeframe 15m or 1h and source not derived_5m in market_data_ohlcv; zero.
  The spec scopes this check to the 186 gate only; it is still written per name.
- coverage_cache: the rebuild's docstring requires the fetcher lock, so D7 calls the fetcher lock's
  non-blocking acquire (`scripts/infrastructure/backfill/_fetcher_lock.py`, read-only import, holder
  `bar-reconciliation-audit`); if it is held, the check is skipped for this run and the skip is counted
  in the run summary. With the lock, `rebuild_from_stored_state` (services/ohlcv_coverage_writer.py,
  phase 189, not edited) runs inside a transaction that is always rolled back, its result is read
  before the rollback and compared column by column (excluding last_fetched_at and
  consecutive_failures) to the committed rows; zero drift. The lock is released in a finally block.

Migration 450 (re-check free, apply and commit together) seeds
`threshold.bar_integrity.slot_coverage_min_intraday` 0.995 (`[rca_analysis]`, measured 2007-2023 level
0.996) and `infra.bar_integrity.intraday_full_sweep_days` 7 (`[conventional]`, the spec's weekly
sweep), both read by D7 at init.

Pure arithmetic in src/intelligence/bars/integrity_checks.py; D7 does IO, symbol by symbol. Metric
labels stay check-only. Unit tests use fakes (todo 494). No em dashes; no AI attribution.
