<objective>
Wire D1 capture into the historical backfill, and serialize every IBKR historical fetch through
one lease so the todo 449 chain, the nightly and the phase 185 campaigns share the single stream
IBKR actually serves (D-29) instead of contending for it or skipping.

Why a lease and not the old tools: todo 449 measured that concurrent history streams add no
throughput and mostly time out, so a pilot that "passes" under contention proves nothing, and the
nightly's `pgrep` skip turns every long backfill into days of silently stale daily bars. An
advisory lock is released by the server when its process dies (no stale lease to clean up), and
PostgreSQL grants queued lock requests in arrival order, so a waiter behind a yielding bulk
holder gets the stream next.

Discipline: the running todo 449 chain belongs to another lane; editing the pipeline does not
affect its already-running process, which only picks up the lease on its next attempt (task 4).
This file is not an ic_engine import. No em dashes; no AI attribution; `except ... as error`.
</objective>

Contract (Ring 0, no domain vocabulary; plans 13, 14, 15, 20, 22 use it through the pipeline or directly):
- `class Tier(StrEnum)`: BULK = "bulk", PRIORITY = "priority"
- `class LeaseTimeout(RuntimeError)`
- `class ResourceLease` constructed with `(dsn: str, name: str, *, tier: Tier, holder: str)`; the lock key is a stable 64-bit hash of `name` (for example the first 8 bytes of sha256, signed), never Python's `hash()`. It opens its own connection with `application_name = "lease:<name>:<tier>:<holder>"`.
  - `acquire(timeout_s: float | None) -> None`: blocking `pg_advisory_lock` with a statement timeout; raises LeaseTimeout.
  - `waiters() -> list[str]`: tiers of sessions waiting on this key (`pg_locks` where locktype = 'advisory', not granted, same key, joined to `pg_stat_activity.application_name`).
  - `checkpoint() -> bool`: call at a safe unit boundary. BULK: if any waiter exists, unlock, then re-acquire (it queues behind the waiter) and return True. PRIORITY: same, but only when a PRIORITY waiter exists. Also verifies the lease is still held (`pg_locks` granted for its own backend pid) and re-acquires if the connection was lost, logging it.
  - `release()`, and context-manager support.
- Lease name constant `IBKR_HISTORY_LEASE = "ibkr_history_stream"` lives beside the provider (for example `src/providers/ibkr_lease.py` or the pipeline), not in Ring 0.
- `scripts/ops/bars/_campaign.py`: `class CampaignRefused(RuntimeError)`; `preflight(*, client_id: int, apr: Mapping[str, Any]) -> None` raises on a client id outside `infra.bar_campaign.client_ids`. Pilots, blackout windows and pacing-error counting are deleted from the design.
- Pipeline CLI gains `--lease-tier {bulk,priority}` (default bulk). The nightly and every phase 185 campaign pass `priority`.
