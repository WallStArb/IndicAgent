<objective>
Owner requirement relayed 2026-10-06: eliminate complexity debt with mechanisms, not a promise. This plan
runs in the first wave of the data layer integrity work, before any change lands, so the numbers exist
first. It measures the baseline and adds three CI guards that stop the debt returning; 185-43 (the final
cleanup) reruns the same census and must show each count down or explained.

Census definitions (the script implements exactly these, and the baseline file states them):
- scripts: `*.py` and `*.sh` files under scripts/ (total) and under scripts/ops/ (subtotal), excluding
  `__init__.py` and `__pycache__`.
- TEMPORARY entries: allow-list entries whose reason contains "TEMPORARY" in tests/unit/test_*boundary*.py
  and tests/unit/test_*_registry.py.
- tables in public: `select count(*) from information_schema.tables where table_schema = 'public' and
  table_type = 'BASE TABLE'`, plus views separately.
- APR keys with no reader: config_state keys whose literal (or the prefix before a `.{tf}` style suffix
  built in code, resolved by the registry's own naming rule) does not appear in services/, src/ or
  scripts/ (ConfigService reads by literal key; migrations and tests do not count as readers).
- services with no live consumer: `_DAG_ORDER` units (services/service_auditor.py) whose systemd unit is
  failed, missing, or inactive without being a oneshot or timer-driven unit (`systemctl show -p
  Type,ActiveState,LoadState`), plus units documented as archived or dormant in CLAUDE.md.
- todos in pending: files in .planning/todos/pending/.
- docs with stale Status lines: files under docs/ (excluding docs/research and dated docs/plans whose
  Status is implemented, superseded or archived) whose Status line is proposed, draft or in progress and
  whose last git change is older than 30 days, or whose Status names a plan or phase whose SUMMARY says
  it is complete.

Guards (CI-clean: filesystem only, no database, except where stated):
1. test_temporary_allow_list_expiry.py: every TEMPORARY reason names its retirement as a plan id
   (`retire: 185-42`) or a todo (`retire: todo 489`); the test fails when that plan's SUMMARY exists or
   the todo is in completed/, and when a TEMPORARY reason names nothing, unless the entry is in the
   frozen list of entries that existed on 2026-10-06 (the list may only shrink: an entry in it that no
   longer exists fails as stale).
2. test_single_writer_registry.py: a registry mapping each canonical table to its writer modules,
   one per table, or one per declared disjoint segment (timeframe set) with the segment named; tables
   that already have a dedicated boundary test (market_data_ohlcv, ohlcv_intraday_raw_archive,
   ohlcv_coverage, canonical_bar_lineage and bar_content_digest, ohlcv_load and ohlcv_revision after
   185-31) are registered as covered by that file, and the test asserts the file exists and holds the
   table's name; the rest (ohlcv_observation, ohlcv_request, bar_quality_flag, corporate_action,
   listing_venue, ohlcv_empty_history, bar_derivation_batch, integrity_monitor, bar_source_policy after
   185-36) are scanned here for INSERT, UPDATE, DELETE and COPY outside their registered writers. A
   canonical table with no registry entry fails.
3. test_table_and_apr_key_readers.py: derives the table set (CREATE TABLE minus DROP TABLE) and the APR
   key set (config_schema inserts minus deletes) from production/migrations/ by parsing, then greps
   services/, src/ and scripts/ for a reader of each; fails on a reader-less name unless it is in the
   frozen 2026-10-06 list (shrink-only, stale entries fail) or in a reasoned keep list (raw market data
   tables kept by rule, e.g. the vendor archive used only by parity checks, written but read by D7).

Adds without removing: one script and three tests. Justification: they are the mechanism the owner asked
for; the census replaces ad hoc counting in every later cleanup, and the guards replace review-time
vigilance. The census script is listed in its own baseline.

Read-only against the live database (the census). No em dashes; no AI attribution.
</objective>
