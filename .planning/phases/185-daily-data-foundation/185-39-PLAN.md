<revision date="2026-10-06" source="plan check (6 BLOCK, 13 FLAG); owner calls relayed by the coordinator">
Named deviation from spec section 4 ("digests in the same transaction as the bar change"): the
5m month digests are written by the grid stage after the fetch run (the fetcher's run-end grid stage
digests 5m, 15m and 1h months it touched), not inside each ingress chunk's transaction. Rationale: a
month digest needs the whole month, which a 150-day chunk rarely holds alone, and the grid stage
already recomputes those months on the same run; the per-request content digest added here is the
in-transaction record of what each answer stored. 185-40's digest_fresh verdict catches any month the
grid stage missed. The SUMMARY records this deviation.
UPDATE boundary: resolved with ON CONFLICT DO UPDATE on the changed set; no allow-list entry.
Tail-window refusal: resolved by the min-stored floor seeded in 185-31.
</revision>
