<objective>
Add GARCH/Kalman I4 field groups to the drill panel's I4 Context section, and add BSL/SSL detail + premium/discount fields to the Smart Money section.

Purpose: GARCH sigma, vol_ratio, shock and Kalman slope/position/uncertainty are computed every bar by the pipeline but never shown. BSL/SSL touches/significance and price_in_premium/equilibrium_level similarly missing from UI.

Renaissance framing: The UI should be a passive consumer of pipeline decisions — it must never make its own threshold calls. GARCH regime is already classified by the pipeline as 0/1/2 (low/normal/high). The UI styles on that classification directly. Adding a hardcoded `garch_shock > 2.0` UI threshold would be fragile and wrong: if the pipeline's distribution or scaling changes, the UI threshold silently diverges. Use what the pipeline computes. The regime label is the signal; the raw number is context.

Output: Extended ContextData type, mapped in parseIntelligence(), rendered with conditional amber styling on high regime.
</objective>
