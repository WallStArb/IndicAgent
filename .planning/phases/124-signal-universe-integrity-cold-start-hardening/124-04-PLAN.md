<threat_model>
**ASVS Level 1 Threat Model for PatternCompletion Rewrite**

High severity threats:
1. **Instance ID collision (MEDIUM):** If structural anchor rounding (4 decimal places) causes collision between distinct patterns, false deduplication occurs. MITIGATION: Pattern name included in instance_id; anchor rounding precision per existing pattern; tolerance band NOT needed for neckline (exact price level).
2. **State corruption (MEDIUM):** If _instances not isolated per (symbol, tf), cross-symbol contamination. MITIGATION: instance_id includes symbol and tf; factory lazy init.
3. **Infinite fired_bars (LOW):** If fired_bars never resets, same pattern level re-swept prevents new fire. MITIGATION: deduplicate_event has min_bars_between_fires default (handles re-sweeps of same level).

Opt-out: None - structural rewrite is mandatory for QUALITY-01.
</threat_model>
