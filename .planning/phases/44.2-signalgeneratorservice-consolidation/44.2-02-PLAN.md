    **Phase 4: Add _drain_audit_queue() method**

    ```python
    async def _drain_audit_queue(self) -> None:
        """Background task: drain audit payloads to Kafka pipeline.* topics."""
        while not self._shutdown_event.is_set():
            try:
                payload = await asyncio.wait_for(self._audit_queue.get(), timeout=1.0)
                await self._kafka_producer.publish(payload["topic"], payload["data"])
            except TimeoutError:
                continue
            except asyncio.CancelledError:
                break
            except Exception as e:
                self.logger.warning("audit_drain_error", error=str(e))
    ```

    Start this task in `run()` alongside other background tasks:
    ```python
    asyncio.create_task(self._drain_audit_queue())
    ```

    **Phase 5: Add _queue_stage_audits() method**

    ```python
    async def _queue_stage_audits(self, payloads: list[dict]) -> None:
        for p in payloads:
            try:
                self._audit_queue.put_nowait(p)
            except asyncio.QueueFull:
                _AUDIT_DROPS.inc()
    ```

    **Phase 6: Create new _process_event() method**

    This replaces the DAG dispatch section of `_process_bar()`. The new method:

    1. Receives the already-computed `raw_signals` list (from `_run_setup_plugins()` / `_run_i7_plugins()`)
    2. Captures `raw_confidence` for each signal BEFORE pipeline runs (for RankedSignal.raw_confidence)
    3. Extracts thresholds from IntelligenceEvent: `thresholds = {"hurst_quality": event.i4.get("hurst_trend_quality", 1.0), "entropy_quality": event.i4.get("entropy_quality", 1.0), "drift_penalty": ...}` — note: drift_penalty comes from wherever `_dag_meta` previously injected it; check the existing `_process_bar()` code to find the extraction point
    4. Extracts regime_data from `self._regime_cache` using `_REGIME_AUTHORITY_TF` (existing pattern)
    5. Computes `hour_et` from event timestamp converted to ET
    6. Calls all 6 pure functions in sequence:
       ```python
       quality_gated = apply_quality_gate(raw_signals, thresholds)
       regime_gated = apply_regime_gate(quality_gated, regime_data)
       tod_adjusted = apply_tod_adjustment(regime_gated, self._tod_multipliers, tf, hour_et)
       calibrated = apply_calibration(tod_adjusted, self._calibration_curves, tf)
       ranked = rank_signals(calibrated, self._perf_weights, tf)
       winner, all_ranked, resolution_method = select_winner(ranked, self._cis_scorer, features)
       ```
    7. Increments `_PIPELINE_STAGE_INPUT`/`_PIPELINE_STAGE_OUTPUT` per stage with correct counts
    8. Queues audit payloads (using existing `topic_quality_gated()` etc. functions for topic names)
    9. Writes winner to signal_ledger (moved from `_consume_winner_signals()`):
       ```python
       ledger_written = False
       if winner and self._cooldown_clear(symbol, tf):
           try:
               await self._write_signal_ledger(event, winner)
               ledger_written = True
               self._update_cooldown(symbol, tf)
           except Exception as e:
               self.logger.error("signal_ledger_write_failed", error=str(e))
               _LEDGER_WRITE_FAILURES.inc()
       ```
    10. Builds and publishes BarIntelligenceRecord:
        ```python
        record = BarIntelligenceRecord(
            intelligence=event,
            ranked_signals=[self._to_ranked_signal(s, winner) for s in all_ranked],
            winner_plugin=winner.get("setup_plugin") if winner else None,
            winner_confidence=winner.get("calibrated_confidence") or winner.get("confidence") if winner else None,
            winner_direction=str(winner.get("direction")) if winner else None,
            signals_evaluated=len(raw_signals),
            signals_after_quality=len(quality_gated),
            signals_after_regime=len([s for s in regime_gated if s.get("regime_eligible", True)]),
            signals_after_tod=len(tod_adjusted),
            signals_after_calibration=len(calibrated),
            ledger_written=ledger_written,
            session_type=getattr(event, "session_type", "rth"),
            days_to_expiry=None,
            i7_computed_at=datetime.now(UTC),
            pipeline_latency_ms=...,  # compute from event timestamp
        )
        await self._kafka_producer.publish(
            topic_intelligence_record(self._env),
            record.model_dump_json(),
        )
        ```
    11. Publishes backward-compat `development.intelligence.i7` (existing scorecard publish)
    12. Publishes `development.signals.aggregated` if winner (existing pattern)
