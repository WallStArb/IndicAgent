3. Create `src/intelligence/cross_asset_features.py` — pure-function module (no Kafka, no DB):
```python
from __future__ import annotations
import math
from collections import deque
from datetime import datetime

_EQ_INDEX_BASES = frozenset({"ES", "NQ", "RTY", "YM"})
_SHORT_WINDOW = 5    # bars for return computation
_Z_SCORE_WINDOW = 20 # bars for z-score baseline
_Z_CLAMP = 10.0
_LOW_VOL_THRESHOLD = 1e-8

def compute_eq_index_features(
    close_windows: dict[str, deque[float]],
    vol_windows: dict[str, deque[float]],
    tf: str,
    ts: datetime,
    window_bars: int = 20,
) -> dict[str, object]:
    ...
```

Algorithm:
- Check all 4 symbols have >= window_bars data; return `{"ready": False}` if not
- Compute 5-bar log returns per symbol: `ln(close[-1] / close[-6])` (use math.log)
- Compute spread: `return_ES - return_NQ` and `return_ES - return_RTY`
- Z-score each spread over last window_bars spread values using deque-based rolling mean/std
- For z-score: maintain internal spread deques as part of the computation; the caller should pass close/vol deques that already have full history
- Actually, the function should accept pre-built spread_history deques OR compute z-score from the close_windows directly. Simplest: compute returns from last window_bars closes, compute spread series, z-score the latest value against the series
- `eq_corr_break`: compute 5-bar and 20-bar pairwise Pearson correlation of all 4 returns, take abs diff
- `eq_vol_imbalance`: (ES_vol/mean(ES_vol_window)) / (NQ_vol/mean(NQ_vol_window)); guard div-by-zero
- All float outputs wrapped in `float()` to avoid numpy types
- Clamp z-scores to (-_Z_CLAMP, _Z_CLAMP)
- Set `low_vol_flag=True` when either spread's rolling std < _LOW_VOL_THRESHOLD

Return dict shape:
```python
{
    "ready": True,
    "ts": ts.isoformat() + "Z",
    "tf": tf,
    "group": "EQ_INDEX",
    "es_nq_spread_z": float,
    "es_rty_spread_z": float,
    "eq_corr_break": float,
    "eq_vol_imbalance": float,
    "active_pair": "ES_NQ" | "ES_RTY",
    "pairs_confirming": int (0, 1, or 2),
    "data_quality_score": float (0-1),
    "low_vol_flag": bool,
}
```

Create `services/cross_asset_service.py` following the signal_generator_service.py lifecycle pattern:

```python
class CrossAssetService:
    def __init__(self):
        self.running = False
        self.shutdown_requested = False
        settings = Settings()
        self.env_name = settings.env_name or ""
        self._cross_asset_enabled = settings.cross_asset_enabled
        self._window_bars = settings.cross_asset_window_bars
        self._metrics_port = settings.cross_asset_metrics_port
        self._kafka_bootstrap = settings.kafka_bootstrap_servers
        self._database_url = settings.database_url

        # Rolling windows keyed by "BASE:tf" (e.g. "ES:1m")
        self._close_windows: dict[str, deque] = defaultdict(lambda: deque(maxlen=self._window_bars + _SHORT_WINDOW))
        self._vol_windows: dict[str, deque] = defaultdict(lambda: deque(maxlen=self._window_bars + _SHORT_WINDOW))

        # Staleness tracking: last bar timestamp per "BASE:tf"
        self._last_bar_ts: dict[str, datetime] = {}

        # Dedup: last published timestamp per tf
        self._last_published_ts: dict[str, datetime] = {}

        # Group config (extensible for future groups)
        self._groups = CROSS_ASSET_GROUPS

        setup_service_logging("logs/cross_asset_service.log")
        self.logger = structlog.get_logger("cross_asset_service")
```

Key implementation details:
- `CROSS_ASSET_GROUPS = {"EQ_INDEX": frozenset({"ES", "NQ", "RTY", "YM"})}`
- `_TF_INTERVAL_SECONDS = {"1m": 60, "5m": 300, "15m": 900, "1h": 3600}`
- Consumer: `KafkaConsumerClient(topic_intelligence(env_name), group_id="cross_asset_group", auto_offset_reset="latest")`
- Producer: `KafkaProducerClient(bootstrap_servers=...)`
- `_extract_base_symbol(symbol)`: strip trailing expiry chars. Use the pattern: iterate from end, strip digits and uppercase letters that are IBKR month codes. Simplest: `for base in _EQ_INDEX_BASES: if symbol.startswith(base): return base; return None`
- `_process_intelligence_message(payload)`: parse with IntelligenceEvent.model_validate_json, extract base_symbol, skip if not in any group, append close/volume to deques, update _last_bar_ts, check if all group members have sufficient data, check staleness, check dedup, call compute_eq_index_features, publish result
- `_seed_from_db()`: async startup method using DatabaseManager to query last window_bars rows from intelligence_features per (symbol, tf) for each group member. Use `SELECT close, volume, computed_at FROM intelligence_features WHERE symbol=$1 AND timeframe=$2 ORDER BY computed_at DESC LIMIT $3`. Fallback: log warning, continue
- `_is_group_stale(group_name, tf, now)`: check each member's _last_bar_ts; if any member has gap > TF interval, return True. Compute data_quality_score = count of fresh members / total members
- Signal handlers: SIGINT/SIGTERM set shutdown_requested=True
- Metrics: `cross_asset_messages_processed` counter, `cross_asset_spreads_published` counter, `cross_asset_data_quality` gauge
- `start_metrics_server(port=self._metrics_port)` in __init__
- Main block: `if __name__ == "__main__": asyncio.run(CrossAssetService().start())`
