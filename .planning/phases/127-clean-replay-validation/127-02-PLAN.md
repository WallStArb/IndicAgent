<critical_corrections>
1. **NO WELCH'S T-TEST. NO CROSS-POPULATION PNL_R COMPARISON.** ROADMAP SC-04 explicitly forbids it. The before (pre-replay, whatever volume) and after (post-clean-replay, ~4M) populations are NOT exchangeable. Do NOT implement `_welch_t_test`. Do NOT report `pnl_t_stat` or `pnl_p_value` columns. Any before/after pnl_r comparison via t-test is a methodology violation. If you find yourself computing `se_sq_sum = (after_std**2/after_n) + (before_std**2/before_n)`, STOP — that is the forbidden statistic.

2. **Methodology is DIFFERENT from the 121-02 spec.** The 121-02 plan included Welch's t-test (Subsection B). Phase 127 REMOVES it entirely and REPLACES with a null-distribution / firing-rate validation. The correct measures per ROADMAP SC-04: signal volume delta, CTF as feature (coverage), firing rates (per-setup selection rates vs < 3% target), bootstrap 95% CI on calibration correlation (this stays — it's same-setup resampled, valid), null distribution (plugins firing at expected rates).

3. **3-TABLE SCHEMA ONLY.** No signal_outcomes, no signal_ledger_full, no signal_type/bucket_scores/staleness_score. Use signal_ledger (JOIN view, renamed in Phase 130) for legacy-compat queries; use signal_events/trade_frames/trade_executions directly for new metrics.

4. **counterfactual_pnl_r is NULL in Phase 127.** For shadow-setup calibration pairs, use actual_pnl_r from trade_executions (per 127-RESEARCH.md Issue 4). Note "counterfactual_pnl_r populated in v2.11" in the report. The bootstrap CI gate (n >= 30) applies to actual_pnl_r non-null count.

5. **CTF = context_features coverage.** "CTF as feature" (ROADMAP) is operationalized as context_features JSONB not-null/not-empty coverage on the non-cold-start subset (> 99% target, SC-02). Do NOT invent a separate CTF metric.
</critical_corrections>

    - Fetch raw pairs for the setup. Shadow: `(raw_confidence, (actual_pnl_r > 0)::int)`. Non-shadow: `(raw_confidence, was_selected::int)`.
    - Gate: require non-null pair count >= 30 (the `n >= 30` Renaissance sample gate). If < 30, return (None, None) and flag "n<30".
    - Bootstrap: sample with replacement n_boot times, compute `np.corrcoef(sample[:,0], sample[:,1])[0,1]` each iteration. 95% CI = [np.percentile(boot_corrs, 2.5), np.percentile(boot_corrs, 97.5)].
    - Populate calib_ci_lo, calib_ci_hi columns.

    - delta_pct = (after - before) / before * 100 (signals_before/snr_before come from the loaded JSON, matched on setup_plugin+is_shadow)
