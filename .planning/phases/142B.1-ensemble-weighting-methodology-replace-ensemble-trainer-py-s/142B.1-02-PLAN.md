Define and implement the pure-math contracts for E1 (empirical-Bayes IC shrinkage) and E2 (mean-variance Σ⁻¹·IC combination) as standalone, DB-free, unit-tested functions. This is the interface-definition plan: Plans 03 (E1 wiring) and 04 (E2 wiring) consume these exact signatures. Purpose: Both formulas are textbook-standard (James-Stein / empirical-Bayes shrinkage; Grinold-Kahn `w ∝ Σ⁻¹·IC`) but have three correctness traps that must be baked into the code and locked by tests: (1) degenerate `n_eff <= 0` must return the prior, not NaN/raise (Pitfall 1); (2) the peer-group prior must be leave-one-out to avoid self-contamination, which is NOT immaterial at n=3 for the `cross_tf`/`macro` groups (Pitfall 2, D-06); (3) the Σ⁻¹·IC solve must be gated on condition number and use `solve` not `inv` (Pitfall 3, D-08, Assumption A3).

Output: `shrinkage.py` (new), `mean_variance_weights()` added to `weights.py`, two unit test files.
</objective>

Core shrinkage function (RESEARCH Pattern 1 draft — implement as specified):
  shrink_ic(ic_raw: float, n_eff: float, ic_prior: float, k: float) -> tuple[float, float]
    returns (ic_shrunk, shrinkage_weight)
    w = n_eff / (n_eff + k); ic_shrunk = w*ic_raw + (1-w)*ic_prior
    n_eff <= 0 -> return (ic_prior, 0.0)   # degenerate guard, no divide-by-zero

Leave-one-out group prior (NEW — no existing analog; write fresh in same pure style):
  leave_one_out_group_prior(group_ic_values: np.ndarray, self_index: int) -> float
    prior = (sum(group) - group[self_index]) / (n_group - 1)
    n_group == 1 -> caller must handle (single-member group has no peer prior)

Mean-variance combination (RESEARCH Pattern 2 draft — implement as specified):
  mean_variance_weights(cov_matrix: np.ndarray, ic_shrunk: np.ndarray, condition_max: float) -> tuple[np.ndarray | None, float]
    cond = float(np.linalg.cond(cov_matrix))   # 2-norm (np default), per Assumption A3
    if not finite(cond) or cond > condition_max: return (None, cond)   # caller falls back
    raw = np.linalg.solve(cov_matrix, ic_shrunk)   # solve, NEVER np.linalg.inv
    normalize by sum(|raw|); total < 1e-10 -> return (zeros, cond)
    returns RAW (uncapped, unsigned) weights — cap/sign applied later by caller (D-08)

weights.py module conventions (weights.py:1-16): "Pure functions only — no DB imports, no Kafka imports."
APR-backed thresholds are passed as function args, never read via ConfigService inside these modules.
APR-exempt constants allowed: 1e-10 (convergence epsilon), 1.0 (renormalization target).
