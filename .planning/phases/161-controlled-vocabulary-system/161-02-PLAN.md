## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DB → VocabularyService cache | Trusted DB rows loaded once at init; no untrusted input reaches the service |
| process startup → ENUM divergence check | A registry/enum/catalog mismatch is a fail-loud condition (intentional crash) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-161-03 | Tampering | VocabularyService as write path | mitigate | Service is read-only projection (no INSERT/UPDATE/DELETE); never a runtime write gate — enforced by having no write methods (design doc anti-pattern) |
| T-161-04 | Denial of Service | ENUM divergence check crashing startup | accept | Hard crash on divergence is by-design safety; not exercised by any of the six TEXT-backed seeded namespaces |
