  <action>
    RED: Write tests/unit/intelligence/test_gradient_utils.py with parameterized tests for all 8 functions covering boundaries, midpoints, and gradient continuity. Use pytest.mark.parametrize for boundary/midpoint tests. Include a dedicated `test_gradient_continuity_never_binary` test that asserts mid-range inputs produce outputs strictly between 0 and 1.

    GREEN: Create src/intelligence/utils/gradient_utils.py with these 8 functions:

    1. `linear_ramp(x, lo, hi, out_lo=0.0, out_hi=1.0) -> float` -- Piecewise-linear map from [lo, hi] to [out_lo, out_hi], clamped at boundaries. The canonical "distance-from-threshold" gradient. Use `max(out_lo, min(out_hi, ...))` pattern.

    2. `threshold_decay(x, center, width, peak=1.0, floor=0.0) -> float` -- Score that peaks at center and linearly decays to floor over +/-width. Use triangular/tent function: `peak * max(0, 1 - abs(x - center) / width)` clamped to floor. For proximity-to-level scoring.

    3. `sigmoid_score(x, center, steepness=1.0) -> float` -- Standard sigmoid: `1.0 / (1.0 + math.exp(-steepness * (x - center)))`. For RSI extremes, z-score conversions. Import math, not numpy (scalar function).

    4. `z_score_to_score(z, sigma_scale=2.0) -> float` -- Maps absolute z-score to [0, 1]: `min(1.0, max(0.0, abs(z) / sigma_scale))` but using linear_ramp internally: `linear_ramp(abs(z), 0, sigma_scale)`. For vol_spike intensity.

    5. `session_progress(elapsed_frac, start_frac, end_frac) -> float` -- Bell-shaped score: 1.0 at midpoint of [start, end], decays to 0 at edges. Implement as tent function: `position = (elapsed_frac - start_frac) / (end_frac - start_frac)`, then `max(0, 1 - abs(2 * position - 1))`. Returns 0 outside window.

    6. `hmm_regime_weight(features: dict, regime_direction: str) -> float` -- Extract continuous HMM probability. Map "up" -> hmm_prob_trending_up, "down" -> hmm_prob_trending_down, "ranging" -> hmm_prob_ranging. Fallback to 0.5 if key missing. Clamp to [0, 1].

    7. `freshness_decay(touch_count: int, k: float = 0.5) -> float` -- `math.exp(-k * touch_count)`. Exponential decay from 1.0 (fresh) toward 0.0 (stale).

    8. `streak_score(streak_count: int, saturation: int = 5) -> float` -- `min(1.0, streak_count / saturation)`. Linear ramp from 0 to 1 over [0, saturation].

    Design rules:
    - Every function takes scalar inputs, returns scalar float (plugins vectorize if needed)
    - No numpy imports -- pure math module only (these are scalar primitives)
    - Every function has a docstring: one-line summary, parameter explanation, what binary pattern it replaces, example usage
    - Module-level `__all__` exports list
    - Functions are stateless, no side effects

    REFACTOR: Verify streak_score can delegate to linear_ramp. Verify z_score_to_score delegates to linear_ramp. DRY where natural.

  <action>
    Create `tools/scan_binary_patterns.py` -- a standalone script that scans all plugin source files for binary scoring patterns. First: `mkdir -p tools/`.

    Scanner logic:
    1. Walk all `.py` files under `src/intelligence/` (features/, composites/, context/, trading/, confluence/)
    2. Use regex patterns to find:
       - `= 1 if .* else 0` and `= 1.0 if .* else 0.0` (binary assignment)
       - `= 0 if .* else 1` and `= 0.0 if .* else 1.0` (inverted binary)
       - `np.where(.*, 1, 0)` and `np.where(.*, 1.0, 0.0)` (numpy binary)
       - `int(condition)` used as a score (not as a count)
       - `== 1.0` or `== 0.0` equality comparisons on continuous fields (hmm_regime == 1.0)
    3. Apply an allowlist to exclude legitimate patterns:
       - Direction encoders: lines containing `direction`, `_dir`, `_sign`, `signal_type` assignments
       - Crossover event detections: lines containing `cross`, `crossed`
       - Day-of-week flags: `is_monday`, `is_friday`
       - Type/category fields: `fvg_type`, `sweep_type`, `swing_high_type`, `swing_low_type`
       - Existing tested patterns in `utils/common.py` (crossover_detect, threshold_cross)
       - Lines with `# gradient-exempt` comment (escape hatch for future use)
    4. Output: JSON list of violations with file, line number, matched pattern, surrounding context
    5. Exit code: 0 if zero violations, 1 if any found
    6. Support `--verbose` flag for full context output
    7. Support `--baseline` flag that saves current count to `tools/.binary_baseline.json` (for pre-fix snapshot)

    The scanner should be runnable as: `python tools/scan_binary_patterns.py`

    Include a shebang line and make it executable. Add `if __name__ == "__main__"` block with argparse.
