    - `vol_spike`: Replace `1 if z > 2.0 else 0` with `z_score_to_score(z, sigma_scale=3.0)` -- 0 at z=0, 1.0 at z=3.0, continuous in between. Use sigma_scale=3.0 so z=2.0 gives ~0.67 (meaningful but not saturated).
    - `vol_drying`: Replace `1 if volume < vol_sma * 0.5 else 0` with `linear_ramp(vol_sma * 0.5 - volume, 0, vol_sma * 0.5)` -- intensity of drying. When volume is exactly 0.5*sma, score is 0. As volume drops further below, score rises toward 1.
    - `bb_upper_touch`: Replace `1 if abs(close - bb_upper) <= threshold else 0` with `threshold_decay(close, bb_upper, bb_width * 0.15)` -- proximity score that peaks when price is at band and decays.
    - `bb_lower_touch`: Same approach with bb_lower.
    - `bb_walking_upper`: Replace `1 if streak >= 3 else 0` with `streak_score(streak, saturation=5)`.
    - `bb_walking_lower`: Same.

For OS: `sigmoid_score(30 - rsi + 30, 70, 0.15)` (mirror). Or simpler: `max(linear_ramp(rsi, 70, 100), linear_ramp(100 - rsi, 70, 100))` -- distance into extreme zone normalized.
