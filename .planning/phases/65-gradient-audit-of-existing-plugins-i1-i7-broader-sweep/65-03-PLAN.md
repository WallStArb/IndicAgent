<objective>
Add continuous gradient companion fields to I3 structure, SMC context, and I5 pattern plugins. These plugins detect discrete events (BOS, sweep, squeeze) -- the detection stays binary but a continuous strength/quality field is added alongside.

Renaissance design principles:
- **Additive only.** Detection flags (bos_detected, sweep_detected, squeeze_fired) are genuinely discrete events. I7 plugins use them for direction gating. Keep the flag, add a _strength companion. This is the "segment relentlessly" principle -- don't treat all binary outputs the same.
- **Existing partial gradients.** Several plugins already have some gradient companions (fib_cluster_strength, demand_strength, sweep_depth_pct). Don't duplicate -- add only what's missing.
- **Schema registration is the #1 failure mode.** Every new field in plugin.outputs MUST have a matching field in the schema class. Extra='forbid' means startup crash if missed. Register FIRST, modify plugins SECOND.

Output: ~18 new additive fields across 10 plugins, with schema registration and tests.
</objective>
