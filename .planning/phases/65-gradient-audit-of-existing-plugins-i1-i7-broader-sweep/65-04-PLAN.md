```python
def hmm_regime_weight(features: dict, regime_direction: str) -> float:
    """Extract continuous HMM probability for a regime direction.
    regime_direction: "up" | "down" | "ranging"
    Returns: hmm_prob_trending_up for up, hmm_prob_trending_down for down, hmm_prob_ranging for ranging.
    Fallback: 0.5 if key missing.
    """
```

<!-- HMM regime fields available in features dict at I7 compute time -->
From SMC HMMRegime plugin outputs (verified in schemas.py):
- hmm_regime: int (0=ranging, 1=trend_up, 2=trend_down)
- hmm_prob_ranging: float (probability of ranging state)
- hmm_prob_trending_up: float (probability of trend_up state)
- hmm_prob_trending_down: float (probability of trend_down state)

<!-- I7 confidence contract -->
From confidence_utils.py:
- compose_confidence(raw) clamps to [0.10, 0.95]
- All I7 plugins must route final confidence through compose_confidence()

<!-- I7 plugin regime_type attribute -->
- "trend" plugins: use max(hmm_prob_trending_up, hmm_prob_trending_down) as trending probability
