Implement it inside the per-symbol/per-tf compute function, NOT as a global pre-pass:
- When `--recompute` is set, issue exactly one
  `DELETE FROM feature_vectors WHERE symbol = %s AND tf = %s;` for the partition, then run the
  existing compute plus `_batch_insert` loop unchanged.
- Choose a transaction boundary that never leaves the partition permanently short: commit the
  DELETE together with the first insert batch, then continue with the existing per-batch commits.
  Record the chosen boundary in the SUMMARY. Do NOT hold one transaction open across an entire
  multi-million-row partition.

`ProcessPoolExecutor` worker — CLAUDE.md's rule: workers are compute-only, and concurrent writers
