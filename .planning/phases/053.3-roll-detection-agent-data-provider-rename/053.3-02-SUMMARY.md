# Phase 053.3 Plan 02: DataProviderAgent Rename Summary

Provider-agnostic rename of `services/tws_daemon.py` to `services/data_provider_agent.py`, class `TwsDaemon` → `DataProviderAgent`, with full removal of `RollMonitor` coupling from the data provider.

## What Was Built

### Task 1: git mv + class rename + RollMonitor removal

`services/tws_daemon.py` renamed to `services/data_provider_agent.py` via `git mv`. The `TwsDaemon` class was renamed to `DataProviderAgent` throughout. The entire `RollMonitor` class (lines 73-365 in the original) was deleted, including:
- `PAPER_SKIP_CONTRACTS`, `PAPER_ACCOUNT_HOSTS` constants
- All RollMonitor methods: `__init__`, `_is_paper_account`, `should_skip_symbol`, `get_threshold`, `_apply_tod_adjustment`, `update_volume`, `check_roll`, `_on_roll_confirmed`
- The roll detection call site in `_emit_bar()` (update_volume / check_roll / _on_roll_confirmed block)
- `self._roll_monitor = RollMonitor(self.settings)` from `DataProviderAgent.__init__`
- Imports used exclusively by RollMonitor: `derive_roll_chain`, `get_roll_window`, `topic_system_events`, `numpy`
- `_ROLL_MIN_WINDOW` module-level constant

### Task 2: Tests, systemd unit, CLAUDE.md

- `tests/unit/daemons/test_tws_daemon.py`: all imports updated to `DataProviderAgent` from `services.data_provider_agent`; `_roll_monitor` fixture wiring removed; file path references updated
- `services/indicagent-data-provider.service`: new systemd unit created with `ExecStart` pointing directly to `services/data_provider_agent.py --client-id 35`; includes `PYTHONUNBUFFERED=1`, `SyslogIdentifier=indicagent-data-provider`, `LimitNOFILE=65536`

- `production/scripts/pipeline_reset.py`: comment updated from `tws_daemon` to `data_provider_agent`

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Missing `_UNSET` sentinel in `__new__` test fixture**

- **Found during:** Task 2 test run
- **Issue:** `DataProviderAgent.__init__` sets `self._UNSET = object()` as a sentinel for distinguishing "no prev_close" from a 0.0 price. The test helper `_make_rtb_loop_daemon()` uses `__new__` to bypass `__init__`, so `_UNSET` was missing. Tests failed with `AttributeError: 'DataProviderAgent' object has no attribute '_UNSET'`.
- **Fix:** Added `daemon._UNSET = object()` to `_make_rtb_loop_daemon()` fixture, consistent with the CLAUDE.md Service test `__new__` pattern note.
- **Files modified:** `tests/unit/daemons/test_tws_daemon.py`
- **Commit:** a7dc016

These were pre-existing failures (the `production/daemons/` directory was never created). These tests will be addressed in a future plan when the production daemon wrapper is created or removed.
- Pre-existing ruff E501 (line-too-long) errors in `data_provider_agent.py` at lines 240, 399, 403 — these were present in the original `tws_daemon.py` and are out of scope for this rename plan.
