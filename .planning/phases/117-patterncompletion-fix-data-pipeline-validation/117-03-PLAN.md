<objective>
Build `ConfidenceCalibrationMonitor`: a timer-triggered oneshot that measures, per setup_plugin, the correlation between `cis_score` and aggregator selection (`was_selected`), publishing it as an OTel gauge and alerting when a setup's confidence is non-predictive (correlation < 0.3 at N>=100).

Purpose: Make per-setup confidence-formula quality visible in Grafana. The correlation measures aggregator-selection predictiveness (NOT profitability) — `was_selected` is downstream of `cis_score`, so framing must say "confidence not predictive of aggregator selection."
Output: New oneshot service, systemd .service + .timer pair, registry entry, unit test for the alert threshold logic.
</objective>
