# Phase 52.5 Plan 01: Parity Auditor Agent Summary

**One-liner:** Timer-based ParityAuditorAgent using JSONB-recursive row comparison + DB-derived certification against CERTIFICATION_THRESHOLD=12 clean 5-min windows.

## What Was Built

ParityAuditorAgent — an autonomous 5-minute timer agent that earns the right to cut over primary writes by proving 60 consecutive clean minutes of shadow parity. No human judgment required.

### Components Delivered

**`src/core/schemas/parity.py` — FieldViolation model**
- Pydantic model: `ts, symbol, tf, field_name, primary_value, shadow_value, abs_diff`
- `field_name` uses dotted paths for JSONB recursion (e.g. `"i1.sma"`, `"i3.regime_type"`)
- `abs_diff` is `float | None` — numeric only, None for string/None comparisons

**`services/parity_auditor_agent.py` — Agent + pure function**
- `NUMERIC_TOLERANCE = 1e-9`, `CERTIFICATION_THRESHOLD = 12`, `COMPARISON_INTERVAL_SECS = 300`
- `_compare_rows(primary, shadow) -> list[FieldViolation]`: pure function, handles identical rows, numeric tolerance, JSONB recursion, None vs value, string divergence
- `ParityAuditorAgent(BaseAgent)`: 5-min timer loop, `_compare_cycle()`, `_check_certification()`
- Shadow-only rows: `SHADOW_AHEAD_ROWS_TOTAL.inc()` only — never stored as FieldViolation (D-03/D-07)
- Primary-only rows: skipped (shadow hasn't caught up — D-07)
- Certification derived from `fetch_clean_cycles` DB query, not in-memory counters (D-01)
- `SHADOW_PARITY_CERTIFIED` published to `topic_system_events()` when all pairs certified (D-06)

**`src/persistence/repository/parity_repository.py` — ParityRepository**
- `fetch_window(table_name, since, until)`: validates against `_ALLOWED_TABLES` allow-list, returns `list[dict]`
- `insert_violations(violations, run_id)`: `executemany` batch INSERT into `feature_parity_violations`
- `fetch_clean_cycles(symbol, tf, threshold)`: `COUNT(DISTINCT date_trunc)` query — one scan via composite index; returns `threshold - dirty_window_count`
- No `fetch_certification_state` or `update_certification_state` methods (D-09)

**`src/observability/metrics.py` — 4 new parity metrics**
- `PARITY_MATCH_RATE` (Gauge, labels: symbol, tf)
- `SHADOW_AHEAD_ROWS_TOTAL` (Counter, labels: symbol, tf)
- `PARITY_VIOLATIONS_TOTAL` (Counter, labels: symbol, tf)
- `PARITY_CYCLES_TOTAL` (Counter, no labels)

**`production/systemd/indicagent-parity-auditor.service`**
- Port :9120 (D-04/D-08), `RestartSec=10` (appropriate for 5-min timer), `LimitNOFILE=65536`
