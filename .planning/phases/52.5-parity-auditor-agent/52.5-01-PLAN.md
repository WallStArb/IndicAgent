<objective>
Build `ParityAuditorAgent` — a timer-based (5-min) autonomous comparison engine that validates
`feature_snapshots_shadow` against `intelligence_features` per (symbol, tf), stores field-level
violations in `feature_parity_violations`, emits `parity_match_rate` Prometheus metrics per pair,
and self-certifies parity after `CERTIFICATION_THRESHOLD` (12) consecutive clean 5-min windows
by publishing `SHADOW_PARITY_CERTIFIED` to `topic_system_events`.

Purpose: This is the automated gate for primary-write cutover. The auditor earns the right through
proof — 60 consecutive clean minutes, not human judgment. Renaissance principle: instrument everything.

Output: Working `ParityAuditorAgent` service with systemd unit, full test coverage, Prometheus
metrics on :9120.
</objective>

    **Step 2: Implement ParityAuditorAgent** in `services/parity_auditor_agent.py` (add class after existing _compare_rows function):

    Class: `ParityAuditorAgent(BaseAgent)` (per D-05)
    - `__init__(self)`:
      - `super().__init__(name="ParityAuditorAgent")`
      - `setup_service_logging("logs/parity_auditor_agent.log")`
      - `self._settings = Settings()`
      - `self._pool: asyncpg.Pool | None = None`
      - `self._repo: ParityRepository | None = None`
      - `self._producer: AIOKafkaProducer | None = None`
    - `async def _run(self)`:
      - Initialize asyncpg pool: `self._pool = await asyncpg.create_pool(self._settings.database_url)`
      - Initialize ParityRepository with pool
      - Initialize AIOKafkaProducer
      - Start metrics server on port 9120 (per D-04/D-08)
      - Loop: `while not self._stop_event.is_set():`
        - `await self._compare_cycle()`
        - `try: await asyncio.wait_for(self._stop_event.wait(), timeout=COMPARISON_INTERVAL_SECS)` then break
        - `except asyncio.TimeoutError: pass` (continue loop)
    - `async def _compare_cycle(self)`:
      1. `now = datetime.now(UTC)`; `since = now - timedelta(minutes=10)` (per D-02: 2x timer interval)
      2. Fetch primary rows: `self._repo.fetch_window("intelligence_features", since, now)`
      3. Fetch shadow rows: `self._repo.fetch_window("feature_snapshots_shadow", since, now)`
      4. Build lookup dicts keyed by `(ts, symbol, tf)` for both
      5. Identify all keys across both sets
      6. For each key:
         - Primary-only (in primary, not in shadow): **skip** — shadow hasn't caught up (per D-07)
         - Shadow-only (in shadow, not in primary): **increment `SHADOW_AHEAD_ROWS_TOTAL.labels(symbol=sym, tf=tf).inc()`** — NEVER create FieldViolation (per D-03/D-07)
         - Both present: call `_compare_rows(primary_row, shadow_row)` -> violations
      7. Collect all violations; if any: `self._repo.insert_violations(violations, run_id)`
      8. Per (symbol, tf): compute match_rate = matched_clean / total_matched; set `PARITY_MATCH_RATE.labels(symbol=sym, tf=tf).set(match_rate)`
      9. Increment `PARITY_CYCLES_TOTAL.inc()`
      10. Increment `PARITY_VIOLATIONS_TOTAL.labels(symbol=sym, tf=tf).inc(len(violations))` per pair
      11. Check certification: for each active (symbol, tf), call `self._repo.fetch_clean_cycles(symbol, tf, CERTIFICATION_THRESHOLD * 5)` (per D-01)
      12. If ALL pairs have clean_cycles >= CERTIFICATION_THRESHOLD: publish `SHADOW_PARITY_CERTIFIED` to `topic_system_events(self._settings.env_name)` (per D-06)
      13. Log cycle summary via structlog
    - `async def stop(self)`:
      - Close producer, pool
      - `await super().stop()`
