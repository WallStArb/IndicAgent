    **Transformation 1 — Replace `_no_signal()` (all 28 plugins, per D-04):**
    - Remove the `@staticmethod def _no_signal()` method definition from the class
    - Add `from .plugin_utils import no_signal` to imports
    - Replace all `self._no_signal()` and `cls._no_signal()` calls with `no_signal()`
    - Also replace `return {"signal_type": "none", ...}` inline returns with `return no_signal()`

    **Transformation 2 — Replace OHLCV extraction (all 28 plugins, per D-04):**
    - Add `from .plugin_utils import extract_ohlcv` to the existing plugin_utils import line
    - Replace the 3-line block:
      ```python
      df = frames.get("main")
      if df is None or len(df) < self.min_lookback:
          return self._no_signal()
      close = df["close"].to_numpy(dtype=float)
      high = df["high"].to_numpy(dtype=float)
      low = df["low"].to_numpy(dtype=float)
      ```
      with:
      ```python
      result = extract_ohlcv(frames, self.min_lookback)
      if result is None:
          return no_signal()
      open_, high, low, close = result
      ```
    - Extract `features = frames.get("features") or {}` separately (kept as-is, not part of extract_ohlcv)
    - Some plugins don't use all 4 arrays — use `_` for unused: `_, high, low, close = result`

    **Transformation 3 — Replace ATR access (17 plugins that read atr_14, per D-05/D-06/D-07):**
    - Add `from .atr_utils import get_atr` to imports
    - Replace:
      ```python
      atr = features.get("atr_14", 0.0)
      if atr <= 0:
          atr = float(np.mean(high[-14:] - low[-14:]))
      if atr <= 0:
          return self._no_signal()
      ```
      with:
      ```python
      atr = get_atr(features)
      if atr is None:
          return no_signal()
      ```
    - Also replace simpler variants like `atr = features.get("atr_14", 0.0); if atr <= 0: return ...`
    - Remove any `import numpy as np` that becomes unused after removing the fallback computation

    **Transformation 4 — Replace confidence clamping (all 28 plugins, per D-12/D-13/D-14):**
    - Add `from .confidence_utils import compose_confidence` to imports
    - Replace all inline clamping patterns:
      - `confidence = round(min(1.0, max(0.0, raw_conf)), 4)` → remove this line
      - `confidence = round(min(0.95, max(0.10, confidence)), 4)` → `confidence = compose_confidence(raw_conf)`
      - Single-step: `confidence = min(0.95, max(0.10, raw))` → `confidence = compose_confidence(raw)`
    - The final confidence assignment must be a single `compose_confidence()` call. Any adjustments (penalty, boost) must happen to the raw value BEFORE calling `compose_confidence()`.

    **Transformation 5 — Route inline ATR stops through frame_trade() (14 plugins, per D-09/D-10):**
    The 14 plugins with inline `entry ± atr * multiplier` stop/target logic must be refactored:
    - Add `from .trade_framer import frame_trade` to imports
    - Replace inline stop/target blocks:
      ```python
      # OLD:
      if direction == 1:
          stop = entry - atr * self.atr_stop_multiplier
          targets = [round(entry + atr * m, 2) for m in self.atr_target_multipliers]
      else:
          stop = entry + atr * self.atr_stop_multiplier
          targets = [round(entry - atr * m, 2) for m in self.atr_target_multipliers]
      ```
      with:
      ```python
      # NEW:
      signal_type = signal_type_for_direction(self.name.replace("Plugin", "").lower(), direction)
      tf = frame_trade(signal_type, direction, entry, features, atr)
      if not tf.viable:
          return no_signal()
      stop = tf.stop
      targets = [t.price for t in tf.targets]
      ```
    - Add `from .plugin_utils import signal_type_for_direction` if not already imported
    - The `signal_type` string prefix should match the plugin's existing naming convention (e.g., `"trend"` for TrendFollowingPlugin, `"squeeze"` for SqueezeExpansionPlugin)
    - After refactoring, remove any `atr_stop_multiplier` and `atr_target_multipliers` class attributes that are no longer used (unless referenced elsewhere in the plugin)

    **Important per D-31:** Plugins continue to assemble the full signal dict internally. The `make_signal()` factory wiring happens in Plan 04. This plan only changes how stops/targets/confidence/ATR are computed within the plugin.

    **Order of execution:** Start with `trend_following.py` (has all 4 patterns — use as reference). Then do remaining 27 in alphabetical order. After each plugin, run its unit test if one exists.
