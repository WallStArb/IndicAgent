Contract this plan creates in `src/config/classification_service.py`. Wave-2 plans 03/04/05/06 are
written against exactly these names; do not rename.

Module constants:
- `DEFAULT_SCHEME = "indicagent_v1"`
- `SECTOR_LEVEL = 2` (indicagent_v1's sector level; a scheme-definition constant, APR-exempt as a
  schema identifier, per CLAUDE.md's exempt list)
- `SOURCE_REF_IBKR_REVIEWED = "ibkr_contract_details+review"` (single names, D-06)

- `SOURCE_REF_CONTRACT_SPEC = "contract_spec"` (inactive futures and FX pairs, which D-06 does not
  cover; see Plan 03)
- `ALLOWED_SOURCE_REFS: frozenset[str]` = the three values above

Functions:
- `unclassified_code(scheme: str = DEFAULT_SCHEME) -> str` returns `f"{scheme}:unclassified"`
- `label_or_unclassified(name: str | None, scheme: str = DEFAULT_SCHEME) -> str` returns name when
  non-empty, else `unclassified_code(scheme)`
- `current_level_name_sql(instrument_alias: str, level: int = SECTOR_LEVEL, scheme: str = DEFAULT_SCHEME) -> str`
  returns a parenthesized correlated scalar subquery yielding the name of the level-`level`
  ancestor of the symbol's CURRENT (valid_to IS NULL) assignment, or NULL when there is no current
  assignment or it does not reach that level. Shape: select `anc.name` from
  instrument_classification ic join classification_node n on (n.scheme, n.code) = (ic.scheme,
  ic.code) join classification_node anc on anc.scheme = ic.scheme and anc.code = n.path[level],
  where ic.symbol = `<alias>.symbol` and ic.scheme = '<scheme>' and ic.valid_to IS NULL.
  `instrument_alias` must match `^[a-z_][a-z0-9_]*$`, `scheme` must match `^[a-z0-9_]+$`, `level`
  must be an int >= 1; anything else raises ValueError (the text is embedded in SQL, so only
  module-validated identifiers ever reach it, never caller data).

Frozen dataclasses:
- `ClassificationAssignment(code: str, source_ref: str)`; `__post_init__` raises ValueError when
  code is empty or source_ref not in ALLOWED_SOURCE_REFS. Used by onboarding (Plan 04).
- `ClassificationNode(scheme: str, code: str, parent_code: str | None, level: int, name: str, path: tuple[str, ...])`
- `AssignmentRow(symbol: str, scheme: str, code: str, valid_from: date, valid_to: date | None, source_ref: str)`

Class `ClassificationService(database_url: str, pool: asyncpg.Pool | None = None)`:
- `async initialize()`, `async close()`, `async _load_all()` (VocabularyService shape exactly)
- `node(code: str, scheme: str = DEFAULT_SCHEME) -> ClassificationNode | None`
- `assignment_as_of(symbol: str, *, scheme: str = DEFAULT_SCHEME, as_of: date | None = None) -> AssignmentRow | None`
- `node_at_level(symbol: str, level: int, *, scheme: str = DEFAULT_SCHEME, as_of: date | None = None) -> str`
- `name_at_level(symbol: str, level: int, *, scheme: str = DEFAULT_SCHEME, as_of: date | None = None) -> str`
- `max_level(scheme: str = DEFAULT_SCHEME) -> int` (deepest level loaded for the scheme, 0 if none)
