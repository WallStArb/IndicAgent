```python
"""Instructor-patched LiteLLM async client for structured LLM output.

INSTRUCTOR_CLIENT is a module-level singleton — instructor.from_litellm(acompletion).
Calls go to litellm.acompletion directly, BYPASSING LiteLLMBackend's circuit breakers
(_OLLAMA_CB, _REMOTE_CB). This is an accepted Phase 094 tradeoff documented in
.planning/phases/094-instructor-structured-output/094-RESEARCH.md (Pitfall 2).

TODO(phase-095): Pydantic AI integration unifies the structured + unstructured paths
through LiteLLMBackend so circuit breakers apply to both.

Usage:
    from src.core.ai.structured_client import INSTRUCTOR_CLIENT
    result = await INSTRUCTOR_CLIENT.chat.completions.create(
        model="ollama/nemotron-3-nano:4b",
        messages=[...],
        response_model=MyModel,
        max_retries=3,
    )
"""
from __future__ import annotations

import instructor
from litellm import acompletion

INSTRUCTOR_CLIENT = instructor.from_litellm(acompletion)
```

2. Edit `src/core/ai/base_agent.py`:

   a. Add imports after the existing OTel/span imports (do NOT add a module-level `_INSTRUCTOR_CLIENT` alias):
   ```python
   from typing import TypeVar
   from src.core.ai.structured_client import INSTRUCTOR_CLIENT
   _T = TypeVar("_T")
   ```

   b. Add the following method to `BaseAIAgent` immediately AFTER the existing `_llm_generate` method:

   ```python
   async def _llm_generate_structured(
       self,
       context: "AIContext",
       result_type: type[_T],
       prompt: str,
       system: str,
       max_tokens: int,
       timeout: float,
       max_retries: int = 3,
   ) -> _T | None:
       """LLM call with Instructor-enforced structured output and automatic retry.

       Replaces _llm_generate + _parse_multiplier_response + _validate_*_fields.
       Instructor injects Pydantic ValidationError back into the prompt and
       retries up to max_retries times (4 total attempts max with default).

       Returns None when:
         - No providers configured (providers list empty)
         - Timeout exceeded (asyncio.wait_for raises TimeoutError)
         - All Instructor retries exhausted (raises last ValidationError)
         - Any other exception during the call

       Note: bypasses LiteLLMBackend circuit breakers — see structured_client.py.
       """
       providers = getattr(getattr(self._llm, "_inner", None), "providers", None) or []
       if not providers:
           return None

       with self.tracer.start_as_current_span(
           "agent.llm_generate_structured",
           attributes={
               ATTR_AGENT_ID: self.agent_id,
               ATTR_SYMBOL: context.symbol,
               ATTR_TF: context.timeframe,
           },
       ) as span:
           try:
               result = await asyncio.wait_for(
                   INSTRUCTOR_CLIENT.chat.completions.create(
                       model=providers[0],
                       messages=[
                           {"role": "system", "content": system},
                           {"role": "user", "content": prompt},
                       ],
                       response_model=result_type,
                       max_tokens=max_tokens,
                       max_retries=max_retries,
                   ),
                   timeout=timeout,
               )
               return result
           except Exception as exc:
               span.set_status(StatusCode.ERROR, str(exc))
               span.record_exception(exc)
               logger.warning(
                   "agent.structured_generate_failed",
                   agent_id=self.agent_id,
                   error=str(exc)[:120],
               )
               return None
   ```

   Important: the method body references `INSTRUCTOR_CLIENT` directly (the imported name). Tests patch `src.core.ai.structured_client.INSTRUCTOR_CLIENT` — Python's `from X import Y` semantics mean the name `INSTRUCTOR_CLIENT` in base_agent.py is a reference to the same object; patching at the source module rebinds it but ONLY if test patches `src.core.ai.structured_client.INSTRUCTOR_CLIENT` AND base_agent.py looks up the attribute via a module reference. To make tests work as specified, base_agent.py must access via module: change the call site to `from src.core.ai import structured_client as _sc` import, then call `_sc.INSTRUCTOR_CLIENT.chat.completions.create(...)`. This guarantees `patch('src.core.ai.structured_client.INSTRUCTOR_CLIENT', ...)` is visible to base_agent.py at call time.

   Replace the import lines and call site accordingly:
   ```python
   from src.core.ai import structured_client as _sc
   ```
   And in the method body:
   ```python
   INSTRUCTOR_CLIENT_REF = _sc.INSTRUCTOR_CLIENT
   result = await asyncio.wait_for(
       INSTRUCTOR_CLIENT_REF.chat.completions.create(...),
       ...
   )
   ```
