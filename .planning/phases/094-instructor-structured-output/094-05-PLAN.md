<task id="3" name="Live smoke test against Ollama">
<action>
Run the live smoke test verifying Instructor + Ollama produces a parsed Pydantic model. This validates the entire stack end-to-end before service restart.

```bash
.venv/bin/python - <<'EOF'
import asyncio, os
os.environ.setdefault("OLLAMA_API_BASE", "http://localhost:11434")

import instructor
from litellm import acompletion
from pydantic import BaseModel, Field

class TestResult(BaseModel):
    score: float = Field(ge=0.0, le=1.0)
    label: str

client = instructor.from_litellm(acompletion)

async def run():
    result = await client.chat.completions.create(
        model="ollama/nemotron-3-nano:4b",
        messages=[
            {"role": "system", "content": "OUTPUT ONLY RAW JSON. NO PROSE. NO EXPLANATION. NO PREAMBLE. Begin your response with { and end with }."},
            {"role": "user", "content": "Rate this market signal: strong bullish momentum. Return JSON with score (0-1) and label."},
        ],
        response_model=TestResult,
        max_tokens=100,
        max_retries=3,
    )
    assert 0.0 <= result.score <= 1.0, f"score out of range: {result.score}"
    assert isinstance(result.label, str) and len(result.label) > 0, f"label invalid: {result.label}"
    assert isinstance(result, TestResult), f"wrong type: {type(result).__name__}"
    print(f"score={result.score} label={result.label} type={type(result).__name__}")

asyncio.run(run())
print("SMOKE TEST PASSED")
EOF
```

If smoke test fails (Ollama unavailable), check `docker exec ollama ollama ps` and `docker ps | grep ollama` before aborting — do NOT proceed to service restart if smoke fails.
