    - `@dataclass` class `ORB15Plugin`
    - `name = "trad_ORB15"`
    - `regime_type = "trend"` (per CONTEXT.md: trend preferred for continuation ORB)

    **compute_full() logic:**
    1. Extract df, features, symbol, tf. Guard len(df) < min_lookback.
    2. Extract timestamp from df: `ts = df["timestamp"].iloc[-1]`. Handle `to_pydatetime()`. Ensure tz-aware UTC. Convert to ET: `et = ts.astimezone(_ET_TZ)`.
    3. Get state: `state = self._state.get((symbol, tf), {})`.
    4. Session date check: if `et.date() != state.get("session_date")`, reset state for new session.
    5. **Session gate**: if NOT `_in_window(et, (9, 30), (11, 30))`, write state back, return _no_signal().
    6. **Range accumulation** (09:30-09:45 for ORB15):
       - If `_in_window(et, (9, 30), (9, 45))` and not `state.get("range_complete")`:
         - Get current bar high/low from df
         - Update `state["orb_high"] = max(state.get("orb_high", -inf), float(df["high"].iloc[-1]))`
         - Update `state["orb_low"] = min(state.get("orb_low", inf), float(df["low"].iloc[-1]))`
         - Write state back, return _no_signal() (still accumulating)
       - If past 09:45 and not range_complete: mark `state["range_complete"] = True`
    7. If not `state.get("range_complete")`: write state back, return _no_signal().
    8. Get close, high, low, volume arrays. Get `atr = float(features.get("atr_14", 0.0))` with ATR fallback.
    9. **Breakout detection**: `close_price = float(df["close"].iloc[-1])`. Check if `close_price > state["orb_high"]` (long breakout) or `close_price < state["orb_low"]` (short breakout).
    10. If no breakout: write state back, return _no_signal().
    11. **Volume gate**: `bar_volume = float(df["volume"].iloc[-1])`. Compute session avg volume from df (use `df["volume"].mean()`). If `bar_volume < 1.5 * avg_volume`: write state back, return _no_signal(). Alternative: check `rel_volume = features.get("rel_volume")` — if available and > 1.5, pass; otherwise use df volume.
    12. **Fire-once gate**: if `state.get("fired_long")` and direction==1, or `state.get("fired_short")` and direction==-1: no_signal.
    13. Direction: 1 for long breakout, -1 for short.
    14. Entry price = close_price.
    15. **Gap bias**: `pdc = features.get("prior_session_close")`. If pdc and isinstance(pdc, (int, float)) and pdc > 0: `gap_pct = (float(df["open"].iloc[0]) - pdc) / pdc`. If abs(gap_pct) > 0.001: boost confidence if gap aligns with direction (+0.10), reduce if misaligns (-0.05).
    16. Confidence: base 0.50. Regime boost: if hmm_regime in (1.0, 2.0): +0.10. Gap bias adjustment. Clamp [0.10, 0.95].
    17. Call `frame_trade(setup_type="orb15_breakout_long"/"orb15_breakout_short", direction=direction, entry=entry, features=features, atr=atr)`. If not viable: no_signal.
    18. Mark `state["fired_long"] = True` or `state["fired_short"] = True`. Write state back.
    19. Return signal dict.
