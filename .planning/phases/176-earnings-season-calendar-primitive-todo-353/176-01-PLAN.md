Corrected earnings-season window (D-04, supersedes the todo's 0-42 day window):
  in-season iff START_DAYS <= days_since_quarter_end <= END_DAYS, with START_DAYS=14, END_DAYS=42
  quarter ends: Mar 31, Jun 30, Sep 30, Dec 31
  days_since_quarter_end = (bar_ts.date() - most_recent_quarter_end).days, always >= 0

Reference implementation verified during research (Spearman rho 0.935 vs. the live
`quarter_position` column, n=4018):

    def days_since_quarter_end(d: date) -> int:
        quarter_ends = [date(y, m, day) for y in (d.year - 1, d.year)
                        for m, day in ((3, 31), (6, 30), (9, 30), (12, 31))]
        last_qe = max(qe for qe in quarter_ends if qe <= d)
        return (d - last_qe).days

Breadth criterion (D-01a's "broad, not single-symbol-concentrated"). A feature is BROAD iff all
three hold, and all three are fixed here before measurement:
  (B1) it survives BH-FDR at alpha=0.05 across the 57-feature family;
  (B2) >= 55% of the symbols with sufficient rows individually show the same SIGN of
       (|in-season IC| - |off-season IC|) as the pooled result — the same breadth discipline D-04
       applied to the primary effect (67% of symbols, 155/233);
  (B3) the pooled effect survives leave-one-symbol-out jackknife on the FIVE highest-row-count
       symbols: dropping any one of them individually must leave the sign unchanged and the raw
       pooled p-value still below 0.05.
A feature that clears B1 but fails B2 or B3 is recorded as FDR-significant-but-narrow and does NOT
enter `SWEEP_SURVIVORS`.
