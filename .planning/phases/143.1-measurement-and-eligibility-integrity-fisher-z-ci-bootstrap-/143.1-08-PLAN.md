<objective>
Component E, shadow validation (mandatory, not optional). The sign-symmetric change (Plan 04) alters champion scoring behavior, eligibility membership, and score distribution simultaneously - for what becomes the owner's live trading capital. Validate it in shadow mode BEFORE any promotion.

REAL BEHAVIOR SWITCH (Fable review BLOCKER 2): `weight_version` is a data-scoping tag ONLY - it does not gate any eligibility/walk-forward/quality-weight logic, so training a "champion tag" and a "challenger tag" without the `alpha.ensemble.sign_symmetric` flag would produce byte-identical weights and a vacuous, self-comparing FRAME-04. Plan 04 introduced the real switch: the boolean APR key `alpha.ensemble.sign_symmetric` (default false) plus an ensemble_trainer `--sign-symmetric/--no-sign-symmetric` CLI override. This plan trains the CHAMPION with the flag OFF and the CHALLENGER with the flag ON, under distinct weight_version tags, both from Plan 07's single corrected corpus. The FRAME-04 comparison is now genuinely old-eligibility (flag off) vs new-eligibility (flag on) on identical data.

Pre-commitment: the FRAME-04 decision rule for the full-corpus result MUST be written down BEFORE the result is seen - deciding after seeing the number is how goalposts quietly move.

Re-run the E1-vs-E2 A/B judgment: the prior 20/20 E1-win result was produced on an all-long-vs-all-long input where E2's sign-symmetric distinguishing capability was structurally unexercisable. It does not carry forward once the challenger universe becomes genuinely sign-symmetric.

Promotion is a single, explicit, evidence-gated act: flip the `alpha.ensemble.sign_symmetric` APR DEFAULT from false to true (recorded in the methodology-change-ledger), and ONLY if the pre-committed FRAME-04 rule clears. If it does not clear, HOLD - the flag stays default-false and the champion keeps long-only eligibility.

Uses the EXISTING `weight_version` scoping mechanism for data separation plus the NEW `sign_symmetric` flag for behavior separation - no new schema. Runs on top of Plan 07's completed corpus re-run.

Output: a completed shadow-validation cycle with a pre-committed decision rule, champion(flag-off)-vs-challenger(flag-on) criteria evaluation, the E1/E2 re-run result, the re-measured emission volume, and a promote (flip the APR default) or HOLD decision.
</objective>
