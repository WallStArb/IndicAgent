- **After every task commit:** Run the specific affected test file(s) from the Component -> Test Map below
- **After every plan wave:** Run full suite (`.venv/bin/pytest tests/unit/ -v`)
- **Before `/gsd:verify-work`:** Full suite must be green
- **Phase gate (hard sequencing gate, not just a test):** Component A's staged-validation diagnostic must show zero/near-zero SUSPECT rate on the same 66-72 cell sample used by `ops_ic_null_calibration.py` before the full corpus-wide `ic_engine` re-run is triggered
