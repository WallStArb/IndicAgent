**2. [Rule 1 - Bug] Replaced a statistically-flawed Monte Carlo martingale-expectation test before it was ever committed as GREEN**
- **Found during:** Task 1, running the initial GREEN implementation against the RED test
- **Issue:** The originally-written test compounded the e-value process over 20 simulated reruns across 20,000 simulations and asserted the sample mean matched 1.0 within an 0.05 absolute tolerance. The compounded process is a heavy-tailed multiplicative martingale (variance grows geometrically with the number of compounded reruns — `Var[cumulative] ≈ 1.25^20 - 1 ≈ 85.7` at `n_runs=20`), giving a standard error of the sample mean (`≈0.065`) already larger than the assertion's own tolerance — the test would fail intermittently regardless of a correct implementation, not because of one (observed failure: `0.923 ± 0.05` vs expected `1.0`).
- **Fix:** Replaced the flaky assertion with an exact closed-form check (`E_H0[factor] = 0.5*(p_alt/0.5) + 0.5*((1-p_alt)/0.5) = 1.0` by construction of a likelihood ratio against a fixed alternative — no simulation needed) plus a statistically-sound single-step empirical corroboration (bounded variance 0.25 at the single-observation level converges tightly at 20,000 sims, unlike the compounded 20-run version).
- **Files modified:** `tests/unit/test_e_values.py`
- **Verification:** Both replacement tests pass deterministically; full test file (21 tests) green.
- **Committed in:** `81a81119` (Task 1 GREEN commit — the flawed version was never committed as a passing test; corrected before the GREEN commit was made)
