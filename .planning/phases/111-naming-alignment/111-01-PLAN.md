**Part A — BaseDaemon (src/core/agent/base.py):**

Add a module-level function before the BaseDaemon class:

```python
def _to_snake_case(name: str) -> str:
    """Convert PascalCase/CamelCase to snake_case.
    BarAggregator -> bar_aggregator, MLDiscoveryAnalyzer -> ml_discovery_analyzer
    """
    s1 = re.sub(r'([A-Z]+)([A-Z][a-z])', r'\1_\2', name)
    s2 = re.sub(r'([a-z0-9])([A-Z])', r'\1_\2', s1)
    return s2.lower()
```

Update `BaseDaemon.__init__` signature from `def __init__(self, name: str, ...)` to `def __init__(self, name: str | None = None, ...)`. At the top of __init__, before the log_name derivation, add:

```python
if name is None:
    name = _to_snake_case(self.__class__.__name__)
```

Remove the inline `import re` at line 124 (it is now at module level). The existing `log_name = re.sub(r"(?<!^)(?=[A-Z])", "_", name).lower()` logic becomes a no-op on an already-snake name — leave it as-is since name may still be passed explicitly. The log path derivation continues to work correctly.

Add `import re` at the top of the module-level imports section (after `from __future__ import annotations`, before `import abc`).

**Part B — BaseWriter (src/core/agent/base_writer.py):** REQUIRED to prevent TypeError at writer-service startup.

`BaseWriter.__init__` currently has `def __init__(self, name: str, **kwargs)` calling `super().__init__(name=name, **kwargs)`. Because `name` is positional-required here, any writer service (bar_writer.py, lineage_writer.py, signal_metrics_writer.py, graduation_writer.py, swarm_ledger_writer.py, context_writer.py, feature_writer.py) that drops `name=` in Task 2 would raise `TypeError: __init__() missing 1 required positional argument: 'name'`.

Change the BaseWriter signature to:

```python
def __init__(
    self,
    name: str | None = None,
    **kwargs: Any,
) -> None:
    super().__init__(name=name, **kwargs)
```

Passing `name=None` through to BaseDaemon is now safe because Part A makes BaseDaemon derive the name from the class when `name is None`. Do not change any other lines in BaseWriter.__init__ (the `_buffer`, `_last_flush`, `_payload_adapter` setup stays).
