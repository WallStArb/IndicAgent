<threat_model>
**Threat:** State threading is the single highest-correctness change in this phase. If state is not threaded through correctly, incremental plugins will silently revert to full-recompute (low impact: slower), OR worse, plugins will read empty state and emit incorrect signals (high impact: signal drift).

- **Race condition existence (the bug being fixed):** Pre-fix, `plugin._state = plugin_states.get(plugin_name, {})` is assigned at executor.py lines 298 (run_i1), 360 (run_tier), 508 (run_i7_plugins) BEFORE `loop.run_in_executor()` dispatch. With per-key workers (Plan 06), the same plugin instance could have `_state` overwritten by a concurrent bar before the thread-pool call fires. This is THE bug PERF-03 fixes.
- **Plugin protocol break:** Adding `state=` keyword to `compute_full`/`compute_next` must be backward-compatible — plugins that don't accept it will TypeError. Mitigation: protocol signature uses `**kwargs` OR explicit `state: dict | None = None` default; all 132 plugins inherit from a base that accepts it OR are updated explicitly if they override.
- **`_timed_plugin_call` reads `plugin._state`:** Line 76+83 of executor.py — `_timed_plugin_call` checks `plugin._state` truthiness for incremental path selection. After PERF-03, that check moves to `state` parameter truthiness. Mitigation: change the gating expression to use the new `state` parameter.
- **State write-back:** Plugins mutate state during compute. The mutation must propagate back to PluginStateManager. Mitigation: protocol returns `(result, state_update)` OR plugins write into the dict passed by reference (current pattern) — pick one and enforce.
- **No new endpoints, no auth, no DB writes.**
</threat_model>

<objective>
Fix the plugin state race condition (PERF-03) by threading state as an explicit parameter through `_timed_plugin_call` and the `compute_full`/`compute_next` protocol. After this plan, the same plugin instance can be safely dispatched to the thread pool from multiple concurrent bars (prerequisite for Plan 06 PERF-07).

Purpose: Renaissance correctness invariant — independent (symbol, tf) bars must be safely parallelizable. Per-key workers cannot ship until this race is eliminated.

Output: `_timed_plugin_call(plugin, frames, state)` signature; three call sites in `run_i1`/`run_tier`/`run_i7_plugins` updated to pass state by parameter; `plugin.compute_full` and `plugin.compute_next` accept `state` kwarg; zero `plugin._state =` assignments remaining in executor.py.
</objective>
