HMA formula reference:
```
WMA(k, series) = sum(weights * series[-k:]) where weights = [1, 2, ..., k] / sum(weights)
HMA(n=20):
  half_period = n // 2  # = 10
  sqrt_n = int(round(n ** 0.5))  # = 4 (sqrt(20) ≈ 4.47 → use 4 or 5, implementation plan uses int(round()))
  wma_half = WMA(half_period, close)
  wma_full = WMA(n, close)
  diff_series = 2 * wma_half_last - wma_full_last  # need last sqrt_n values
  hma_20 = WMA(sqrt_n, diff_series[-sqrt_n:])
  # Requires storing diff_series rolling buffer in _state
  # min_lookback = 20 (need 20 bars for wma_full; wma_half needs 10)
```
