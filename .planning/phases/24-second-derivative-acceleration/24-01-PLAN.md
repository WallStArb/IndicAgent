New outputs to be added (Plan 02 target — test stubs check for these):
- `rsi_curvature`: float — second derivative of RSI, 0.0 on first bar
- `macd_hist_slope`: float — reads `macd_histogram_12_26_9` from features (NOT `macd_12_26_9`), state-based
- `price_accel`: float — ATR-normalized price second derivative, 0.0 when ATR missing
- `hma_slope`: float — hma_20[t] - hma_20[t-1], state-based, 0.0 when hma_20 not in features
- `hma_accel`: float — hma_slope[t] - hma_slope[t-1], state-based

New plugin: ExhaustionScore (Plan 03 target):
- `exhaustion_score`: float 0.0–1.0 (3/3 conditions = 1.0, 2/3 = 0.6, 1/3 = 0.2, 0/3 = 0.0)
- `exhaustion_side`: str ("bull" | "bear" | "none")
- `exhaustion_bars`: float (consecutive bars condition holds; resets to 0 when condition breaks)
- Bullish conditions: rsi_14 > 70 AND rsi_curvature < 0 AND macd_hist_slope < 0
- Bearish conditions: rsi_14 < 30 AND rsi_curvature > 0 AND macd_hist_slope > 0

New plugin: AccelerationRegime (Plan 03 target):
- `accel_regime`: str ("building" | "peak" | "waning" | "trough" | "neutral")
- `accel_score`: float -1.0 to +1.0
- `accel_agreement`: float 0.0–1.0 (fraction of measures in agreement)
- Regime: "building" if accel_score > 0.5; "peak" if prev > 0.3 AND current <= 0.3 (single-bar event)
- "trough" if prev < -0.3 AND current >= -0.3; "waning" if accel_score < -0.3; "neutral" otherwise

New plugin: SwingMomentum (Plan 04 target):
- Returns `{}` until 6 confirmed extremes (3 complete swings)
- `swing_amplitude_ratio`, `swing_amplitude_expanding` (int 0/1), `swing_velocity_bars`
- `swing_velocity_trend` ("accelerating"|"decelerating"|"stable"), `struct_energy` (0.0–1.0), `struct_accel_bias` (+1/0/-1)
- struct_energy = clamp(amplitude_ratio * speed_factor / 3.0, 0.0, 1.0)

New I1 plugin: HMA (Plan 02 target):
- File: src/intelligence/indicators/hma.py
- name = "HMA"
- outputs = frozenset({"hma_20"})
- min_lookback = 20
- Formula: WMA(2×WMA(n/2, close) − WMA(n, close), sqrt(n)) where n=20

I7 exhaustion wires (Plan 05 target):
- LiquiditySweepReclaim + LiquidityHunt: exhaustion_score > 0.6 in sweep dir → confidence += 0.1, "exhaustion_sweep_boost" in supporting
- MomentumBreakout + TrendFollowing: exhaustion_score > 0.7 AND exhaustion_bars >= 3 → confidence -= 0.15, "exhaustion_guard_penalty" in supporting; if confidence < threshold → _no_signal()
