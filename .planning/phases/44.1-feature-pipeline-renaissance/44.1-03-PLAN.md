    **Startup sequence (per D-26 through D-33):**
    1. `await self._db.connect()` — DB before bar consumption (D-26)
    2. `await self._seed_bar_history()` — single ROW_NUMBER() window query (D-27):
       ```sql
       WITH ranked AS (
           SELECT symbol, tf, ts, bar,
                  ROW_NUMBER() OVER (PARTITION BY symbol, tf ORDER BY ts DESC) AS rn
           FROM intelligence_features
           WHERE symbol = ANY($1)
             AND ts > NOW() - INTERVAL '7 days'
       )
       SELECT symbol, tf, ts, bar
       FROM ranked
       WHERE rn <= 200
       ORDER BY symbol, tf, ts ASC;
       ```
       Parse `bar` JSONB column into BarMessage objects, call `self._bar_history.seed(symbol, tf, bars)`.
       Fallback (D-28): if `intelligence_features` has < `min_bars_for_tf(tf)` rows for a pair, query `market_data_ohlcv` for that (symbol, tf).
    3. Reconstruct BarAccumulator partial state (D-30): short-lived consumer seeking recent 1m bars from `development.market.bars` topic.
    4. Re-publish last known IntelligenceEvent per (symbol, tf) (D-31): if cached from seed, publish to `development.intelligence`.
    5. Subscribe to `topic_system_events()` for roll events (D-32).
    6. Begin consuming `development.market.bars` ONLY AFTER seeding complete (D-33).

    **Per-bar execution (D-34 through D-36):**
    ```python
    async def _on_bars(self, messages: list[dict]) -> None:
        bars = [BarMessage.model_validate(msg) for msg in messages]
        async def _bounded(bar: BarMessage) -> None:
            async with self._sem:
                await self._process_bar(bar)
        await asyncio.gather(*[_bounded(b) for b in bars], return_exceptions=True)

    async def _process_bar(self, bar: BarMessage) -> None:
        t0 = time.perf_counter()
        # 1. Append to BarHistory
        self._bar_history.append(bar)
        # 2. BarAccumulator update — get completed HTF bars
        htf_bars = self._bar_accumulator.update(bar)
        for htf_bar in htf_bars:
            self._bar_history.append(htf_bar)
            await self._publish_htf_bar(htf_bar)  # to development.market.bars.htf
        # 3. Process bar + all completed HTF bars through pipeline
        all_bars = [bar] + htf_bars
        for b in all_bars:
            if not self._bar_history.is_warm(b.symbol, b.tf, min_bars_for_tf(b.tf)):
                continue
            await self._run_pipeline(b, t0)
    ```
