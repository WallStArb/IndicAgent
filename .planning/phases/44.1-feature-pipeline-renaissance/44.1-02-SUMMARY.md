## What Was Built

### BarHistory (`src/core/bar_history.py`)

Fully implemented typed deque store per (symbol, tf):

- `append(bar)` — creates deque with maxlen if missing, appends bar
- `get(symbol, tf)` — returns deque or empty deque for unknown keys
- `to_dataframe(symbol, tf)` — DataFrame with `[timestamp, open, high, low, close, volume]` columns
- `is_warm(symbol, tf, min_bars)` — warmup gate: `len(get(...)) >= min_bars`
- `seed(symbol, tf, bars)` — replaces deque from DB-loaded list; `bars[-maxlen:]` honors capacity
- `migrate_symbol(old, new)` — atomic rename across 4 standard TFs; no-op for unknown symbols

Key implementation choice: `deque(maxlen=self._maxlen)` enforces capacity automatically via Python's built-in deque eviction — no manual size checks needed.

### BarAccumulator + TradingSession (`src/core/bar_accumulator.py`)

Session-aware 1m→HTF aggregator:

**TradingSession.is_session_break(prev_ts, curr_ts)**:
- CRYPTO/FX: always False (24h continuous)
- RTH/ETH: scans days spanned by [prev_ts, curr_ts] checking two UTC boundaries:
  - 13:30 UTC (09:30 ET) — RTH open / ETH close
  - 20:00 UTC (16:00 ET) — RTH close / ETH open
- Returns True if any boundary falls strictly within the interval

**BarAccumulator.update(bar_1m)**:
- Guards `if bar_1m.tf != "1m"` — returns `[]` immediately for non-1m input (D-15)
- Reuses `_floor_to_period` from `src.core.timeframe_builder` (no duplication)
- Per (symbol, tf) accumulator: tracks open/high/low/close/volume/last_ts/period_ts
- Session break check fires before window boundary check — partial bar closed and emitted
- Completed bars have `source="htf_derived"` (D-13)
- OHLCV aggregation: open=first, high=max, low=min, close=last, volume=sum (D-12)

**BarAccumulator.current_partial(symbol, tf)**:
- Returns BarMessage from current accumulator state; None if no data
