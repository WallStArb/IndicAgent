<objective>
Implement D-05: promote `causality_basis` from a self-declared comment into an enforced gate. No
`StratificationDimension` provider may enter gate 0 without first passing an automated
acausal-placebo test, generalizing the existing, production-proven `canary_acausal_placebo`
mechanism from a single planted-leak feature check into a mandatory per-provider registration
precondition.

Purpose: this codebase has hit unverified-causality failures three times (todo 243 CTF momentum
batch-join lookahead, todo 248 HMM full-history parameter fit, todo 204 canary POOLED anomaly). A
self-reported, unchecked `causality_basis` field is the same silent-wrong-answer shape that let
all three ship. Per the project principle, silent wrong answers are worse than loud crashes, so
this gate raises.

Output: `acausal_placebo_gate.py` with a pure `evaluate_provider_causality()` plus a
`make_placebo_gate()` factory producing the callable `contract.validate_registration()` demands,
and a RED-first unit suite proving both a positive and a negative control.

`check_prefix_invariance(provider, frame, params, fractions=_PREFIX_CHECK_FRACTIONS) -> tuple[bool, dict[str, Any]]`
— Sub-check A, the deterministic look-ahead detector. For each fraction, compute
`provider.compute(frame.iloc[:k], params)` and compare elementwise against
`provider.compute(frame, params).iloc[:k]`. Any divergence means past labels changed retroactively
once future bars arrived, which falsifies any `causality_basis` claim. Guard order first: frames
with fewer than 2 rows return a skip-shaped `(True, {"reason": "insufficient_rows", ...})` before
any indexing. On failure report `reason="prefix_invariance_violated"`, the failing fraction, and
the first divergent positional index. Docstring must state that this check catches exactly the
todo 243 (batch-join lookahead) and todo 248 (full-history HMM parameter fit) shapes, and must
note that a `fitted` provider using a full-history fit is EXPECTED to fail this check — that is
the finding, not a gate bug.

`check_placebo_ic(provider, frame, forward_returns, params, alpha=_PLACEBO_ALPHA_DEFAULT, n_shuffles=_PLACEBO_SHUFFLES_DEFAULT, seed=145) -> tuple[bool, dict[str, Any]]`
— Sub-check B, the placebo. Build a future-blind copy of the provider's input by shuffling the
frame's value columns with a seeded `np.random.default_rng(seed)` while preserving the index, run
`provider.compute()` on it, ordinal-encode the resulting labels, and measure IC against the real
`forward_returns` via `compute_ic_vectorized`. Compare the observed |IC| against the null
distribution built from `n_shuffles` independent reshuffles, and fail when the empirical
one-sided p-value is below `alpha` — labels derived from a future-blind input must carry no
information about real forward returns; if they do, the provider is reading something other than
its declared input. Guard order first: fewer than 2 distinct labels returns a skip-shaped
`(True, {"reason": "degenerate_labels", ...})`; length mismatch between labels and
`forward_returns` returns `(True, {"reason": "length_mismatch", ...})`. Report the observed IC,
the null p-value, and the label cardinality in diagnostics on every path.

`evaluate_provider_causality(provider, frame, forward_returns, *, params=None, alpha=..., n_shuffles=..., seed=145) -> dict[str, Any]`
— the pure orchestrator, mirroring `ops_canary_integrity_assert.py::evaluate` exactly: no IO,
accumulate a `failures` list across both sub-checks, and
`raise AcausalPlaceboRegistrationViolation("; ".join(failures))` when non-empty, naming the
provider's `name` and the specific failing sub-check in each message. On success return a report
dict containing `passed=True`, `provider`, `causality_basis`, and both sub-check diagnostics
dicts. There must be NO warn-and-continue path.

`make_placebo_gate(frame, forward_returns, *, params=None, alpha=..., n_shuffles=..., seed=145) -> Callable[[Any], None]`
— returns a one-argument closure calling `evaluate_provider_causality` and discarding the report,
so it can be passed directly as `contract.validate_registration`'s required second positional
argument.

Module docstring must state D-05 in substance (no provider enters gate 0 without passing this
check), name `ops_canary_integrity_assert.py` and `feature_factory.py::_canary_acausal_placebo` as
the mechanism being generalized, explain that the assertion here is the INVERSE of the existing
positive control (there a planted leak MUST be detected; here a provider's labels must NOT be
informative from a future-blind input), and record this phase's answer to the re-run question:
this is a registration-time gate that must be re-run whenever a provider's `compute()`
implementation changes, in the same spirit as `ic_engine.py`'s existing `code_content_key`
fingerprint invalidation.

Ring rule: imports limited to stdlib, numpy, pandas, and `src/`. Zero imports from `services/` and
zero imports from `scripts/`.
