<objective>
Build the three-stage gate cascade's statistical primitives as pure, DB-free Ring 1 functions:
the structural redundancy pre-filter (gate 0), the orthogonality study (gate 1), the
effective-N-corrected substitution test (gate 2, D-04), and the BH-FDR correction across a
`regime_group`'s cumulative candidate-test history (D-03).

Purpose: D-03 and D-04 are the two statistical safeguards this phase adds beyond the original
design docs. `regime_model`'s cascade currently has no family-wise error control (unlike the
`confluence` domain's already-specced gate 2) and states its N floor in raw bars, which is wrong
for autocorrelated, `min_hold_bars`-smoothed regime labels. This plan closes both.

D-03's family is a `regime_group`'s CUMULATIVE test history, which only means something if that
history outlives the run that produced it. This plan therefore also ships the durable append-only
store the family is loaded from, so the second candidate dimension tested (a later phase, per D-06)
inherits every test this phase logged instead of silently starting a fresh, artificially small
family. Addresses cross-AI review concern (145-REVIEWS.md, codex HIGH #2): the FDR family had no
durable runtime store outside the pilot artifact.

Output: `gates.py`, `fdr.py`, `family_history.py`, and a unit suite proving guard ordering, family
scoping, durable family accumulation, and the refuse-rather-than-guess behavior of the unset
correlation threshold.
</objective>
