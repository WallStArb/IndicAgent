<objective>
Build the Ring 0 foundation for the YAML-driven agent registry: the AgentDependencies dependency container, the registry module (AgentSpec validation, the _REGISTRY dict, AgentRegistry.build/validate, and the two error classes), and the extension of BaseAIWorker.__init_subclass__ so every concrete agent self-registers by agent_id at class-definition time.

Purpose: This is the construction substrate the swarm coordinators will call. It must fail fast on bad config, duplicate IDs (both at class-definition time AND duplicate YAML entries), and wrong-group placement, and it must not introduce Ring 0 -> Ring 1 import violations.
Output: src/core/ai/agent_dependencies.py (new), src/core/ai/registry.py (new), modified base_agent.py, and a unit test suite proving validation/registration behavior.
