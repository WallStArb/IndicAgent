<objective>
Migrate every agent constructor from loose kwargs (llm_chain=, pool=) to the unified keyword-only `deps: SwarmDeps` signature, and change BaseAIWorker.__init__ to accept `deps`. This is the constructor-uniformity change that lets AgentRegistry.build construct every agent identically with `cls(deps=deps)`.

Purpose: Eliminate the constructor inconsistency (MLEvaluator needs pool; LLM agents need llm_chain) that cannot be absorbed cleanly by **kwargs. After this plan, mypy catches wrong-dep access at type-check time.
Output: Six migrated agent files, modified base_agent.py __init__, and updated agent unit tests that instantiate via SwarmDeps.
</objective>
