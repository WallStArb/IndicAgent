<objective>
Migrate every agent constructor from loose kwargs (llm_chain=, pool=) to the unified keyword-only `deps: SwarmDeps` signature, change BaseAIWorker.__init__ to accept `deps`, and update EVERY direct call site — including the on-demand narrative API route — to construct via SwarmDeps. This is the constructor-uniformity change that lets AgentRegistry.build construct every swarm agent identically with `cls(deps=deps)`.

Purpose: Eliminate the constructor inconsistency (MLEvaluator needs pool; LLM agents need llm_chain) that cannot be absorbed cleanly by **kwargs. After this plan, mypy catches wrong-dep access at type-check time, and no caller anywhere passes `llm_chain=`/`pool=` to a migrated agent.
Output: Six migrated agent files, modified base_agent.py __init__, the migrated narrative API route, and updated agent + route unit tests that instantiate via SwarmDeps.
</objective>
