<objective>
Replace the LLM CorrelationAgent + VolumeAgent with deterministic math that lives in the right tier of the pipeline:

1. **VolumeZscorePlugin (I1)** — rolling z-score of bar volume, computed once per bar, stored in `intelligence_features.i1.volume_z_score`.
2. **corr_z in CrossAssetComputeAgent** — rolling Pearson-correlation z-score per (instrument, lead) pair, computed once per bar, included in the cross-asset payload and propagated into `intelligence_features` via `feature_writer_agent`.
3. **AlphaSwarmComputeAgent simplification** — drop CorrelationAgentComputeAgent and VolumeAgentComputeAgent. The swarm now runs exactly one agent: SkepticAgentComputeAgent. `_enrich_context` becomes a pass-through. `_LEAD_INDEX_MAP`, `_find_lead_context`, and `_extract_volume_profile` are deleted in their entirety because their only consumers are gone.
4. **Legacy file removal** — `git rm` the four LLM agent/prompt files plus their tests.
5. **Shadow registry cleanup** — emit a one-time idempotent SQL script removing `correlation_v1` / `volume_v1` rows from `shadow_registry`.

Skeptic v2 sees both new features automatically because Plan 05's `_render_full_context(ctx: AIContext)` iterates `AIContext.model_fields` — `volume_z_score` is a field on `I1Indicators` (extra='allow' so it serializes through), and `corr_z` flows in via the cross-asset tier already rendered by Plan 05's open-ended iteration. Zero explicit prompt wiring needed.

Renaissance principle: compute once per bar, store once, consume everywhere. The swarm is a consumer of the feature store, not a producer.

Output: a new I1 plugin (or a documented decision to reuse an existing equivalent), `corr_z` wired through cross-asset → feature-writer, a stripped-down swarm service, deleted legacy files, and a shadow-registry cleanup script.

       ```python
       """Volume Z-Score (I1) — rolling z-score of bar volume.

       """

       from __future__ import annotations

       import collections
       from typing import Any, ClassVar

       from src.intelligence.plugins import PatternPlugin


       _WINDOW = 20


       class VolumeZscorePlugin(PatternPlugin):
           name: ClassVar[str] = "volume_zscore"
           SHADOW_SKIP: ClassVar[bool] = True  # I1 measurement, not signal

           # Match outputs/inputs/tags shapes from src/intelligence/features/i1_indicators/atr.py
           # The exact field types here MUST mirror the canonical I1 plugin —
           # adapt to whatever shape atr.py uses (frozenset[str], tuple[InputSpec, ...]).
           outputs: ClassVar[frozenset[str]] = frozenset({"volume_z_score"})

           def compute(self, features: dict, state: dict, **kwargs: Any) -> dict:
               s = state.setdefault(self.name, {"history": collections.deque(maxlen=_WINDOW)})
               history: collections.deque = s["history"]

               # Read current bar volume from the same place every other I1 plugin
               # reads OHLCV — confirm the exact key by reading atr.py first.
               bar = features.get("bar") or {}
               volume = bar.get("v") if "v" in bar else bar.get("volume")
               if volume is None:
                   return {"volume_z_score": 0.0}

               history.append(float(volume))

               if len(history) < 2:
                   return {"volume_z_score": 0.0}

               # Compare current bar to history EXCLUDING current (history[:-1])
               import numpy as np
               hist = np.asarray(list(history)[:-1], dtype=float)
               mean = float(hist.mean())
               std = float(hist.std())
               if std <= 0.0:
                   return {"volume_z_score": 0.0}
               z = (history[-1] - mean) / std
               return {"volume_z_score": float(z)}


       plugin = VolumeZscorePlugin()
       ```
