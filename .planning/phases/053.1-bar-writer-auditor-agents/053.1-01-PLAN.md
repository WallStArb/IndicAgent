**Create `services/bar_writer_agent.py`:**

```python
#!/usr/bin/env python3
"""BarWriterAgent — dedicated OHLCV persistence agent.

Subscribes to market.bars (1m) + market.bars.htf (5m-1d), batch-writes
to market_data_ohlcv with ON CONFLICT DO NOTHING for idempotent writes.

Decouples bar persistence from the feature compute hot path (D-02 through D-07).

Metrics port: :9121

Golden Signals (D-06):
- Traffic: events_consumed_total, bars_written_total{tf}
- Latency: persistence_batch_latency_seconds
- Errors: write_errors_total, conflict_skips_total
- Saturation: persistence_consumer_lag
"""
```

Implementation details:
- Follow `config-before-super` pattern from `bar_aggregator_agent.py`
- `__init__`: `Settings()`, `self._env_name`, `super().__init__(name="bar_writer_agent", metrics_port=9121)`
- Store `self._kafka_consumer: KafkaConsumerClient | None = None`
- Store `self._db_pool: asyncpg.Pool | None = None`
- Buffer: `self._buffer: list[tuple] = []`, `self._last_flush: float = 0.0`
- Constants: `_BATCH_SIZE = 50`, `_FLUSH_INTERVAL = 5.0` (per D-05, matching FCA defaults)
- INSERT SQL includes `source` column (9 columns, $1-$9):
  ```sql
  INSERT INTO market_data_ohlcv (timestamp, symbol, timeframe, open, high, low, close, volume, source)
  VALUES ($1, $2, $3, $4, $5, $6, $7, $8, $9)
  ON CONFLICT (timestamp, symbol, timeframe) DO NOTHING
  ```
- Golden Signals metrics using `prometheus_client` directly (like bar_aggregator_agent, not metrics.py helper) for label support:
  - `Counter("bar_writer_events_consumed_total", ..., ["agent"])`
  - `Counter("bar_writer_bars_written_total", ..., ["agent", "tf"])` — cache labeled children for 1m, 5m, 15m, 1h, 4h, 1d
  - `Histogram("bar_writer_persistence_batch_latency_seconds", ..., ["agent"])`
  - `Counter("bar_writer_write_errors_total", ..., ["agent"])`
  - `Counter("bar_writer_conflict_skips_total", ..., ["agent"])`
  - `Gauge("bar_writer_persistence_consumer_lag", ..., ["agent"])` — set to buffer length as proxy (Phase 52.1 pattern: no partition end-offset API)

- `topics_consumed` property: `[topic_market_bars(self._env_name), topic_market_bars_htf(self._env_name)]`
- `topics_produced` property: `[]`

- `_setup()`: create asyncpg pool via `asyncpg.create_pool(self._settings.database_url)`, create KafkaConsumerClient with both topics, group_id=`"bar_writer_consumer"`, auto_offset_reset=`"latest"`, start both.

- `_teardown()`: stop consumer, close pool.

- `_run()`: main loop — `async for _topic, _key, payload in self._kafka_consumer.messages()`. On each message:
  1. Parse bar using same `_parse_bar()` pattern as bar_aggregator_agent (BarMessage.model_validate first, flat-dict fallback)
  2. Call `_buffer_bar(bar)` — appends tuple (bar.ts, bar.symbol, bar.tf, bar.open, bar.high, bar.low, bar.close, bar.volume, source). Source: `"live_1m"` if `bar.tf == "1m"` else `"live_htf"` (per D-04).
  3. Increment events_consumed counter
  4. Check flush condition: `len(self._buffer) >= _BATCH_SIZE or (self._buffer and time.monotonic() - self._last_flush > _FLUSH_INTERVAL)`
  5. If flush: call `await self._flush_buffer()`

- `_flush_buffer()`: if buffer empty, return. Copy buffer. `async with self._db_pool.acquire() as conn: await conn.executemany(_INSERT_SQL, batch)`. On success: increment bars_written counters (per tf from batch), clear buffer, update `_last_flush`. Time the batch with `persistence_batch_latency_seconds`. On exception: log error, increment write_errors, leave buffer intact for retry.

- `__main__` block: `init_tracing("bar_writer_agent")`, `asyncio.run(BarWriterAgent().start())`
