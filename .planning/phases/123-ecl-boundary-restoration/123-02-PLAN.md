<objective>
Collect a `factor_scores` audit dict in every I7 setup plugin before its confidence composite, and thread it through to the emitted signal. This is the persisted pre-composite factor breakdown that v2.11 APR ML weight optimization regresses against `counterfactual_pnl_r`. Without it, the factor contributions die at function return and weight learning is impossible.

Purpose: Complete ECL-03 — "all 37 I7 plugins collect factor_scores dict before compositing". (TIER_I7 has 37 entries; 2 are aggregators which do not composite per-setup factors, so the 35 setup plugins are in scope. Confirm aggregator handling in Task 3.)
Output: factor_scores dict added to every setup plugin's compute_full, passed to signal construction; test assertion that factor_scores is populated.

Depends on Plan 01: make_signal_from_frame must already accept the factor_scores param (added in 123-01 Task 1). This plan only populates and passes it.
</objective>
