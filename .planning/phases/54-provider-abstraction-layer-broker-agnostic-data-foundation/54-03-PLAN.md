# Plan 54-03: BaseProviderAgent + IBKRProviderAgent

## Objective

Create the shared agent base class that handles lifecycle, metrics, reconnect, and gap-fill for any provider. `IBKRProviderAgent` is a thin subclass. The existing `DataProviderAgent` keeps running during this plan -- no cutover yet. Both can run simultaneously on different consumer groups.

Purpose: This is the moat. One BaseProviderAgent handles lifecycle/metrics/reconnect/gap-fill for every provider. Adding a new provider = one thin subclass + one systemd unit.

Output: BaseProviderAgent, IBKRProviderAgent, systemd unit file.

```python
def __init__(self):
    self._settings = Settings()
    super().__init__(name=self._agent_name(), metrics_port=self._agent_metrics_port())
    # Pre-cache labeled metric children (avoid per-bar dict lookups)
    pname = self._provider_name_str()
    aname = self._agent_name()
    self._m_bars_raw = PROVIDER_BARS_PRODUCED_TOTAL.labels(provider=pname, agent=aname)
    self._m_reconnects = PROVIDER_RECONNECTS_TOTAL.labels(provider=pname, agent=aname)
    self._g_connected = PROVIDER_CONNECTED.labels(provider=pname, agent=aname)
    self._m_gaps_filled = PROVIDER_GAPS_FILLED_TOTAL.labels(provider=pname, agent=aname)
    self._circuit_breaker = PluginCircuitBreaker(...)
```

Abstract properties/methods (use `@abc.abstractmethod`):
- `_agent_name(self) -> str`
- `_agent_metrics_port(self) -> int`
- `_provider_name_str(self) -> str`
- `_create_adapter(self) -> DataProviderAdapter`

`_setup()`: Start `KafkaProducerClient`; `self._adapter = self._create_adapter()`; `await self._adapter.connect()`; set `self._g_connected` to 1.

`_run()`: Launch `_stream_loop()` and `_gap_requests_loop()` as `asyncio.create_task()`. `await self._stop_event.wait()`. Cancel both tasks on shutdown, await with suppress(CancelledError).

`_stream_loop()`: `async for bar in self._adapter.stream_bars(instruments): self._publish_bar(bar)`. On adapter disconnect → `_reconnect()`.

`_reconnect()`: Exponential backoff base=2s, max=60s. Formula: `min(2 ** attempt, 60)`. Circuit breaker check before each attempt. Increment `_m_reconnects`. On success, reset backoff counter.

`_gap_requests_loop()`: **Extract verbatim from `DataProviderAgent._gap_requests_loop()`**. Changes:
- Replace `self.provider.fetch_historical_bars()` → `self._adapter.fetch_historical()`
- Publish filled bars to `topic_market_bars_raw(env, self._provider_name_str())` (NOT `topic_market_bars`)
- Consumer group: `f"{self._provider_name_str()}_provider_gap_consumer"` (e.g., `ibkr_provider_gap_consumer`)

`_publish_bar(bar)`: Publish to `topic_market_bars_raw(self._settings.INDICAGENT_ENV, self._provider_name_str())`; `self._m_bars_raw.inc()`; `self._g_connected.set(1)`.

`_teardown()`: Drain producer; `await self._adapter.disconnect()`; `self._g_connected.set(0)`.

```python
from src.providers.base_provider_agent import BaseProviderAgent
from src.providers.ibkr_adapter import IBKRAdapter
from src.providers.base import DataProviderAdapter

class IBKRProviderAgent(BaseProviderAgent):
    def _agent_name(self) -> str:
        return "ibkr_provider_agent"

    def _agent_metrics_port(self) -> int:
        return 9129

    def _provider_name_str(self) -> str:
        return "ibkr"

    def _create_adapter(self) -> DataProviderAdapter:
        return IBKRAdapter(
            host=self._settings.IBKR_HOST,
            port=self._settings.IBKR_PORT,
            client_id=36,  # next available after existing 35
        )
```
