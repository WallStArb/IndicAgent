## Goal

Plans 3 and 4 both reach into infrastructure this plan creates. Before any alerting YAML can fire webhooks or any dashboard can query `market_data_gaps`, the table must exist, the counters must be registered, and the dispatch methods must be callable. This plan produces exactly those prerequisites — nothing user-visible yet, all correctness-verifiable via tests and migration.

---

## Threat Model

- **Webhook credentials in env vars only.** `telegram_bot_token`, `telegram_chat_id`, `discord_webhook_url` are `str = ""` defaults — populated via `.env` / environment, never committed. Empty string = channel disabled (no-op), not a hard error.
- **Empty-string no-op prevents noisy failures.** If a token is not configured, `_dispatch_webhook()` skips that channel silently. Tests must assert this behaviour explicitly.
- **No credential exposure in logs.** `_notify_telegram()` and `_notify_discord()` must NOT log the token or webhook URL — log `"telegram.notified"` / `"discord.notified"` with severity and title only.
- **aiohttp session reuse.** The existing `_http_session` in `ServiceAuditorAgent` is reused — no new session created, preventing connection pool exhaustion.

  ```python
  async def _notify_telegram(self, title: str, body: str) -> None:
      """POST CRITICAL alert to Telegram bot. No-op if token not configured."""
      token = self._settings.telegram_bot_token
      chat_id = self._settings.telegram_chat_id
      if not token or not chat_id:
          return
      url = f"https://api.telegram.org/bot{token}/sendMessage"
      text = f"*[CRITICAL]* {title}\n{body}"
      try:
          assert self._http_session is not None
          async with self._http_session.post(
              url,
              json={"chat_id": chat_id, "text": text, "parse_mode": "Markdown"},
              timeout=aiohttp.ClientTimeout(total=10),
          ) as resp:
              if resp.status != 200:
                  self.logger.warning("telegram.notify_failed", status=resp.status, title=title)
              else:
                  self.logger.info("telegram.notified", title=title)
      except Exception as exc:
          self.logger.error("telegram.notify_error", error=str(exc))

  async def _notify_discord(self, title: str, body: str, severity: str) -> None:
      """POST HIGH/MEDIUM alert to Discord webhook. No-op if URL not configured."""
      url = self._settings.discord_webhook_url
      if not url:
          return
      content = f"**[{severity}]** {title}\n{body}"
      try:
          assert self._http_session is not None
          async with self._http_session.post(
              url,
              json={"content": content},
              timeout=aiohttp.ClientTimeout(total=10),
          ) as resp:
              if resp.status not in (200, 204):
                  self.logger.warning("discord.notify_failed", status=resp.status, title=title)
              else:
                  self.logger.info("discord.notified", severity=severity, title=title)
      except Exception as exc:
          self.logger.error("discord.notify_error", error=str(exc))

  async def _dispatch_webhook(self, severity: str, title: str, body: str) -> None:
      """Route alert to correct contact point(s) based on severity.

      CRITICAL  -> Telegram only (immediate DM)
      HIGH      -> Discord only (#indicagent-ops)
      MEDIUM    -> Discord only (#indicagent-ops)
      Other     -> no-op (log at debug)
      """
      if severity == "CRITICAL":
          await self._notify_telegram(title, body)
      elif severity in ("HIGH", "MEDIUM"):
          await self._notify_discord(title, body, severity)
      else:
          self.logger.debug("dispatch_webhook.unknown_severity", severity=severity)
  ```
