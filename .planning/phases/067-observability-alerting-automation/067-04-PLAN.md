---

## Threat Model

- **No credentials in dashboard JSON.** Datasource UIDs reference provisioned datasources (`prometheus`, `timescaledb`) — no connection strings, no passwords.
- **Datasource UID convention.** All panels must use `datasourceUid: prometheus` for Prometheus queries and `datasourceUid: timescaledb` for SQL panels. If the Grafana instance uses a different UID, the operator updates the provisioned datasource name — dashboards themselves stay portable.
- **No archived service names.** Every `expr:` field must be validated against the current `CLAUDE.md` Active Services table. Archived names would silently return empty data rather than erroring — the smoke test catches this.
