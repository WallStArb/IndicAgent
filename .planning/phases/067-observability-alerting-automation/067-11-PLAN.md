  <action>
    In `services/llm_writer_service.py`, add three observability features WITHOUT inheriting from BaseAgent:

    **1. Crash detection:**
    - Import `AGENT_CRASH_TOTAL` from `src/observability/metrics.py`
    - Wrap the main processing loop in `run()` (or equivalent) with try/except
    - On unhandled exception: `AGENT_CRASH_TOTAL.labels(agent="llm_writer_service").inc()` + log error + re-raise

    **2. Stall detection:**
    - Add `self._last_message_ts: float | None = None` attribute
    - Add `self._max_idle_seconds = 300` (5 minutes)
    - In the message processing method (where messages are consumed), record `self._last_message_ts = time.monotonic()`
    - Add a `_stall_watchdog()` async task (started alongside the main loop) that checks if `_last_message_ts` is older than `_max_idle_seconds` and logs a warning

    **3. DLQ routing:**
    - Import `DLQ_MESSAGES_TOTAL` and `DLQ_DEPTH` from `src/observability/metrics.py`
    - In the message deserialization/handling code, catch JSON parse errors or validation failures
    - For failed messages: publish to DLQ topic (use `topic_llm_writer_dlq` from stream_keys.py if it exists, otherwise use the pattern `f"{env_prefix}.llm.writer.dlq"`), increment DLQ metrics, log warning
    - Continue processing (don't crash on bad messages)
  </action>
