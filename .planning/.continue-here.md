**Key decisions made:**

1. **Zone width gate location:** `frame_trade()` not `_resolve_zone_bounds()`. Zone resolution resolves geometry; viability gates live in `frame_trade()` alongside all other rejection gates. Uses `_reject_frame()` not `no_signal()`.

2. **Zone width minimum revised from 0.5 to 1.5×ATR.** Noise-band math: for zone-based trades, total stop distance from entry = `zone_width + buffer (0.25×ATR)`. For stop to be outside intrabar noise: `zone_width + buffer >= 2.0×ATR` → `zone_width >= 1.75×ATR`. Rounded to 1.5×ATR as initial estimate pending Step 1 diagnostic. ATR-based stops from entry must be multiples (2-3×ATR) not fractions.

3. **Zone width gate IS the stop distance gate for zone trades.** No separate gate needed for zone path. `min_stop_distance_atr = 0.5` is an independent floor for the non-zone ATR-fallback path only (catches future regressions where a new code path produces fractional ATR stops from entry).

4. **Zone width problem is systemic.** Not confined to 3 fast paths in `_resolve_zone_bounds()`. CVDDivergence (structural engine, 112k signals) has 80.3% zones < $0.025. The zone_engine `MIN_ZONE_WIDTH_ATR = 0.25` exists but is unused as a post-construction gate.

5. **All trade_framer.py constants are APR violations.** `MIN_STOP_ATR_MULTIPLIER=1.0`, `ATR_STOP_DEMAND_MULTIPLIER=0.25`, etc. are hardcoded. Deferred to todo `.planning/todos/pending/2026-06-14-trade-framer-apr-migration.md` - requires Phase 127+130 ML discovery data.

**Step 1 (before writing any code):** Run the zone_width/ATR diagnostic join query:
```sql
-- Need zone_width from signal_events (or signal_ledger) joined with ATR from intelligence_features
-- Measure: distribution of zone_width / ATR across all signals
-- Goal: verify 1.5×ATR threshold empirically before hardening APR seeds
SELECT
    AVG((zone_high - zone_low) / NULLIF(i.atr, 0)) as avg_zone_width_atr,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY (zone_high - zone_low) / NULLIF(i.atr, 0)) as p50,
    PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY (zone_high - zone_low) / NULLIF(i.atr, 0)) as p25,
    COUNT(*) as n
FROM signal_events se
JOIN intelligence_features i ON i.symbol = se.symbol
    AND i.timeframe = se.timeframe
    AND i.ts = se.ts
WHERE zone_high IS NOT NULL AND zone_low IS NOT NULL AND i.atr > 0;
```
