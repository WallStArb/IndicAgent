# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: gauge-type-split — `gauge()` in `metrics.py` returns `UpDownCounter` (use `.add(delta)`). `point_gauge()` returns `create_gauge` (use `.set(value)`). Do NOT change `gauge()` — it has many `.add()` callers. Only use `point_gauge()` for new absolute-value metrics.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| gauge-factory-change | Changing `gauge()` from UpDownCounter to Gauge broke intelligence pipeline (21 `.add()` callers) | blocking | Always audit all callsites before changing a shared factory function |
| callback-injection-for-telemetry | Injecting `_on_fallback` callbacks into plugins for telemetry — plugins are module-level singletons, injection mutates shared state | blocking | `_used_incremental` flows through result dict as a key, extracted by executor. Do NOT revisit callback injection. |
| emit-signal-soft-warning | Making emit_signal() a soft wrapper without enforcement — invalid signals silently enter pipeline | advisory | validate_signal() MUST be called at construction inside emit_signal() and MUST raise ValueError on failure |
